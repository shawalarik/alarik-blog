# Alarik Blog · 个人博客与知识平台

基于 [vitepress-theme-teek](https://github.com/Kele-Bingtang/vitepress-theme-teek) 的二次开发项目，服务于我的个人博客写作与长期知识沉淀。

这个仓库不仅用于文章发布，也用于维护一套可持续扩展的技术知识体系：从前端、后端、数据库到 AI、支付、算法、面试等主题，统一在一个导航与内容模型中管理。

## 项目定位

- **个人博客**：记录日常技术实践、踩坑总结、方案复盘。
- **个人知识平台**：按领域组织可持续迭代的知识树，支持检索、归档、标签、分类。
- **主题二开实验场**：在 Teek 基础上扩展页面能力、组件能力与内容组织能力。

## 内容导航（与 `themeConfig.nav` 对齐）

当前站点采用“一级导航 + 多级分组”结构，核心一级栏目如下：

- 首页
- 前端
- 多端与扩展
- 后端开发
- 数据库
- AI 与集成
- 支付集成
- 算法
- 前沿与面试
- 站点信息
- 索引

### 一级栏目说明

- **前端**：Vue、React、Node.js（前端工程化）、TypeScript、JavaScript。
- **多端与扩展**：小程序、App、桌面端、浏览器扩展。
- **后端开发**：Java、Python、Go、Node 服务端体系。
- **数据库**：关系型与非关系型数据库实践。
- **AI 与集成**：AI 工具、前后端 AI 集成、AI Agent。
- **支付集成**：前端接入、后端处理、安全与证书体系。
- **算法**：数据结构、算法范式、刷题实战、面试题解。
- **前沿与面试**：技术趋势与求职面试专题。
- **站点信息**：博客配置、二次开发能力、版本与日志信息。
- **索引**：归档、清单、分类、标签、友链、关于我。

## 站点特性

- 基于 VitePress + Teek 主题进行深度定制。
- 内容目录与导航结构一体化维护，便于长期扩展。
- 支持分类、标签、归档等知识管理能力。
- 可持续扩展组件、运行时能力与 Markdown 工具链。

## 本地开发

### 1）克隆项目

```bash
git clone https://gitee.com/Alarikshaw/alarik-blog.git
```

### 2）安装依赖

```bash
pnpm install
```

### 3）构建引用包

```bash
pnpm stub
```

### 4）启动文档站点

```bash
pnpm docs:dev
```

## 维护原则

- 导航结构以 `docs/.vitepress/config.ts` 的 `themeConfig.nav` 为唯一事实来源。
- 新增内容优先归入现有导航体系，避免孤立页面。
- 主题改造保持“可维护、可扩展、可迁移”的工程原则。
