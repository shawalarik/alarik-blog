这一模块串联响应式状态与异步流式处理，构建从数据源到视图更新的完整链路。

## 响应式 + 异步：两个维度的交叉

```
        同步              异步
      ┌──────┐         ┌──────────┐
 响应 │ ref  │         │ AsyncRef │
 式   │computed│        │ useFetch  │
      └──────┘         └──────────┘

      ┌──────┐         ┌──────────┐
 流式 │ 数组  │         │ Observable│
 数据 │ 迭代器│         │  Stream   │
      └──────┘         └──────────┘

本模块聚焦右下角：响应式 × 异步 × 流式 = 异步数据流
```

## RxJS（Observable、操作符、调度器）

### 核心概念：Observable vs Promise

```js
// Promise —— 单次值（未来某个时刻完成）
const promise = fetch('/api/user/1');
promise.then(user => console.log(user));     // 一个值
promise.then(user => console.log(user));     // 还是同一个值

// Observable —— 零到多个值（随时间推移持续产生）
import { Observable } from 'rxjs';

const stream$ = new Observable((subscriber) => {
  subscriber.next(1);    // 第一个值
  subscriber.next(2);    // 第二个值
  setTimeout(() => subscriber.next(3), 1000); // 延迟的值
  setTimeout(() => subscriber.complete(), 2000); // 完成

  return () => console.log('清理资源');  // 取消订阅时执行
});

stream$.subscribe({
  next: (val) => console.log('收到:', val),
  error: (err) => console.error('错误:', err),
  complete: () => console.log('完成'),
});
```

### 核心差异对比

| 维度 | Promise | Observable |
|------|---------|------------|
| **值数量** | 单个（resolve/reject） | 零或多个 |
| **可取消** | ❌（无法取消已发起的请求） | ✅（unsubscribe） |
| **惰性** | 创建即执行（eager） | 有订阅才执行（lazy） |
| **可重试** | 手动重新调用 | `retry` 操作符 |
| **支持操作** | `.then()` / `.catch()` / `.finally()` | 丰富的操作符管道 |
| **时间维度** | 不关注时间 | 天然处理时间序列 |

### 常用操作符

```js
import {
  of, from, interval,
  map, filter, switchMap,
  debounceTime, throttleTime,
  takeUntil, distinctUntilChanged,
  startWith, catchError,
} from 'rxjs';
import { fromEvent } from 'rxjs/operators';

// ===== 创建类 =====
of(1, 2, 3)                    // → 1, 2, 3 (同步)
from([1, 2, 3])                 // → 1, 2, 3
from(fetch(url))                // Promise → Observable
interval(1000)                  // → 0, 1, 2... 每秒一次
fromEvent(inputEl, 'input')     // DOM 事件流

// ===== 转换 =====
map(x => x * 2)                  // [1,2,3] → [2,4,6]
switchMap(query => fetchData(query))  // 切换新请求（取消旧的）
exhaustMap(query => fetchData(query))  // 忽略新请求直到当前完成
mergeMap(query => fetchData(query))    // 并行所有请求
concatMap(query => fetchData(query))   // 顺序排队

// ===== 过滤 =====
filter(x => x > 0)               // 只保留正值
distinctUntilChanged()           // 去重连续相同值
take(5)                          // 只取前5个
takeUntil(stop$)                 // 直到 stop$ 发值就结束
first()                           // 只取第一个
debounceTime(300)                // 防抖 300ms
throttleTime(300)                // 节流 300ms

// ===== 组合 =====
startWith('initial')             // 以初始值开始
catchError(() => of(fallback))   // 错误兜底
retry(3)                         // 失败重试3次
delay(1000)                      // 延迟1000ms
tap(val => log(val))            // 副作用但不改变值
```

### 实战：搜索框自动补全

```js
import { fromEvent } from 'rxjs';
import {
  debounceTime,
  distinctUntilChanged,
  switchMap,
  map,
  catchError,
  startWith,
} from 'rxjs';

const searchInput = document.getElementById('search');
const resultsContainer = document.getElementById('results');

fromEvent(searchInput, 'input')
  .pipe(
    // 提取输入值
    .map(event => event.target.value.trim()),

    // 过滤掉太短的查询
    .filter(query => query.length >= 2),

    // 防抖：用户停止输入 300ms 后才搜索
    debounceTime(300),

    // 忽略重复查询
    distinctUntilChanged(),

    // 切换到新的搜索请求（自动取消上一个）
    switchMap(query =>
      fetch(`/api/search?q=${query}`).then(r => r.json())
    ),

    // 错误处理
    catchError(error => of({ results: [], error })),

    // 加载状态
    startWith({ results: [], loading: true }),
  )
  .subscribe(({ results, loading, error }) => {
    if (loading) resultsContainer.innerHTML = '<p>Searching...</p>';
    else if (error) resultsContainer.innerHTML = `<p>Error: ${error}</p>`;
    else renderResults(results);
  });
```

### 调度器（Scheduler）

调度器控制 Observable 在**何时、何地、以何种方式**执行：

```js
import { asyncScheduler, queueScheduler, asapScheduler, animationFrameScheduler } from 'rxjs';

// null / undefined —— 同步执行
of(1, 2, 3).subscribe(console.log);
// 立即输出 1, 2, 3（同步）

// queueScheduler —— 排队后立即执行
queueScheduler.schedule(() => {
  console.log('queued task 1');
  queueScheduler.schedule(() => {
    console.log('queued task 2 (nested)');
  });
});
console.log('after scheduling');

// asapScheduler —— 微任务队列（类似 Promise.then）
asapScheduler.schedule(() => console.log('microtask'));

// asyncScheduler —— setInterval / setTimeout
asyncScheduler.schedule(() => console.log('macro task'), 500);

// animationFrameScheduler —— requestAnimationFrame
animationFrameScheduler.schedule(() => {
  // 动画帧回调
});

// 实际应用：切换调度器
interval(1000)
  .pipe(
    observeOn(animationFrameScheduler),  // 在动画帧中发射值
  )
  .subscribe(renderAnimationFrame);

// 缓冲 + 批量更新
source$
  .pipe(bufferTime(1000, asyncScheduler))  // 每1秒批量收集
  .subscribe(batch => processBatch(batch));
```

## 与框架结合

### Vue 中的异步响应式

```vue
<script setup>
import { ref, watchEffect, toValue } from 'vue';

// ===== 方案一：手动管理异步状态 =====
const data = ref(null);
const loading = ref(false);
const error = ref(null);

async function fetchData() {
  loading.value = true;
  error.value = null;
  try {
    data.value = await fetch('/api/data').then(r => r.json());
  } catch (e) {
    error.value = e.message;
  } finally {
    loading.value = false;
  }
}

fetchData();

// ===== 方案二：封装为 composable（推荐模式） =====
function useAsyncData(fetcher) {
  const data = ref(null);
  const error = ref(null);
  const loading = ref(false);

  const execute = async (...args) => {
    loading.value = true;
    error.value = null;
    try {
      data.value = await fetcher(...args);
    } catch (e) {
      error.value = e;
    } finally {
      loading.value = false;
    }
  };

  execute();

  return { data, error, loading, execute };
}

// 使用
const { data, loading, error } = useAsyncData(async () => {
  return fetch('/api/users').then(r => r.json());
});
</script>

<template>
  <div v-if="loading">加载中...</div>
  <div v-else-if="error">出错: {{ error }}</div>
  <ul v-else-if="data">
    <li v-for="user in data" :key="user.id">{{ user.name }}</li>
  </ul>
</template>
```

### VueUse 的异步 Composables

```vue
<script setup>
import { useFetch, useAsyncState, useRefHistory } from '@vueuse/core';

// useFetch —— 封装好的 HTTP 请求
const { data, isFetching, error, abort } = useFetch('/api/todos', {
  initialData: [],
  beforeFetch(ctx) {
    ctx.options.headers.Authorization = `Bearer ${token}`;
    return ctx;  // 可以修改请求配置
  },
}).json();  // 自动 JSON 解析

// useAsyncState —— 通用异步状态
const { state, isLoading, isReady, execute } = useAsyncState(
  () => fetch('/api/settings').then(r => r.json()),
  { theme: 'dark', language: 'zh' },  // 初始值
  {
    resetOnExecute: false,  // 执行时不重置为初始值
    shallow: true,          // 浅层响应式（性能更好）
  }
);

// useRefHistory —— 自动记录历史（撤销/重做）
const count = useRefHistory(ref(0));
count.undo();
count.redo();

// useWebSocket —— WebSocket 连接
const { status, data: wsData, send, close } = useWebSocket('wss://api.example.com', {
  autoReconnect: true,
  heartbeat: { message: 'ping', interval: 30_000 },
});
</script>
```

### React 中的响应式异步数据

```tsx
// TanStack Query —— 业界标准的 React 数据获取方案
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';

function UserProfile({ userId }: { userId: number }) {
  // useQuery 自动处理：
  // - 缓存、去重、后台刷新、窗口焦点刷新
  // - loading/error/success 状态
  // - 重试、轮询、分页等
  const { data: user, isLoading, error, refetch } = useQuery({
    queryKey: ['user', userId],
    queryFn: () => api.getUser(userId),
    staleTime: 30_000,       // 30秒内视为新鲜数据
    cacheTime: 5 * 60_000,    // 缓存5分钟
    refetchOnWindowFocus: true,
  });

  if (isLoading) return <Skeleton />;
  if (error) return <ErrorDisplay error={error} />;

  return <UserCard user={user} />;
}

// useMutation 处理写操作
function UpdateProfile() {
  const queryClient = useQueryClient();

  const mutation = useMutation({
    mutationFn: api.updateUser,
    onSuccess: (updatedUser) => {
      // 成功后使相关缓存失效
      queryClient.invalidateQueries({ queryKey: ['user'] });
      // 或直接更新缓存（乐观更新）
      queryClient.setQueryData(['user', user.id], updatedUser);
    },
  });

  return (
    <form onSubmit={() => mutation.mutate(formData)}>
      {/* ... */}
      {mutation.isPending && <Spinner />}
      {mutation.isError && <p>保存失败: {mutation.error.message}</p>}
    </form>
  );
}
```

### React Hook Form 的响应式表单

```tsx
import { useForm, Controller } from 'react-hook-form';

function SignupForm() {
  const { control, handleSubmit, watch, formState } = useForm<{
    email: string;
    password: string;
    newsletter: boolean;
  }>({
    defaultValues: {
      email: '',
      password: '',
      newsletter: true,
    },
    mode: 'onBlur',  // 触发校验时机
  });

  // watch 类似于 Vue 的 computed —— 响应式追踪字段变化
  const email = watch('email');  // 订阅单个字段
  const allValues = watch();      // 订阅整个表单

  // 表单级别的派生状态
  const passwordStrength = useMemo(() => {
    return calculateStrength(allValues.password || '');
  }, [allValues.password]);

  const onSubmit = (data: FormData) => {
    console.log(data);  // 校验通过后的值
  };

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <Controller
        name="email"
        control={control}
        rules={{
          required: '邮箱必填',
          pattern: { value: /^\S+@\S+$/, message: '格式不正确' },
        }}
        render={({ field, fieldState }) => (
          <>
            <input {...field} type="email" />
            {fieldState.error && <span>{fieldState.error.message}</span>}
          </>
        )}
      />

      <Controller name="newsletter" control={control} render={({ field }) => (
        <input type="checkbox" {...field} />
      )} />

      <button type="submit" disabled={formState.isSubmitting}>
        注册
      </button>

      <p>密码强度: {passwordStrength.label}</p>
    </form>
  );
}
```

## 响应式数据流架构模式

```
┌─────────────────────────────────────────────────┐
│                   用户交互层                      │
│  点击 / 输入 / 滚动                              │
└──────────────────────┬──────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────┐
│               响应式状态层                        │
│  Signal / Store / State                          │
│  (同步响应式：ref / reactive / useState)          │
└──────────────────────┬──────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────┐
│               异步数据流层                        │
│  Observable / Stream / Query                     │
│  (RxJS / TanStack Query / SWR)                  │
│                                                  │
│  功能：                                          │
│  · 防抖/节流                                    │
│  · 请求去重                                      │
│  · 错误重试                                      │
│  · 并发控制                                      │
│  · 缓存策略                                      │
└──────────────────────┬──────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────┐
│                   数据源层                        │
│  REST API / GraphQL / WebSocket / IndexedDB      │
└─────────────────────────────────────────────────┘
```

## 小结

| 工具 | 解决的问题 | 适用场景 |
|------|-----------|---------|
| **RxJS** | 复杂异步数据流的组合与变换 | 多个异步源需要协调、实时数据（股票、聊天）、复杂事件链 |
| **TanStack Query** | 服务端状态的获取、缓存和同步 | CRUD 应用、API 数据驱动 |
| **SWR / VueUse** | 轻量级数据获取与缓存 | 中小规模应用 |
| **Vue composable** | 封装异步逻辑的可复用单元 | Vue 项目中的通用异步模式 |
| **React Hook Form** | 表单状态管理与校验 | 复杂表单场景 |

关键原则：**将同步响应式（UI 本地状态）与异步数据流（服务端状态）分层管理，各司其职**。
