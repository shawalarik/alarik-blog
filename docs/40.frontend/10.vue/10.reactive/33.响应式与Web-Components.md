这一模块探索标准 Web Components 体系中的响应式实现，并讨论与框架生态的桥接策略。

## Web Components 的响应式挑战

Web Components 作为浏览器原生标准，本身**不包含任何响应式系统**。自定义元素只是 DOM 元素的扩展，需要开发者自行管理状态到视图的同步。

```
原生 Custom Element：
┌──────────────────────┐
│ connectedCallback()  │ ← 元素插入 DOM 时调用
│ attributeChangedCallback() │ ← 属性变化时调用
│ disconnectedCallback()    │ ← 移除时调用
│                      │
│ 手动操作 innerHTML   │ ← 没有"自动更新"机制
└──────────────────────┘

对比框架中的组件：
┌──────────────────────┐
│ state → 自动更新 DOM │ ← 响应式系统自动处理
│ prop change → 重渲染  │
└──────────────────────┘
```

## Lit 的响应式属性（@property）

Lit 是 Google 开发的 Web Components 库，它为标准元素带来了类似框架的响应式体验。

### 安装

```bash
npm install lit
```

### 基础用法

```typescript
import { html, css, LitElement, customElement, property, state } from 'lit';

@customElement('my-counter')
class MyCounter extends LitElement {
  // @property —— 公共属性（可通过 HTML attribute 设置）
  @property({ type: Number })
  count = 0;

  // @property 配置选项：
  // type: 类型转换 (String | Boolean | Number | Array | Object)
  // attribute: 对应的 HTML 属性名（默认驼峰转 kebab-case）
  // reflect: 是否将值反射回 HTML 属性
  // converter: 自定义转换函数
  // hasChanged: 自定义变更检测函数

  @property({
    type: String,
    attribute: 'greeting',  // HTML 中写 greeting="Hello"
    reflect: true,           // 反射到 DOM 属性
  })
  message = 'Hello';

  // @state —— 内部私有状态（不暴露为 attribute）
  @state()
  private _doubleCount = 0;

  static styles = css`
    :host {
      display: block;
      padding: 16px;
      border: 1px solid #ccc;
    }
    .count { font-size: 24px; font-weight: bold; color: var(--primary-color, blue); }
    button { margin-left: 8px; cursor: pointer; }
  `;

  render() {
    return html`
      <p>${this.message}: <span class="count">${this.count}</span></p>
      <p>Doubled: ${this._doubleCount}</p>
      <button @click=${this._increment}>+1</button>
      <slot></slot>
    `;
  }

  private _increment() {
    this.count++;
    this._doubleCount = this.count * 2;
  }

  // willUpdate —— 类似于 beforeUpdate 生命周期
  protected willUpdate(changedProperties: Map<string, unknown>) {
    if (changedProperties.has('count')) {
      console.log(`count changed to: this.count`);
    }
  }

  // updated —— 类似于 afterUpdate
  protected updated(changedProperties: Map<string, unknown>) {
    if (changedProperties.has('count')) {
      this.dispatchEvent(new CustomEvent('count-changed', {
        detail: { value: this.count },
      }));
    }
  }
}
```

### 在 HTML 中使用

```html
<!-- 通过 attribute 设置初始值 -->
<my-counter count="5" greeting="Hi"></my-counter>

<!-- 通过 JS property 设置（响应式） -->
<script>
  const counter = document.querySelector('my-counter');
  counter.count = 100;  // 自动触发 re-render
  counter.message = 'Updated';  // 自动触发 re-render
</script>

<!-- 监听自定义事件 -->
<script>
  document.querySelector('my-counter').addEventListener('count-changed', e => {
    console.log('New count:', e.detail.value);
  });
</script>
```

### Lit 响应式的内部机制

```
@property / @state 装饰器的工作流程：

1. 装饰器生成 getter/setter
2. setter 被调用时：
   a. 将此属性标记为 "dirty"
   b. requestUpdate() —— 请求异步更新
3. microtask 队列为空后执行 update：
   a. 收集所有 dirty properties
   b. 调用 willUpdate()
   c. 调用 render() 生成新的 TemplateResult
   d. diff 新旧模板（类似于 VDOM diff）
   e. 只更新变化的 DOM 节点
   f. 调用 updated()

关键特点：
- 异步批量更新（类似 nextTick）
- 基于属性的细粒度变更检测
- 模板是声明式的，diff 效率高
```

### Reactive Controller（Lit 2.x）

对于更复杂的响应式需求，可以使用 `ReactiveController`:

```typescript
import { ReactiveController, ReactiveControllerHost } from 'lit';

// 自定义控制器 —— 封装可复用的响应式行为
class ClockController implements ReactiveController {
  private host: ReactiveControllerHost;
  value: Date = new Date();
  private timerId: number | undefined;

  constructor(host: ReactiveControllerHost) {
    this.host = host;
    host.addController(this);  // 注册控制器
  }

  hostConnected() {
    this.timerId = window.setInterval(() => {
      this.value = new Date();
      this.host.requestUpdate();  // 通知宿主更新
    }, 1000);
  }

  hostDisconnected() {
    clearInterval(this.timerId);
  }
}

@customElement('my-clock')
class MyClock extends LitElement {
  private clock = new ClockController(this);

  render() {
    return html`<time>${this.clock.value.toLocaleTimeString()}</time>`;
  }
}
```

## 在自定义元素中实现响应式

### 不使用任何库的原生实现

```typescript
class ReactiveElement extends HTMLElement {
  #state = new Map<string, any>();
  #listeners = new Set<() => void>();
  #renderQueued = false;

  setState(key: string, value: any) {
    const oldValue = this.#state.get(key);
    if (oldValue !== value) {
      this.#state.set(key, value);
      this.#notify();
    }
  }

  getState<T>(key: string): T | undefined {
    return this.#state.get(key);
  }

  subscribe(listener: () => void): () => void {
    this.#listeners.add(listener);
    return () => this.#listeners.delete(listener);
  }

  #notify() {
    if (!this.#renderQueued) {
      this.#renderQueued = true;
      queueMicrotask(() => {
        this.#renderQueued = false;
        this.update();
        this.#listeners.forEach(l => l());
      });
    }
  }

  update() {}  // 子类覆写
}
```

### 使用 @vue/reactivity 增强 Web Components

```typescript
import { reactive, effect, stop } from '@vue/reactivity';

class VuePoweredElement extends HTMLElement {
  #reactive: any;
  #cleanup: (() => void) | null = null;

  constructor() {
    super();
    this.#reactive = reactive(this.initialState());
  }

  protected initialState(): Record<string, any> {
    return {};
  }

  get state() {
    return this.#reactive;
  }

  connectedCallback() {
    this.#cleanup = effect(() => {
      this.render(this.#reactive);
    });
  }

  disconnectedCallback() {
    this.#cleanup?.();
    this.#cleanup = null;
  }

  protected render(state: any) {}
}
```

## 与框架响应式系统的桥接

### 从框架中使用 Web Components

```vue
<!-- Vue 中直接使用 Lit 组件 -->
<template>
  <my-counter :count="count" @count-changed="handleCountChange" />
</template>

<script setup lang="ts">
const count = ref(0);
function handleCountChange(e: CustomEvent) {
  count.value = e.detail.value;
}
</script>
```

```tsx
// React 中使用 Lit 组件
import { createComponent } from '@lit-labs/react';
import { MyCounter } from './MyCounter';

const Counter = createComponent(MyCounter, {
  react: React,
});

function App() {
  const [count, setCount] = useState(0);
  return (
    <Counter
      count={count}
      onCountChanged={(e) => setCount(e.detail.value)}
    />
  );
}
```

### 从 Web Components 中消费外部 Store

```typescript
import { useGlobalStore } from '../shared-store';

customElements.define('connected-widget', class extends HTMLElement {
  #store = useGlobalStore();
  #unsubscribe: (() => void) | null = null;

  connectedCallback() {
    this.#unsubscribe = this.#store.subscribe(() => this.render());
    this.render();
  }

  disconnectedCallback() {
    this.#unsubscribe?.();
  }

  private render() {
    const { state } = this.#store;
    this.innerHTML = `<div>Theme: ${state.theme}</div>`;
  }
});
```

## 小结

| 方案 | 复杂度 | 响应式能力 | 框架集成 |
|------|--------|-----------|---------|
| **原生 Custom Elements** | 高 | 需自行实现 | 手动桥接 |
| **Lit @property** | 低 | 属性级细粒度 | lit-labs 适配器 |
| **Lit ReactiveController** | 中 | 可扩展控制器模式 | 同上 |
| **@vue/reactivity + WC** | 中 | 完整 Vue 响应式能力 | 需封装 |
| **Nanostore + WC** | 低-中 | Signal Store | 良好适配器支持 |

Web Components 的响应式不是"有没有"的问题，而是选择什么层次的抽象。Lit 提供了开箱即用的优秀方案；需要在 WC 和框架间共享复杂状态时，独立的响应式库是最实用的选择。
