Vue 2.0 是一次彻底的重写，引入了虚拟 DOM 和全新的渲染管线，标志着 Vue 从"轻量级库"向"成熟框架"的关键跨越。

## 为什么需要 Vue 2.0？

### Vue 1.x 的根本问题

经过一年多的社区实践，Vue 1.x 暴露出三个无法通过修补解决的根本性缺陷：

#### 问题 1：细粒度响应式的规模瓶颈

```
Vue 1.x 方式（无虚拟 DOM）：
┌──────────────┐
│  <div>       │ ← watcher #1
│    {{name}}  │ ← watcher #2 (text node)
│    <span>    │
│      {{age}} │ ← watcher #3 (text node)
│    </span>   │
│  </div>      │

1000 个列表项 × 3 个 binding = 3000 个 watcher
每次数据变更 → 遍历 3000 个 watcher → 性能瓶颈
```

#### 问题 2：渲染函数能力不足

Vue 1.x 的模板编译产物是**命令式 DOM 操作指令序列**，缺乏抽象能力：

```javascript
// Vue 1.x 编译产物示例（伪代码）
function render() {
  var frag = document.createDocumentFragment()
  var el = document.createElement('div')
  // ... 大量命令式 DOM 操作
  return frag
}
```

这意味着：
- 无法进行服务端渲染（SSR）
- 无法生成跨平台输出（Native、Canvas 等）
- 难以实现高级编译优化

#### 问题 3：组件通信机制不够灵活

`$dispatch` / `$broadcast` 的隐式事件链难以调试和维护。

### 解决方案：Virtual DOM

Evan 在 2015 年底决定采用**虚拟 DOM** 作为 Vue 2.0 的核心技术：

```
                    Vue 2.0 渲染管线

Template ──→ Compile ──→ Render Function (虚拟 DOM 创建)
                              │
                              ↓
                         Virtual DOM Tree
                              │
                              ↓
                         Patch Algorithm (Diff)
                              │
                              ↓
                        Real DOM Updates (批量)
```

## 核心架构变革

### 1. 虚拟 DOM 实现

Vue 2.0 的虚拟 DOM 实现参考了 Snabbdom（后来也影响了 Vue 3）：

```javascript
// 虚拟节点结构 (VNode)
{
  tag: 'div',              // 标签名
  data: {                  // 属性、样式、事件
    attrs: { id: 'app' },
    on: { click: handler }
  },
  children: [              // 子节点数组
    { tag: undefined, text: 'Hello' }  // 文本节点
  },
  context: {...},          // 上下文信息
  key: null                // diff 时的唯一标识
}
```

**渲染流程**：

```javascript
// 1. 编译阶段（build-time 或 runtime）
const renderFn = compileToFunctions(`
  <div id="app">
    <p>{{ message }}</p>
  </div>
`)

// 2. 生成虚拟 DOM（render 函数）
const vnode = renderFn.call(vm)
// 返回 VNode tree

// 3. Patch 到真实 DOM
patch(oldVnode || emptyNode, vnode)
```

### 2. 响应式系统重构

虽然仍使用 `Object.defineProperty`，但做了重大改进：

```javascript
// Vue 2.0 响应式核心（简化）
function defineReactive(obj, key, val) {
  const dep = new Dep()  // 收集器
  
  Object.defineProperty(obj, key, {
    get() {
      if (Dep.target) {
        dep.depend()  // 收集当前 watcher 为依赖
      }
      return val
    },
    set(newVal) {
      if (val === newVal) return
      val = newVal
      dep.notify()  // 通知所有 watcher 重新求值
    }
  })
}
```

**关键改进**：

- **组件级粒度**：不再追踪每个文本节点，而是以**组件**为单位触发重新渲染
- **队列批处理**：同一事件循环内的多次数据变更合并为一次渲染
- **深度观测**：递归遍历对象属性建立响应式连接

### 3. 渲染函数与 JSX

Vue 2.0 引入了**渲染函数**作为模板的替代方案：

```javascript
// 使用 h 函数（createElement 的别名）
Vue.component('anchored-heading', {
  functional: true,
  render: function(h, context) {
    var level = context.props.level
    return h(
      'h' + level,
      context.data,
      context.children
    )
  },
  props: {
    level: {
      type: Number,
      required: true
    }
  }
})
```

同时支持 JSX 语法糖：

```jsx
render(h) {
  return (
    <div class="container">
      {this.items.map(item => (
        <ItemComponent
          key={item.id}
          title={item.title}
          onClick={() => this.handleClick(item)}
        />
      ))}
    </div>
  )
}
```

### 4. 服务端渲染（SSR）

虚拟 DOM 使得 SSR 成为可能：

```
Browser                          Server
  │                               │
  │  请求页面                      │
  │ ────────────────────────────→  │
  │                               │  1. 执行 renderToString()
  │                               │  2. 生成 HTML 字符串
  │                               │  3. 发送 HTML
  │  ←──────────────────────────── │
  │                               │
  │  4. 显示 HTML（首屏快速）       │
  │  5. hydrate() 激活交互          │
  │                               │
```

### 5. 单文件组件（SFC）标准化

`.vue` 文件成为 Vue 2.0 的标志性特征：

```vue
<template>
  <div class="hello">
    <h1>{{ msg }}</h1>
  </div>
</template>

<script>
export default {
  name: 'HelloWorld',
  props: {
    msg: String
  }
}
</script>

<style scoped>
.hello h1 {
  color: #42b983;
}
</style>
```

需要 **webpack** + **vue-loader** 配合编译。

## 破坏性变更清单（部分）

以下是从 Vue 1.x 迁移到 2.0 时需要注意的主要破坏性变更：

| 变更类别 | 1.x 写法 | 2.x 写法 |
|----------|----------|----------|
| 生命周期 | `ready()` | `mounted()` |
| 生命周期 | `beforeCompile()` | `created()` |
| 生命周期 | `compiled()` | （移除） |
| 组件注册 | `Vue.extend({...})` | `Vue.component('name', {...})` |
| 父子通信 | `this.$dispatch(...)` | `this.$emit(...)` |
| 子父通信 | `this.$broadcast(...)` | props + `$emit` |
| 过滤器 | `{{ msg \| capitalize }}` | 方法或计算属性 |
| `v-for` | `$index`、`$key` 内置变量 | `v-for="(item, index) in items"` |
| `v-bind` | `v-bind="{...}"` 合并行为改变 | 明确覆盖 |

## 性能提升数据

根据官方基准测试（[vue-benchmarks](https://github.com/kazupon/vue-benchmark)）：

| 操作 | Vue 1.x | Vue 2.0 | 提升 |
|------|---------|---------|------|
| 创建 1000 行 | ~45ms | ~18ms | **2.5x** |
| 更新 1000 行（首屏） | ~120ms | ~35ms | **3.4x** |
| 交换位置（部分更新） | ~85ms | ~12ms | **7x** |
| 内存占用（1000行） | ~2.8MB | ~1.4MB | **2x** |

## 小结

Vue 2.0 是 Vue 发展史上最重要的里程碑：

1. **虚拟 DOM** 使渲染策略现代化
2. **渲染函数** 打开了 SSR / 跨平台的大门
3. **组件化** 更加成熟规范
4. **生态** 开始爆发式增长

Vue 2.0 于 **2016 年 9 月 30 日**正式发布，至今（2024 年）仍是生产环境中使用最多的 Vue 版本之一，其设计理念深深影响了 Vue 3.0 及后续发展。
