系统梳理两代 Vue 在核心机制上的关键差异。理解这些差异是从 Vue 2 平滑迁移到 Vue 3 的前提。

## 总览对比

```
┌──────────────────────┐    ┌──────────────────────┐
│       Vue 2.x        │ →  │       Vue 3.x        │
│                      │    │                      │
│  Object.defineProperty│    │  Proxy (ES6)          │
│  Options API         │    │  Options + Composition │
│  TypeScript (.d.ts)  │    │  TypeScript (原生)     │
│  完整包打包           │    │  Tree-shaking         │
│  this.* 访问         │    │  setup() / ref.value   │
│  $on/$off/$once      │    │  mitt / tinyemitter    │
│  过滤器              │    │  方法/计算属性替代      │
│  inline-template     │    │  已移除                │
│  eventBus 模式       │    │  provide/inject/mitt   │
└──────────────────────┘    └──────────────────────┘
```

## 一、响应式系统

### 核心原理变化

```javascript
// ════════════════════════════════
// Vue 2 — Object.defineProperty
// ════════════════════════════════
const vm = new Vue({
  data: {
    user: { name: 'Alice' },
    list: []
  }
})

vm.user.name = 'Bob'        // ✅ 响应式
vm.user.age = 25            // ❌ 非响应式（需 Vue.set）
vm.list[0] = 'new'         // ❌ 非响应式
delete vm.user.name         // ❌ 非响应式（需 Vue.delete）

// ════════════════════════════════
// Vue 3 — Proxy
// ════════════════════════════════
import { reactive } from 'vue'

const state = reactive({
  user: { name: 'Alice' },
  list: [],
  map: new Map()
})

state.user.age = 25            // ✅ 响应式！
state.list[0] = 'new'         // ✅ 响应式！
delete state.user.name        // ✅ 响应式！
state.map.set('k', 'v')       // ✅ Map 支持！
```

### API 映射表

| Vue 2 | Vue 3 | 说明 |
|-------|-------|------|
| `Vue.set(obj, key, val)` | `obj.key = val` 或 `reactive()` 内直接赋值 | Proxy 自动处理 |
| `Vue.delete(obj, key)` | `delete obj.key` | 直接 delete 即可 |
| `this.$set(...)` | 不需要 | 已废弃 |
| `this.$watch(...)` | `watch()` | Composition API 版本 |
| `new Vue({ data })` | `reactive()` 或 `ref()` | 推荐使用组合式 |

### ref vs reactive 的选择策略

```javascript
import { ref, reactive } from 'vue'

// ✅ 推荐 ref 用于基本类型
const count = ref(0)
const message = ref('hello')
count.value++

// ✅ 推荐 reactive 用于对象/数组
const form = reactive({
  username: '',
  password: '',
  rememberMe: false
})

// ✅ 解构时用 toRefs 保持响应性
const { username, password } = toRefs(form)

// ⚠️ 不推荐：reactive 后再解构（丢失响应性）
const { username: u } = form  // u 不是响应式的！

// ⚠️ 不推荐：ref 包裹对象（多余嵌套）
const user = ref({ name: '' })  // 需要 user.value.name
```

## 二、Composition API vs Options API

### 代码组织方式对比

```javascript
// ══════════════════════════════════════
// Vue 2 Options API — 横切关注点分散
// ══════════════════════════════════════
export default {
  data() {
    return {
      searchQuery: '',
      searchResults: [],
      isLoading: false,
      page: 1,
      pageSize: 10,
      totalCount: 0
    }
  },
  
  computed: {
    hasMorePages() { return this.page < this.totalPages },
    totalPages() { return Math.ceil(this.totalCount / this.pageSize) },
    filteredResults() { /* ... */ }
  },
  
  watch: {
    searchQuery(val) { this.debouncedSearch(val) },
    page(val) { this.fetchPage(val) }
  },
  
  created() { this.fetchPage(1) },
  
  methods: {
    async fetchPage(page) { /* ... */ },
    debouncedSearch: _.debounce(function(q) { /* ... */ }, 300),
    nextPage() { if(this.hasMorePages) this.page++ },
    prevPage() { if(this.page > 1) this.page-- }
  }
}

// ══════════════════════════════════════
// Vue 3 Composition API — 关注点内聚
// ══════════════════════════════════════
export default {
  setup() {
    // ===== 搜索逻辑（内聚） =====
    const searchQuery = ref('')
    const searchResults = ref([])
    
    const { debouncedSearch } = useSearch(searchQuery)
    
    // ===== 分页逻辑（内聚） =====
    const page = ref(1)
    const pageSize = ref(10)
    const totalCount = ref(0)
    const { fetchPage, nextPage, prevPage, totalPages, hasMorePages } 
      = usePagination(fetchDataFn, { page, pageSize })
    
    // ===== 初始化 =====
    onMounted(() => fetchPage())
    
    return {
      searchQuery, searchResults, debouncedSearch,
      page, pageSize, totalCount, 
      nextPage, prevPage, totalPages, hasMorePages
    }
  }
}

// 可复用的组合式函数
function useSearch(query) {
  function doSearch() { /* ... */ }
  const debouncedSearch = useDebounceFn(doSearch, 300)
  return { debouncedSearch }
}
```

### 生命周期钩子映射

| Vue 2 (Options) | Vue 3 (Options) | Vue 3 (Composition) |
|------------------|------------------|---------------------|
| `beforeCreate` | `beforeCreate` | **不需要**（setup 在此之前运行） |
| `created` | `created` | **不需要**（同上） |
| `beforeMount` | `beforeMount` | `onBeforeMount` |
| `mounted` | `mounted` | `onMounted` |
| `beforeUpdate` | `beforeUpdate` | `onBeforeUpdate` |
| `updated` | `updated` | `onUpdated` |
| `beforeDestroy` | ~~`beforeDestroy`~~ | `onBeforeUnmount` |
| `destroyed` | ~~`destroyed`~~ | `onUnmounted` |
| `errorCaptured` | `errorCaptured` | `onErrorCaptured` |
| — | — | `onRenderTracked` (调试) |
| — | — | `onRenderTriggered` (调试) |
| — | `activated` (KeepAlive) | `onActivated` |
| — | `deactivated` (KeepAlive) | `onDeactivated` |
| — | `serverPrefetch` (SSR) | `onServerPrefetch` |

> **注意**：`destroyed` 在 Vue 3 中被重命名为 `unmounted`（语义更准确）。

## 三、全局 API 变化

### Vue 2 全局注册 → Vue 3 应用实例

```javascript
// ═════════════════════════════════
// Vue 2 — 全局污染
// ═════════════════════════════════
import Vue from 'vue'
import Router from 'vue-router'
import Vuex from 'vuex'
import MyComponent from './MyComponent.vue'

Vue.use(Router)
Vue.use(Vuex)
Vue.component('MyComponent', MyComponent)
Vue.directive('focus', { inserted(el) { el.focus() } })
Vue.prototype.$http = axios  // 全局属性污染

new Vue({
  router,
  store,
  render: h => h(App)
}).$mount('#app')

// 问题：所有配置都是全局的，测试时无法隔离

// ═════════════════════════════════
// Vue 3 — 应用实例（可配置、可测试）
// ═════════════════════════════════
import { createApp } from 'vue'
import router from './router'
import store from './store'
import App from './App.vue'

const app = createApp(App)

// 所有配置都在应用实例上
app.use(router)
app.use(store)
app.component('MyComponent', MyComponent)
app.directive('focus', { mounted(el) { el.focus() } })

// 全局属性通过 config.globalProperties
app.config.globalProperties.$http = axios

app.mount('#app')

// 好处：可以创建多个独立的应用实例
const app2 = createApp(App2).mount('#app2')
```

### 移除的 API

| Vue 2 API | Vue 3 处理 | 替代方案 |
|-----------|------------|----------|
| `Vue.on()` / `Vue.off()` / `Vue.once()` | **已移除** | 使用 `mitt` 等事件库 |
| `Vue.filter()` | **已移除** | 使用方法调用或计算属性 |
| `Vue.component()` (全局) | `app.component()` | 改为应用级注册 |
| `Vue.directive()` (全局) | `app.directive()` | 改为应用级注册 |
| `new Vue()` | `createApp()` | 新 API |
| `Vue.extend()` | **已移除** | 直接定义组件或 `defineComponent` |
| `Vue.config.productionTip` | **已移除** | 不再需要 |
| `Vue.config.keyCodes` | **已移除** | 使用 `kebab-case` 名称 |
| `inline-template` 属性 | **已移除** | 使用 SFC 或渲染函数 |
| `$children` / `$listeners` | **已移除** | `$attrs` 合并了 listeners |
| `.sync` 修饰符 (自定义) | **语法变更** | `v-model:propName` |
| `$scopedSlots` | **已移除** | 统一为 `$slots` |

## 四、虚拟 DOM 和编译优化

### Diff 算法改进

```
Vue 2 Diff:
  同层比较 → 双端比较 (头-头 / 尾-尾 / 头-尾 / 尾-头)
  最坏情况 O(n²)，最长递增子序列优化到 O(n log n)

Vue 3 Diff:
  同层比较 → 最长递增子序列 (LIS) 算法
  纯粹 O(n log n)，移动操作更少
```

### PatchFlag 编译优化

```html
<!-- 输入 -->
<div :id="id" :class="cls">{{ msg }}</div>

<!-- Vue 2 编译产物 -->
function render() {
  with(this){
    return _c('div',
      { attrs: { "id": id }, class: cls },
      [_v(_s(msg))]
    )
  }
}
/* 每次更新都要检查 id、class、text */

<!-- Vue 3 编译产物 -->
const _hoisted_1 = { key: "" }

function render(_ctx, _cache) {
  return (_openBlock(), _createBlock("div", _hoisted_1, [
    _createTextVNode(_toDisplayString(_ctx.msg), 1 /* TEXT */)
  ], 12 /* CLASS | PROPS */))
}
/* 只标记变化的类型，跳过其他检查 */
```

## 五、新增功能一览

### Fragment（多根节点）

```vue
<!-- Vue 2: 必须包裹在单一根元素中 -->
<template>
  <div class="wrapper">  <!-- 无意义的包裹元素 -->
    <header>...</header>
    <main>...</main>
    <footer>...</footer>
  </div>
</template>

<!-- Vue 3: 支持多根节点 -->
<template>
  <header>...</header>
  <main>...</main>
  <footer>...</footer>
</template>
```

### Teleport（传送门）

```vue
<Teleport to="body">
  <ModalDialog v-if="showModal" @close="showModal = false" />
</Teleport>

<!-- 渲染到 body 下，不受父级 CSS 影响 -->
```

### Suspense（异步组件）

```vue
<Suspense>
  <template #default>
    <AsyncComponent />
  </template>
  <template #fallback>
    <LoadingSpinner />
  </template>
</Suspense>
```

### `<style scoped>` 增强

```vue
<!-- Vue 3 支持深度选择器的新语法 -->
<style scoped>
/* Vue 2 方式（仍在支持） */
.parent :deep(.child) { color: red; }

/* Vue 3 新增 */
.parent ::v-deep(.child) { color: red; }
.parent :deep(.child) { color: red; }     /* 推荐 */

/* 全局样式 */
:global(.global-class) { font-size: 16px; }

/* 模块化 CSS */
<style module>
.red { color: red; }  /* 自动生成 hash 类名 */
</style>
```

## 六、破坏性变更速查清单

以下是最常见的破坏性变更：

```javascript
// ❌ Vue 2 写法 → Vue 3 会报错

// 1. data 必须是函数（Vue 2 组件中已经是要求）
Vue.component('comp', {
  data: { count: 0 }  // ❌ 对象形式
})
// → 改为: data() { return { count: 0 } }

// 2. $on / $off / $once 移除
eventBus.$on('foo', handler)  // ❌
// → 使用 mitt 库或 provide/inject

// 3. 过滤器移除
{{ msg | capitalize }}  // ❌
// → {{ capitalize(msg) }}

// 4. $listeners 合并到 $attrs
this.$listeners.click  // ❌
// → this.$attrs.onClick

// 5. .sync 修饰符
<Comp :title.sync="pageTitle" />  // ❌
// → <Comp v-model:title="pageTitle" />

// 6. v-model 默认行为
<input v-model="search" />
// Vue 2: :value + input 事件
// Vue 3: :modelValue + update:modelValue 事件
```

## 性能基准对比

基于 [js-framework-benchmark](https://krausest.github.io/js-framework-benchmark/) 最新数据：

| 操作 | Vue 2 | Vue 3 | 差异 |
|------|-------|-------|------|
| 创建 1000 行 | ~45ms | ~18ms | **2.5x 更快** |
| 部分更新 100 行 | ~8ms | ~3ms | **2.7x 更快** |
| 交换行位置 | ~15ms | ~4ms | **3.7x 更快** |
| 清空 1000 行 | ~20ms | ~6ms | **3.3x 更快** |
| 内存占用 | ~1.4MB | ~0.9MB | **35% 更少** |
| 启动时间 (SSR) | 基准 | 快 2~3x | 显著提升 |
