## 一、Vue Router 4.x（Vue 2 对应版本）

### 版本演变

```
Vue Router 0.7.x  →  Vue 1.x 时期（hash 模式基础）
       ↓
Vue Router 2.x   →  Vue 2.0 配套（重写）
       ↓
Vue Router 3.x   →  成熟期（Navigation Guards 完善）
       ↓
Vue Router 4.x   →  Vue 3 配套（Composition API）
```

### 核心概念

```javascript
// router/index.js
import Vue from 'vue'
import VueRouter from 'vue-router'
import Home from '@/views/Home.vue'
import About from '@/views/About.vue'

Vue.use(VueRouter)

export default new VueRouter({
  mode: 'history',        // history 模式（需服务器配置）
  routes: [
    {
      path: '/',
      name: 'home',
      component: Home
    },
    {
      path: '/about/:id?',
      name: 'about',
      component: About,
      // 路由级守卫
      beforeEnter: (to, from, next) => {
        // 权限验证等逻辑
        next()
      }
    },
    {
      path: '/user/:userId',
      name: 'user-profile',
      component: () => import('@/views/UserProfile.vue'),
      // 懒加载（Webpack code splitting）
      meta: { requiresAuth: true }
    }
  ]
})
```

**导航守卫体系**（Navigation Guards）：

```
全局守卫:
  beforeEach → beforeResolve → afterEach

路由独享守卫:
  beforeEnter (在路由配置中)

组件内守卫:
  beforeRouteEnter → beforeRouteUpdate → beforeRouteLeave
```

### Hash vs History 模式对比

| 特性 | Hash Mode (`#`) | History Mode |
|------|-----------------|--------------|
| URL 格式 | `example.com/#/path` | `example.com/path` |
| SEO | 不友好（搜索引擎忽略 hash） | 友好（真实路径） |
| 服务器要求 | 无需配置 | **必须配置 fallback** |
| 兼容性 | 所有浏览器 | 需要 HTML5 History API |
| 刷新 404 | 不会发生 | **会**（需 nginx 配置 try_files） |

## 二、Vuex 3.x — 状态管理的标准答案

### 设计理念

Vuex 受 Elm 语言和 Redux 的启发，采用了**集中式状态管理**模式：

```
┌──────────┐     dispatch      ┌──────────┐
│  Vue     │ ───────────────→  │ Actions  │
│ Component│                   │ (async)  │
└────┬─────┘                   └────┬─────┘
     ↑ mutate                       │ commit
     │                              ↓
     │ mutation                ┌──────────┐
     │                        │ Mutations│
     │                        │(sync)    │
     │                        └────┬─────┘
     │                             │
     │                     state change
     │                             ↓
     │                        ┌──────────┐
     ├←←←←←←←←←←←←←←←←←←←←←←←│ Getters  │
     │  (reactive re-render)    │          │
     │                          └──────────┘
     │
  └──→ View update
```

### 核心代码结构

```javascript
// store/index.js
import Vue from 'vue'
import Vuex from 'vuex'

Vue.use(Vuex)

export default new Vuex.Store({
  // 1. State（单一数据源）
  state: {
    user: null,
    todos: [],
    loading: false
  },

  // 2. Getters（计算属性）
  getters: {
    completedTodos: state => {
      return state.todos.filter(todo => todo.completed)
    },
    todoCount: (state, getters) => {
      return getters.completedTodos.length
    }
  },

  // 3. Mutations（同步状态变更）
  mutations: {
    SET_USER(state, user) {
      state.user = user
    },
    ADD_TODO(state, todo) {
      state.todos.push(todo)
    },
    TOGGLE_LOADING(state, status) {
      state.loading = status
    }
  },

  // 4. Actions（异步操作）
  actions: {
    async fetchUser({ commit }) {
      commit('TOGGLE_LOADING', true)
      try {
        const res = await api.getUser()
        commit('SET_USER', res.data)
      } finally {
        commit('TOGGLE_LOADING', false)
      }
    },

    addTodo({ commit }, todo) {
      return new Promise(resolve => {
        setTimeout(() => {
          commit('ADD_TODO', todo)
          resolve()
        }, 500)
      })
    }
  },

  // 5. Modules（模块化）
  modules: {
    cart: {
      namespaced: true,
      state: () => ({ items: [] }),
      mutations: { /* ... */ },
      actions: { /* ... */ }
    }
  }
})
```

### 在组件中使用

```javascript
// Options API 用法
export default {
  computed: {
    // 使用 mapState 辅助函数
    ...mapState(['user', 'loading']),
    ...mapGetters(['completedTodos']),
    
    // 本地 computed
    displayName() {
      return this.user ? this.user.name : 'Guest'
    }
  },
  
  methods: {
    // 使用 mapActions 辅助函数
    ...mapActions(['fetchUser', 'addTodo']),
    
    handleClick() {
      this.addTodo({ text: 'New task', completed: false })
    }
  }
}
```

## 三、Vue CLI 3/4 — 官方脚手架

### 特性一览

```bash
# 安装
npm install -g @vue/cli

# 创建项目（交互式）
vue create my-project

# 图形化管理界面
vue ui
```

**核心能力**：

| 能力 | 说明 |
|------|------|
| 项目脚手架 | 预设配置（Babel、TypeScript、PWA、Router、Vuex、ESLint...） |
| 插件系统 | 可扩展的 CLI 插件生态 |
| 开发服务器 | 热模块替换（HMR）、自动打开浏览器 |
| 生产构建 | 代码分割、Tree-shaking、压缩优化 |
| 图形界面 | `vue ui` 提供可视化管理 |

**配置文件** (`vue.config.js`)：

```javascript
module.exports = {
  publicPath: process.env.NODE_ENV === 'production'
    ? '/my-app/'
    : '/',

  devServer: {
    port: 8080,
    proxy: {
      '/api': {
        target: 'http://backend.example.com',
        changeOrigin: true
      }
    }
  },

  chainWebpack: config => {
    // 自定义 webpack 配置
    config.resolve.alias.set('@', path.join(__dirname, 'src'))
  }
}
```

## 五、Nuxt.js — 全栈框架

Nuxt.js 将 Vue 2.x 的能力延伸到了**服务端**：

```
Nuxt.js 目录结构:
├── pages/          → 自动路由（文件系统即路由）
├── layouts/        → 布局组件
├── components/     → 共享组件
├── assets/         → 未编译资源（SASS/Less）
├── static/         → 静态文件
├── store/          → Vuex Store（自动模块化）
├── nuxt.config.js  → Nuxt 配置
└── plugins/        → Vue 插件
```

**三种渲染模式**：

| 模式 | 适用场景 | SEO | 加载速度 |
|------|----------|-----|----------|
| Universal (SSR) | 内容型网站 | ✅ 优秀 | 快 |
| Static Generated | 静态站点/博客 | ✅ 优秀 | 最快 |
| Single Page App (SPA) | 后台管理系统 | ❌ 弱 | 中等 |
