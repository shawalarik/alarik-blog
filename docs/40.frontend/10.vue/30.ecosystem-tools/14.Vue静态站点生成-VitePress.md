- 主题定制：布局扩展、样式覆盖、首页个性化
- Markdown 扩展：自定义容器、代码高亮、Mermaid 图表
- Vue 组件嵌入：<script setup> 在 MD 中的使用
- 插件系统：Markdown-it 插件与 VitePress 扩展
- 构建与部署：CI/CD 流程、CDN 加速、SEO 优化
- 多语言（i18n）站点搭建
