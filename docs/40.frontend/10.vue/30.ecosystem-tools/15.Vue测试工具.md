这一模块建立 Vue 应用的完整测试体系，覆盖单元测试到 E2E 测试。

- Vue Test Utils 核心API：mount / shallowMount / flushPromises
- Vitest / Jest 集成配置与环境搭建
- 组件挂载与交互模拟：用户事件触发与断言
- Mock 依赖：axios mock、Vuex/Pinia mock、Vue Router mock
- 快照测试（Snapshot Testing）与更新策略
- Testing Library 风格的 Vue 测试最佳实践
- Coverage 配置与 CI 集成
