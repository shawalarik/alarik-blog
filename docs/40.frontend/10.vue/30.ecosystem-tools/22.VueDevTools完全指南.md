Vue DevTools 是 Vue 开发不可或缺的调试利器。本文全面介绍其各项功能的使用方法与最佳实践。

## 安装与连接

### 浏览器扩展安装

```
支持的浏览器:
├── Chrome / Edge (Chromium 内核)  → Chrome Web Store
├── Firefox                         → Firefox Add-ons
├── Safari                           → Safari Extensions Gallery
└── Electron 应用                    --remote-debugging-port
```

**安装地址**：

| 浏览器 | 安装链接 |
|--------|----------|
| Chrome / Edge | [Chrome Web Store](https://chrome.google.com/webstore/detail/vuejs-devtools/nhdogjmeigligcpckopcgbinccpmenpdmjic) |
| Firefox | [Add-ons](https://addons.mozilla.org/en-US/firefox/addon/vue-js-devtools/) |

### 连接到应用

```bash
# 方式 1: 浏览器自动检测（默认）
# 打开使用 Vue 的页面，DevTools 图标会亮起

# 方式 2: 手动连接（远程调试场景）
# 应用启动时暴露端口
npx vite --port 3000

# DevTools 中点击 "Connect to app"
# 输入 http://localhost:3000

# 方式 3: 独立应用模式（Electron）
# 安装 @vue/devtools standalone
npx @vue/devtools
```

### 实时编辑 State 和 Props

```
选中一个组件后:

Props 标签:
  count: Number = 3           ← 显示 prop 名称、类型、当前值
  user: Object                 ← 可点击展开对象
    ├─ name: String = "Alice"
    └─ role: String = "admin"
  ✓ 可直接编辑值！实时反映到页面上


Data (setup ref) 标签:
  items: Array(5)[...]         ← reactive 数据
  isLoading: Boolean = false
  filterText: String = ""      ← 双击即可编辑


Computed 标签:
  filteredItems: Array(3)       ← 计算属性的当前值
  itemCount: Number = 5         ← 依赖追踪显示
```

### 高级功能

```
组件操作按钮:

🔍 Filter components...    ← 按名称过滤组件树
⚡ Format component       ← 格式化组件数据（美化显示）
📋 Copy component path     ← 复制组件文件路径（跳转到 IDE）
🔄 Refresh                 ← 强制刷新组件数据

右键菜单:
  Scroll into view          ← 滚动到该组件在页面中的位置
  Inspect DOM               ← 切换到 Elements 面板查看 DOM
  Copy reference            ← 复制组件引用表达式
```

### 使用技巧

```javascript
// 1. 在代码中添加性能标记
const start = performance.now()

// ... 要分析的代码块 ...

const end = performance.now()
console.log(`Operation took ${end - start}ms`)


// 2. Vue DevTools 会自动捕获:
//    - Component render 时间
//    - Patch 操作耗时
//    - 重新渲染的原因（哪些响应式数据触发了更新）
```

## 自定义 DevTools 插件

### 扩展 DevTools 面板

```typescript
// plugins/devtools-custom-panel.ts
import type { App } from 'vue'

export function registerCustomPanel(app: App) {
  const devtools = (window as any).__VUE_DEVTOOLS_GLOBAL_HOOK__
  
  if (!devtools) {
    console.warn('Vue DevTools not detected')
    return
  }
  
  // 注册自定义 Tab
  devtools.on.app.init((appAPI) => {
    appAPI.addSettingsTab({
      label: 'My Custom Panel',
      icon: '📊',
      title: 'Custom Debug Panel',
      component: CustomPanelComponent
    })
    
    // 添加自定义 Layer
    appAPI.addLayer({
      id: 'custom:my-layer',
      label: 'My Data Layer',
      color: 0x42b983,  // 绿色
      programmatic: true,
      layers: getCustomLayers(app)
    })
  })
}

// 自定义面板组件
const CustomPanelComponent = {
  template: `
    <div class="custom-panel">
      <h3>Custom Data Viewer</h3>
      <pre>{{ JSON.stringify(data, null, 2) }}</pre>
    </div>
  `,
  data() {
    return { data: {} }
  },
  mounted() {
    // 定期获取数据
    setInterval(() => {
      this.data = {
        timestamp: new Date().toISOString(),
        route: window.location.pathname
        // ... 自定义数据
      }
    }, 1000)
  }
}
```

## 独立应用模式

当无法安装浏览器扩展时（如移动端 WebView、Electron 应用），可使用独立版 DevTools：

```bash
# 安装
npm install -g @vue/devtools

# 连接到正在运行的 Vite 开发服务器
npx @vue-devtools
# 然后在浏览器控制台执行：
window.__VUE_DEVTOOLS_HOST__ = location.origin
# 页面自动连接
```

## 常见问题排查

| 问题 | 解决方案 |
|------|----------|
| DevTools 图标灰色未亮起 | 检查是否为生产构建（`--mode production`）；确保 Vue 是 development 版本 |
| Pinia Store 不显示 | 确保 `app.use(pinia)` 在 `createApp` 之后；刷新页面 |
| 组件树为空 | 可能使用了 SSR 或自定义渲染器；尝试 `window.__VUE_DEVTOOLS_HOOK__` |
| 数据不更新 | 点击刷新按钮；或勾选 "Refresh page on every action" |
| 性能影响 | DevTools 在开发模式下有一定开销；生产环境务必移除 |
