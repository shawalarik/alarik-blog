Element Plus 和 Ant Design Vue 是 Vue 3 生态中最主流的两款 UI 组件库。本文对比它们的设计理念、使用方式和工程化实践。

## 概览对比

| 维度 | Element Plus | Ant Design Vue |
|------|-------------|-----------------|
| **设计语言** | 设计语言 A（简洁/高效） | Ant Design（企业级/规范） |
| **维护团队** | 饿了么前端团队 | 蚎蚁/字节跳动 |
| **Stars** | ~23k | ~19k |
| **周下载量** | ~800k+ | ~400k+ |
| **组件数量** | 80+ | 80+ |
| **Vue 版本** | 3.3+ | 3.0+ |
| **TypeScript** | 完整支持 | 完整支持 |
| **Tree-shaking** | 支持 | 支持 |
| **SSR** | Nuxt 3 友好 | Nuxt 3 友好 |
| **国际化** | 30+ 语言包 | 40+ 语言包 |

## 安装与基础配置

### Element Plus

```bash
npm install element-plus @element-plus/icons-vue
```

```typescript
// main.ts
import { createApp } from 'vue'
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
// 引入图标库（按需引入时需要）
import * as ElementPlusIcons from '@element-plus/icons-vue'

const app = createApp(App)
app.use(ElementPlus)

// 全局注册所有图标组件（可选，也可按需注册）
for (const [key, component] of Object.entries(ElementPlusIcons)) {
  app.component(key, component)
}

app.mount('#app')
```

### Ant Design Vue

```bash
npm install ant-design-vue @ant-design/icons-vue
```

```typescript
// main.ts
import { createApp } from 'vue'
import Antd from 'ant-design-vue'
import 'ant-design-vue/dist/reset.css'

const app = createApp(App)
app.use(Antd)
app.mount('#app')
```

## 按需引入与包体积优化

### 方式一：完整引入（简单但体积大）

```typescript
// Element Plus — 全量引入 (~270KB gzip)
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'

// Ant Design Vue — 全量引入 (~500KB+ gzip)
import Antd from 'ant-design-vue'
import 'ant-design-vue/dist/reset.css'
```

**不推荐用于生产环境**，除非你的应用本身就依赖大量组件。

### 方式二：自动按需引入（推荐）

```typescript
// vite.config.ts
import AutoImport from 'unplugin-auto-import/r-vite'
import Components from 'unplugin-vue-components/vite'
import { ElementPlusResolver } from 'unplugin-vue-components/resolvers'

export default defineConfig({
  plugins: [
    vue(),
    // 自动导入组件（无需 import）
    Components({
      resolvers: [ElementPlusResolver()],
      // 可选：排除某些组件仍手动引入
      exclude: []
    }),
    // 自动导入 API（无需 import ElMessage 等）
    AutoImport({
      resolvers: [ElementPlusResolver()],
    }),
  ],
})
```

```vue
<!-- 现在可以直接用，无需任何 import -->
<template>
  <el-button type="primary">OK</el-button>
  <el-input v-model="text" />
  <ElMessage>消息提示</ElMessage>
</template>
```

### 方式三：手动按需引入（最精细控制）

```typescript
// 只引入需要的组件和样式
import { ElButton, ElInput, ElMessage, ElMessageBox } from 'element-plus'
import 'element-plus/es/components/button/style/css'
import 'element-plus/es/components/input/style/css'
// ... 其他组件的样式

// 手动注册
const app = createApp(App)
app.component('ElButton', ElButton)
app.component('ElInput', ElInput)
// ElMessage / ElMessageBox 不需要注册（函数调用）
```

### 包体积对比

| 引入方式 | Element Plus (gzip) | Ant Design Vue (gzip) |
|---------|-------------------|---------------------|
| 全量 | ~270 KB | ~520 KB |
| 自动按需 | ~60~120 KB（取决于使用的组件数） | ~150~300 KB |
| 手动按需 | ~30~80 KB（最小化） | ~50~150 KB |

## 国际化 (i18n)

### Element Plus

```typescript
// main.ts
import zhCn from 'element-plus/es/locale/lang/zh-cn'
import en from 'element-plus/es/locale/lang/en'

const app = createApp(App)
app.use(ElementPlus, { locale: zhCn })  // 默认中文
```

```vue
<!-- 动态切换语言 -->
<script setup lang="ts">
import { useI18n } from 'vue-i18n'
import { useLocale } from 'element-plus/es/hooks/locale'

const { locale } = useLocale()

// 切换 Element Plus 语言
watch(() => i18n.locale.value, (lang) => {
  locale.value = lang === 'zh-cn' ? zhCn : en
})
</script>

<template>
  <!-- 组件文本会跟随语言切换 -->
  <el-date-picker :placeholder="$t('datePicker.placeholder')" />
</template>
```

### Ant Design Vue

```typescript
// main.ts
import Antd from 'ant-design-vue'
import zhCN from 'ant-design-vue/es/locale/zh_CN'
import dayjs from 'dayjs/locale/zh-cn'

const app = createApp(App)
app.use(Antd, {
  locale: zhCN,
  dayjs,  // 日历等组件需要
})
```

## 二次封装实践

### 表单封装

```vue
<!-- components/ProForm/ProForm.vue -->
<template>
  <el-form
    ref="formRef"
    :model="formData"
    :rules="formRules"
    :label-width="labelWidth"
    label-position="right"
    v-bind="$attrs"
    @submit.prevent="handleSubmit"
  >
    <slot />
    
    <div class="pro-form__footer">
      <slot name="footer">
        <el-button @click="handleReset">重置</el-button>
        <el-button type="primary" native-type="submit" :loading="submitting">
          {{ submitText }}
        </el-button>
      </slot>
    </div>
  </el-form>
</template>

<script setup lang="ts" generic>
export interface ProFormProps {
  modelValue?: Record<string, any>
  rules?: Record<string, any>
  labelWidth?: string | number
  submitText?: string
  onSubmit?: (data: any) => void | Promise<any>
  onReset?: () => void
}

const props = withDefaults(defineProps<ProFormProps>(), {
  labelWidth: '100px',
  submitText: '提交',
})

const emit = defineEmits(['success', 'reset', 'update:modelValue'])

const formRef = ref()
const formData = useVModel(props, emit)
const formRules = computed(() => props.rules || {})
const submitting = ref(false)

async function handleSubmit() {
  try {
    await formRef.value?.validate()
    submitting.value = true
    await props.onSubmit?.(toRaw(formData))
    emit('success', toRaw(formData))
  } finally {
    submitting.value = false
  }
}

function handleReset() {
  formRef.value?.resetFields()
  props.onReset?.()
  emit('reset')
}

defineExpose({ validate: () => formRef.value?.validate(), reset: handleReset })
</script>

<style lang="scss" scoped>
.pro-form {
  max-width: 600px;
  
  &__footer {
    display: flex;
    justify-content: flex-end;
    gap: 12px;
    margin-top: 24px;
  }
}
</style>
```

```vue
<!-- 使用封装后的 ProForm -->
<ProForm
  :model-value="userForm"
  :rules="{ name: [{ required: true, message: '请输入名称' }]}"
  label-width="100px"
  submit-text="保存"
  @success="onUserSaved"
  @reset="onFormReset"
>
  <el-form-item label="用户名">
    <el-input v-model="userForm.name" />
  </el-form-item>
  <el-form-item label="邮箱">
    <el-input v-model="userForm.email" type="email" />
  </el-form-item>
</ProForm>
```

## 升级策略与 Breaking Changes 应对

### 升级检查清单

```
升级前:
□ 查看当前版本: npm list element-plus
□ 阅读 CHANGELOG.md 了解 breaking changes
□ 在分支上先测试
□ 备份自定义主题文件
□ 通知团队成员

升级后:
□ 运行测试套件
□ 逐页面视觉回归检查
□ 检查控制台警告/错误
□ 测试表单验证/弹窗交互
□ 检查打包产物大小变化
```

### 常见 Breaking Changes 处理

```typescript
// Element Plus 2.x → 3.x 迁移:

// 1. el-dialog 的 wrapper 属性移除
// 旧: <el-dialog :wrapper-classname="...">
// 新: <dialog-class="..." /> 或全局 CSS

// 2. el-form 的 size 属性值变更
// 旧: size="medium"
// 新: size="default"

// 3. el-upload 的 http-request 签名变更
// 旧: :http-request="customUpload"
//  新: :custom-request="customUpload"

// 4. el-menu 的 router 模式默认行为改变
// 需要显式设置 :router="true"
```
