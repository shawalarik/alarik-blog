Nuxt 是基于 Vue 的全栈框架，其服务端渲染（SSR）能力是 Vue 生态中最成熟的解决方案。本文深入 Nuxt 3 的核心架构与最佳实践。

## Nuxt 3 架构变革

### 与 Nuxt 2 的核心区别

```
Nuxt 2 (Vue 2 + Webpack):
├── 核心引擎: Vue Server Renderer
├── 文件系统: 基于 vue-router 的文件路由
├── 构建: Webpack (慢)
├── 模块: @nuxt/core, @nuxt/server 等
└── SSR: 集成在 Vue 内部


Nuxt 3 (Vue 3 + Vite + Nitro):
├── 核心引擎: Nitro (独立于 Vue 的运行时)
├── 文件系统: 基于 unjs/file 的文件路由 (更强大)
├── 构建: Vite (极快)
├── 模块: 内置模块化架构
└── SSR: Nitro 提供跨平台部署能力
```

## 文件系统路由

### 自动路由生成

```
pages/ 目录 → URL 路径映射:

pages/index.vue                    → /
pages/about.vue                   → /about

pages/users/index.vue             → /users
pages/users/[id].vue              → /users/:id    (动态参数)
pages/users/[id]/profile.vue       → /users/:id/profile
pages/users/[id]/posts/[postId]    → /users/:id/posts/:postId

pages/blog/index.vue              → /blog
pages/blog/[...slug].vue           → /blog/:slug(*) (catch-all)

pages/search.vue                 → /search?...
pages/search/[q].vue              → /search/:q

嵌套路由:
pages/
  parent.vue                      → /parent
    child.vue                     → /parent/child
      grandchild.vue               → /parent/child/grandchild
```

## 数据获取策略

### 三种渲染模式对比

| 模式 | 触发时机 | SEO | 适用场景 |
|------|----------|-----|----------|
| **SSR** (Universal) | 每次访问服务端渲染 | ✅ 最佳 | 内容型页面、SEO 关键页 |
| **SSG** (Static) | 构建时预渲染 | ✅ 好 | 博客、文档站、营销页 |
| **SPA** (Client) | 浏览器端渲染 | ❌ 无 | 后台管理、需要登录的应用 |

### useAsyncData vs useFetch vs $fetch

```vue
<!-- pages/users/[id].vue -->
<script setup lang="ts">

// ========== 方式 1: useAsyncData (推荐) ==========
// 特点：自动追踪异步状态、防重复请求、导航时刷新
const { data: user, pending, error, refresh } = await useAsyncData(
  () => $fetch(`/api/users/${useRoute().params.id}`),
  {
    // 缓存 key（默认基于路由）
    watch: false,  // 不监听参数变化
    initialCacheMaxAge: 60 * 1000,  // 客户端缓存 60 秒
    deep: true,
    // lazy: true,  // 延迟获取（首屏不阻塞）
  }
)

// ========== 方式 2: useFetch ==========
// 特点：更底层控制，可自定义选项
const {
  data: posts,
  error,
  execute,
  abortRefresh,
} = useFetch('/api/posts', {
    // baseURL: '/api',
    headers: { Authorization: `Bearer ${authToken.value}` },
    query: { category: 'tech' },
    // 初始数据（SSR 时使用）
    default: () => [],
    // GET 参数
    params: { page: '1', limit: '10' },
    // POST 请求体
    body: { search: 'nuxt' },
    // 响应拦截/转换
    onResponse(r) => r.data.items,
    onRequest({ request }) => {
      console.log('Requesting:', request.url)
    },
    // 错误处理
    onError(e) => { showErrorToast(`Failed: ${e.message}`) }
  })
</script>

<template>
  <div v-if="pending">Loading...</div>
  
  <pre v-if="error" class="text-red">{{ error }}</pre>
  
  <div v-else>
    <h1>User: {{ user?.name }}</h1>
    
    <ul>
      <li v-for="post in posts" :key="post.id">{{ post.title }}</li>
    </ul>
  </div>
</template>
```

### 数据获取时机

```
Nuxt 3 数据获取生命周期:

浏览器请求 /api/users/42
        ↓
┌─────────────┐
│  Nuxt Middleware  ← ① 中间件层执行
│  ├─ auth.ts     → 检查 token，未登录则重定向到 /login
│  └─ logger.ts   → 记录日志
└─────────────┘
        ↓
┌─────────────┐
│  Vue Server   ← ② 创建 Vue 应用实例
│  ├─ setup()     ← ③ 执行 <script setup>
│  │  ├─ useAsyncData()  ← ④ 数据获取
│  │  │  → fetch('/api/users/42')  ← ⑤ 发起 HTTP 请求
│  │  │  → 返回数据
│  │  └─ data 可用
│  ├─ <template> 渲染  ← ⑥ 生成 HTML 字符串
│  └─ send()        ← ⑦ 发送给浏览器
└─────────────┘
        ↓
浏览器接收 HTML
→ hydration（激活 Vue 客户端实例）
→ 变为交互式 SPA
```

## 部署策略

### Nitro 多平台部署

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  nitro: {
    // 部署目标
    preset: 'node-server',     // Node.js 服务器
    // preset: 'static'           // 静态站点
    // preset: 'cloudflare'       // Cloudflare Edge
    // preset: 'vercel'          // Vercel 平台
    
    // Node.js 服务器配置
    nodeServer: {
      port: 3000
      host: '0.0.0.0'
    }
  }
})
```

```
部署方式:

1. Node.js 服务器 (最常用)
   npx .output/server  # 启动服务器
   → 访问 http://localhost:3000
   
   生产环境:
   PM2 start ecosystem.config.cjs
   Docker + Kubernetes
   Railway / Render / Fly.io

2. 静态导出 (npx nuxi generate)
   npx nuxi generate
   → 生成完全静态的 HTML/CSS/JS
   → 可部署到:
     Netlify / Vercel / CloudFlare Pages
     S3 + CloudFront
     任何静态文件服务器

3. Cloudflare Workers (Edge Computing)
   npx nuxi preview --cloudflare
   → 在全球边缘节点运行
   → 极低的 TTFB (Time To First Byte)

4. Deno Deploy
   npx nuxi preview --deno
   → 基于 Deno runtime
```

## 性能优化

### 混合渲染（Hybrid Rendering）

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  routeRules: [
    {
      // 首页：SSR 保证 SEO 和首屏速度
      match: '/',
      prerender: true,        // 预渲染
      swr: false,
    },
    {
      // 用户仪表盘：纯客户端（已登录后不需要 SEO）
      match: '/dashboard/**',
      swr: false,
      ssr: false,             // 纯 SPA
    },
    {
      // 博客文章：SSG（构建时生成，超快加载）
      match: '/blog/**',
      swr: false,
      static: true,
      prerender: false,
    },
    {
      // 管理后台：纯 SPA
      match: '/admin/**',
      swr: false,
      ssr: false,
      prerender: false,
    },
  ]
})
```

## Nuxt Module 系统

### 自定义 Module

```typescript
// modules/my-module.ts
import { defineNuxtModule } from '@nuxt/schema'

export default defineNuxtModule({
  meta: {
    name: 'my-module',
    version: '1.0.0',
    configKey: 'myModule',
    compatibility: { nuxt: '^3.0.0' }
  },
  
  // 安装时的钩子
  install(nuxt) {
    console.log('[myModule] Installing...')
    
    // 添加全局 CSS
    nuxt.options.css.push('~/assets/custom.css')
    
    // 注册全局组件
    nuxt.options.components['MyGlobal'] = resolve(__dirname, './components/MyGlobal.vue')
  },
  
  // hooks (等同于 app hooks)
  hooks: {
    'app:created'() {
      console.log('[myModule] App created')
    },
    'page:start'() => {
      // 每个页面开始时执行
    }
  }
})
```
