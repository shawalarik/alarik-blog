# JSX 本质与编译

## 1. 什么是 JSX

JSX（JavaScript XML）是 React 团队提出的一种**语法扩展**，它允许你在 JavaScript 中书写类似 HTML 的标记：

```jsx
const element = <h1>Hello, world!</h1>;
```

### 关键认知：JSX 不是模板引擎

| 特性 | 模板引擎（如 Vue template / EJS） | JSX |
|------|-----------------------------------|-----|
| 本质 | 独立的 DSL，需专门解析器 | JavaScript 的语法糖 |
| 表达能力 | 受限于模板语法 | 完全的 JS 表达能力 |
| 编译产物 | 字符串拼接或 render 函数 | `React.createElement()` 调用 |
| 类型检查 | 弱 | 可配合 TypeScript 强类型 |

**JSX 本质上就是 `React.createElement()` 的语法糖**，没有任何魔法。

## 2. 编译过程

### 2.1 从 JSX 到 React.createElement

```jsx
// 你写的 JSX
const element = (
  <div className="greeting">
    <h1 style={{ color: 'red' }}>Hello</h1>
    <p>{name}</p>
  </div>
);
```

**Babel 编译后等价于：**

```js
// 编译产物
var element = React.createElement(
  'div',                          // type: 元素类型
  { className: 'greeting' },      // props: 属性对象
  React.createElement(             // children: 子元素
    'h1',
    { style: { color: 'red' } },
    'Hello'
  ),
  React.createElement(
    'p',
    null,
    name                         // 表达式求值后作为子节点
  )
);
```

### 2.2 React.createElement 签名

```ts
function createElement(
  type: string | Component,
  props?: Record<string, any> | null,
  ...children: ReactNode[]
): ReactElement;
```

| 参数 | 说明 | 示例 |
|------|------|------|
| `type` | HTML 标签字符串 或 组件引用 | `'div'`、`MyComponent` |
| `props` | 属性对象（`null` 表示无属性） | `{ className: 'foo', onClick: fn }` |
| `children` | 子元素（剩余参数收集） | 文本、元素、数组等 |

### 2.3 createElement 返回值 —— 虚拟 DOM 对象

```js
// 上例中 element 的实际结构（简化）
{
  $$typeof: Symbol(react.element), // React 元素标识
  type: 'div',
  key: null,
  ref: null,
  props: {
    className: 'greeting',
    children: [
      { type: 'h1', props: { style: {...}, children: ['Hello'] } },
      { type: 'p',   props: { children: ['Alarik'] } }
    ]
  }
}
```

这是一个**纯 JavaScript 对象**（Plain Old JavaScript Object），描述了你想在屏幕上看到的内容。

```
┌─────────────────────────────────────────────┐
│                  编译流程                      │
│                                              │
│  JSX  ──→  Babel (@babel/plugin-transform-react-jsx)
│              │                                │
│              ▼                                │
│     React.createElement()                    │
│              │                                │
│              ▼                                │
│        React Element (虚拟DOM)                │
│              │                                │
│              ▼                                │
│         ReactDOM.render()                     │
│              │                                │
│              ▼                                │
│          Real DOM                             │
└─────────────────────────────────────────────┘
```

## 3. JSX 表达式与限制

### 3.1 可以在 JSX 中使用的表达式

```jsx
// 变量引用
const name = "Alarik";
<div>{name}</div>

// 对象属性
const user = { firstName: "Alarik", lastName: "Blog" };
<div>{user.firstName} {user.lastName}</div>

// 函数调用
function formatName(user) {
  return `${user.firstName} ${user.lastName}`;
}
<div>{formatName(user)}</div>

// 三元表达式
<div>{user.isLoggedIn ? <Welcome /> : <Login />}</div>

// 逻辑与（短路求值）
<div>{user.messages.length > 0 && `(${user.messages.length})`}</div>

// Map 渲染列表
<ul>
  {items.map(item => <li key={item.id}>{item.name}</li>)}
</ul>
```

### 3.2 JSX 的限制

```jsx
// ❌ 不能使用 if/else 语句（需要用三元或立即执行函数）
<div>{if (show) "Yes"}</div>   // SyntaxError!

// ✅ 正确做法
<div>{show ? "Yes" : "No"}</div>
<div>{(() => { if (show) return "Yes" })()}</div>

// ❌ 对象不能直接作为子元素（会被解释为空对象）
<div>{{ a: 1 }}</div>  // 显示 [object Object]

// ✅ 正确做法：JSON.stringify
<div>{JSON.stringify({ a: 1 })}</div>
```

### 3.3 布尔值、null 和 undefined 会被忽略

```jsx
// 以下都不会渲染任何内容：
<div>{false}</div>
<div>{null}</div>
<div>{undefined}</div>
<div>{true}</div>

// 但数字 0 会渲染！
<div>{0}</div>       // 渲染 "0"

// 利用这个特性做条件渲染：
{showHeader && <Header />}   // showHeader 为 false 时不渲染
{count > 0 && <span>{count}</span>}  // count 为 0 时不渲染 span
```

> **⚠️ 注意**：`count && <span>` 当 count 为 0 时不会渲染 span（因为 0 是 falsy），但如果直接写 `<span>{count}</span>` 则会渲染出 `"0"`。这是常见的陷阱。

## 4. Babel 插件演进

### 4.1 React 17 之前的编译

```bash
# 旧版配置 (.babelrc)
{
  "plugins": ["@babel/plugin-transform-react-jsx"]
}

// 编译结果自动注入 React import
import React from 'react';
React.createElement('div', null, 'Hello');
```

### 4.2 React 17+ 的新 JSX Transform

从 React 17 开始引入了 **新的 JSX Transform**，无需在每个文件顶部手动 `import React`：

```bash
# 新版配置
{
  "plugins": [
    ["@babel/plugin-transform-react-jsx", { "runtime": "automatic" }]
  ]
}

// 编译结果：自动导入 jsx runtime
import { jsx as _jsx } from 'react/jsx-runtime';
/* @__PURE__*/ _jsx('div', { children: 'Hello' });
```

**对比表：**

| 维度 | Classic Runtime (`classic`) | Automatic Runtime (`automatic`) |
|------|---------------------------|-------------------------------|
| 需要手动 `import React` | ✅ 需要 | ❌ 不需要 |
| 导入来源 | `react` | `react/jsx-runtime` |
| 函数调用 | `React.createElement()` | `_jsx()` / `_jsxs()` (static children) |
| 包体积 | 较大（包含 React 全量） | 更小（仅运行时函数） |
| 兼容性 | React 0.14+ | React 17+ |
| 开发模式支持 | 无内置 | 自动附加源码位置信息 |

### 4.3 Vite 中的 JSX 处理

Vite 使用 **esbuild** 预处理 JSX，默认启用 automatic runtime：

```js
// vite.config.js
export default {
  esbuild: {
    jsx: 'automatic',           // 使用新 transform
    jsxImportSource: 'react'    // 默认值
  }
}
```

对于 Preact、Solid 等替代框架，只需修改 `jsxImportSource`：

```js
esbuild: {
  jsx: 'automatic',
  jsxImportSource: 'preact'     // 切换到 Preact
}
```

## 5. JSX 与 TypeScript —— TSX

TypeScript 中使用 JSX 时文件扩展名为 `.tsx`：

```tsx
interface Props {
  title: string;
  count?: number;               // 可选属性
  onAction?: (id: string) => void;  // 回调类型
}

// 类型安全的 Props
function Card({ title, count = 0, onAction }: Props) {
  return (
    <div className="card">
      <h2>{title}</h2>
      {count > 0 && <span>{count} items</span>}
      <button onClick={() => onAction?.('click')}>
        Action
      </button>
    </div>
  );
}

// 使用 FC 泛型（不推荐，丢失字面量类型推断）
type CardProps = {
  title: string;
};
const Card2: React.FC<CardProps> = ({ title }) => <h2>{title}</h2>;
```

> **推荐**：直接声明 Props interface + 解构参数，而非使用 `React.FC<>`。后者会导致隐含 `children` 属性且泛型推断能力弱化。

## 6. Fragment —— 多根节点

JSX 要求必须有唯一根节点，Fragment 解决了这一限制：

```jsx
// ❌ 错误：相邻的多个根元素
return (
  <h1>Title</h1>
  <p>Description</p>
);

// ✅ 方案一：用 div 包裹（增加无意义层级）
return (
  <div>
    <h1>Title</h1>
    <p>Description</p>
  </div>
);

// ✅ 方案二：用 Fragment（推荐）
return (
  <>
    <h1>Title</h1>
    <p>Description</p>
  </>
);

// ✅ 等价写法（带 key 时必须显式写法）
return (
  <React.Fragment key="section">
    <h1>Title</h1>
    <p>Description</p>
  </React.Fragment>
);
```

**Fragment 的实际价值**：

| 场景 | 说明 |
|------|------|
| 列表渲染 | `<dl>` 内只能包含 `<dt>`/`<dd>`，Fragment 保持合法语义 |
| CSS Table | `<tr>` 内多列用 Fragment 避免 `div` 破坏表格布局 |
| 条件返回 | 根据条件返回不同数量的子元素 |
| Portal 配合 | 配合 `createPortal` 返回多节点 |

## 7. JSX 中的属性约定

```jsx
// class → className（保留字冲突）
<div className="container"></div>

// for → htmlFor
<label htmlFor="input-name">Name:</label>
<input id="input-name" />

// style 接受对象（驼峰命名）
<div style={{ 
  backgroundColor: '#f0f0f0',   // 驼峰
  fontSize: 16,                 // 数字默认 px
  lineHeight: 1.5,              
  '--custom-var': 'value'       // CSS 自定义属性用引号
}}></div>

// 事件处理：camelCase
<button onClick={handleClick}>Click</button>
<input onChange={handleChange} />

// data-* / aria-* 保持原样
<div data-id="123" aria-label="Close button"></div>
```

```
┌──────────────────────────────────────────────────┐
│              JSX 核心要点速查                      │
├──────────────────────────────────────────────────┤
│ 本质 → React.createElement() 的语法糖            │
│ 产物 → 虚拟 DOM 对象（纯 JS Object）             │
│ 编译器 → Babel / esbuild (Vite) / SWC            │
│ Transform → classic(旧) vs automatic(新, React17+) │
│ 表达式 → {} 包裹任意 JS 表达式                     │
│ 忽略值 → false/null/undefined/true 不渲染         │
│ 多根节点 → <>...</> (Fragment)                    │
│ 保留字 → className / htmlFor / onClick           │
└──────────────────────────────────────────────────┘
```
