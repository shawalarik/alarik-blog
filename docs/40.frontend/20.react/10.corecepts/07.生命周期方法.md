# 生命周期方法

## 1. 概述

React 组件的生命周期是指**组件从创建到销毁所经历的全过程**。理解生命周期有助于在正确的时机执行正确的操作（如数据获取、订阅、DOM 操作、清理资源）。

> **重要说明**：以下生命周期方法仅适用于**类组件**。函数组件使用 `useEffect` 等Hooks 来模拟类似行为。虽然类组件已不再推荐用于新代码，但在维护遗留项目时仍需掌握这些知识。

## 2. 类组件生命周期全景图

```
                        ┌─────────────────────────────────────┐
                        │           挂载阶段 (Mounting)        │
                        │                                     │
   constructor() ──►    │  getDerivedStateFromProps()         │
   static getDerivedStateFromProps() ──►                      │
                        │  render()                           │
                        │  componentDidMount() ★             │
                        └─────────────────┬───────────────────┘
                                          │
                    ┌─────────────────────┼─────────────────────┐
                    │         更新阶段 (Updating)               │
                    │                                         │
     props/state变更  ◄── 新的 props/state 进入               │
                    │                                         │
                    │  shouldComponentUpdate() ?               │
                    │    ├─ Yes → 继续                         │
                    │    └─ No  → 跳过                         │
                    │                                         │
                    │  getDerivedStateFromProps()              │
                    │  render()                               │
                    │  getSnapshotBeforeUpdate() ★            │
                    │  componentDidUpdate() ★                │
                    └─────────────────────┬───────────────────┘
                                          │
                    ┌─────────────────────┴───────────────────┐
                    │         卸载阶段 (Unmounting)             │
                    │                                        │
                    │  componentWillUnmount() ★             │
                    │                                        │
                    │  (组件从 DOM 中移除)                     │
                    └────────────────────────────────────────┘
                        
    ★ = 常用 / 带副作用的钩子
```

## 3. 挂载阶段（Mounting）

按调用顺序：

### 3.1 constructor(props)

```jsx
class Counter extends React.Component {
  constructor(props) {
    super(props);  // 必须首先调用 super()
    
    // ✅ 初始化 state
    this.state = {
      count: 0,
      error: null
    };
    
    // ✅ 绑定事件处理器（如果不用类字段箭头函数）
    this.handleClick = this.handleClick.bind(this);
    
    // ❌ 不要在这里调用 setState()
    // ❌ 不要在这里做副作用操作（AJAX、DOM 操作）
  }
}
```

| 要点 | 说明 |
|------|------|
| `super(props)` | 必须在 `this` 使用之前调用 |
| 唯一用途 | 初始化 `state` 和绑定方法 |
| 不要做的 | AJAX 请求、setTimeout、DOM 操作 |

### 3.2 static getDerivedStateFromProps(props, state)

```jsx
static getDerivedStateFromProps(nextProps, prevState) {
  // 根据 props 计算派生 state
  if (nextProps.userId !== prevState.userId) {
    return {
      userId: nextProps.userId,
      userData: null  // 触发重新获取
    };
  }
  
  // 不更新 state 时返回 null
  return null;
}
```

> **注意**：这是一个静态方法，无法访问 `this`。使用频率较低，大部分场景可以用更简单的方案替代。

### 3.3 render()

```jsx
render() {
  // 必须是纯函数：相同的输入产生相同的输出
  // ❌ 不要在这里修改 state
  // ❌ 不要在这里有副作用
  // ❌ 不要直接与浏览器交互
  
  const { items, loading } = this.props;
  
  if (loading) return <Loading />;
  if (!items || items.length === 0) return <Empty />;
  
  return (
    <ul>
      {items.map(item => <li key={item.id}>{item.name}</li>)}
    </ul>
  );
}
```

### 4.4 componentDidMount()

```jsx
componentDidMount() {
  // ✅ 数据获取（AJAX/Fetch）
  fetch('/api/users')
    .then(res => res.json())
    .then(data => this.setState({ users: data }));
  
  // ✅ 订阅（WebSocket、事件监听）
  this.ws = new WebSocket('wss://example.com');
  this.ws.onmessage = (e) => this.handleMessage(JSON.parse(e.data));
  
  // ✅ 定时器
  this.timer = setInterval(this.tick, 1000);
  
  // ✅ DOM 操作（需要真实 DOM 引用时）
  this.chart = new Chart(this.canvasRef.current, config);
}
```

**最佳实践**：这是发起网络请求、设置订阅的最佳时机。

## 4. 更新阶段（Updating）

触发更新的原因：`setState()` / `forceUpdate()` / 父组件重新渲染

### 4.1 shouldComponentUpdate(nextProps, nextState)

性能优化的关键钩子：

```jsx
shouldComponentUpdate(nextProps, nextState) {
  // 返回 true: 执行更新（默认行为）
  // 返回 false: 跳过更新及其子组件的更新
  
  // 浅比较示例
  return (
    nextProps.id !== this.props.id ||
    nextState.count !== this.state.count
  );
}
```

> **现代替代**：函数组件中使用 `React.memo()` + `useMemo()` / `useCallback()` 实现。

### 4.2 getSnapshotBeforeUpdate(prevProps, prevState)

在最近一次渲染输出（commit 到 DOM）之前调用，可捕获 DOM 信息：

```jsx
getSnapshotBeforeUpdate(prevProps, prevState) {
  // 在 DOM 更改之前保存滚动位置
  if (prevProps.list.length < this.props.list.length) {
    const listRef = this.listRef.current;
    return listRef.scrollHeight - listRef.scrollTop;
  }
  return null;
}

componentDidUpdate(prevProps, prevState, snapshot) {
  // 使用 snapshot 恢复滚动位置
  if (snapshot !== null) {
    const listRef = this.listRef.current;
    listRef.scrollTop = listRef.scrollHeight - snapshot;
  }
}
```

**典型应用**：聊天窗口新消息到来时保持滚动位置不变。

### 4.3 componentDidUpdate(prevProps, prevState, snapshot)

```jsx
componentDidUpdate(prevProps, prevState, snapshot) {
  // 典型用法：
  
  // 1. 基于 props 变更发起请求
  if (this.props.userId !== prevProps.userId) {
    this.fetchUser(this.props.userId);
  }
  
  // 2. 操作更新后的 DOM
  if (prevState.isOpen !== this.state.isOpen && this.state.isOpen) {
    this.inputRef.current.focus();
  }
  
  // ⚠️ 注意：可以在 setState() 但必须加条件判断，
  //    否则会导致无限循环！
}
```

## 5. 卸载阶段（Unmounting）

### 5.1 componentWillUnmount()

**最重要的清理钩子**：

```jsx
componentWillUnmount() {
  // 清理所有副作用！否则会导致内存泄漏
  
  // 清除定时器
  clearInterval(this.timer);
  clearTimeout(this.timeoutId);
  
  // 取消网络请求（如果有 AbortController）
  this.abortController.abort();
  
  // 关闭 WebSocket
  if (this.ws) {
    this.ws.close();
  }
  
  // 移除事件监听
  window.removeEventListener('resize', this.handleResize);
  
  // 销毁第三方库实例
  if (this.chart) {
    this.chart.destroy();
  }
}
```

## 6. 已废弃的生命周期（了解即可）

| 已废弃的方法 | 替代方案 | 废弃原因 |
|-------------|---------|---------|
| `componentWillMount` | `constructor` + `componentDidMount` | 易引发异步问题 |
| `componentWillReceiveProps` | `getDerivedStateFromProps` | 设计缺陷导致滥用 |
| `componentWillUpdate` | `getSnapshotBeforeUpdate` + `componentDidUpdate` | 安全隐患 |

> 这些方法以 `UNSAFE_` 前缀形式存在于 React 16.3~16.x，React 17+ 中完全移除。

## 7. useEffect —— 函数组件的生命周期替代

### 7.1 生命周期映射对照

| 类组件 Hook | useEffect 等价写法 |
|------------|-------------------|
| `componentDidMount` | `useEffect(fn, [])` |
| `componentDidUpdate` | `useEffect(fn, [dep])` |
| `componentWillUnmount` | `useEffect` 的 return cleanup 函数 |
| `componentDidMount` + `componentWillUnmount` | `useEffect(fn, [])` 带 cleanup |
| `componentDidMount` + `componentDidUpdate` | `useEffect(fn, [dep])` 带 cleanup |

### 7.2 具体映射示例

```jsx
// ========== componentDidMount ==========
useEffect(() => {
  console.log('组件已挂载');
  fetchData();
}, []);

// ========== componentDidUpdate ==========
useEffect(() => {
  // 每次 count 变化时执行
  document.title = `Count: ${count}`;
}, [count]);

// ========== componentWillUnmount ==========
useEffect(() => {
  const timer = setInterval(tick, 1000);
  
  return () => {
    // cleanup 相当于 componentWillUnmount
    clearInterval(timer);
  };
}, []);

// ========== componentDidMount + componentWillUnmount ==========
useEffect(() => {
  // setup（挂载时执行）
  const ws = new WebSocket(url);
  ws.onmessage = handleMessage;

  return () => {
    // cleanup（卸载时执行）
    ws.close();
  };
}, []);
```

### 7.3 useLayoutEffect —— 同步版 useEffect

```jsx
import { useLayoutEffect, useRef } from 'react';

function Tooltip({ targetRef, text }) {
  const tooltipRef = useRef();

  // 在浏览器绑制之前同步执行
  useLayoutEffect(() => {
    const rect = targetRef.current.getBoundingClientRect();
    tooltipRef.current.style.top = `${rect.bottom + 8}px`;
    tooltipRef.current.style.left = `${rect.left}px`;
  });

  return <div ref={tooltipRef}>{text}</div>;
}
```

| | `useEffect` | `useLayoutEffect` |
|--|------------|------------------|
| 执行时机 | 浏览器绘制**之后**（异步） | 浏览器绘制**之前**（同步） |
| 适用场景 | 大多数副作用、数据获取、订阅 | DOM 测量、避免闪烁 |
| 阻塞绘制 | 否 | 是 |
| 性能影响 | 小 | 大（应谨慎使用） |

## 8. 错误处理（Error Boundaries）

```
class ErrorBoundary extends React.Component {
  constructor(props) {
    super(props);
    this.state = { hasError: false, error: null };
  }

  // 静态方法：捕获子组件渲染错误
  static getDerivedStateFromError(error) {
    return { hasError: true, error };
  }

  // 实例方法：记录错误信息
  componentDidCatch(error, errorInfo) {
    logErrorToService(error, errorInfo);
  }

  render() {
    if (this.state.hasError) {
      return <FallbackUI error={this.state.error} />;
    }
    return this.props.children;
  }
}

// 使用
<ErrorBoundary>
  <MyRiskyComponent />
</ErrorBoundary>
```

> **注意**：Error Boundary 只能捕获**子组件树**渲染过程中的错误，无法捕获自身的事件处理器错误、异步代码错误。目前没有函数组件版本的 Error Boundary（需要类组件实现）。

## 9. 总结

```
┌──────────────────────────────────────────────────┐
│              生命周期速查卡                       │
├──────────────────────────────────────────────────┤
│ 挂载：                                           │
│   constructor → render → componentDidMount      │
│                                                  │
│ 更新：                                           │
│   新props/state                                  │
│   → shouldComponentUpdate?(可选)                  │
│   → render                                       │
│   → getSnapshotBeforeUpdate(可选)                │
│   → componentDidUpdate                           │
│                                                  │
│ 卸载：                                           │
│   componentWillUnmount (清理!)                  │
│                                                  │
│ 函数组件替代：                                    │
│   componentDidMount  → useEffect(fn, [])         │
│   componentDidUpdate   → useEffect(fn, [deps])   │
│   componentWillUnmount → return cleanup          │
│   同步DOM操作          → useLayoutEffect          │
└──────────────────────────────────────────────────┘
```
