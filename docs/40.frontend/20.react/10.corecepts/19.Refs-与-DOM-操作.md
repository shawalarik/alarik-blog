# Refs 与 DOM 操作

## 1. 什么是 Ref

Ref（reference）是 React 提供的一种**访问 DOM 元素或 React 元素实例的方式**。它绕过了常规的数据流（props/state），用于那些"需要直接操作 DOM"的场景。

### 何时使用 Ref

| 适用场景 | 不适用场景 |
|----------|----------|
| 管理**焦点**、文本选中、媒体播放 | 管理可以通过 state 控制的任何东西 |
| 触发**命令式动画** | 声明式的 UI 变更 |
| 与第三方 **DOM 库**集成 | 数据传递 |
| 测量 DOM **尺寸/位置**（偶尔） | 通知其他组件变更 |

## 2. useRef Hook（函数组件）

### 2.1 访问 DOM 元素

```jsx
import { useRef, useEffect } from 'react';

function TextInputWithFocus() {
  const inputRef = useRef(null);

  useEffect(() => {
    // 挂载后自动聚焦
    inputRef.current?.focus();
    inputRef.current?.select();
  }, []);

  return (
    <div>
      <input ref={inputRef} defaultValue="Auto-focused" />
      <button onClick={() => inputRef.current?.focus()}>
        Focus Input
      </button>
    </div>
  );
}
```

### 2.2 Ref 存储任意可变值（非 DOM 用途）

```jsx
function Timer() {
  const [count, setCount] = useState(0);
  const countRef = useRef(0);

  useEffect(() => {
    const timer = setInterval(() => {
      countRef.current += 1;
      setCount(countRef.current);  // ref.current 始终是最新的
    }, 1000);

    return () => clearInterval(timer);
  }, []);

  // countRef 的变化不会触发重渲染
  // 这正是它与 state 的关键区别
  return <p>Seconds: {count}</p>;
}
```

**useRef vs useState 对比：**

| 特性 | `useRef` | `useState` |
|------|---------|------------|
| 存储值变化 | **不触发重渲染** | **触发重渲染** |
| 返回值 | `{ current: value }` | `[value, setter]` |
| 典型用途 | DOM 引用、定时器 ID、前一个值缓存 | UI 状态管理 |
| 读取方式 | `ref.current` | 直接读取变量 |

## 3. 回调 Ref（Callback Ref）

### 3.1 基本语法

```jsx
function MeasureExample() {
  const [height, setHeight] = useState(0);

  // ref 是一个回调函数
  const measuredRef = useCallback((node) => {
    if (node !== null) {
      // node 就是 DOM 元素
      setHeight(node.getBoundingClientRect().height);
    }
  }, []);

  return (
    <div>
      <h1 ref={measuredRef}>Hello</h1>
      <p>The header is {height}px tall</p>
    </div>
  );
}
```

### 3.2 回调 Ref vs useRef

| | useRef | Callback Ref |
|--|--------|-------------|
| 赋值时机 | React 分配（首次渲染后可用） | 每次 DOM 节点挂载/卸载时调用 |
| 获取时机 | 需要 useEffect 等待挂载完成 | 回调内 node 参数即最新 DOM |
| 清理 | 无自动清理 | 返回清理函数（或 node 为 null 时处理） |
| 适用场景 | 大多数场景 | 需要知道节点何时挂载/卸载 |

```jsx
// 回调 Ref 的完整生命周期
function LogLifecycle() {
  const callbackRef = (node) => {
    if (node !== null) {
      console.log('Node mounted:', node);
      // 可在此初始化第三方库
    } else {
      console.log('Node unmounted');
      // 可在此清理
    }
  };

  return <div ref={callbackRef}>Watch Console</div>;
}
```

## 4. forwardRef — 转发 Ref 到子组件

默认情况下，ref 不能传递给函数组件。`forwardRef` 解决了这个问题：

### 4.1 基本用法

```jsx
const FancyInput = forwardRef(function FancyInput(props, ref) {
  return <input ref={ref} className="fancy" {...props} />;
});

// 使用
function App() {
  const inputRef = useRef(null);

  function handleClick() {
    inputRef.current?.focus();
  }

  return (
    <div>
      <FancyInput ref={inputRef} placeholder="Type here..." />
      <button onClick={handleClick}>Focus</button>
    </div>
  );
}
```

### 4.2 forwardRef + useImperativeHandle（暴露自定义方法）

```jsx
const CustomInput = forwardRef(function CustomInput(props, ref) {
  const inputRef = useRef(null);

  // 向父组件暴露精简的 API
  useImperativeHandle(ref, () => ({
    focus: () => {
      inputRef.current?.focus();
    },
    clear: () => {
      inputRef.current.value = '';
    },
    getValue: () => {
      return inputRef.current?.value ?? '';
    }
  }), []);  // 依赖数组（类似 useEffect）

  return <input ref={inputRef} {...props} />;
});

// 父组件使用暴露的方法
function Form() {
  const customInputRef = useRef(null);

  const handleSubmit = () => {
    const value = customInputRef.current?.getValue();
    if (!value) {
      customInputRef.current?.focus();
      return;
    }
    submitData(value);
  };

  const handleReset = () => {
    customInputRef.current?.clear();
  };

  return (
    <form onSubmit={handleSubmit}>
      <CustomInput ref={customInputRef} />
      <button type="submit">Submit</button>
      <button type="button" onClick={handleReset}>Reset</button>
    </form>
  );
}
```

**useImperativeHandle 的签名**：

```ts
useImperativeHandle<T>(ref, createHandle: () => T, deps?: DependencyList);
// ref: 转发来的 ref
// createHandle: 返回要暴露的对象
// deps: 依赖数组，变化时重新创建 handle
```

## 5. Ref 列表（多个 Ref）

### 5.1 用 ref Map 管理多个元素

```jsx
function ItemList({ items }) {
  const itemRefs = useRef(new Map());

  function scrollToItem(id) {
    const node = itemRefs.current.get(id);
    node?.scrollIntoView({ behavior: 'smooth', block: 'center' });
  }

  return (
    <div>
      {items.map(item => (
        <div
          key={item.id}
          ref={(node) => {
            if (node) itemRefs.current.set(item.id, node);
            else itemRefs.current.delete(item.id);
          }}
        >
          {item.content}
        </div>
      ))}
      <nav>
        {items.map(item => (
          <button key={item.id} onClick={() => scrollToItem(item.id)}>
            Go to #{item.id}
          </button>
        ))}
      </nav>
    </div>
  );
}
```

### 5.2 用数组存储多个 Ref

```jsx
function InputGroup({ count }) {
  const refs = Array.from({ length: count }, () => useRef(null));

  const focusNext = (currentIndex) => {
    const nextIndex = currentIndex + 1;
    if (nextIndex < refs.length) {
      refs[nextIndex].current?.focus();
    }
  };

  return (
    <div>
      {refs.map((ref, i) => (
        <input
          key={i}
          ref={ref}
          onKeyDown={(e) => e.key === 'Tab' && focusNext(i)}
        />
      ))}
    </div>
  );
}
```

## 6. 类组件中的 Ref

### 6.1 createRef

```jsx
class TextInput extends React.Component {
  constructor(props) {
    super(props);
    // 创建 ref
    this.inputRef = React.createRef();
  }

  componentDidMount() {
    // 通过 this.inputRef.current 访问 DOM
    this.inputRef.current.focus();
  }

  render() {
    return <input ref={this.inputRef} />;
  }
}
```

### 6.2 回调 Ref（类组件）

```jsx
class TextInput extends React.Component {
  setInputRef = (element) => {
    this.textInput = element;
  };

  render() {
    return <input ref={this.setInputRef} />;
  }
}
```

## 7. Ref 与第三方 DOM 库集成

### 7.1 Chart.js 集成

```jsx
import { useEffect, useRef } from 'react';
import { Chart } from 'chart.js/auto';

function LineChart({ data, options }) {
  const canvasRef = useRef(null);
  const chartRef = useRef(null);

  useEffect(() => {
    if (!canvasRef.current) return;

    // 创建图表实例
    chartRef.current = new Chart(canvasRef.current, {
      type: 'line',
      data,
      options
    });

    return () => {
      // 销毁图表实例，防止内存泄漏
      chartRef.current?.destroy();
      chartRef.current = null;
    };
  }, [data, options]);

  return <canvas ref={canvasRef}></canvas>;
}
```

### 7.2 D3.js 集成

```jsx
import { useEffect, useRef } from 'react';
import * as d3 from 'd3';

function D3Chart({ dataset }) {
  const svgRef = useRef(null);

  useEffect(() => {
    const svg = d3.select(svgRef.current);
    
    svg.selectAll('rect')
      .data(dataset)
      .enter()
      .append('rect')
      .attr('x', (d, i) => i * 30)
      .attr('y', d => 200 - d.value)
      .attr('width', 25)
      .attr('height', d => d.value)
      .attr('fill', '#61dafb');

    return () => {
      // 清理 D3 创建的元素
      svg.selectAll('*').remove();
    };
  }, [dataset]);

  return <svg ref={svgRef} width="600" height="200"></svg>;
}
```

## 8. 常见陷阱与最佳实践

### 8.1 不要过度使用 Ref

```jsx
// ❌ 反例：应该用 state 控制
function Toggle() {
  const divRef = useRef(null);
  
  const toggle = () => {
    if (divRef.current.style.display === 'none') {
      divRef.current.style.display = 'block';
    } else {
      divRef.current.style.display = 'none';
    }
  };
  
  return (
    <>
      <button onClick={toggle}>Toggle</button>
      <div ref={divRef}>Content</div>
    </>
  );
}

// ✅ 正确：用 state 声明式控制
function Toggle() {
  const [isVisible, setIsVisible] = useState(true);
  return (
    <>
      <button onClick={() => setIsVisible(!isVisible)}>Toggle</button>
      {isVisible && <div>Content</div>}
    </>
  );
}
```

### 8.2 条件渲染中的 Ref

```jsx
// ⚠️ 条件渲染可能导致 ref.current 为 null
function MaybeInput({ showInput }) {
  const inputRef = useRef(null);

  useEffect(() => {
    // 当 showInput 从 false 变 true 时，这里才会执行
    inputRef.current?.focus();
  }, [showInput]);

  return (
    <div>
      {showInput && <input ref={inputRef} />}
      {/* 当 showInput=false 时，inputRef.current === null */}
    </div>
  );
}
```

### 8.3 Ref 在循环中的使用

```jsx
// ⚠️ 循环中不能直接用同一个 ref
{items.map(item => (
  // 这样写所有元素共享同一个 ref！
  <div ref={myRef}>{item.name}</div>  // ❌
))}

// ✅ 正确做法见第 5 节的 ref Map 模式
```

## 9. 总结

```
┌──────────────────────────────────────────────────┐
│           Ref 核心要点                             │
├──────────────────────────────────────────────────┤
│ 用途: 访问DOM / 存储可变值但不触发重渲染           │
│ 函数组件: useRef()                               │
│ 类组件: React.createRef() 或 回调 ref             │
│ 子组件转发: forwardRef                           │
│ 自定义API: useImperativeHandle                    │
│ 多元素: ref Map 或 ref 数组                       │
│ 原则: 能用state解决的不要用ref                     │
│ 清理: 第三方库实例要在 effect cleanup 中销毁       │
└──────────────────────────────────────────────────┘
```
