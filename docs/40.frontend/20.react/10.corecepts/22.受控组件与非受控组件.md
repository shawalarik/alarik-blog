# 受控组件与非受控组件

## 1. 核心概念

在 React 中处理表单元素有两种模式——**受控组件（Controlled）**和**非受控组件（Uncontrolled）**。它们的本质区别在于：**谁拥有表单数据的"真相来源"（Source of Truth）。**

| 维度 | 受控组件 | 非受控组件 |
|------|---------|-----------|
| 数据源 | **React State** | **DOM 自身** |
| 值的设置者 | React (`value={state}`) | 用户直接操作 DOM |
| 读取方式 | 读 state 变量 | 通过 `ref` 读取 DOM 值 |
| 单向数据流 | ✅ 严格遵循 | ❌ 脱离了单向流 |
| 实时校验 | ✅ 天然支持（每次 keystroke 都经过 state） | 需手动监听 |
| 适用场景 | 大多数表单、需要实时反馈 | 一次性提交、文件上传、集成第三方库 |

## 2. 受控组件详解

### 2.1 基本模式

```jsx
function ControlledForm() {
  const [name, setName] = useState('');
  const [email, setEmail] = useState('');

  const handleSubmit = (e) => {
    e.preventDefault();
    // 直接从 state 读取，始终是最新的值
    console.log({ name, email });
  };

  return (
    <form onSubmit={handleSubmit}>
      <div>
        <label>Name:</label>
        <input
          type="text"
          value={name}                          // ← 受控的关键：value 由 state 决定
          onChange={(e) => setName(e.target.value)}  // ← 每次输入都更新 state
        />
      </div>

      <div>
        <label>Email:</label>
        <input
          type="email"
          value={email}
          onChange={(e) => setEmail(e.target.value)}
        />
      </div>

      <button type="submit">Submit</button>
    </form>
  );
}
```

**数据流向图**：

```
User types "a"
  ↓
onChange fires → setState("a")
  ↓
Re-render → value={"a"}
  ↓
DOM shows "a"

每一次键盘输入都经历完整的 cycle
```

### 2.2 多种表单元素

```jsx
function AllControlledInputs() {
  const [text, setText] = useState('');
  const [selected, setSelected] = useState('apple');
  const [isChecked, setIsChecked] = useState(false);
  const [areaValue, setAreaValue] = useState('');
  const [selectedColor, setSelectedColor] = useState('#ff0000');

  return (
    <div>
      {/* 文本输入 */}
      <input value={text} onChange={e => setText(e.target.value)} />

      {/* 单选按钮组 */}
      <fieldset>
        <legend>Fruit:</legend>
        {['apple', 'banana', 'orange'].map(fruit => (
          <label key={fruit}>
            <input
              type="radio"
              name="fruit"
              checked={selected === fruit}
              onChange={() => setSelected(fruit)}
            />
            {fruit}
          </label>
        ))}
      </fieldset>

      {/* 复选框 */}
      <label>
        <input
          type="checkbox"
          checked={isChecked}
          onChange={e => setIsChecked(e.target.checked)}
        />
        Accept terms
      </label>

      {/* 多行文本 */}
      <textarea value={areaValue} onChange={e => setAreaValue(e.target.value)} />

      {/* 颜色选择器 */}
      <input
        type="color"
        value={selectedColor}
        onChange={e => setSelectedColor(e.target.value)}
      />

      {/* 选择框（单选） */}
      <select value={selected} onChange={e => setSelected(e.target.value)}>
        <option value="">-- Select --</option>
        <option value="apple">Apple</option>
        <option value="banana">Banana</option>
      </select>

      {/* 选择框（多选） */}
      <select multiple size={3} value={['a', 'c']} onChange={...}>
        <option value="a">A</option>
        <option value="b">B</option>
        <option value="c">C</option>
      </select>
    </div>
  );
}
```

**各表单元素对应的受控属性和事件**：

| 元素类型 | Value 属性 | Change 事件 | 特殊之处 |
|---------|-----------|------------|---------|
| `<input type="text">` | `value` | `onChange` | — |
| `<input type="checkbox">` | `checked` | `onChange` | 用 `checked` 非 `value` |
| `<input type="radio">` | `checked` | `onChange` | 同名 radio 共用一个 state |
| `<textarea>` | `value` | `onChange` | 不用 children 设值 |
| `<select>` | `value` | `onChange` | 多选用数组作为 value |
| `<input type="file">` | **不支持** | — | 只能是非受控的 |

### 2.3 封装通用受控表单 Hook

```jsx
function useForm(initialValues) {
  const [values, setValues] = useState(initialValues);
  const [errors, setErrors] = useState({});

  const handleChange = (e) => {
    const { name, value, type, checked } = e.target;
    setValues(prev => ({
      ...prev,
      [name]: type === 'checkbox' ? checked : value
    }));
  };

  const reset = () => setValues(initialValues);
  const setFieldValue = (name, value) => setValues(prev => ({ ...prev, [name]: value }));

  return { values, errors, handleChange, reset, setFieldValue, setErrors };
}

// 使用
function SignupForm() {
  const { values, handleChange } = useForm({
    username: '',
    email: '',
    acceptTerms: false
  });

  return (
    <form>
      <input name="username" value={values.username} onChange={handleChange} />
      <input name="email" value={values.email} onChange={handleChange} />
      <input name="acceptTerms" type="checkbox" checked={values.acceptTerms} onChange={handleChange} />
    </form>
  );
}
```

## 3. 非受控组件详解

### 3.1 基本模式

```jsx
function UncontrolledForm() {
  // 用 ref 来持有对 DOM 的引用
  const nameRef = useRef(null);
  const emailRef = useRef(null);

  const handleSubmit = (e) => {
    e.preventDefault();
    // 提交时才从 DOM 读取值
    console.log({
      name: nameRef.current?.value,
      email: emailRef.current?.value
    });
  };

  return (
    <form onSubmit={handleSubmit}>
      <div>
        <label>Name:</label>
        {/* 没有 value 属性 = 非受控 */}
        <input type="text" name="name" defaultValue="Alarik" ref={nameRef} />
      </div>

      <div>
        <label>Email:</label>
        <input type="email" name="email" ref={emailRef} />
      </div>

      <button type="submit">Submit</button>
    </form>
  );
}
```

**关键区别**：

```jsx
// 受控：React 控制值
<input value={state} onChange={setState} />  // 每次敲键都同步到 state

// 非受控：DOM 自己管值
<input defaultValue="initial" ref={myRef} />  // React 不管输入过程
```

### 3.2 defaultValue vs value

| 属性 | 含义 | 适用场景 |
|------|------|---------|
| `defaultValue` | 设置**初始值**，之后不管 | 非受控组件 |
| `value` | 设置**当前值**，每次渲染同步 | 受控组件 |
| `defaultChecked` | checkbox/radio 的初始选中状态 | 非受控 |
| `checked` | checkbox/radio 的当前状态 | 受控 |

```jsx
// 非受控：只设置一次初始值
<input defaultValue="hello" />  // 用户修改后 React 不管

// 受控：始终保持一致
<input value={state} />  // 用户输入 → onChange → setState → re-render → value 更新
```

## 4. 如何选择

### 4.1 决策流程

```
你需要处理表单吗？
  │
  ├─ 需要实时校验/格式化？ ──► 受控组件
  ├─ 需要根据输入动态禁用/启用其他字段？ ──► 受控组件
  ├─ 需要字符计数/即时搜索建议？ ──► 受控组件
  ├─ 表单字段互相依赖（如确认密码）？ ──► 受控组件
  │
  ├─ 简单的一次性提交表单？ ──► 非受控组件（更简单）
  ├─ 文件上传 <input type="file">？ ──► 必须非受控
  ├─ 集成第三方 DOM 库（如日期选择器）？ ──► 通常非受控
  └─ 性能敏感的超大表单？ ──► 考虑非受控（减少 state 更新频率）
```

### 4.2 混合使用

同一个表单中可以同时使用两种模式：

```jsx
function MixedForm() {
  // 需要实时校验的字段 → 受控
  const [username, setUsername] = useState('');
  
  // 一次性提交的字段 → 非受控
  const bioRef = useRef(null);
  
  // 文件上传 → 只能非受控
  const fileInputRef = useRef(null);

  const isValid = username.length >= 3;

  return (
    <form onSubmit={(e) => {
      e.preventDefault();
      submit({
        username,
        bio: bioRef.current?.value,
        avatar: fileInputRef.current?.files[0]
      });
    }}>
      
      {/* 受控 */}
      <input
        value={username}
        onChange={e => setUsername(e.target.value)}
        placeholder="Username (min 3 chars)"
      />
      {!isValid && <span style={{ color: 'red' }}>Too short!</span>}
      
      {/* 非受控 */}
      <textarea ref={bioRef} defaultValue="Tell us about yourself..." />
      
      {/* 文件（必须非受控） */}
      <input type="file" ref={fileInputRef} accept="image/*" />
      
      <button type="submit" disabled={!isValid}>Submit</button>
    </form>
  );
}
```

## 5. 高级场景

### 5.1 受控组件的性能优化

对于大型表单（数十个字段），每个字段的 `onChange` 都触发 `setState` 可能造成性能问题：

```jsx
// 方案1：合并状态为单个对象，减少 setState 调用
const [form, setForm] = useState({ a: '', b: '', c: '' });
const updateField = (field, value) => setForm(prev => ({ ...prev, [field]: value }));

// 方案2：防抖（适用于搜索类输入）
const [search, setSearch] = useState('');
const debouncedSearch = useDebounce(search, 300);
useEffect(() => { fetchResults(debouncedSearch); }, [debouncedSearch]);

// 方案3：使用 useReducer 管理复杂表单状态
function formReducer(state, action) {
  switch (action.type) {
    case 'FIELD_CHANGE':
      return { ...state, [action.field]: action.value };
    case 'RESET':
      return initialState;
    default:
      return state;
  }
}
```

### 5.2 非受控组件获取值的时机

```jsx
function UncontrolledWithValidation() {
  const emailRef = useRef(null);
  const [error, setError] = useState('');

  const validateAndSubmit = (e) => {
    e.preventDefault();
    const email = emailRef.current?.value;
    
    if (!email || !email.includes('@')) {
      setError('Please enter a valid email');
      emailRef.current?.focus();
      return;
    }
    
    setError('');
    submitEmail(email);
  };

  return (
    <form onSubmit={validateAndSubmit}>
      <input type="email" ref={emailRef} defaultValue="" />
      {error && <span style={{ color: 'red' }}>{error}</span>}
      <button type="submit">Subscribe</button>
    </form>
  );
}
```

## 6. 总结

```
┌──────────────────────────────────────────────────┐
│         受控 vs 非受控速查                         │
├──────────────────────────────────────────────────┤
│ 受控: value + onChange + state                    │
│   → React 完全控制                                │
│   → 适合: 校验、联动、实时反馈                    │
│                                                  │
│ 非受控: ref / defaultValue                      │
│   → DOM 自己管理                                 │
│   → 适合: 一次性提交、文件上传、第三方库集成       │
│                                                  │
│ 文件 input[type=file] 只能是非受控的             │
│ 同一表单中可以混合使用两种模式                    │
└──────────────────────────────────────────────────┘
```
