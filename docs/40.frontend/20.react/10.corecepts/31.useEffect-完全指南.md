# useEffect 完全指南

## 1. 什么是 useEffect

`useEffect` 让你在函数组件中执行**副作用（Side Effects）**——即在渲染之外的操作：

- 数据获取（fetch/AJAX）
- 手动 DOM 操作
- 定时器（setTimeout/setInterval）
- 订阅事件（WebSocket、addEventListener）
- 日志记录

## 2. 基础用法

```jsx
import { useEffect, useState } from 'react';

function DataFetcher({ url }) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    // effect body：副作用操作
    let ignore = false;

    fetch(url)
      .then(res => res.json())
      .then(json => {
        if (!ignore) {       // 防止组件卸载后的状态更新
          setData(json);
          setLoading(false);
        }
      });

    // cleanup function：清理副作用
    return () => {
      ignore = true;  // 标记忽略后续的异步操作
    };
  }, [url]);  // dependency array：决定何时重新执行 effect

  if (loading) return <LoadingSpinner />;
  return <pre>{JSON.stringify(data)}</pre>;
}
```

## 3. 依赖数组机制

依赖数组决定了 **effect 何时重新执行**：

```jsx
useEffect(() => {
  // effect code
}, [deps]);  // 依赖数组
```

| 依赖数组 | 行为 |
|----------|------|
| `[]` | **仅在挂载时执行一次**（类似 componentDidMount） |
| `[a, b]` | **a 或 b 变化时执行**（类似 componentDidUpdate） |
| **省略**（不传） | **每次渲染都执行**（极少使用！） |

### 3.1 不同依赖的效果对比

```jsx
function Demo({ userId, theme }) {
  
  // 1. 仅挂载执行一次
  useEffect(() => {
    console.log('Mounted once');
  }, []);

  // 2. userId 变化时执行
  useEffect(() => {
    console.log(`Fetch user ${userId}`);
    fetchUser(userId);
  }, [userId]);

  // 3. 多个依赖：任一变化就执行
  useEffect(() => {
    document.body.className = theme;
  }, [theme]);  // 注意：这里只需要 theme，不需要 userId

  // 4. 无依赖数组：每次渲染都执行
  useEffect(() => {
    console.log('Rendered');
  });  // ⚠️ 通常不是你想要的

  // 5. 空依赖 + cleanup = mount/unmount
  useEffect(() => {
    const timer = setInterval(tick, 1000);
    return () => clearInterval(timer);  // unmount 时清理
  }, []);
}
```

## 4. Cleanup 函数

Cleanup 在**下一次 effect 执行前**或**组件卸载前**运行：

```jsx
function ChatRoom({ roomId }) {
  useEffect(() => {
    const connection = createConnection(roomId);

    connection.connect();           // setup
    console.log(`📡 Connected to ${roomId}`);

    return () => {                  // cleanup
      connection.disconnect();
      console.log(`❌ Disconnected from ${roomId}`);
    };
  }, [roomId]);

  return <h1>Welcome to room {roomId}!</h1>;
}
```

**生命周期对应关系**：

```
组件挂载:
  → effect 执行 (setup)

roomId 从 'general' 变为 'music':
  → cleanup for 'general' (断开 general 连接)
  → effect 执行 for 'music' (建立 music 连接)

组件卸载:
  → cleanup 执行 (断开当前连接)
```

### 4.1 Cleanup 的典型用途

| 场景 | Setup | Cleanup |
|------|-------|---------|
| 定时器 | `setInterval()` | `clearInterval()` |
| 网络请求 | `fetch()` / AbortController | `controller.abort()` |
| WebSocket | `new WebSocket()` | `ws.close()` |
| DOM 事件 | `addEventListener()` | `removeEventListener()` |
| 第三方库 | `new Chart()` / `new Map()` | `.destroy()` |
| 订阅 | `store.subscribe()` | `store.unsubscribe()` |
| 动画 | `requestAnimationFrame()` | `cancelAnimationFrame()` |

## 5. 执行时机

```
渲染阶段 (Rendering):
  React 调用你的组件函数 → 返回 JSX

提交阶段 (Commit):
  React 将更改写入 DOM

  ┌──────────────────────────────────────┐
  │ 浏览器绑制屏幕 (Paint)               │
  │                                      │
  │  useLayoutEffect (同步，绑制前执行)   │ ← 阻塞绘制
  │                                      │
  │  ████████████████████ 屏幕更新        │
  │                                      │
  │  useEffect (异步，绑制后执行)         │ ← 不阻塞绘制
  └──────────────────────────────────────┘
```

| Hook | 执行时机 | 适用场景 |
|------|---------|---------|
| `useEffect` | 浏览器**绑制后**（异步） | 大多数副作用 |
| `useLayoutEffect` | 浏览器**绑制前**（同步） | DOM 测量、防止闪烁 |
| `useInsertionEffect` | DOM **变更前**（CSS-in-JS） | 注入 `<style>` 标签 |

## 6. 常见模式

### 6.1 数据获取（带竞态保护）

```jsx
function UserProfile({ userId }) {
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    let cancelled = false;

    async function loadUser() {
      try {
        setLoading(true);
        const res = await fetch(`/api/users/${userId}`);
        const data = await res.json();
        
        if (!cancelled) {  // 竞态保护
          setUser(data);
        }
      } catch (err) {
        if (!cancelled) {
          console.error(err);
        }
      } finally {
        if (!cancelled) {
          setLoading(false);
        }
      }
    }

    loadUser();

    return () => { cancelled = true; };  // 清理：标记取消
  }, [userId]);

  if (loading) return <Skeleton />;
  if (!user) return <Error />;
  return <UserCard user={user} />;
}
```

### 6.2 轮询

```jsx
function StockPrice({ symbol }) {
  const [price, setPrice] = useState(null);

  useEffect(() => {
    async function poll() {
      const res = await fetch(`/api/price/${symbol}`);
      const data = await res.json();
      setPrice(data.price);
    }

    poll();                    // 立即执行一次
    const id = setInterval(poll, 5000);  // 每 5 秒轮询

    return () => clearInterval(id);
  }, [symbol]);

  return <span>${price}</span>;
}
```

### 6.3 防抖搜索

```jsx
function SearchBox() {
  const [query, setQuery] = useState('');
  const [results, setResults] = useState([]);

  useEffect(() => {
    // 防抖效果：延迟执行
    const timer = setTimeout(async () => {
      if (query.trim()) {
        const res = await fetch(`/api/search?q=${query}`);
        const data = await res.json();
        setResults(data);
      } else {
        setResults([]);
      }
    }, 300);

    return () => clearTimeout(timer);  // 用户继续输入时清除上一个定时器
  }, [query]);  // 每次 query 变化都会先清除之前的定时器

  return (
    <div>
      <input value={query} onChange={e => setQuery(e.target.value)} />
      <ul>
        {results.map(item => <li key={item.id}>{item.title}</li>)}
      </ul>
    </div>
  );
}
```

### 6.4 监听浏览器事件

```jsx
function WindowSize() {
  const [size, setSize] = useState({
    width: window.innerWidth,
    height: window.innerHeight
  });

  useEffect(() => {
    function handleResize() {
      setSize({
        width: window.innerWidth,
        height: window.innerHeight
      });
    }

    window.addEventListener('resize', handleResize);
    return () => window.removeEventListener('resize', handleResize);
  }, []);  // 空依赖：只在挂载/卸载时执行

  return <span>{size.width} x {size.height}</span>;
}
```

### 6.5 document.title 同步

```jsx
function DocumentTitle({ title }) {
  useEffect(() => {
    const previousTitle = document.title;
    
    document.title = typeof title === 'string'
      ? title
      : `${title.prefix} — ${title.suffix}`;

    return () => {
      document.title = previousTitle;  // 恢复原标题
    };
  }, [title]);  // title 变化时更新

  return children;
}
```

## 7. 依赖数组的常见错误

### 7.1 遗漏依赖

```jsx
// ❌ 遗漏了 options 依赖
useEffect(() => {
  fetchData(url, options);  // 用到了 options 但没放入依赖
}, [url]);

// ✅ 正确：包含所有 effect 内部使用的响应式变量
useEffect(() => {
  fetchData(url, options);
}, [url, options]);
```

> **ESLint 规则**：安装 `eslint-plugin-react-hooks` 并启用 `exhaustive-deps` 规则，自动检测遗漏的依赖。

### 7.2 过度依赖导致的无限循环

```jsx
// ❌ 无限循环：effect 改变了依赖中的变量
useEffect(() => {
  setCount(count + 1);  // 触发重渲染
}, [count]);  // count 变化又触发 effect...

// ✅ 正确做法：如果确实需要在 effect 中触发状态更新，
// 确保有退出条件或使用不同的状态管理方式
useEffect(() => {
  if (someCondition) {
    setCount(c => c + 1);  // 有条件地更新
  }
}, [someCondition]);  // 依赖的是条件而非被更新的状态
```

### 7.3 对象/数组依赖的处理

```jsx
// ⚠️ 问题：每次渲染都创建新的对象/函数引用
useEffect(() => {
  subscribe(options);
  return () => unsubscribe(options);
}, [options]);  // 如果 options 是每次渲染新建的对象 → 每次都执行！

// ✅ 解决方案1：用 JSON.stringify 作为依赖（仅用于简单对象）
useEffect(() => {
  // ...
}, [JSON.stringify(options)]);

// ✅ 解决方案2：提取具体的基元值作为依赖
useEffect(() => {
  subscribe(userId, page, pageSize);
}, [userId, page, pageSize]);  // 这些通常是稳定的基本类型

// ✅ 解决方案3：用 useRef 存储最新的值
const optionsRef = useRef(options);
optionsRef.current = options;  // 始终保持最新

useEffect(() => {
  subscribe(optionsRef.current);
}, []);  // 但只在挂载时执行一次...需要权衡
```

## 8. useEffect vs 其他 Effect Hooks

| Hook | 用途 | 特点 |
|------|------|------|
| `useEffect` | 大多数副作用 | 异步，不阻塞绘制 |
| `useLayoutEffect` | DOM 测量/操作 | 同步，阻塞绘制 |
| `useInsertionEffect` | CSS-in-JS | DOM 变更前执行 |
| `useSyncExternalStore` | 外部 store 订阅 | 支持 concurrent mode |

## 9. 总结

```
┌──────────────────────────────────────────────────┐
│         useEffect 要点速查                         │
├──────────────────────────────────────────────────┤
│ 用途: 数据获取、订阅、DOM 操作等副作用            │
│ 依赖 [] : 仅挂载时执行一次                        │
│ 依赖 [a,b]: a 或 b 变化时执行                     │
│ cleanup: 下次 effect 前或卸载时执行               │
│ 执行时机: 浏览器绑制后（异步）                    │
│ 竞态保护: 用 cancelled flag                      │
│ ESLint: exhaustive-deps 规则必开                 │
│ 避免遗漏依赖: 所有使用的响应式变量都要列入         │
└──────────────────────────────────────────────────┘
```
