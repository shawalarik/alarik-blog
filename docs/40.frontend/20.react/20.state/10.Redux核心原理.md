# Redux 核心原理

## 1. 三大原则

Redux 遵循三个核心设计原则：

```
┌─────────────────────────────────────────────────────┐
│              Redux 三大原则                          │
│                                                     │
│  ① Single Source of Truth (单一数据源)             │
│     整个应用的 state 存储在一个 object tree 中      │
│     这个 object tree 只存在于唯一的 store 中        │
│                                                     │
│ ② State is Read-Only (状态只读)                    │
│     唯一改变 state 的方式是触发 action               │
│     action 是一个描述发生了什么的普通对象            │
│                                                     │
│ ③ Changes are Made with Pure Functions (纯函数修改)  │
│     为了描述 action 如何改变 state tree              │
│     你需要编写纯函数 reducers                      │
│     (same input → same output, no side effects)     │
└─────────────────────────────────────────────────────┘
```

## 2. 核心概念

### 2.1 Action

描述"发生了什么"的普通对象：

```js
// 标准 Action 结构（FSA: Flux Standard Action）
{
  type: 'todos/add',       // 必填：字符串常量，唯一标识动作
  payload: { text: 'Learn Redux' },  // 可选：负载数据
  meta: { timestamp: Date.now() },   // 可选：元信息
  error: false                     // 可选：是否为错误
}
```

**Action Creator** —— 创建 action 的工厂函数：

```js
// 同步 action creator
function addTodo(text) {
  return {
    type: 'todos/add',
    payload: { text, id: nanoid(), completed: false },
  };
}

// 使用
dispatch(addTodo('Learn Redux'));
```

### 2.2 Reducer

**纯函数**，接收旧 state 和 action，返回新 state：

```js
// (previousState, action) => newState

const initialState = {
  entities: {},
  ids: [],
  status: 'idle',
  error: null,
};

function todosReducer(state = initialState, action) {
  switch (action.type) {
    case 'todos/add':
      const { id, text } = action.payload;
      return {
        ...state,
        entities: { ...state.entities, [id]: { id, text, completed: false } },
        ids: [...state.ids, id],
      };

    case 'todos/toggle':
      const { id: toggleId } = action.payload;
      return {
        ...state,
        entities: {
          ...state.entities,
          [toggleId]: {
            ...state.entities[toggleId],
            completed: !state.entities[toggleId].completed,
          },
        },
      };

    case 'todos/delete':
      const { id: deleteId } = action.payload;
      const { [deleteId]: removed, ...remainingEntities } = state.entities;
      return {
        ...state,
        entities: remainingEntities,
        ids: state.ids.filter(id => id !== deleteId),
      };

    default:
      return state;
  }
}
```

**Reducer 的规则**：

| 规则 | 说明 | 违反后果 |
|------|------|---------|
| 纯函数 | 相同输入必定产生相同输出 | 不可预测的行为 |
| 不可变 | 不能修改原 state | 状态污染、视图不更新 |
| 无副作用 | 不能做 API 调用、路由跳转等 | 测试困难、时间旅行调试失效 |
| 默认返回原 state | `default: return state` | 未匹配 action 时 state 变为 undefined |

### 2.3 Store

**持有整个 application state tree**的对象：

```js
import { createStore } from 'redux';

const store = createStore(todosReducer);

// Store 提供的方法：
store.getState();           // 获取当前 state
store.dispatch(action);     // 发送 action
store.subscribe(listener);  // 注册监听器
store.replaceReducer(nextReducer); // 替换 reducer（热加载用）
```

**Store 内部简化模型**：

```
Store 内部结构:
{
  currentReducer: todosReducer,   // 当前的 root reducer
  currentState: {},               // 当前的 state tree
  listeners: [],                  // 订阅者回调数组
  isDispatching: false,           // 是否正在 dispatching

  getState() { return currentState; },
  
  dispatch(action) {
    if (isDispatching) throw Error("Cannot dispatch while dispatching");
    
    isDispatching = true;
    try {
      currentState = currentReducer(currentState, action);  // 核心！
    } finally {
      isDispatching = false;
    }
    
    listeners.forEach(listener => listener());  // 通知所有订阅者
    return action;
  },
  
  subscribe(listener) {
    listeners.push(listener);
    return function unsubscribe() { /* 移除 listener */ };
  }
}
```

## 3. combineReducers —— 合并 Reducer

```js
import { combineReducers } from 'redux';

const rootReducer = combineReducers({
  todos: todosReducer,       // state.todos
  filter: filterReducer,     // state.filter
  user: userReducer,         // state.user
});

// 等价于手动实现：
function rootReducer(state = {}, action) {
  return {
    todos: todosReducer(state.todos, action),  // 只传入自己的 slice
    filter: filterReducer(state.filter, action),
    user: userReducer(state.user, action),
  };
}

// 每个 reducer 只负责自己那片 state（slice）
// action 会传递给所有 reducer（每个 reducer 都有机会响应同一个 action）
```

## 4. 中间件（Middleware）

中间件是**在 action 到达 reducer 之前**执行的函数链：

```
正常流程:
  View → dispatch(action) → Reducer → State change → Re-render

带中间件的流程:
  View → dispatch(action)
    → Middleware 1 (如 logger: 打印 action)
    → Middleware 2 (如 thunk: 处理异步)
    → Middleware 3 (如 crash reporter)
    → Reducer → State change → Re-render
```

### 4.1 中间件的签名

```js
// middleware = storeAPI => next => action => result
const loggerMiddleware = storeAPI => next => action => {
  console.log('dispatching', action);
  let result = next(action);  // 传递给下一个中间件/reducer
  console.log('next state', storeAPI.getState());
  return result;
};
```

### 4.2 applyMiddleware

```js
import { createStore, applyMiddleware, compose } from 'redux';

const store = createStore(
  rootReducer,
  applyMiddleware(
    loggerMiddleware,      // 日志
    thunkMiddleware,       // 异步
    crashReporter         // 错误上报
  )
);

// applyMiddleware(m1, m2, m3)
// 执行顺序: m1 → m2 → m3 → reducer
// 但每个 middleware 的 next 是"包装后的下一个"
// 所以 action 经过 middleware 的顺序是 m1 → m2 → m3
// 而 next(action) 的调用是从里到外执行
```

### 4.3 Redux Thunk —— 异步 Action

默认情况下 Redux 只支持同步 action。Thunk 中间件让 dispatch 可以接受函数：

```js
// 普通 dispatch：只能接收普通对象
dispatch({ type: 'todos/fetch/start' });

// Thunk dispatch：可以接收函数
const fetchTodos = () => async (dispatch, getState) => {
  dispatch({ type: 'todos/fetch/start' });
  
  try {
    const res = await fetch('/api/todos');
    const data = await res.json();
    dispatch({ type: 'todos/fetch/success', payload: data });
  } catch (err) {
    dispatch({ type: 'todos/fetch/error', payload: err.message });
  }
};

// 使用
dispatch(fetchTodos());  // dispatch 了一个 thunk 函数
```

## 5. React-Redux 绑定

Redux 本身与框架无关。要在 React 中使用，需要 `react-redux`：

```jsx
import { Provider, useSelector, useDispatch } from 'react-redux';

// 1. 顶层的 Provider 注入 store
<Provider store={store}>
  <App />
</Provider>

// 2. useSelector —— 从 store 中提取数据
function TodoList() {
  const todos = useSelector(state => state.todos.entities);
  // 只有返回值变化时才触发重渲染（=== 比较）
  
  const ids = useSelector(state => state.todos.ids);
  // 可以多次 useSelector 取不同 slice

  return (
    <ul>
      {ids.map(id => (
        <li key={id}>{todos[id].text}</li>
      ))}
    </ul>
  );
}

// 3. useDispatch —— 获取 dispatch 函数
function AddTodoInput() {
  const dispatch = useDispatch();
  const [text, setText] = useState('');

  const handleSubmit = (e) => {
    e.preventDefault();
    if (!text.trim()) return;
    dispatch(addTodo(text));
    setText('');
  };

  return (
    <form onSubmit={handleSubmit}>
      <input value={text} onChange={(e) => setText(e.target.value)} />
    </form>
  );
}
```

**connect（类组件/HOC 方式，已不推荐用于新代码）**：

```jsx
// 旧写法（了解即可）
import { connect } from 'react-redux';

function TodoList({ todos, addTodo }) {
  // ...
}

const mapStateToProps = (state) => ({
  todos: state.todos.entities,
});

const mapDispatchToProps = {
  addTodo,
};

export default connect(mapStateToProps, mapDispatchToProps)(TodoList);
```

## 6. 数据流全景

```
┌─────────────────────────────────────────────────────┐
│                 Redux 数据流                          │
│                                                     │
│   ┌──────────┐                                     │
│   │  View    │  React Component                     │
│   │ (React)  │                                     │
│   └────┬─────┘                                     │
│        │ dispatch(action)                           │
│        ▼                                            │
│   ┌──────────────────────────────┐                  │
│   │        Middleware Chain       │                  │
│   │                               │                  │
│   │  Logger → Thunk → CrashReport│                  │
│   └──────────────┬────────────────┘                  │
│                  │                                   │
│                  ▼                                   │
│   ┌──────────────────────────────┐                  │
│   │          Root Reducer        │                  │
│   │                               │                  │
│   │  combineReducer:              │                  │
│   │    todos: todosReducer       │                  │
│   │    user: userReducer         │                  │
│   │    ...                        │                  │
│   └──────────────┬────────────────┘                  │
│                  │ returns newState                │
│                  ▼                                   │
│   ┌──────────────────────────────┐                  │
│   │           Store               │                  │
│   │  state updated               │                  │
│   │  notify subscribers          │                  │
│   └──────────────┬────────────────┘                  │
│                  │                                   │
│                  ▼                                   │
│   ┌──────────┐   useSelector triggers re-render     │
│   │  View    │ ◄───────────────────────────────────│
│   │ (React)  │                                      │
│   └──────────┘                                      │
│                                                     │
│   单向数据流: View → Action → Reducer → Store → View│
└─────────────────────────────────────────────────────┘
```

## 7. 总结

```
┌──────────────────────────────────────────────────┐
│         Redux 核心要点速查                         │
├──────────────────────────────────────────────────┤
│ 三原则: 单一数据源 / 只读 / 纯函数修改             │
│ Action: { type, payload? } 描述"发生了什么"       │
│ Reducer: (state, action) => newState 纯函数        │
│ Store: getState / dispatch / subscribe             │
│ combineReducers: 拆分 reducer 管理不同 state 片段     │
│ Middleware: action → reducer 之间的拦截器          │
│ Thunk: 让 dispatch 支持异步函数                    │
│ React-Redux: Provider / useSelector / useDispatch   │
│ 数据流: 单向循环 View → Action → Store → View     │
└──────────────────────────────────────────────────┘
```
