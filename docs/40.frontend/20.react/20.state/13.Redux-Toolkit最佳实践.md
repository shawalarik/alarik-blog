# Redux Toolkit (RTK) 最佳实践

## 1. 为什么需要 Redux Toolkit？

传统 Redux 的痛点：

| 痛点 | 传统 Redux | RTK 解决方案 |
|------|-----------|-------------|
| 大量样板代码 | 手写 action types、creators、switch-case | `createSlice` 一站式生成 |
| 复杂的 store 配置 | 手动组合 enhancers/middlewares | `configureStore` 开箱即用 |
| immutable 更新冗长 | 手动 spread 操作 | Immer 内置，可直接"修改" |
| 异步处理繁琐 | thunks 写法啰嗦 | `createAsyncThunk` + 自动 pending/fulfilled/rejected |
| 开发体验差 | 需手动配置 devtools/logger | 自动集成 Redux DevTools + serializable-check |
| Selector 性能 | 需手写记忆化 | 内置 `createSelector`（reselect） |

## 2. configureStore —— 配置 Store

```ts
// store.ts
import { configureStore } from '@reduxjs/toolkit';
import todosReducer from './features/todos/todosSlice';
import userReducer from './features/users/userSlice';
import { apiSlice } from './services/apiSlice';

export const store = configureStore({
  reducer: {
    todos: todosReducer,
    users: userReducer,
    [apiSlice.reducerPath]: apiSlice.reducer,  // RTK Query
  },
  middleware: (getDefaultMiddleware) =>
    getDefaultMiddleware()
      .concat(apiSlice.middleware),  // 添加 RTK Query 中间件

  devTools: process.env.NODE_ENV !== 'production',
});

// 类型推断
export type RootState = ReturnType<typeof store.getState>;
export type AppDispatch = typeof store.dispatch;

// 类型安全的 hooks
export const useAppDispatch = () => useDispatch<AppDispatch>();
export const useAppSelector: TypedUseSelectorHook<RootState> = useSelector;
```

**`configureStore` 自动包含的中间件**：

```
getDefaultMiddleware() 自动启用:
  1. redux-thunk          (异步 action)
  2. immer                (不可变更新，允许直接"修改")
  3. serializable-check   (开发环境检测非序列化值)
  4. redux-devtools        (开发环境自动连接)
```

## 3. createSlice —— 现代 Reducer 编写

```ts
// features/todos/todosSlice.ts
import { createSlice, PayloadAction } from '@reduxjs/toolkit';

interface Todo {
  id: string;
  text: string;
  completed: boolean;
  createdAt: number;
}

interface TodosState {
  items: Record<string, Todo>;
  ids: string[];
  status: 'idle' | 'loading' | 'succeeded' | 'failed';
  error: string | null;
}

const initialState: TodosState = {
  items: {},
  ids: [],
  status: 'idle',
  error: null,
};

const todosSlice = createSlice({
  name: 'todos',
  initialState,

  // ✅ 定义 reducers（同步操作）
  // Immer 让你可以像修改一样写"不可变更新"
  reducers: {
    addTodo: {
      reducer(state, action: PayloadAction<string>) {
        const id = nanoid();
        state.items[id] = {
          id,
          text: action.payload,
          completed: false,
          createdAt: Date.now(),
        };
        state.ids.push(id);
      },
      prepare(text: string) {
        // prepare: 预处理 payload（可选）
        return { payload: text.trim() };
      },
    },

    toggleTodo(state, action: PayloadAction<string>) {
      const todo = state.items[action.payload];
      if (todo) {
        todo.completed = !todo.completed;  // Immer: 看起来像 mutation!
      }
    },

    deleteTodo(state, action: PayloadAction<string>) {
      delete state.items[action.payload];       // Immer
      state.ids = state.ids.filter(id => id !== action.payload);  // Immer
    },

    clearCompleted(state) {
      for (const id of state.ids) {
        if (state.items[id]?.completed) {
          delete state.items[id];
        }
      }
      state.ids = state.ids.filter(id => state.items[id]);
    },
  },

  // ✅ 定义 extraReducers（外部 action）
  extraReducers: (builder) => {
    builder
      .addCase(fetchTodos.pending, (state) => {
        state.status = 'loading';
        state.error = null;
      })
      .addCase(fetchTodos.fulfilled, (state, action) => {
        state.status = 'succeeded';
        // normalize data
        state.items = {};
        state.ids = [];
        for (const todo of action.payload) {
          state.items[todo.id] = todo;
          state.ids.push(todo.id);
        }
      })
      .addCase(fetchTodos.rejected, (state, action) => {
        state.status = 'failed';
        state.error = action.error.message || 'Failed to fetch';
      });
  },
});

// 导出 actions（自动生成）
export const { addTodo, toggleTodo, deleteTodo, clearCompleted } = todosSlice.actions;

// 导出 async thunk
export const fetchTodos = createAsyncThunk('todos/fetchAll', async () => {
  const response = await fetch('/api/todos');
  if (!response.ok) throw new Error('Network error');
  return (await response.json()) as Todo[];
});

export default todosSlice.reducer;
```

**createSlice 生成的产物**：

```
name: 'todos'
  ↓
自动生成的 action creators:
  todos/addTodo(payload)     → { type: 'todos/addTodo', payload }
  todos/toggleTodo(payload)  → { type: 'todos/toggleTodo', payload }
  todos/deleteTodo(payload)  → { type: 'todos/deleteTodo', payload }

自动生成的 reducer:
  todosReducer(currentState, action) → nextState

extraReducers 处理 createAsyncThunk 的 lifecycle actions:
  todos/fetchAll/pending
  todos/fetchAll/fulfilled
  todos/fetchAll/rejected
```

## 4. createAsyncThunk —— 异步操作

```ts
import { createAsyncThunk } from '@reduxjs/toolkit';

// 基本语法
const fetchData = createAsyncThunk(
  'data/fetch',                                    // action type prefix
  async (arg: { userId: string }, { rejectWithValue }) => {
    // async payload creator
    try {
      const res = await fetch(`/api/users/${arg.userId}`);
      if (!res.ok) {
        const errData = await res.json().catch(() => ({}));
        return rejectWithValue(errData.message || 'Request failed');
      }
      return await res.json();  // fulfilled value
    } catch (err) {
      return rejectWithValue(err instanceof Error ? err.message : String(err));
    }
  }
);
```

**三个 lifecycle action**：

| Action Type | 触发时机 | State 通常设置 |
|------------|---------|---------------|
| `${prefix}/pending` | 开始请求 | `status: 'loading'`, 清除旧 error |
| `${prefix}/fulfilled` | 请求成功 | `status: 'succeeded'`, 存入数据 |
| `${prefix}/rejected` | 请求失败 | `status: 'failed'`, 存储 error |

**使用方式**：

```tsx
function UserProfile({ userId }: { userId: string }) {
  // 自动派发 thunk
  const dispatch = useAppDispatch();
  
  useEffect(() => {
    dispatch(fetchData({ userId }));
  }, [userId, dispatch]);

  // 读取状态
  const { status, data, error } = useAppSelector(state => state.data);

  if (status === 'loading') return <Skeleton />;
  if (status === 'failed') return <ErrorDisplay error={error} onRetry={() => dispatch(fetchData({ userId }))} />;
  
  return <Card data={data} />;
}
```

## 5. RTK Query —— 数据获取与缓存

RTK Query 是 Redux Toolkit 内置的服务端数据管理方案：

```ts
// services/apiSlice.ts
import { createApi, fetchBaseQuery } from '@reduxjs/toolkit/query/react';

export const apiSlice = createApi({
  reducerPath: 'api',
  baseQuery: fetchBaseQuery({ baseUrl: '/api' }),
  
  tagTypes: ['Post', 'User'],  // 缓存标签系统

  endpoints: (builder) => ({
    // Query（GET 类请求）
    getPosts: builder.query<Post[], void>({
      query: () => '/posts',
      providesTags: ['Post'],  // 缓存标签
    }),

    getPostById: builder.query<Post, string>({
      query: (id) => `/posts/${id}`,
      providesTags: (_result, _error, id) => [{ type: 'Post', id }],
    }),

    // Mutation（POST/PUT/DELETE 类请求）
    createPost: builder.mutation<Post, Partial<Post>>({
      query: (newPost) => ({
        url: '/posts',
        method: 'POST',
        body: newPost,
      }),
      invalidatesTags: ['Post'],  // 创建后使 Post 缓存失效
    }),

    updatePost: builder.mutation<Post, { id: string; changes: Partial<Post> }>({
      query: ({ id, changes }) => ({
        url: `/posts/${id}`,
        method: 'PATCH',
        body: changes,
      }),
      invalidatesTags: (_result, _error, arg) => [
        { type: 'Post', id: arg.id },
      ],
    }),

    deletePost: builder.mutation<void, string>({
      query: (id) => ({ url: `/posts/${id}`, method: 'DELETE' }),
      invalidatesTags: ['Post'],
    }),
  }),
});

// 自动生成的 hooks
export const {
  useGetPostsQuery,        // GET → { data, isLoading, error, refetch }
  useGetPostByIdQuery,     // GET single
  useCreatePostMutation,   // POST → [trigger, { isLoading, reset }]
  useUpdatePostMutation,   // PATCH
  useDeletePostMutation,   // DELETE
  util: { invalidateTags }, // programmatic cache invalidation
} = apiSlice;
```

**在组件中使用**：

```tsx
function PostsList() {
  const { data: posts, isLoading, isError, error, refetch } = useGetPostsQuery();
  const [createPost, { isLoading: isCreating }] = useCreatePostMutation();

  if (isLoading) return <LoadingSpinner />;
  if (isError) return <ErrorMessage error={error} onRetry={refetch} />;

  return (
    <div>
      <button
        disabled={isCreating}
        onClick={() => createPost({ title: 'New Post', content: '...' })}
      >
        {isCreating ? 'Creating...' : 'Create Post'}
      </button>

      <ul>
        {posts?.map(post => (
          <PostItem key={post.id} post={post} />
        ))}
      </ul>
    </div>
  );
}

// RTK Query 自动处理：
// ✅ 缓存（相同参数复用结果，避免重复请求）
// ✅ 去重（同一参数并发请求只发一次）
// ✅ 轮询/重新聚焦窗口时自动刷新
// ✅ 乐观更新支持
// ✅ 分页/无限滚动
// ✅ 缓存生命周期管理（gcTime / staleTime）
```

## 6. createSelector —— 记忆化选择器

```ts
import { createSelector } from '@reduxjs/toolkit';

// 基本 usage
const selectTodos = (state: RootState) => state.todos.items;
const selectFilter = (state: RootState) => state.todos.filter;

// 派生 selector（记忆化的）
const selectFilteredTodos = createSelector(
  [selectTodos, selectFilter],  // input selectors
  (todos, filter) => {
    switch (filter) {
      case 'active': return Object.values(todos).filter(t => !t.completed);
      case 'completed': return Object.values(todos).filter(t => t.completed);
      default: return Object.values(todos);
    }
  }
);

const selectStats = createSelector(
  [selectFilteredTodos],
  (filtered) => ({
    total: filtered.length,
    active: filtered.filter(t => !t.completed).length,
    completed: filtered.filter(t => t.completed).length,
  })
);

// 使用
function TodoStats() {
  // selectStats 只有当输入 selectors 的返回值变化时才重新计算
  const stats = useAppSelector(selectStats);
  return (
    <footer>Total: {stats.total} | Active: {stats.active} | Done: {stats.completed}</footer>
  );
}
```

## 8. 总结

```
┌──────────────────────────────────────────────────┐
│      Redux Toolkit 要点速查                       │
├──────────────────────────────────────────────────┤
│ configureStore: 一行配置 store（含 devTools/thunk） │
│ createSlice: reducers + actions + asyncThunks     │
│ Immer: 内置支持，可直接"修改" state              │
│ createAsyncThunk: pending/fulfilled/rejected      │
│ RTK Query: 内置数据缓存、去重、自动刷新          │
│ createSelector: reselect 记忆化选择器              │
│ 目录: store/features/ 按功能模块组织             │
│ 推荐: 新 Redux 项目首选 RTK，不再手写样板代码     │
└──────────────────────────────────────────────────┘
```
