# Zustand —— 轻量级原子化状态管理

## 1. 为什么 Zustand？

Zustand（德语 "state"）是目前 React 社区最流行的轻量级状态库之一：

```
Zustand 的核心卖点:

✅ 极简 API — create() 一个函数搞定一切
✅ 零 Boilerplate — 不需要 Provider、action types、reducers
✅ 极小包体 — gzip 后 ~1.5KB（对比 Redux 全家桶 ~45KB+）
✅ 内置优化 — selector 模式自动避免不必要的重渲染
✅ 并发安全 — 完美支持 React 18 Concurrent Mode
✅ 中间件生态 — persist / devtools / immer / temporal 等
✅ TypeScript 一等公民 — 类型推断开箱即用
✅ 服务端友好 — SSR / Next.js 支持良好
✅ 无需 Context — 不受 Context 性能陷阱影响
```

## 2. 快速开始

### 2.1 基本 Store

```ts
import { create } from 'zustand';

// 定义 Store
interface BearState {
  bears: number;
  increase: (by?: number) => void;
  decrease: () => void;
  reset: () => void;
}

const useBearStore = create<BearState>((set) => ({
  bears: 0,

  increase: (by = 1) => set((state) => ({ bears: state.bears + by })),
  decrease: () => set((state) => ({ bears: state.bears - 1 })),
  reset: () => set({ bears: 0 }),
}));

// 使用 — 就像 useState 一样简单！
function BearCounter() {
  const bears = useBearStore((s) => s.bears);       // 选择特定 slice
  const increase = useBearStore((s) => s.increase);   // 选择方法

  return (
    <div>
      Bears: {bears}
      <button onClick={() => increase(1)}>+1</button>
      <button onClick={() => increase(5)}>+5</button>
    </div>
  );
}
```

### 2.2 对比 Redux Toolkit 的代码量

```ts
// ========== Redux Toolkit ==========
// 1. Slice 文件
const counterSlice = createSlice({
  name: 'counter',
  initialState: { count: 0 },
  reducers: {
    increment: (state) => { state.count += 1; },
    decrement: (state) => { state.count -= 1; },
  },
});
export const { increment, decrement } = counterSlice.actions;
export default counterSlice.reducer;

// 2. Store 配置
const store = configureStore({ reducer: { counter: counterReducer } });
type RootState = ReturnType<typeof store.getState>;

// 3. App 包裹 Provider
<Provider store={store}><App /></Provider>

// 4. 组件中使用
const count = useSelector((s: RootState) => s.counter.count);
const dispatch = useDispatch();
dispatch(increment());


// ========== Zustand ==========
// 1. 一行搞定！
const useCountStore = create((set) => ({
  count: 0,
  inc: () => set((s) => ({ count: s.count + 1 })),
  dec: () => set((s) => ({ count: s.count - 1 })),
}));

// 2. 直接用！不需要 Provider！
const count = useCountStore((s) => s.count);
const inc = useCountStore((s) => s.inc);
inc();
```

## 3. 核心 API 详解

### 3.1 create()

```ts
interface StoreApi<T> {
  getState: () => T;           // 获取当前完整 state
  setState: PartialSetter<T>;   // 设置 state
  subscribe: Listener<T>;       // 订阅变更
  getInitialState: () => T;     // 获取初始 state
  // ...
}

const useStore = create<State>()((set, get, api) => ({
  // set: 类似 setState，合并更新
  // get: getState，获取当前值
  // api: Store API 本身（高级用法）
}));
```

**三种 set 写法**：

```ts
create((set) => ({
  // 1. 直接替换
  replace: () => set({ count: 100 }),           // 替换整个 state

  // 2. 合并更新（默认行为）
  merge: () => set({ count: 100 }),            // Object.assign 语义

  // 3. 函数式更新（基于旧值）
  functional: () => set((state) => ({          // 推荐用于依赖旧值的场景
    count: state.count + 1,
  })),
}));
```

### 3.2 Selector 模式 —— 性能关键

```tsx
// ⚠️ 反例：选择整个 state → 任何字段变化都重渲染
const { bears, food, status } = useBearStore();

// ✅ 正确：只选择需要的部分
const bears = useBearStore((state) => state.bears);
// 只有 bears 变化才触发此组件重渲染

// ✅ 浅比较：选择对象时注意引用稳定性
const settings = useBearStore(
  (state) => ({ theme: state.theme, lang: state.lang }),
  shallow  // 使用浅比较（需要导入 shallow）
);
```

### 3.3 getState / setState 在外部使用

```ts
// 在组件外访问/修改 store（非 Hook 场景）
const useAuthStore = create<AuthState>((set) => ({
  user: null,
  token: null,
  login: async (creds) => {
    const res = await authAPI.login(creds);
    set({ user: res.user, token: res.token });
  },
  logout: () => set({ user: null, token: null }),
}));

// 在 axios interceptor 中使用（非 React 环境）：
api.interceptors.response.use(
  (res) => res,
  (err) => {
    if (err.response?.status === 401) {
      useAuthStore.getState().logout();  // 在组件外调用！
    }
    return Promise.reject(err);
  }
);

// 在路由守卫中使用：
router.beforeEach((to) => {
  if (to.meta.requiresAuth && !useAuthStore.getState().token) {
    return '/login';
  }
});
```

## 4. 中间件（Middleware）

### 4.1 persist 中间件 — 状态持久化

```ts
import { persist, createJSONStorage } from 'zustand/middleware';

interface SettingsState {
  theme: 'light' | 'dark' | 'system';
  language: 'en' | 'zh-CN' | 'ja';
  fontSize: number;
  setTheme: (t: SettingsState['theme']) => void;
  setLanguage: (l: SettingsState['language']) => void;
}

const useSettingsStore = create<SettingsState>()(
  persist(
    (set) => ({
      theme: 'system',
      language: 'zh-CN',
      fontSize: 16,

      setTheme: (theme) => set({ theme }),
      setLanguage: (language) => set({ language }),
    }),
    {
      name: 'app-settings',           // localStorage key
      storage: createJSONStorage(() => localStorage),  // 存储引擎
      partialize: (state) => ({       // 只持久化部分字段
        theme: state.theme,
        language: state.language,
        fontSize: state.fontSize,
      }),
      version: 1,                      // 版本号（用于迁移）
      onRehydrateStorage: () => (state) => {
        console.log('Hydrated:', state);
      },
    }
  )
);

// 也支持 sessionStorage / IndexedDB (via idb-keyval)
// import { idbStorage } from 'zustand/middleware/idb';
// storage: idbStorage('my-db'),
```

### 4.2 devtools 中间件

```ts
import { devtools } from 'zustand/middleware';

const useStore = create<State>()(
  devtools(
    (set) => ({ /* ... */ }),
    { name: 'MyAppStore', enabled: process.env.NODE_ENV === 'development' }
  )

// 配合 Redux DevTools 扩展使用！
// 支持 time-travel 调试、状态回放等功能
```

### 4.3 immer 中间件 — 可变风格写法

```ts
import { immer } from 'zustand/middleware/immer';

interface TodoState {
  todos: Record<string, Todo>;
  ids: string[];
  addTodo: (text: string) => void;
  toggleTodo: (id: string) => void;
  deleteTodo: (id: string) => void;
}

const useTodoStore = create<TodoState>()(
  immer((set) => ({
    todos: {},
    ids: [],

    addTodo: (text) =>
      set((state) => {
        const id = crypto.randomUUID();
        state.todos[id] = { id, text, completed: false };
        state.ids.push(id);
      }),

    toggleTodo: (id) =>
      set((state) => {
        if (state.todos[id]) {
          state.todos[id].completed = !state.todos[id].completed;
        }
      }),

    deleteTodo: (id) =>
      set((state) => {
        delete state.todos[id];
        state.ids = state.ids.filter((i) => i !== id);
      }),
  }))
);
```

### 4.4 自定义中间件模板

```ts
import { StateCreator, StoreMutatorIdentifier } from 'zustand';

// 日志中间件
const logger = (config) => (set, get, api) =>
  config(
    (...args) => {
      console.log(`  applying`, args);
      set(...args);
      console.log(`  new state`, get());
    },
    get,
    api
  );

// 组合多个中间件
const useStore = create<LogState>()(
  persist(devtools(logger(immer(/* ... */))), {
    name: 'logged-store',
  })
);
```

## 5. 切片模式（Slices）

当 store 变大时，按功能拆分：

```ts
// slices/userSlice.ts
interface UserSlice {
  user: User | null;
  setUser: (user: User | null) => void;
  logout: () => void;
}
const createUserSlice: StateCreator<
  AppState, [], [], UserSlice
> = (set) => ({
  user: null,
  setUser: (user) => set({ user }, false, 'user/set'),
  logout: () => set({ user: null }, false, 'user/logout'),
});

// slices/todoSlice.ts
interface TodoSlice { /* ... */ }
const createTodoSlice: StateCreator<AppState, [], [], TodoSlice> = (set) => ({
  /* ... */
});

// store.ts — 组合所有切片
const useStore = create<AppState>()((...a) => ({
  ...createUserSlice(...a),
  ...createTodoSlice(...a),
  ...createUISlice(...a),
}));
```

## 6. 与 Next.js / SSR 集成

```ts
// Zustand 天然支持 SSR（无单例问题）
// 因为每次 create() 都会创建新的 store

// 但通常我们希望服务端和客户端共享同一个 store：
let store: AppStore | undefined;

const initializeStore = (preloadedState?: Partial<AppState>) => {
  const _store = store ?? createAppStore(preloadedState);

  // CSR 时复用已有 store
  if (typeof window === 'undefined') return _store;

  if (!store) store = _store;
  return _store;
};
```
