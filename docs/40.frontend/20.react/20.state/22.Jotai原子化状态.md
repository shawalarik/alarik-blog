# Jotai —— 原子化状态管理

## 1. 设计哲学

Jotai（日语"状态"的发音）由 **Poimandres 团队**开发，核心灵感来自 ** Recoil** 和 **MobX**，但更加精简：

```
传统状态管理 vs Jotai:

Redux/Zustand:
  Store (大对象树)
    ├── user
    ├── todos
    ├── settings
    └── notifications
    ↓ 任何一个叶子变化 → 可能影响读取整个树的消费者

Jotai (原子化):
  atom("user") ──────────┐
  atom("userName")  ◄─────┤  derived atom
  atom("todos")     ───────┤
  atom("filteredTodos") ◄─┤  derived atom (依赖 todos + filter)
  atom("theme")      ──────┘

每个 atom 是独立的单元
只有被实际使用的 atom 变化时，组件才会更新
```

**Jotai 的核心理念**：

| 原则 | 说明 |
|------|------|
| **原子化 (Atomicity)** | 最小独立状态单位，不再有"一棵大树" |
| **派生 (Derivation)** | atom 可以基于其他 atom 派生，形成依赖图 |
| **按需渲染** | 只有组件订阅的 atom 变化时才重渲染 |
| **无 Provider** | 不需要顶层 Provider 包裹 |
| **TypeScript 友好** | 原生 TS 支持，类型推断完善 |

## 2. 基础 Atoms

### 2.1 Primitive Atom（原始原子）

```tsx
import { atom, useAtom } from 'jotai';

// 定义一个原子
const countAtom = atom(0);                // 初始值为 0
const nameAtom = atom('Alarik');          // 字符串
const isActiveAtom = atom(false);          // 布尔值
const configAtom = objectAtom({            // 对象（需要特殊处理）
  theme: 'dark',
  language: 'zh-CN',
});

// 在组件中消费
function Counter() {
  const [count, setCount] = useAtom(countAtom);  // 类似 useState！

  return (
    <div>
      Count: {count}
      <button onClick={() => setCount(c => c + 1)}>+</button>
      <button onClick={() => setCount(0)}>Reset</button>
    </div>
  );
}
```

### 2.2 只读 Atom（Read-only）

```tsx
const doubleCountAtom = atom((get) => {
  const count = get(countAtom);
  return count * 2;
});  // 没有 set 方法 → 只读派生 atom

function DisplayDouble() {
  const [double] = useAtom(doubleCountAtom);  // 只能读，不能写
  return <span>Double: {double}</span>;
}
```

### 2.3 可写派生 Atom（Write-only Derived）

```tsx
// 派生 atom 同时提供读写
const multipliedCountAtom = atom(
  (get) => get(countAtom) * 3,           // read: 计算派生值
  (get, set, args) => {                   // write: 自定义写入逻辑
    // args 是 set(newVal) 传入的新值
    // 可以反向更新原始 atom
    if (typeof args === 'number') {
      set(countAtom, Math.round(args / 3));
    }
  }
);

// 使用
const [multiplied, setMultiplied] = useAtom(multipliedCountAtom);
setMultiplied(15);  // 会将 count 设为 5
```

### 2.4 异步 Atom

```tsx
// 异步只读 atom（配合 React Suspense）
const userDataAtom = atom(async (get) => {
  const userId = get(userIdAtom);
  const response = await fetch(`/api/users/${userId}`);
  if (!response.ok) throw new Error('Failed to fetch');
  return response.json() as User;
});

// 使用（需要 Suspense 边界）
<Suspense fallback={<UserSkeleton />}>
  <UserProfile />
</Suspense>

function UserProfile() {
  // Jotai 集成了 React Suspense
  // 数据加载完成前组件会被 Suspense 的 fallback 取代
  const [user] = useAtom(userDataAtom);
  return <Card name={user.name} avatar={user.avatarUrl} />;
}
```

### 2.5 带 Error Handling 的异步 Atom

```tsx
// 异步 atom + 错误处理
const safeUserDataAtom = atom(async (get) => {
  const userId = get(userIdAtom);
  try {
    const res = await fetch(`/api/users/${userId}`);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    return await res.json();
  } catch (error) {
    // 可以返回默认值或抛出给 ErrorBoundary
    return { id: userId, name: 'Unknown', error: true };
  }
});
```

## 3. 高级模式

### 3.1 Atom Family（原子家族）

```tsx
// 当你需要同一模式的多个 atom（如列表中的每行）
const createTodoAtom = (id: string) => atom({
  id,
  text: '',
  completed: false,
});

// 或更常见的：参数化的 atom factory
const todoAtomFamily = atomFamily((id: string) => ({
  id,
  text: '',
  completed: false,
  updatedAt: Date.now(),
}));

// 使用
function TodoItem({ id }: { id: string }) {
  const [todo, setTodo] = useAtom(todoAtomFamily(id));
  
  return (
    <li>
      <input
        checked={todo.completed}
        onChange={(e) => setTodo((prev) => ({ ...prev, completed: e.target.checked }))}
      />
      <input
        value={todo.text}
        onChange={(e) => setTodo((prev) => ({ ...prev, text: e.target.value }))}
      />
    </li>
  );
}
```

### 3.2 atomWithStorage —— 持久化 Atom

```tsx
import { atomWithStorage } from 'jotai/utils';

// 自动同步到 localStorage
const themeAtom = atomWithStorage<'light' | 'dark'>('theme', 'dark');
// 参数1: key, 参数2: 初始值

// 使用（完全透明，就像普通 atom 一样）
function ThemeSwitcher() {
  const [theme, setTheme] = useAtom(themeAtom);
  // 主题切换后自动保存到 localStorage
  // 页面刷新后自动从 localStorage 恢复
  
  return <button onClick={() => setTheme(theme === 'light' ? 'dark' : 'light')}>
    Current: {theme}
  </button>;
}

// 也支持 session / URL hash / 自定义 storage
const pageAtom = atomWithStorage('page', 1, undefined, { getStorage: () => sessionStorage });
```

### 3.3 atomWithHash —— URL Hash 同步

```tsx
import { atomWithHash } from 'jotai/utils';

const tabAtom = atomWithHash<string>('tab', 'overview'); // sync with #tab=xxx
const filterAtom = atomWithHash('filter', 'all');

// URL: myapp.com/page#tab=settings&filter=active
// 修改 atom 自动更新 URL hash，反之亦然
```

### 3.4 selectAtom —— 精确选择大 atom 中的字段

```tsx
const bigObjectAtom = atom({
  a: { nested: { value: 1 } },
  b: { list: [1, 2, 3] },
  c: { flag: true },
  d: { text: 'hello' },
  e: { num: 42 },
  // ... 很多字段
});

// 如果直接 useAtom(bigObjectAtom)，任何字段变化都重渲染

// 解决方案1：拆分成小 atom（推荐）
const atomA = atom((get) => get(bigObjectAtom).a);
const atomB = atom((get) => get(bigObjectAtom).b);

// 解决方案2：selectAtom
import { selectAtom } from 'jotai/utils';

const aValueAtom = selectAtom(bigObjectAtom, (obj) => obj.a.nested.value);
// 只在 a.nested.value 变化时触发更新
```

## 4. Jotai vs Zustand vs Recoil

| 特性 | Jotai | Zustand | Recoil |
|------|-------|---------|-------|
| 模型 | 原子 (atom) 图 | 单 Store | 原子 (atom) 图 |
| 派生值 | atom(get) ⇒ derived | 手动 selector | selector family |
| 异步 | 原生支持 + Suspense | 需自行处理 | 原生支持 + Suspense |
| 包大小 | ~5KB (gzip) | ~1.5KB (gzip) | ~19KB (gzip) |
| DevTools | jotai-devtools | zustand-middleware-devtools | recoilize |
| React 版本 | Concurrent-safe | Concurrent-safe | Concurrent-beta |
| 维护状态 | 活跃 | 非常活跃 | 低维护 (Meta 已停止积极维护) |
| 学习成本 | 低 | 极低 | 中等 |

## 5. 实战：完整的 Todo 应用

```tsx
// atoms.ts
import { atom, atomFamily, useAtom } from 'jotai';
import { atomWithStorage } from 'jotai/utils';

// Filter
const filterAtom = atom<'all' | 'active' | 'completed'>('all');

// Todos data
export interface Todo { id: string; text: string; completed: boolean; }
const todosAtom = atom<Todo[]>([]);

// Derived: filtered todos
const filteredTodosAtom = atom((get) => {
  const todos = get(todosAtom);
  const filter = get(filterAtom);
  switch (filter) {
    case 'active': return todos.filter((t) => !t.completed);
    case 'completed': return todos.filter((t) => t.completed);
    default: return todos;
  }
});

// Derived: stats
const statsAtom = atom((get) => {
  const todos = get(todosAtom);
  return {
    total: todos.length,
    active: todos.filter((t) => !t.completed).length,
    completed: todos.filter((t) => t.completed).length,
  };
});

// Actions
export function useTodoActions() {
  const [, setTodos] = useAtom(todosAtom);
  
  return {
    addTodo: (text: string) => {
      setTodos((prev) => [
        ...prev,
        { id: crypto.randomUUID(), text, completed: false },
      ]);
    },
    toggleTodo: (id: string) => {
      setTodos((prev) =>
        prev.map((t) => (t.id === id ? { ...t, completed: !t.completed } : t))
      );
    },
    deleteTodo: (id: string) => {
      setTodos((prev) => prev.filter((t) => t.id !== id));
    },
    clearCompleted: () => {
      setTodos((prev) => prev.filter((t) => !t.completed));
    },
  };
}

// Components
function TodoApp() {
  const [todos] = useAtom(filteredTodosAtom);
  const [stats] = useAtom(statsAtom);
  const [filter, setFilter] = useAtom(filterAtom);
  const { addTodo, toggleTodo, deleteTodo, clearCompleted } = useTodoActions();
  const [newTodo, setNewTodo] = useState('');

  return (
    <div>
      <form onSubmit={(e) => { e.preventDefault(); addTodo(newTodo); setNewTodo(''); }}>
        <input value={newTodo} onChange={(e) => setNewTodo(e.target.value)} />
        <button>Add</button>
      </form>

      <select value={filter} onChange={(e) => setFilter(e.target.value as any)}>
        <option value="all">All ({stats.total})</option>
        <option value="active">Active ({stats.active})</option>
        <option value="completed">Done ({stats.completed})</option>
      </select>

      <ul>
        {todos.map((todo) => (
          <li key={todo.id}>
            <input type="checkbox" checked={todo.completed} onChange={() => toggleTodo(todo.id)} />
            {todo.text}
            <button onClick={() => deleteTodo(todo.id)}>×</button>
          </li>
        ))}
      </ul>

      {stats.completed > 0 && (
        <button onClick={clearCompleted}>Clear completed ({stats.completed})</button>
      )}
    </div>
  );
}
```

## 6. 总结

```
┌──────────────────────────────────────────────────┐
│         Jotai 要点速查                             │
├──────────────────────────────────────────────────┤
│ 核心: atom() 创建最小状态单位                     │
│ 消费: useAtom(atom) — 像 useState 一样简单         │
│ 派生: atom((get) => ...) 自动追踪依赖            │
│ 异步: 原生支持，配合 Suspense 使用                │
│ 家族: atomFactory() 参数化批量创建                 │
│ 持久化: atomWithStorage / atomWithHash            │
│ 精选: selectAtom 避免大 atom 的无效重渲染          │
│ 优势: 细粒度控制、天然并发安全、无 Provider        │
│ 适合: 需要精细控制更新范围的复杂交互场景           │
└──────────────────────────────────────────────────┘
```
