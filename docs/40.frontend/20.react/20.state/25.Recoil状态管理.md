# Recoil 状态管理

## 1. 概述

Recoil 是 Meta（Facebook）开发的实验性状态管理库，提供了**原子化（atomic）**和**派生（derived）**的状态模型：

```
React Component Tree:
<App>
  <RecoilRoot>           ← 必须的根节点
    <PageA>
      <ComponentB />    ← 使用 atom X
      <ComponentC />    ← 使用 atom Y + derived selector Z
    </PageA>
  </RecoilRoot>
</App>
```

> **重要提示**：Meta 已于 2023 年宣布 **Recoil 进入维护模式**（maintenance mode），不再积极开发新特性。新项目建议优先考虑 **Jotai** 或 **Zustand**。

## 2. 核心概念

### 2.1 Atom（原子）— 状态的基本单位

```tsx
import { atom, useRecoilState } from 'recoil';

// 原子定义：最小的独立状态单元
const textState = atom({
  key: 'textState',           // 唯一标识（在整个应用中必须唯一）
  default: '',                // 默认值
});

// 在组件中使用（类似 useState）
function TextInput() {
  const [text, setText] = useRecoilState(textState);
  
  return (
    <div>
      <input type="text" value={text} onChange={(e) => setText(e.target.value)} />
      <p>You typed: {text}</p>
    </div>
  );
}
```

**Atom 配置选项**：

```tsx
const complexAtom = atom<MyType>({
  key: 'complex',
  default: initialValue,
  
  effects: [
    // effect 1: 日志
    ({ onSet }) => {
      onSet((newValue) => {
        console.log(`${key} changed to:`, newValue);
      });
    },
    
    // effect 2: 持久化到 localStorage
    ({ onSet, setSelf, trigger }) => {
      const saved = localStorage.getItem(key);
      if (saved !== null && trigger === 'get') {
        setSelf(JSON.parse(saved));  // 从 storage 恢复
      }
      onSet((value) => {
        localStorage.setItem(key, JSON.stringify(value));
      });
    },
  ],
  
  // 危险选项：允许存储不可序列化的值
  dangerouslyAllowMutability: false,
});
```

### 2.2 Selector（选择器）— 派生状态

```tsx
import { selector, useRecoilValue } from 'recoil';

const charCountState = selector({
  key: 'charCountState',
  get: ({ get }) => {              // get 函数获取其他 atom/selector 的值
    const text = get(textState);
    return text.length;
  },
});

function CharCounter() {
  // useRecoilValue: 只读（类似 useState 的第一个元素）
  const count = useRecoilValue(charCountState);
  return <span>Character count: {count}</span>;
}
```

**Selector Hooks 对照表**：

| Hook | 读 | 写 | 说明 |
|------|----|----|------|
| `useRecoilState(atom)` | ✅ | ✅ | 完整读写（类似 useState） |
| `useRecoilValue(atom)` | ✅ | ❌ | 只读 |
| `useSetRecoilState(atom)` | ❌ | ✅ | 只写 |
| `useResetRecoilState(atom)` | ❌ | ✅ | 重置为默认值 |

### 2.3 异步 Selector

```tsx
const currentUserQuery = selector({
  key: 'currentUserQuery',
  get: async ({ get }) => {
    const userId = get(currentUserIdState);
    const response = await fetch(`/api/users/${userId}`);
    if (!response.ok) throw new Error('User not found');
    return response.json();
  },
});

// 使用（需要 Suspense + ErrorBoundary 包裹）
<Suspense fallback={<LoadingSpinner />}>
  <ErrorBoundary fallback={<ErrorDisplay />}>
    <UserProfile />
  </ErrorBoundary>
</Suspense>

function UserProfile() {
  const user = useRecoilValue(currentUserQuery);
  // 加载期间: Suspense 显示 fallback
  // 出错时: ErrorBoundary 显示 fallback
  // 成功后: 正常渲染
  return <h1>Welcome, {user.name}!</h1>;
}
```

## 3. RecoilRoot

```tsx
import { RecoilRoot } from 'recoil';

function App() {
  return (
    <RecoilRoot>
      {/* 整个应用只需要一个 RecoilRoot */}
      <Router>
        <Routes>
          <Route path="/" element={<Home />} />
          <Route path="/about" element={<About />} />
        </Routes>
      </Router>
    </RecoilRoot>
  );
}

// 可选：初始化状态
<RecoilRoot initializeState={({ set }) => {
  set(textState, 'Initial value from server...');
}}>
  <App />
</RecoilRoot>
```

## 4. 高级功能

### 4.1 Atom Family

```tsx
import { atomFamily } from 'recoil';

// 参数化的 atom 工厂
const todoAtomFamily = atomFamily({
  key: 'Todo',
  default: (id: string) => ({
    id,
    text: '',
    completed: false,
  }),
});

// 使用
function TodoItem({ id }: { id: string }) {
  const [todo, setTodo] = useRecoilState(todoAtomFamily(id));
  return (
    <li>
      <input
        type="checkbox"
        checked={todo.completed}
        onChange={() => setTodo((prev) => ({ ...prev, completed: !prev.completed }))}
      />
      {todo.text}
    </li>
  );
}
```

### 4.2 Selector Family

```tsx
import { selectorFamily } from 'recoil';

const evenNumbersSelector = selectorFamily({
  key: 'EvenNumbers',
  get: (max: number) => ({ get }) => {
    const numbers = get(numberListState);
    return numbers.filter(n => n <= max && n % 2 === 0);
  },
});

// 使用
const evens = useRecoilValue(evenNumbersSelector(100)); // ≤100 的偶数
```

### 4.3 Snapshot —— 状态快照

```tsx
import { useRecoilSnapshot, snapshot_UNSTABLE } from 'recoil';

// 获取当前快照
function DebugPanel() {
  const snapshot = useRecoilSnapshot();

  return (
    <details>
      <summary>Snapshot Info</summary>
      <pre>{JSON.stringify(snapshot.getLoadable(textState).contents, null, 2)}</pre>
    </details>
  );
}

// 时间旅行调试
async function timeTravelDemo() {
  const snap1 = snapshot_UNSTABLE();
  // ... do some mutations ...
  const snap2 = snapshot_UNSTABLE();
  
  // 回到 snap1
  snap1.retain();  // 保持不被垃圾回收
  gotoSnap(snap1);
}
```

### 4.4 Persistence（持久化）

Recoil 提供了官方的持久化效果：

```tsx
import { RecoilPersist, atom } from 'recoil/persist';

// 需要持久化的 atom
const settingsAtom = atom({
  key: 'settings',
  default: { theme: 'light', lang: 'en' },
  effects: [RecoilPersist({ key: 'my-settings' })],
});

// 所有配置了该效果的 atom 会自动持久化到 localStorage
```

## 5. Recoil vs Jotai（继承者对比）

| 维度 | Recoil | Jotai |
|------|--------|-------|
| 开发者 | Meta (Facebook) | Poimandres |
| 维护状态 | ⚠️ 维护模式 (2023+) | ✅ 积极维护 |
| API 风格 | config object (`{ key, default }`) | 函数式 (`atom(default)`) |
| Root 节点 | 需要 `<RecoilRoot>` | 不需要 |
| 异步 | 原生 + Suspense | 原生 + Suspense |
| Snapshots | 官方内置 | 需第三方工具 |
| 包大小 | ~19KB gzipped | ~5KB gzipped |
| TypeScript | 良好 | 优秀（函数式天然友好） |
| 生态插件 | persistence / location / sync | utils (storage/hash/family) |
| 学习资源 | 官方文档 + 视频 | 官方文档 + 社区示例 |

## 6. 迁移建议

如果你正在使用 Recoil，以下是迁移路径：

```
现有项目使用 Recoil:
  ├── 项目稳定、无需新功能 → 继续用 Recoil（已足够稳定）
  ├── 开始新项目 → 选择 Jotai（API 相似但更活跃）
  └── 需要简化架构 → 考虑 Zustand（更少概念）

迁移 Recoil → Jotai 的主要差异:
  1. 去掉 <RecoilRoot> 包裹
  2. atom({ key, default }) → atom(default)
  3. selector({ key, get }) → atom((get) => ...)
  4. useRecoilState → useAtom
  5. atomFamily → atomFamily（基本相同）
```

## 7. 总结

```
┌──────────────────────────────────────────────────┐
│         Recoil 要点速查                             │
├──────────────────────────────────────────────────┤
│ 核心: Atom(原子) + Selector(派生)                │
│ 根节点: <RecoilRoot> 必须包裹                     │
│ Hooks: useRecoilState / Value / Set / Reset      │
│ 异步: Selector + Suspense + ErrorBoundary        │
│ 批量: atomFamily / selectorFamily                 │
│ 快照: useRecoilSnapshot 用于调试和时间旅行         │
│ 持久化: @recoil/persist effects                 │
│ 状态: Meta 维护模式，新项目推荐 Jotai             │
│ 贡献: 原子化模型的先驱，影响了 Jotai/Valtio 等    │
└──────────────────────────────────────────────────┘
```
