# Valtio —— 基于 Proxy 的代理状态管理

## 1. 设计理念

Valtio 由 Poimandres 团队开发（与 Zustand/Jotai 同源），核心理念是**让状态管理像操作普通 JavaScript 对象一样自然**：

```jsx
// Valtio 的体验：
const state = proxy({ count: 0 });  // 创建代理对象
state.count++;                       // 直接修改！就像改普通对象一样

// 自动追踪变化并更新订阅的组件
function Counter() {
  const snap = useSnapshot(state);  // 获取快照
  return <button onClick={() => state.count++}>{snap.count}</button>;
}
```

**与 MobX 的相似之处**：都是基于 Proxy 的响应式系统。
**与 MobX 的不同之处**：Valtio 更简洁、无 Class 依赖、更现代。

## 2. 核心概念

### 2.1 proxy() — 创建代理状态

```ts
import { proxy, useSnapshot } from 'valtio';

// 创建一个代理对象
const state = proxy({
  user: null as User | null,
  todos: [] as Todo[],
  ui: {
    theme: 'dark' as 'light' | 'dark',
    sidebarOpen: true,
    modal: null as string | null,
  },
});

// 直接修改——就像修改普通 JS 对象
state.user = { name: 'Alarik', role: 'admin' };
state.ui.theme = 'light';          // 嵌套对象的属性也可以直接修改
state.todos.push({ id: 1, text: 'Learn Valtio', completed: false });

// 数组方法也能直接用
state.todos.splice(0, 1);         // 删除第一项
state.todos[0].completed = true;   // 修改嵌套数组中的对象
```

### 2.2 useSnapshot() — 订阅快照

```tsx
import { useSnapshot } from 'valtio';

function UserProfile() {
  // useSnapshot 返回代理状态的快照
  // 只有当快照中你实际使用的属性变化时，组件才会重渲染
  const snap = useSnapshot(state);

  return (
    <div className={`app-${snap.ui.theme}`}>
      <h1>Hello, {snap.user?.name || 'Guest'}!</h1>
      <button onClick={() => (state.ui.theme = snap.ui.theme === 'dark' ? 'light' : 'dark')}>
        Toggle Theme
      </button>
    </div>
  );
}
```

**`useSnapshot` 的性能机制**：

```
useSnapshot 内部工作原理:

1. 创建 state 的 Proxy 快照（深冻结的副本）
2. 组件 render 时读取快照的属性（如 snap.ui.theme）
3. Valtio 追踪本次 render 中访问了哪些路径
4. 下次 state 变化时：
   → 仅当被访问的路径发生变化时触发 re-render
   → 未被访问的变化不会导致此组件更新
```

### 2.3 snapshot() — 获取纯值快照

```ts
import { snapshot } from 'valtio';

// 在非 React 环境获取当前快照
const current = snapshot(state);  // 普通 JS 对象，不是 Proxy

// 适用于：
console.log(snapshot(state));     // 日志输出
localStorage.setItem('state', JSON.stringify(snapshot(state)));
sendAnalytics(snapshot(state));
```

### 2.4 subscribe() — 精细订阅

```ts
import { subscribe } from 'valtio';

// 订阅特定属性的变化
const unsubscribe = subscribe(state.ui, 'theme', () => {
  console.log('Theme changed to:', state.ui.theme);
});

// 或订阅整个对象
const unsubAll = subscribe(state, () => {
  console.log('State updated:', snapshot(state));
});

// 取消订阅
unsubscribe();
unsubAll();
```

## 3. 衍生状态（Derivations）

Valtio 提供 `derive()` 来创建派生状态：

```ts
import { proxy, derive, useSnapshot } from 'valtio';

const state = proxy({
  todos: [] as Todo[],
  filter: 'all' as 'all' | 'active' | 'completed',
});

// 派生状态：自动根据依赖计算
const derived = derive({
  filteredTodos: (get) => {
    const { todos, filter } = get(state);
    switch (filter) {
      case 'active': return todos.filter(t => !t.completed);
      case 'completed': return todos.filter(t => t.completed);
      default: return [...todos];
    }
  },

  stats: (get) => {
    const todos = get(state).todos;
    return {
      total: todos.length,
      active: todos.filter(t => !t.completed).length,
      completed: todos.filter(t => t.completed).length,
    };
  },
});

// 使用
function TodoStats() {
  // useSnapshot 对 derive 的结果同样有效
  const snap = useSnapshot(derived);
  return (
    <footer>
      Total: {snap.stats.total} | Active: {snap.stats.active} | Done: {snap.stats.completed}
    </footer>
  );
}
```

## 5. 持久化

### 5.1 localStorage

```ts
import { proxy, subscribeKey } from 'valtio';

const state = proxy({
  theme: 'dark',
  language: 'zh-CN',
  fontSize: 16,
});

// 监听单个 key 变化并持久化
subscribeKey(state, 'theme', () => {
  localStorage.setItem('theme', state.theme);
});

subscribeKey(state, 'language', () => {
  localStorage.setItem('language', state.language);
});

// 初始化时恢复
const savedTheme = localStorage.getItem('theme');
if (savedTheme) state.theme = savedTheme as any;
```

### 5.2 valtio-persist 库（自动化方案）

```bash
npm install valtio-persist
```

```ts
import { persist } from 'valtio/utils';
import { proxy } from 'valtio';

const state = proxy({
  user: null,
  settings: { theme: 'dark' },
});

persist(state, {
  key: 'my-app-state',          // localStorage key
  partialize: (s) => ({          // 只持久化这些字段
    settings: s.settings,
  }),
  version: 1,                    // schema versioning
  migrate: (persisted, version) => {
    // 迁移逻辑
    if (version === 0) {
      persisted.settings.theme = 'dark'; // v0 → v1: 强制 dark
    }
    return persisted;
  },
});
```

## 6. Valtio vs MobX 对比

| 特性 | Valtio | MobX |
|------|--------|------|
| API 风格 | 函数式（proxy/useSnapshot） | OOP（class + decorators） |
| 响应式原理 | Proxy | Proxy (v5) / defineProperty (v4) |
| React 集成 | useSnapshot hook | observer HOC |
| 包大小 | ~2KB (core) | ~16KB (+ react-lite) |
| DevTools | valtio/utils/devtools | mobx-devtools |
| TypeScript | 优秀 | 良好 |
| 派生状态 | derive() | computed |
| 异步处理 | 需自行实现 | flow / runInAction |
| 学习成本 | 极低 | 低~中 |
| 维护者 | Poimandres (PMDRS) | MobX Core Team |

**Valtio 更适合的场景**：
- 喜欢**函数式编程**风格（而非 Class）
- 追求**极致简洁**的 API
- 需要**快速原型开发**
- 团队熟悉 **Vue 3 的 reactive/ref**（体验非常接近）

## 7. 实际案例：购物车

```tsx
// store/cart.ts
import { proxy, useSnapshot, derive } from 'valtio';

interface CartItem {
  id: number;
  name: string;
  price: number;
  quantity: number;
}

export const cart = proxy({
  items: [] as CartItem[],
  currency: 'CNY' as 'CNY' | 'USD',
  discountCode: '' as string,
});

export const cartDerived = derive({
  itemCount: (get) => get(cart).items.reduce((sum, item) => sum + item.quantity, 0),
  subtotal: (get) =>
    get(cart).items.reduce((sum, item) => sum + item.price * item.quantity, 0),
  shipping: (get) => (get(cart).subtotal > 200 ? 0 : 15),
  discount: (get) => {
    const code = get(cart).discountCode.toLowerCase();
    const sub = get(cart).subtotal;
    if (code === 'save10') return sub * 0.1;
    if (code === 'half') return sub * 0.5;
    return 0;
  },
  total: (get) => {
    const d = get(cartDerived);  // 可以引用自身或其他 derive
    return d.subtotal + d.shipping - d.discount;
  },
});

// Components
function CartBadge() {
  const { itemCount } = useSnapshot(cartDerived);
  return <Badge count={itemCount} />;
}

function CartTotal() {
  const { subtotal, shipping, discount, total, currency } = useSnapshot(cartDerived);
  return (
    <div>
      <Row label="Subtotal">{currency}{subtotal.toFixed(2)}</Row>
      <Row label="Shipping">{shipping === 0 ? 'FREE' : `${currency}${shipping}`}</Row>
      {discount > 0 && <Row label="Discount">-{currency}{discount.toFixed(2)}</Row>}
      <hr />
      <strong>Total: {currency}{total.toFixed(2)}</strong>
    </div>
  );
}
```

## 8. 总结

```
┌──────────────────────────────────────────────────┐
│         Valtio 要点速查                             │
├──────────────────────────────────────────────────┤
│ 创建: proxy({ ... })                              │
│ 修改: 直接赋值/push/splice（像普通对象）          │
│ 订阅: useSnapshot(proxy) → 快照 + 自动重渲染     │
│ 派生: derive({ field: (get) => computed })        │
│ 快照: snapshot(proxy) → 纯值（非 React 环境）     │
│ 订阅: subscribe(proxy, key, cb)                  │
│ DevTools: devtools(proxy, { name })               │
│ 持久化: valtio-persist 或手动 subscribeKey        │
│ 优势: 极简 API、Proxy 原力、类 Vue 体验          │
│ 注意: 生产环境需确认 Proxy 兼容性（IE 不支持）    │
└──────────────────────────────────────────────────┘
```
