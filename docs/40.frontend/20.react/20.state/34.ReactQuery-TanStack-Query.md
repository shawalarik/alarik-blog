# React Query / TanStack Query

## 1. 服务端状态 vs 客户端状态

理解 **Server State（服务端状态）** 和 **Client State（客户端状态）** 的区别是使用 TanStack Query 的前提：

| 特性 | Client State (Zustand/Redux) | Server State (TanStack Query) |
|------|------------------------------|-------------------------------|
| 所有权 | 应用完全控制 | 应用不拥有（API 服务方控制） |
| 存储位置 | 内存（应用内） | 远程服务器 + 本地缓存 |
| 同步方式 | 即时同步 | 异步（网络请求） |
| 生命周期 | 组件挂载即存在 | 可能过期、失效、被其他人修改 |
| 需要处理 | — | 缓存策略、重试、轮询、乐观更新 |
| 典型示例 | 主题、表单输入、UI 开关 | 用户数据、文章列表、搜索结果 |

> **核心洞察**：服务端状态的管理比客户端状态复杂得多。TanStack Query 就是专门为此设计的。

## 2. 核心概念

### 2.1 基本用法

```tsx
import { useQuery } from '@tanstack/react-query';

// 获取数据
function UsersList() {
  const {
    data,           // 返回的数据
    isLoading,      // 是否首次加载中（无缓存）
    isError,        // 是否出错
    error,          // 错误对象
    isSuccess,      // 是否成功且有数据
    refetch,        // 手动触发重新请求
    isFetching,     // 是否正在请求（包括 refetch/background）
    isRefetching,   // 是否正在后台 refetch
  } = useQuery({ 
    queryKey: ['users'],           // 唯一标识这个查询的 key
    queryFn: () => fetch('/api/users').then(r => r.json()),  // 获取函数
  });

  if (isLoading) return <Skeleton />;
  if (isError) return <ErrorPage error={error} />;

  return (
    <ul>
      {data.map(user => <li key={user.id}>{user.name}</li>)}
    </ul>
  );
}
```

### 2.2 Query Key —— 缓存的唯一标识

```ts
// QueryKey 可以是一个数组，用于精确匹配缓存
useQuery({ queryKey: ['users'] });
useQuery({ queryKey: ['users', { page: 1 }] });
useQuery({ queryKey: ['user', userId], queryFn: () => getUser(userId) });

// 相同 queryKey → 共享同一个缓存条目
// 不同参数 → 不同的缓存 → 并行请求互不干扰
```

### 2.3 三种 loading 状态

```
isLoading: true
  → 还没有任何缓存数据（第一次加载或缓存过期后）
  → 通常显示骨架屏/全屏加载器

isFetching: true (但 isLoading: false)
  → 有旧数据，同时后台在更新
  → 通常显示旧数据 + 微妙的刷新指示

isPending: true  (v5 新增)
  → 查询已创建但尚未开始执行
  → 区别于 isLoading（已开始执行）
```

## 3. 数据变更操作

### 3.1 Mutations

```tsx
import { useMutation, useQueryClient } from '@tanstack/react-query';

function CreatePost() {
  const queryClient = useQueryClient();

  const mutation = useMutation({
    mutationFn: (newPost: Partial<Post>) =>
      fetch('/api/posts', {
        method: 'POST',
        body: JSON.stringify(newPost),
        headers: { 'Content-Type': 'application/json' },
      }).then(r => r.json()),

    onSuccess: (newData) => {
      // 成功后使相关查询的缓存失效 → 自动重新获取
      queryClient.invalidateQueries({ queryKey: ['posts'] });
      
      // 或者直接更新缓存（无需重新请求）
      queryClient.setQueryData(['posts'], (old) => [...old, newData]);
    },

    onError: (err) => {
      toast.error(`创建失败: ${err.message}`);
    },

    onSettled: () => {
      // 无论成功还是失败都执行（如重置表单）
    },
  });

  return (
    <form onSubmit={(e) => {
      e.preventDefault();
      mutation.mutate({ title: 'New Post', content: '...' });
    }}>
      <button disabled={mutation.isPending}>
        {mutation.isPending ? 'Creating...' : 'Create Post'}
      </button>
    </form>
  );
}
```

### 3.2 乐观更新（Optimistic Update）

```tsx
function TodoToggle({ todo }: { todo: Todo }) {
  const queryClient = useQueryClient();

  const toggleMutation = useMutation({
    mutationFn: (id: string) => fetch(`/api/todos/${id}/toggle`, { method: 'PATCH' }).then(r => r.json()),
    
    onMutate: async (id) => {
      // 取消可能正在进行的其他查询
      await queryClient.cancelQueries({ queryKey: ['todos'] });
      
      // 保存当前快照以便回滚
      const previousTodos = queryClient.getQueryData(['todos']);
      
      // 乐观更新：立即假设成功
      queryClient.setQueryData(['todos'], (old: Todo[]) =>
        old.map(t => t.id === id ? { ...t, completed: !t.completed } : t)
      );

      return { previousTodos };  // 传给 onError 用于回滚
    },
    
    onError: (_err, _vars, context) => {
      // 回滚到之前的快照
      queryClient.setQueryData(['todos'], context.previousTodos);
    },
    
    onSettled: () => {
      // 无论成败，最终用服务器数据同步
      queryClient.invalidateQueries({ queryKey: ['todos'] });
    },
  });

  return (
    <input
      type="checkbox"
      checked={todo.completed}
      onChange={() => toggleMutation.mutate(todo.id)}
    />
  );
}

// 用户体验：
// 点击 → 立即显示勾选（乐观）
// 后台请求 → 成功则保持 / 失败则闪回原状
```

## 4. 高级功能

### 4.1 分页

```tsx
// 无限滚动 / Load More
function InfiniteUserList() {
  const {
    data,
    fetchNextPage,
    hasNextPage,
    isFetchingNextPage,
  } = useInfiniteQuery({
    queryKey: ['projects'],
    queryFn: ({ pageParam }) => fetchProjects(pageParam),
    getNextPageParam: (lastPage) =>
      lastPage.hasMore ? lastPage.nextCursor : undefined,
    initialPageParam: 0,
  });

  return (
    <>
      {data?.pages.map((page, i) => (
        <div key={i}>{page.projects.map(p => <ProjectCard key={p.id} {...p} />)}</div>
      ))}
      {hasNextPage && (
        <button
          onClick={() => fetchNextPage()}
          disabled={isFetchingNextPage}
        >
          {isFetchingNextPage ? 'Loading more...' : 'Load More'}
        </button>
      )}
    </>
  );
}
```

### 4.2 轮询 / Refetch Intervals

```tsx
// 每 30 秒自动刷新（如股票价格、通知数）
function StockPrice({ symbol }: { symbol: string }) {
  const { data } = useQuery({
    queryKey: ['stock-price', symbol],
    queryFn: () => getStockPrice(symbol),
    refetchInterval: 30_000,  // 30秒
    refetchIntervalInBackground: false,  // 页面不可见时不刷新（省资源）
  });
  
  return <span>${data?.price.toFixed(2)}</span>;
}

// 条件性轮询：仅在特定条件下启用
const { data } = useQuery({
  queryKey: ['online-users'],
  queryFn: getOnlineUsers,
  refetchInterval: (query) => {
    const count = query.state.data?.count ?? 0;
    return count > 100 ? 5_000 : 60_000;  // 人多则更频繁
  },
});
```

### 4.3 预取（Prefetching）

```tsx
// 在用户看到链接时就预先加载数据
function ProductLink({ productId }: { productId: string }) {
  const queryClient = useQueryClient();
  
  const prefetchProduct = useCallback(() => {
    queryClient.prefetchQuery({
      queryKey: ['product', productId],
      queryFn: () => getProduct(productId),
      staleTime: 10 * 60 * 1000,  // 10分钟内视为新鲜
    });
  }, [productId, queryClient]);

  return (
    <a href={`/products/${productId}`} onMouseEnter={prefetchProduct}>
      View Product
    </a>
  );
  // 用户鼠标移入 → 触发 prefetch
  // 用户实际点击 → 缓存命中 → 秒开！
}
```

### 4.4 占位符查询（Placeholder Queries）

```tsx
// 先渲染 UI，数据稍后到达
queryClient.setQueryData(['user', userId], {
  id: userId,
  name: 'Loading...',
  avatar: defaultAvatar,
  email: '',
});

// 当真实数据到达时，React 会平滑替换
// 配合 skeleton 效果极佳
```

## 5. 缓存配置

### 5.1 全局默认配置

```tsx
// main.tsx
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'

const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 1000 * 60 * 5,     // 5 分钟内认为数据是新鲜的
      gcTime: 1000 * 60 * 30,      // 30 分钟未使用的缓存才被垃圾回收
      retry: 3,                    // 失败重试 3 次
      retryDelay: attemptIndex => Math.min(1000 * 2 ** attemptIndex, 30000), // 指数退避
      refetchOnWindowFocus: false,  // 窗口聚焦时不自动重取
      refetchOnReconnect: true,     // 重连网络时重取
    },
    mutations: {
      retry: 0,                    // mutations 默认不重试
    },
  },
});

<QueryClientProvider client={queryClient}>
  <App />
</QueryClientProvider>
```

### 5.2 单个查询覆盖全局配置

```ts
useQuery({
  queryKey: ['realtime-data'],
  queryFn: fetchRealtimeData,
  staleTime: 0,                  // 始终视为过期
  refetchInterval: 1000,           // 每秒刷新
  gcTime: Infinity,                // 永不回收
});
```

## 7. TanStack Query vs SWR vs RTK Query

| 特性 | TanStack Query v5 | SWR | RTK Query |
|------|------------------|-----|-----------|
| 包大小 | ~13KB | ~7KB | 内含于 RTK (~45KB+) |
| 分页支持 | `useInfiniteQuery` 内置 | 需自行实现 | `endpoints.injectEndpoints` |
| 乐观更新 | 内置 `onMutate` 回滚 | 需自行实现 | 内置 |
| Prefetch | `prefetchQuery` | `prefetch` | `util.prefetch` |
| DevTools | 官方 DevTools | 无官方工具 | Redux DevTools |
| Suspense | 一等公民支持 | 支持 | 支持 |
| 选择器 | queryKey 数组 | 自定义 key | endpoint name |
| SSR/SSG | Next.js SSG/ISR 一等支持 | 支持 | 支持 |

## 8. 总结

```
┌──────────────────────────────────────────────────┐
│     TanStack Query 要点速查                      │
├──────────────────────────────────────────────────┤
│ 定位: 服务端状态管理专家                         │
│ 核心: useQuery(读取) + useMutation(写入)        │
│ 缓存: queryKey 标识，自动去重/共享/过期         │
│ 生命周期: fresh → stale → fetching → success/error│
│ 高级: 分页/无限滚动/轮询/乐观更新/预取          │
│ 配置: staleTime / gcTime / retry / interval    │
│ DevTools: @tanstack/react-query-devtools        │
│ 推荐: 所有涉及 API 数据获取的 React 项目        │
│ 搭配: Zustand/Jotai 管理 Client State          │
└──────────────────────────────────────────────────┘
```
