# 状态持久化与同步

## 1. 概述

状态持久化是指将应用的运行时状态**保存到持久化存储介质**中，使得页面刷新、浏览器重启甚至跨会话后能够恢复。

```
┌────────────────────────────────────────────────────┐
│                 状态持久化层次                        │
│                                                    │
│  Level 1: 浏览器会话                              │
│    ┌──────────┐  ┌──────────┐  ┌──────────┐      │
│    │sessionSto│  │URL params│  │history   │      │
│    │rage     │  │(hash)    │  │state     │      │
│    └──────────┘  └──────────┘  └──────────┘      │
│    ↓ 关闭标签页即丢失                              │
│                                                    │
│  Level 2: 本地持久化                               │
│    ┌──────────┐  ┌──────────┐  ┌──────────┐      │
│    │localStor│  │IndexedDB │  │Cookie    │      │
│    │age (5MB)│  │ (No limit│  │(4KB)     │      │
│    └──────────┘  │)         │  └──────────┘      │
│                   └──────────┘                       │
│    ↓ 清除数据 / 换浏览器可能丢失                     │
│                                                    │
│  Level 3: 远程持久化                                │
│    ┌──────────┐  ┌──────────┐  ┌──────────┐      │
│    │REST API │  │GraphQL   │  │WebSocket│      │
│    │/DB sync  │  │subscription│ │sync      │      │
│    └──────────┘  └──────────┘  └──────────┘      │
│    ↓ 跨设备、永久保存                               │
└────────────────────────────────────────────────────┘
```

## 2. 各存储方案对比

| 存储方案 | 容量限制 | 过期策略 | 跨标签页 | 跨域 | 适用场景 |
|---------|---------|---------|---------|------|---------|
| **localStorage** | 5~10MB | 手动清除 | ✅ 共享 | ❌ | 用户偏好设置、主题 |
| **sessionStorage** | 5~10MB | 标签关闭 | ❌ 独立 | ❌ | 表单临时数据、wizard 步骤 |
| **IndexedDB** | 可达数百MB | 手动清除 | ✅ | ❌ | 大量结构化数据、文件 |
| **Cookie** | 4KB | 可设 max-age/expires | ✅ | ✅ | 认证 token、A/B 测试 |
| **URL SearchParams** | URL 长度限制(~2KB) | 导航后丢失 | ✅ | ✅ | 搜索筛选、分页、分享链接 |
| **URL Hash** | 类似 searchParams | 导航后保留 | ✅ | ✅ | Tab 切换状态 |
| **Remote DB/API** | 无限制 | 服务端控制 | ✅ | ✅ | 用户数据、业务记录 |

## 3. localStorage 方案

### 3.1 Zustand persist 中间件

```ts
import { persist, create } from 'zustand/middleware';

interface Settings {
  theme: 'light' | 'dark' | 'system';
  language: 'en' | 'zh-CN' | 'ja' | 'ko';
  fontSize: number;
  sidebarCollapsed: boolean;
  accentColor: string;
}

const useSettingsStore = create<Settings>()(
  persist(
    (set) => ({
      theme: 'system',
      language: 'zh-CN',
      fontSize: 16,
      sidebarCollapsed: false,
      accentColor: '#61dafb',

      setTheme: (theme) => set({ theme }),
      setLanguage: (language) => set({ language }),
      toggleSidebar: () => set((s) => ({ sidebarCollapsed: !s.sidebarCollapsed })),
    }),
    {
      name: 'app-settings',           // localStorage key
      version: 2,                     // schema 版本号
      partialize: (state) => ({        // 只持久化这些字段
        theme: state.theme,
        language: state.language,
        fontSize: state.fontSize,
        sidebarCollapsed: state.sidebarCollapsed,
        accentColor: state.accentColor,
      }),
      migrate: (persistedState, version) => {
        // 版本迁移：v1 → v2 时添加新字段
        if (version === 1) {
          (persistedState as any).accentColor = '#61dafb';  // 设置默认值
        }
        return persistedState as Settings;
      },
      merge: (persisted, current) => ({ ...current, ...persisted }),  // 合并策略
      storage: createJSONStorage(() => localStorage),  // 默认就是 localStorage
    }
  )
);

// 使用完全透明——就像普通 zustand store 一样
// 但关闭浏览器再打开时，设置会被恢复！
```

### 3.3 自定义 Hook 封装

```tsx
// hooks/useLocalStorage.ts
import { useState, useEffect, useCallback } from 'react';

function useLocalStorage<T>(
  key: string,
  initialValue: T,
): [T, (value: T | ((prev: T) => T)) => void] {
  // 读取初始值（优先 localStorage）
  const [storedValue, setStoredValue] = useState<T>(() => {
    try {
      const item = window.localStorage.getItem(key);
      return item ? JSON.parse(item) : initialValue;
    } catch (error) {
      console.warn(`Error reading localStorage key "${key}":`, error);
      return initialValue;
    }
  });

  // 设置值（同步到 localStorage）
  const setValue = useCallback((value: T | ((prev: T) => T)) => {
    try {
      const valueToStore = value instanceof Function ? value(storedValue) : value;
      setStoredValue(valueToStore);
      window.localStorage.setItem(key, JSON.stringify(valueToStore));
    } catch (error) {
      console.warn(`Error setting localStorage key "${key}":`, error);
    }
  }, [key, storedValue]);

  // 监听其他标签页的变化
  useEffect(() => {
    const handleStorageChange = (e: StorageEvent) => {
      if (e.key === key && e.newValue !== null) {
        try {
          setStoredValue(JSON.parse(e.newValue));
        } catch {
          // ignore parse errors
        }
      }
    };

    window.addEventListener('storage', handleStorageChange);
    return () => window.removeEventListener('storage', handleStorageChange);
  }, [key]);

  return [storedValue, setValue];
}

// 使用
function DarkModeToggle() {
  const [isDark, setIsDark] = useLocalStorage<boolean>('darkMode', false);
  return <Switch checked={isDark} onChange={setIsDark} />;
}
```

## 4. IndexedDB 方案

当数据量较大或需要复杂查询时，localStorage（5MB 限制、同步阻塞）不够用：

### 4.1 Dexie.js（IndexedDB 包装库）

```bash
npm install dexie
```

```ts
// db.ts
import Dexie, { liveQuery } from 'dexie';
import { useState } from '@dexie/react-hooks';

class AppDatabase extends Dexie {
  messages!: Table<Message, number>;
  users!: Table<User, number>;

  constructor() {
    super('MyAppDB');
    this.version(1).stores({
      messages: '++id, text, createdAt, senderId',
      users: '++id, name, avatarUrl',
    });
  }
}

export const db = new AppDatabase();

// 在组件中使用
function MessageList() {
  // liveQuery: 响应式查询，数据变化自动更新组件
  const messages = useState(
    () => db.messages.orderBy('createdAt').reverse().toArray(),
    []
  );

  return (
    <ul>
      {messages.map(msg => <MessageItem key={msg.id} message={msg} />)}
    </ul>
  );
}

// 写入
await db.messages.add({ text: 'Hello!', senderId: 1, createdAt: new Date() });
```

## 5. URL 参数方案

### 5.1 react-router useSearchParams

```tsx
import { useSearchParams, useParams } from 'react-router-dom';

function ProductFilters() {
  const [searchParams, setSearchParams] = useSearchParams();
  
  // 读取
  const category = searchParams.get('category') || 'all';
  const minPrice = Number(searchParams.get('minPrice')) || 0;
  const page = Number(searchParams.get('page')) || 1;

  // 更新（自动反映到 URL）
  const setCategory = (c: string) => {
    setSearchParams(prev => {
      prev.set('category', c);
      prev.set('page', '1');  // 重置分页
      return prev;
    });
  };

  return (
    <div>
      <select value={category} onChange={(e) => setCategory(e.target.value)}>
        <option value="all">All</option>
        <option value="electronics">Electronics</option>
      </select>
      <Pagination page={page} onPageChange={(p) => setSearchParams(prev => { prev.set('page', String(p)); return prev; })} />
    </div>
  );
}

// URL: /products?category=electronics&page=2&minPrice=50
// 可分享、可收藏、刷新后保持
```

## 6. 跨标签页同步

### 6.1 BroadcastChannel API

```ts
// channel.ts
class SyncChannel {
  private channel: BroadcastChannel;

  constructor(name: string) {
    this.channel = new BroadcastChannel(name);
  }

  post(data: unknown) {
    this.channel.postMessage(data);
  }

  subscribe(handler: (data: unknown) => void): () => void {
    const listener = (event: MessageEvent) => handler(event.data);
    this.channel.addEventListener('message', listener);
    return () => this.channel.removeEventListener('message', listener);
  }
}

// 使用
const settingsSync = new SyncChannel('app-settings-sync');

// 组件 A（发送变更）
settingsSync.post({ type: 'THEME_CHANGE', value: 'dark' });

// 组件 B（接收变更）
useEffect(() => {
  return settingsSync.subscribe((data) => {
    if (data.type === 'THEME_CHANGE') setTheme(data.value);
  });
}, []);
```

### 6.2 Storage Event（适用于 localStorage 同步）

```tsx
function CrossTabCounter() {
  const [count, setCount] = useLocalStorage('shared-count', 0);

  useEffect(() => {
    // 监听来自其他标签页的 storage 变更
    const handler = (e: StorageEvent) => {
      if (e.key === 'shared-count' && e.newValue !== null) {
        setCount(JSON.parse(e.newValue));
      }
    };
    window.addEventListener('storage', handler);
    return () => window.removeEventListener('storage', handler);
  }, []);

  return <span>{count}</span>;
}
// 标签 A: count++ → localStorage 更新
// 标签 B: storage event 触发 → count 同步更新
```

## 7. SSR / Next.js 注意事项

```tsx
// ⚠️ SSR 环境下 localStorage/window 不可用！

// 方案1: 动态导入（只在客户端执行）
import { useState, useEffect } from 'react';

function ThemeWrapper({ children }: { children: ReactNode }) {
  const [mounted, setMounted] = useState(false);
  
  useEffect(() => setMounted(true), []);
  
  if (!mounted) return <div style={{ visibility: 'hidden' }}>{children}</div>;
  return <ThemeProvider>{children}</ThemeProvider>;
}

// 方案2: 使用 next/dynamic 禁用 SSR
import dynamic from 'next/dynamic';
```

## 8. 选型决策树

```
你的状态需要？
  ├── 仅当前会话（关闭标签就丢）
  │   → sessionStore / URL state
  │
  ├── 刷新页面后还要
  │   ├── 小量简单数据 (< 几 KB)
  │   │   → localStorage（最简单通用）
  │   │
  │   └── 结构化大数据 / 文件
  │       → IndexedDB (Dexie.js)
  │
  ├── 需要在 URL 中体现（可分享/可书签）
  │   → URL searchParams / hash
  │
  ├── 需要发给服务器的
  │   → POST/PUT API
  │
  ├── 需要跨设备/跨浏览器同步
  │   → Remote DB + 用户认证
  │
  └── 需要跨标签页实时同步
      → BroadcastChannel / storage event
```

## 9. 总结

```
┌──────────────────────────────────────────────────┐
│         持久化方案速查                             │
├──────────────────────────────────────────────────┤
│ localStorage: 简单偏好设置，5MB 限制             │
│ sessionStorage: 临时表单数据，标签关闭即丢        │
│ IndexedDB: 大量结构化数据，需 Dexie 简化          │
│ Cookie: 认证 token（4KB），每次请求自动携带    │
│ URL params/hash: 可分享状态，容量小             │
│ Remote API: 业务数据的最终来源                  │
│ BroadcastChannel: 跨标签页实时同步              │
│ SSR注意: localStorage 不可用，需 mounted 检测    │
│ 库集成: Zustand persist / Jotai atomWithStorage │
└──────────────────────────────────────────────────┘
```
