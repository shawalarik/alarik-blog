# React 元框架中的样式方案

## 概述

在 Next.js、Remix、Astro 等 React 元框架中选择合适的样式方案至关重要。不同的样式技术在 **SSR 兼容性**、**运行时开销**、**DX 体验** 上各有优劣。

## 一、方案全面对比

| 方案 | 运行时开销 | SSR 支持 | 包体积 | 类型安全 | 灵活性 |
|------|-----------|----------|--------|----------|--------|
| **Tailwind CSS** | ~0 (编译时) | ✅ 原生 | ~12kB | ⭐⭐⭐⭐ | ⭐⭐⭐ |
| **CSS Modules** | 0 | ✅ 原生 | 0 | ⭐⭐⭐ | ⭐⭐⭐⭐ |
| **styled-components** | ~15KB | ✅ 需插件 | ~15KB | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| **Emotion** | ~8KB | ✅ 需插件 | ~8KB | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| **Vanilla Extract** | 0 (编译时) | ✅ 原生 | ~3KB | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| **Stitches** | ~3KB | ✅ 原生 | ~3KB | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |

## 二、Tailwind CSS（推荐首选）

### 2.1 安装与配置

```bash
npm install tailwindcss @tailwindcss/postcss postcss autoprefixer
npx tailwindcss init -p
```

```typescript
// tailwind.config.ts
import type { Config } from "tailwindcss"

const config: Config = {
  content: [
    "./app/**/*.{ts,tsx}",
    "./components/**/*.{ts,tsx}",
  ],
  theme: {
    extend: {
      colors: {
        brand: { 50: '#eff6ff', 500: '#3b82f6', 900: '#1e3a8a' },
      },
      fontFamily: { sans: ['Inter', 'system-ui'] },
    },
  },
}

export default config
```

```css
/* globals.css */
@import "tailwindcss";

@theme {
  --color-brand-500: #3b82f6;
  --color-brand-900: #1e3a8a;
}
```

### 2.2 Next.js 集成示例

```tsx
// app/layout.tsx
import "./globals.css"

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="zh-CN">
      <body className="font-sans antialiased bg-white text-gray-900">
        {children}
      </body>
    </html>
  )
}

// components/card.tsx — utility-first
export function Card({ title, children }: Props) {
  return (
    <div className="rounded-xl border border-gray-200 bg-white p-6 shadow-sm 
                    hover:shadow-md transition-shadow">
      <h3 className="text-lg font-semibold text-gray-900 mb-3">{title}</h3>
      <p className="text-gray-600">{children}</p>
    </div>
  )
}
```

### 2.3 最佳实践：cva + Tailwind

```bash
npm install class-variance-authority clsx tailwind-merge
```

```tsx
// lib/cn.ts — 合并 className 工具
import { clsx, type ClassValue } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}

// components/button.tsx
import { cva, type VariantProps } from "class-variance-authority"
import { cn } from "@/lib/cn"

const buttonVariants = cva(
  "inline-flex items-center justify-center rounded-lg font-medium transition-colors focus:outline-none",
  {
    variants: {
      variant: {
        primary: "bg-blue-600 text-white hover:bg-blue-700",
        secondary: "bg-gray-100 text-gray-900 hover:bg-gray-200",
        ghost: "text-gray-600 hover:bg-gray-100",
        destructive: "bg-red-600 text-white hover:bg-red-700",
      },
      size: {
        sm: "h-8 px-3 text-xs",
        md: "h-10 px-4 text-sm",
        lg: "h-12 px-6 text-base",
        icon: "h-10 w-10",
      },
    },
    defaultVariants: { variant: "primary", size: "md" }
  }
)

export interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement>,
  VariantProps<typeof buttonVariants> {}

export const Button = ({ className, variant, size, ...props }: ButtonProps) => (
  <button className={cn(buttonVariants({ variant, size, className }))} {...props} />
)
```

## 三、CSS Modules

### 3.1 基础用法

```css
/* Card.module.css */
.card {
  padding: 1.5rem;
  border-radius: 0.75rem;
  background: white;
  border: 1px solid var(--color-border);
  box-shadow: var(--shadow-sm);
  transition: box-shadow 200ms ease;
}
.card:hover { box-shadow: var(--shadow-md); }

.title {
  font-size: 1.125rem;
  font-weight: 600;
  color: var(--color-text);
  margin-bottom: 0.75rem;
}
```

```tsx
import styles from "./Card.module.css"

export function Card({ title, children }: Props) {
  return (
    <div className={styles.card}>
      <h3 className={styles.title}>{title}</h3>
      {children}
    </div>
  )
}
```

### 3.2 CSS Modules + CSS Variables 主题

```css
/* themes/theme.css */
:root {
  --color-bg: #ffffff;
  --color-text: #1a1a1a;
  --color-primary: #3b82f6;
  --radius-card: 0.75rem;
  --shadow-sm: 0 1px 2px rgba(0,0,0,0.05);
}
[data-theme="dark"] {
  --color-bg: #0f172a;
  --color-text: #e2e8f0;
  --color-primary: #60a5fa;
  --shadow-sm: 0 1px 2px rgba(0,0,0,0.3);
}
```

## 四、styled-components（运行时 CSS-in-JS）

### 4.1 Next.js 集成

```typescript
// next.config.ts
const nextConfig = {
  compiler: {
    styledComponents: true, // 关键：SSR 编译支持
  },
}
```

```tsx
// components/StyledCard.tsx
import styled from "styled-components"

const StyledCard = styled.div<{ $variant?: "default" | "featured" }>`
  padding: 1.5rem;
  border-radius: 0.75rem;
  background: white;
  border: 1px solid ${props => props.theme.colors.border};
  transition: box-shadow 200ms ease;

  &:hover { box-shadow: ${props => props.theme.shadows.md}; }

  ${props => props.$variant === "featured" && `
    border-color: ${props => props.theme.colors.primary};
  `}
`

const Title = styled.h3`
  font-size: 1.125rem;
  font-weight: 600;
  color: ${props => props.theme.colors.text};
`
```

### 4.2 主题 Provider

```tsx
// providers/theme-provider.tsx
"use client"
import { ThemeProvider as SCThemeProvider } from "styled-components"

const theme = {
  colors: {
    primary: "#3b82f6",
    text: "#1a1a1a",
    border: "#e5e7eb",
  },
  shadows: {
    sm: "0 1px 2px rgba(0,0,0,0.05)",
    md: "0 4px 6px rgba(0,0,0,0.1)",
  },
}

export default function ThemeProvider({ children }: { children: React.ReactNode }) {
  return <SCThemeProvider theme={theme}>{children}</SCThemeProvider>
}
```

## 五、Vanilla Extract（零运行时 CSS-in-JS）

```bash
npm install @vanilla-extract/css
```

```tsx
// styles/card.css.ts
import { style, themeVars } from "@vanilla-extract/css"

export const card = style({
  padding: "1.5rem",
  borderRadius: "0.75rem",
  backgroundColor: white,
  border: `1px solid ${theme.vars.color.border}`,
  selectors: {
    "&:hover": { boxShadow: theme.vars.shadow.md },
  },
})

export const title = style({
  fontSize: "1.125rem",
  fontWeight: 600,
  color: theme.vars.color.text,
  marginBottom: "0.75rem",
})

// 使用
// import { card, title } from "./card.css.ts"
// <div className={card}><h3 className={title}>Title</h3></div>
```

## 六、各框架 SSR 特殊注意事项

### 6.1 SSR 中的关键问题

| 问题 | 说明 | 解决方案 |
|------|------|----------|
| **FOUC (Flash of Unstyled Content)** | 样式加载前闪现无样式内容 | Critical CSS 内联 + `style-loader` |
| **Hydration Mismatch** | SSR 和 CSR 渲染结果不一致 | 确保 class/id 稳定、避免随机值 |
| **CSS Order** | 样式加载顺序导致覆盖异常 | 统一导入顺序、使用 CSS Layers |
| **重复注入** | 每次渲染重复插入 `<style>` | 使用缓存机制（如 `styled-components` Babel 插件） |

### 6.2 各框架的样式集成建议

| 框架 | 推荐方案 | 备选方案 |
|------|---------|----------|
| **Next.js** | Tailwind CSS + cva | CSS Modules / Vanilla Extract |
| **Remix** | Tailwind CSS | CSS Modules / Vanilla Extract |
| **Astro** | Tailwind CSS / Scoped CSS | Astro 的 `:global()` / CSS Modules |
| **Gatsby** | Tailwind CSS / CSS Modules | styled-components（有官方插件） |

### 6.3 性能优化清单

- [ ] 启用 **Critical CSS 内联**（Next.js 自动处理）
- [ ] 使用 **PurgeCSS**（Tailwind 默认）移除未使用的类
- [ ] 图片用 **WebP/AVIF** 格式
- [ ] 字体使用 `font-display: swap` + 预加载关键字体
- [ ] 动画优先用 **GPU 加速属性**（transform/opacity）
- [ ] 避免运行时 **CSS-in-JS** 在大型列表中使用
- [ ] 使用 **CSS containment** (`contain: layout style`) 隔离重排范围

## 七、选型建议

```
追求最佳性能？     → Tailwind CSS 或 Vanilla Extract
需要极致灵活？     → Emotion 或 styled-components
团队熟悉传统 CSS？ → CSS Modules
需要强类型安全？   → Vanilla Extract 或 Stitches
已有设计系统？     → Tailwind + 设计 Token
需要动态主题？     → CSS Variables + 任意方案
```
