# 元框架中的状态管理策略

## 概述

在 Next.js、Remix 等元框架中，状态管理比传统 SPA 更复杂——你需要同时考虑 **服务端数据（Server State）**、**客户端状态（Client State）**、**URL 状态** 以及 **Server Components 中的特殊限制**。

```
┌─────────────────────────────────────────────────────────┐
│              元框架中的状态分类                            │
│                                                          │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐   │
│  │ Server State │  │ Client State │  │   URL State  │   │
│  │ 服务端数据    │  │ 客户端数据    │  │ URL 参数/Hash │   │
│  ├──────────────┤  ├──────────────┤  ├──────────────┤   │
│  │ • API 数据   │  │ • UI 状态    │  │ • searchParams│   │
│  │ • 数据库记录 │  │ • 表单中间态  │  │ • pathname    │   │
│  │ • 缓存策略   │  │ • 主题偏好   │  │ • hash         │   │
│  │ • 同步/异步  │  │ • Modal/Tabs │  │ • history API  │   │
│  └──────┬───────┘  └──────┬───────┘  └──────┬───────┘   │
│         │                 │                 │             │
│         ▼                 ▼                 ▼             │
│  TanStack Query / SWR   Zustand / Jotai  useSearchParams │
│  Server Actions          useReducer       router.replace  │
│  RSC Fetch               Context API                     │
│                                                         │
│  ┌─────────────────────────────────────────────────┐   │
│  │           Server Components 限制                  │   │
│  │  ❌ useState/useEffect/useContext (不可用)         │   │
│  │  ❌ 仅可访问 async/await fetch                   │   │
│  │  ✅ 数据通过 props 向下传递                      │   │
│  │  ✅ 通过 Server Actions 触发变更                │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
```

## 一、Server State 管理

### 1.1 Next.js App Router 中的数据获取

```tsx
// app/blog/[slug]/page.tsx — Server Component 直接获取
async function getPost(slug: string) {
  const res = await fetch(`${API_URL}/posts/${slug}`, {
    // ISR: 缓存 + 定期重新验证
    next: { revalidate: 3600 }, // 1 小时
  })
  if (!res.ok) notFound()
  return res.json()
}

export default async function BlogPost({ params }: { params: Promise<{ slug: string }> }) {
  const { slug } = await params
  const post = await getPost(slug)

  return <Article post={post} />
}
```

### 1.2 TanStack Query v5（客户端数据获取首选）

```bash
npm install @tanstack/react-query axios
```

```tsx
// providers/query-provider.tsx
"use client"
import { QueryClient, QueryClientProvider } from "@tanstack/react-query"
import { useState } from "react"

export default function QueryProvider({ children }: { children: React.ReactNode }) {
  const [queryClient] = useState(() => new QueryClient({
    defaultOptions: {
      queries: {
        staleTime: 60 * 1000,       // 1 分钟内认为数据新鲜
        gcTime: 10 * 60 * 1000,    // 10 分钟垃圾回收
        retry: 2,                   // 失败重试 2 次
        refetchOnWindowFocus: false, // 窗口聚焦不自动重取
      },
    },
  }))

  return <QueryClientProvider client={queryClient}>{children}</QueryClientProvider>
}
```

```tsx
// hooks/use-posts.ts
"use client"
import { useQuery, useMutation, useQueryClient } from "@tanstack/react-query"
import api from "@/lib/api"

export function usePosts(params?: { page?: number; tag?: string }) {
  return useQuery({
    queryKey: ["posts", params],
    queryFn: () => api.getPosts(params),
  })
}

export function useCreatePost() {
  const queryClient = useQueryClient()

  return useMutation({
    mutationFn: (data: CreatePostInput) => api.createPost(data),
    onSuccess: () => {
      // 创建成功后使 posts 列表失效，触发重新获取
      queryClient.invalidateQueries({ queryKey: ["posts"] })
    },
  })
}

export function useUpdatePost() {
  const queryClient = useQueryClient()

  return useMutation({
    mutationFn: ({ id, data }: { id: string; data: UpdatePostInput }) =>
      api.updatePost(id, data),
    // 乐观更新
    onMutate: async ({ id, data }) => {
      await queryClient.cancelQueries({ queryKey: ["posts", id] })
      const previous = queryClient.getQueryData(["posts", id])
      queryClient.setQueryData(["posts", id], data)
      return { previous }
    },
    onError: (_err, { id }, context) => {
      // 回滚到之前的状态
      queryClient.setQueryData(["posts", id], context!.previous)
    },
    onSettled: () => {
      queryClient.invalidateQueries({ queryKey: ["posts"] })
    },
  })
}
```

```tsx
// app/posts/page.tsx
"use client"
import Link from "next/link"
import { usePosts, useDeletePost } from "@/hooks/use-posts"

export default function PostsPage() {
  const { data: posts, isLoading, error } = usePosts()
  const deleteMutation = useDeletePost()

  if (isLoading) return <PostsSkeleton />
  if (error) return <ErrorDisplay error={error} />

  return (
    <div>
      <h1>文章列表</h1>
      <ul>
        {posts?.map(post => (
          <li key={post.id} className="flex justify-between items-center py-2">
            <Link href={`/posts/${post.id}`}>{post.title}</Link>
            <button
              onClick={() => deleteMutation.mutate(post.id)}
              disabled={deleteMutation.isPending}
              className="text-red text-sm"
            >
              删除
            </button>
          </li>
        ))}
      </ul>
    </div>
  )
}
```

### 1.3 SWR 替代方案

```tsx
// SWR 更轻量，API 更简洁
import useSWR from "swr/mutation" // 支持 mutation
import useSWR from "swr/immutable" // 只获取一次

const fetcher = (url: string) => fetch(url).then(r => r.json())

function Profile() {
  const { data, error, isLoading } = useSWR("/api/user", fetcher, {
    revalidateOnFocus: false,
  })

  if (isLoading) return <Spinner />
  if (error) return <ErrorMessage />

  return <div>Hello, {data.name}!</div>
}
```

| 维度 | TanStack Query | SWR |
|------|----------------|-----|
| **包体积** | ~13kB (gzipped) | ~6kB (gzipped) |
| **功能完整度** | ★★★★★ | ★★★★☆ |
| **DevTools** | ✅ 优秀 | ❌ 无官方 |
| **Mutation API** | 内置丰富 | 需 swr/mutation |
| **TypeScript** | ★★★★★ | ★★★★☆ |
| **社区活跃度** | ★★★★★ | ★★★★☆ |
| **学习曲线** | 中等 | 较低 |

## 二、客户端状态管理

### 2.1 Zustand（推荐用于元框架）

```bash
npm install zustand immer
```

```tsx
// stores/ui-store.ts
import { create } from "zustand"
import { devtools, persist } from "zustand/middleware"
import { immer } from "zustand/middleware/immer"

interface UIState {
  sidebarOpen: boolean
  activeModal: string | null
  theme: "light" | "dark"
  toggleSidebar: () => void
  openModal: (id: string) => void
  closeModal: () => void
  setTheme: (theme: "light" | "dark") => void
}

export const useUIStore = create<UIState>()(
  devtools(
    persist(
      immer((set) => ({
        sidebarOpen: true,
        activeModal: null,
        theme: "light",

        toggleSidebar: () =>
          set((state) => { state.sidebarOpen = !state.sidebarOpen }),

        openModal: (id) =>
          set((state) => { state.activeModal = id }),

        closeModal: () =>
          set((state) => { state.activeModal = null }),

        setTheme: (theme) =>
          set((state) => { state.theme = theme }),
      })),
      { name: "ui-storage", partialize: (s) => ({ theme: s.theme }) }
    ),
    { name: "UIStore" }
  )
)
```

```tsx
// components/sidebar.tsx
"use client"
import { useUIStore } from "@/stores/ui-store"

export default function Sidebar() {
  const sidebarOpen = useUIStore(s => s.sidebarOpen)
  const toggleSidebar = useUIStore(s => s.toggleSidebar)

  if (!sidebarOpen) return null

  return (
    <aside className="w-64 bg-gray-100 h-full">
      {/* ... */}
      <button onClick={toggleSidebar}>收起</button>
    </aside>
  )
}
```

### 2.2 Jotai（原子化状态）

```tsx
// atoms/post-atom.ts
import { atom } from "jotai"

// 原子
export const postIdAtom = atom<string>("")

// 派生原子（异步）
export const postAtom = atom(async (get) => {
  const id = get(postIdAtom)
  if (!id) return null
  const res = await fetch(`/api/posts/${id}`)
  return res.json()
})

// 可写派生原子
export const editModeAtom = atom(false, (get, set, value: boolean) => {
  set(editModeAtom, value)
})
```

```tsx
// components/post-editor.tsx
"use client"
import { useAtomValue, useSetAtom } from "jotai"
import { postIdAtom, postAtom, editModeAtom } from "@/atoms/post-atom"

export default function PostEditor() {
  const setPostId = useSetAtom(postIdAtom)
  const post = useAtomValue(postAtom)
  const [editMode, setEditMode] = useAtom(editModeAtom)

  useEffect(() => { setPostId("123") }, [])

  if (!post) return <Loading />

  return (
    <div>
      {!editMode ? (
        <article>{post.content}</article>
      ) : (
        <form>...</form>
      )}
      <button onClick={() => setEditMode(!editMode)}>
        {editMode ? "取消" : "编辑"}
      </button>
    </div>
  )
}
```

## 三、Server Components 与状态管理的交互

### 3.1 数据流向图

```
Server Component (RSC Payload)
  │
  ├── props → Client Component
  │              │
  │              ├── useState (本地 UI 状态)
  │              ├── Zustand/Jotai (全局客户端状态)
  │              └── TanStack Query (服务端状态同步)
  │
  ├── Server Action (用户触发变更)
  │              │
  │              ├── 写入数据库
  │              └── revalidatePath / revalidateTag
  │                    │
  │                    ↓ (下一次请求)
  │              Server Component 重新执行
  │                    │
  │                    ↓ (新 RSC Payload)
  │              Client Component 接收新 props
  │
  └── URL 变化 → 新的 Server Component 执行
```

### 3.2 RSC 中不能用的 Hook

| Hook | Server Component 可用? | 替代方案 |
|------|-----------------------|----------|
| `useState` | ❌ | URL searchParams / Server Action 返回值 |
| `useEffect` | ❌ | 不需要（组件每次请求都重新执行） |
| `useContext` | ❌ | Props drilling / Server Action 参数 |
| `useSWR` | ❌ | `fetch()` + `next: { revalidate }` |
| `useQuery` | ❌ | 同上 |
| `Zustand` | ❌ | 数据库直接查询 |
| `Jotai` | ❌ | 同上 |
| `cookies()` | ✅ | Next.js 内置 |
| `headers()` | ✅ | Next.js 内置 |
| `fetch()` | ✅ | 扩展版，支持缓存选项 |

### 3.3 典型架构模式

```tsx
// app/dashboard/page.tsx —— Server Component 作为数据边界
import { auth } from "@/lib/auth"
import { DashboardShell } from "@/components/dashboard-shell"
import { DashboardClient } from "@/components/dashboard-client"

export default async function DashboardPage() {
  // 1. 认证检查
  const session = await auth()
  
  // 2. 服务端获取核心数据
  const [stats, recentActivity] = await Promise.all([
    getDashboardStats(session.user.id),
    getRecentActivity(session.user.id),
  ])

  // 3. 将数据传递给 Client Component
  return (
    <DashboardShell user={session.user}>
      <DashboardClient
        initialStats={stats}
        initialActivity={recentActivity}
        userId={session.user.id}
      />
    </DashboardShell>
  )
}

// components/dashboard-client.tsx —— Client Component 管理交互状态
"use client"
import { useQuery } from "@tanstack/react-query"
import { useUIStore } from "@/stores/ui-store"
import type { DashboardClientProps } from "./types"

export function DashboardClient({ initialStats, initialActivity, userId }: DashboardClientProps) {
  const [activeTab, setActiveTab] = useState("overview")
  const sidebarOpen = useUIStore(s => s.sidebarOpen)

  // 用初始数据作为占位符，后台静默刷新
  const { data: stats } = useQuery({
    queryKey: ["dashboard-stats", userId],
    queryFn: () => getDashboardStats(userId),
    initialData: initialStats,
  })

  return (
    <div className={cn("flex", !sidebarOpen && "sidebar-collapsed")}>
      <TabBar activeTab={activeTab} onChange={setActiveTab} />
      {activeTab === "overview" && <StatsCards stats={stats} />}
      {activeTab === "activity" && <ActivityFeed items={initialActivity} />}
    </div>
  )
}
```

## 四、Remix 中的状态管理

### 4.1 Remix 的独特方式

Remix 不鼓励复杂的客户端状态库——它的 loader/action 模型已经解决了大部分需求：

```tsx
// Remix 推荐的数据流：
//
// 1. Loader → 服务端加载数据 → useLoaderData() 获取
// 2. 用户操作 → Form submit → action 处理
// 3. Action 完成 → 所有 loaders 自动 revalidate
// 4. 更新后的数据 → useLoaderData() 自动更新
//
// 不需要 React Query / SWR 来做数据同步！

// 仅需在以下场景引入额外状态管理：
// - 跨路由共享的纯 UI 状态（侧边栏、主题）
// - WebSocket 实时数据
// - 复杂的表单中间态（草稿保存）
```

### 4.2 Remix + Zustand 示例

```tsx
// app/stores/editor-store.ts
import { create } from "zustand"

interface EditorDraft {
  title: string
  content: string
  lastSaved: Date | null
}

export const useEditorStore = create<{
  drafts: Record<string, EditorDraft>
  updateDraft: (postId: string, partial: Partial<EditorDraft>) => void
  clearDraft: (postId: string) => void
}>((set) => ({
  drafts: {},
  updateDraft: (postId, partial) =>
    set((s) => ({
      drafts: { ...s.drafts, [postId]: { ...s.drafts[postId], ...partial } },
    })),
  clearDraft: (postId) =>
    set((s) => {
      const { [postId]: _, ...rest } = s.drafts
      return { drafts: rest }
    }),
}))
```

## 五、URL 作为状态源

### 5.1 Next.js URL State

```tsx
// app/products/page.tsx
"use client"
import { useSearchParams, useRouter, usePathname } from "next/navigation"

export default function ProductsPage() {
  const searchParams = useSearchParams()
  const router = useRouter()
  const pathname = usePathname()

  const page = Number(searchParams.get("page") ?? "1")
  const sort = searchParams.get("sort") ?? "newest"
  const category = searchParams.get("category")

  const handleFilterChange = (key: string, value: string | null) => {
    const params = new URLSearchParams(searchParams.toString())
    if (value) params.set(key, value)
    else params.delete(key)
    
    // 替换 URL，不触发重新渲染（如果只是 URL state）
    router.push(`${pathname}?${params.toString()}`, { scroll: false })
  }

  return (
    <div>
      <select value={sort} onChange={(e) => handleFilterChange("sort", e.target.value)}>
        <option value="newest">最新</option>
        <option value="popular">最热</option>
      </select>

      <ProductGrid page={page} sort={sort} category={category} />

      <Pagination current={page} total={totalPages} onPageChange={(p) => handleFilterChange("page", String(p))} />
    </div>
  )
}
```

### 5.2 Remix URL State

      {/* ... */}

      {/* 分页也用 URL 参数 */}

}

## 六、状态管理组合策略

### 6.1 推荐组合

| 场景 | 推荐方案 | 理由 |
|------|---------|------|
| **服务端数据（API/DB）** | TanStack Query / SWR | 缓存、重试、乐观更新 |
| **全局 UI 状态** | Zustand | 轻量、简单、SSR 安全 |
| **局部组件状态** | React useState / useReducer | 无需额外依赖 |
| **复杂状态逻辑** | Jotai / XState | 原子化或状态机 |
| **URL 驱动状态** | useSearchParams | 可分享、可书签、SEO 友好 |
| **表单状态** | react-hook-form / zod | 校验 + 性能优化 |
| **主题/国际化** | Zustand (persist) + CSS Variables | 持久化到 localStorage |
| **实时数据 (WebSocket)** | 自定义 Hook / Zustand + ws | 手动管理连接 |

### 6.2 架构模板

```
你的应用
│
├── Server Components (Next.js) / Loaders (Remix)
│   └── fetch() 数据 → 传递给 Client Components
│
├── Client Components
│   │
│   ├── Server State 层
│   │   └── TanStack Query (或 SWR)
│   │       ├── useQuery() — 获取
│   │       ├── useMutation() — 变更
│   │       └── useInfiniteQuery() — 分页
│   │
│   ├── Global UI State 层
│   │   └── Zustand Store(s)
│   │       ├── uiStore — 侧边栏/主题/模态框
│   │       └── userStore — 当前用户信息（从 session 同步）
│   │
│   ├── Local State 层
│   │   └── useState / useReducer
│   │       └── 表单输入、展开/折叠等
│   │
│   └── URL State 层
│       └── useSearchParams / usePathname
│           └── 搜索/筛选/分页/标签页
│
└── 持久化层
    └── localStorage / IndexedDB / Cookie
        └── Zustand persist / TanStack persist
```
