# 开发服务器中间件实战

## 概述

开发服务器（Dev Server）是前端工程化的核心基础设施。无论是 Vite、Webpack Dev Server 还是自定义 dev server，其本质都是基于 **HTTP 中间件** 的请求处理管道。

## 一、Express vs Connect vs H3

### 1.1 框架选择

| 特性 | Express | Connect (Vite 用) | H3 (Nitro/UnJS) |
|------|---------|-------------------|------------------|
| **体积** | ~800KB | ~100KB | ~50KB |
| **路由** | 内置 express.Router | 需自行实现或用 find-my-way | 内置 router |
| **中间件风格** | `(req, res, next)` | 同左 | 事件驱动 |
| **性能** | 基准 | 更快 | 最快 |
| **生态** | 最大 | 中等 | 增长中 |

## 二、Express 开发服务器

### 2.1 完整示例

```typescript
// server/dev-server.ts
import express from "express"
import compression from "compression"
import cors from "cors"
import { createProxyMiddleware } from "http-proxy-middleware"
import history from "connect-history-api-fallback"
import { WebSocketServer, WebSocket } from "ws"
import chokidar from "chokidar"
import path from "path"

const app = express()
const PORT = process.env.PORT ?? 3000

// ① 日志中间件
app.use((req, _res, next) => {
  console.log(`${req.method} ${req.url}`)
  next()
})

// ② CORS
app.use(cors({
  origin: ["http://localhost:5173"],
  credentials: true,
}))

// ③ Gzip/Brotli 压缩
app.use(compression({
  threshold: 1024,
  filter: (req, res) => {
    if (req.headers["x-no-compression"]) return false
    return compression.filter(req, res)
  },
}))

// ④ JSON 解析（用于 Mock API）
app.use(express.json())

// ⑤ API 代理
app.use("/api", createProxyMiddleware({
  target: "https://api.example.com",
  changeOrigin: true,
  pathRewrite: { "^/api": "" },
  onProxyReq(proxyReq, req) {
    // 注入认证 header
    if (req.headers.authorization) {
      proxyReq.setHeader("Authorization", req.headers.authorization!)
    }
  },
  onError(err, _req, res) {
    console.error("代理错误:", err.message)
    res.status(502).json({ error: "上游服务不可用" })
  },
}))

// ⑥ Mock API
app.get("/api/users", (_req, res) => {
  res.json([
    { id: 1, name: "Alice", email: "alice@example.com" },
    { id: 2, name: "Bob", email: "bob@example.com" },
  ])
})

// ⑦ SPA History 回退
app.use(history({
  index: "/index.html',
  rewrites: [
    { from: /^\/api\/.*$/, to: (context) => context.parsedUrl.pathname },
  ],
}))

// ⑧ 静态文件服务
app.use(express.static(path.resolve(__dirname, "../public"), {
  maxAge: "1h",
  etag: true,
  setHeaders(res, filePath) {
    if (filePath.endsWith(".html")) {
      res.setHeader("Cache-Control", "no-cache")
    }
  },
}))

// 启动 HTTP 服务器
const server = app.listen(PORT, () => {
  console.log(`🚀 Dev Server running at http://localhost:${PORT}`)
})

// ⑨ WebSocket (HMR 通信)
const wss = new WebSocketServer({ server, path: "/ws" })

wss.on("connection", (ws) => {
  console.log("WebSocket client connected")

  ws.on("message", (raw) => {
    try {
      const msg = JSON.parse(raw.toString())
      
      switch (msg.type) {
        case "ping":
          ws.send(JSON.stringify({ type: "pong", timestamp: Date.now() }))
          break
        
        case "subscribe":
          // 订阅特定资源变更
          console.log(`Client subscribed to: ${msg.resource}`)
          break
      }
    } catch (e) {
      // ignore invalid messages
    }
  })
})

// ⑩ 文件监听 → HMR 推送
const watcher = chokidar.watch(path.resolve(__dirname, "../src"), {
  ignored: [/node_modules/, /\.git/],
  persistent: true,
})

watcher.on("change", (filePath) => {
  const relativePath = path.relative(process.cwd(), filePath).replace(/\\/g, "/")
  
  console.log(`[HMR] File changed: ${relativePath}`)
  
  wss.clients.forEach((client) => {
    if (client.readyState === WebSocket.OPEN) {
      client.send(JSON.stringify({
        type: "update",
        timestamp: Date.now(),
        file: relativePath,
      }))
    }
  })
})
```

### 3.2 简易 Mock（无需 MSW）

```typescript
// server/mocks.ts
import express from "express"
import { randomUUID } from "crypto"

interface MockDB<T extends { id: string }> {
  data: T[]
}

class SimpleMockDB<T extends Record<string, unknown>> implements MockDB<T & { id: string }> {
  data: (T & { id: string })[] = []

  getAll() { return [...this.data] }
  
  getById(id: string) { return this.data.find(item => item.id === id) }
  
  create(item: Omit<T & { id: string }, "id">) {
    const newItem = { ...item, id: randomUUID() } as T & { id: string }
    this.data.push(newItem)
    return newItem
  }
  
  update(id: string, updates: Partial<T>) {
    const idx = this.data.findIndex(i => i.id === id)
    if (idx === -1) return null
    this.data[idx] = { ...this.data[idx], ...updates }
    return this.data[idx]
  }
  
  delete(id: string) {
    const idx = this.data.findIndex(i => i.id === id)
    if (idx === -1) return false
    this.data.splice(idx, 1)
    return true
  }
}

// 使用
const postsDB = new SimpleMockDB<{ title: string; content: string; published: boolean }>()

// 初始化种子数据
postsDB.create({ title: "Hello World", content: "First post!", published: true })
postsDB.create({ title: "Draft Post", content: "Not ready yet...", published: false })

// 生成 CRUD 路由
function createCRUDRouter(db: SimpleMockDB<any>, basePath: string): express.Router {
  const router = express.Router()

  router.get("/", (_, res) => res.json(db.getAll()))
  router.get("/:id", (req, res) => {
    const item = db.getById(req.params.id)
    item ? res.json(item) : res.status(404).json({ error: "Not found" })
  })
  router.post("/", (req, res) => res.status(201).json(db.create(req.body)))
  router.put("/:id", (req, res) => {
    const updated = db.update(req.params.id, req.body)
    updated ? res.json(updated) : res.status(404).json({ error: "Not found" })
  })
  router.delete("/:id", (req, res) => {
    db.delete(req.params.id) ? res.status(204).send() : res.status(404).json({ error: "Not found" })
  })

  return router
}
```

## 五、热更新通信协议

### 5.1 标准 HMR 协议

```
Client → Server:
  {"type": "ping"}
  {"type": "custom:subscribe", "resource": "/src/App.tsx"}

Server → Client:
  {"type": "connected"}                          // 连接确认
  {"type": "pong", "timestamp": 1700000000000}     // 心跳响应
  {"type": "full-reload"}                         // 整页刷新
  {"type": "update", "updates": [                 // HMR 更新
    {
      "type": "js-update",                        // 或 css-update / js-update / custom-update
      "timestamp": 1700000000000,
      "path": "/src/App.tsx",
      "acceptedPath": "/src/App.tsx",
      "explicitImportRequired": false,
      "isWithinCircularImport": false
    }
  ]}
  {"type": "custom", "event": "config-changed",    // 自定义事件
   "data": {"path": "/vite.config.ts"}}
  {"type": "error", "err": {                       // 错误推送
    "message": "...",
    "stack": "...",
    "plugin": "vite:react",
    "id": "...",
    "loc": { file, line, column }
  }}
```

## 六、Dev Server 性能优化

| 优化项 | 方法 | 效果 |
|--------|------|------|
| **静态缓存** | `Cache-Control: immutable` for hashed assets | 减少重复传输 |
| **Gzip/Brotli** | compression 中间件 | 减少 70% 传输量 |
| **按需编译** | 只编译被请求的文件（Vite 方式） | 启动速度极快 |
| **内存缓存** | 编译结果缓存到内存 Map | 二次请求零开销 |
| **Watch 排除** | chokidar.ignored 排除 node_modules | 减少 IO |
| **Worker 线程** | 重计算任务放入 Worker Thread | 不阻塞主线程 |
