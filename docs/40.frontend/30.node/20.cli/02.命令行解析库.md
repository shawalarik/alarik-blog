## 概述

手动解析 `process.argv` 在简单场景下可行，但面对复杂需求时显得力不从心。社区提供了多个成熟的命令行参数解析库，它们能自动处理参数类型转换、帮助信息生成、子命令等功能。本章介绍主流库的使用方法与选型建议。

## Commander.js 基础与高级用法

Commander.js 是最流行的 Node.js 命令行框架之一，被 Vue CLI、Webpack Dev Server 等知名工具采用。

### 安装

```bash
npm install commander
```

### 基础用法

```js
#!/usr/bin/env node
import { program } from 'commander';

program
  .name('my-tool')
  .description('一个示例 CLI 工具')
  .version('1.0.0')
  .option('-p, --port <number>', '指定端口号', '3000')
  .option('--verbose', '启用详细输出')
  .parse();

const options = program.opts();

if (options.verbose) {
  console.log(`端口: ${options.port}, 详细模式开启`);
}
```

### 子命令定义

```js
#!/usr/bin/env node
import { Command } from 'commander';

const program = new Command();

program
  .name('git-like')
  .description('Git 风格的 CLI 工具')
  .version('1.0.0');

// create 子命令
program.command('create')
  .description('创建新项目')
  .argument('<name>', '项目名称')
  .option('-t, --template <type>', '模板类型', 'default')
  .action((name, options) => {
    console.log(`创建项目: ${name}，使用模板: ${options.template}`);
  });

// deploy 子命令
program.command('deploy')
  .description('部署项目')
  .option('-e, --env <environment>', '部署环境', 'production')
  .option('--dry-run', '模拟运行')
  .action((options) => {
    if (options.dryRun) {
      console.log('[Dry Run] 模拟部署到环境:', options.env);
    } else {
      console.log('正在部署到环境:', options.env);
    }
  });

program.parse();
```

### 变长参数

```js
program.command('build')
  .argument('[files...]', '要构建的文件列表')
  .action((files) => {
    console.log('待构建文件:', files);
  });
```

### 自定义选项处理

```js
program
  .option('--scale <value>', '缩放比例', parseFloat)
  .option('--list <items>', '列表项', (val) => val.split(','))
  .option('--json <data>', 'JSON 数据', JSON.parse);

program.parse();

const opts = program.opts();
// --scale 3.14 → opts.scale === 3.14 (数字类型)
// --list a,b,c → opts.list === ['a', 'b', 'c']
// --json '{"a":1}' → opts.json === { a: 1 }
```

### 命令钩子

```js
program
  .hook('preAction', (thisCommand, actionCommand) => {
    console.log(`即将执行: ${actionCommand.name()}`);
  })
  .hook('postAction', (thisCommand, actionCommand) => {
    console.log(`已完成: ${command.name()}`);
  })
  .command('init')
  .action(() => {
    console.log('执行初始化操作');
  });
```

## Yargs 链式调用

Yargs 以其优雅的链式 API 和丰富的功能著称。

### 安装

```bash
npm install yargs
```

### 基础用法

```js
#!/usr/bin/env node
import yargs from 'yargs';
import { hideBin } from 'yargs/helpers';

yargs(hideBin(process.argv))
  .usage('Usage: $0 [options]')
  .option('port', {
    alias: 'p',
    type: 'number',
    default: 3000,
    description: '服务器端口号'
  })
  .option('host', {
    alias: 'h',
    type: 'string',
    default: 'localhost',
    description: '服务器主机名'
  })
  .demandOption(['port'], '必须指定端口号')
  .help()
  .alias('help', '?')
  .argv;

console.log(yargs(hideBin(process.argv)).argv);
```

### 中间件机制

```js
yargs(hideBin(process.argv))
  .middleware((argv) => {
    // 全局中间件：对所有命令生效
    if (argv.verbose) {
      console.log('[Verbose] 启用详细日志');
    }
  }, true)

  .command(
    'deploy',
    '部署应用',
    (yargs) => {
      return yargs
        .option('env', {
          type: 'string',
          choices: ['dev', 'staging', 'prod'],
          default: 'prod'
        });
    },
    (argv) => {
      console.log('部署到:', argv.env);
    }
  )

  .strictCommands()  // 未知的子命令会报错
  .recommendCommands()  // 自动推荐相似命令
  .parse();
```

### 配置校验

```js
yargs(hideBin(process.argv))
  .option('timeout', {
    type: 'number',
    coerce: (val) => {
      if (val <= 0) throw new Error('超时时间必须为正数');
      return val * 1000;  // 自动转毫秒
    },
    description: '超时时间(秒)'
  })

  .check((argv) => {
    if (argv.port && (argv.port < 1024 || argv.port > 65535)) {
      throw new Error('端口号必须在 1024-65535 范围内');
    }
    return true;
  })

  .fail((msg, err, yargs) => {
    if (msg) console.error(`\x1b[31m错误:\x1b[0m ${msg}`);
    console.error(yargs.help());
    process.exit(1);
  })
  .parse();
```

### 嵌套命令组

```js
yargs(hideBin(process.argv))
  .command('db', '数据库相关操作', (yargs) => {
    return yargs
      .command('migrate', '运行迁移', {}, () => {
        console.log('运行数据库迁移');
      })
      .command('seed', '填充种子数据', () => {
        console.log('填充数据');
      })
      .command('reset', '重置数据库', () => {
        console.log('重置数据库');
      });
  })

  .command('user', '用户管理', (yargs) => {
    return yargs
      .command('create', '创建用户', () => {})
      .command('delete', '删除用户', () => {});
  })

  .demandCommand(1, '请指定要执行的命令')
  .parse();
```

## Minimist 轻量解析

Minimist 是极简风格的参数解析器，体积小（~1KB），无依赖，适合需要精细控制的场景。

### 安装

```bash
npm install minimist
```

### 基本用法

```js
import minimist from 'minimist';

const argv = minimist(process.argv.slice(2));

console.log(argv);
// node app.js --foo=bar -a 1 -b 2
// { _: [], foo: 'bar', a: 1, b: 2 }
```

### 默认值与别名

```js
const options = {
  default: {
    port: 3000,
    host: 'localhost',
    verbose: false
  },
  alias: {
    p: 'port',
    h: 'host',
    v: 'verbose'
  },
  string: ['host'],     // 强制字符串类型
  boolean: ['verbose']   // 强制布尔类型
};

const argv = minimist(process.argv.slice(2), options);
```

### 特殊语法支持

```js
// --no-* 语法：自动转为 false
minimist(['--no-color']);
// { color: false }

// 短选项合并
minimist(['-abc']);
// { a: true, b: true, c: true }

// 分隔符 --
minimist(['--flag', '--', '--not-a-flag']);
// { flag: true, _ : ['--not-a-flag'] }
```

## 对比选型

| 特性 | Commander.js | Yargs | Minimist |
|------|-------------|-------|----------|
| **包大小** | ~50KB | ~100KB | ~1KB |
| **学习曲线** | 低 | 中等 | 极低 |
| **子命令** | ✅ 内置支持 | ✅ 强大支持 | ❌ 不支持 |
| **自动帮助生成** | ✅ | ✅ | ❌ |
| **Tab 补全** | ✅ | ✅ | ❌ |
| **参数校验** | 基础 | 强大（coerce/check） | 手动实现 |
| **中间件/钩子** | hook 机制 | middleware 机制 | ❌ |
| **Shell 补全生成** | ✅ | ✅ | ❌ |
| **TypeScript 支持** | ✅ 原生 | ✅ 原生 | ✅ 类型声明 |
| **适用场景** | 大多数 CLI 工具 | 企业级/复杂 CLI | 微型工具/底层封装 |

### 选型建议

- **选择 Commander.js**：大多数场景的首选，平衡功能与简洁性
- **选择 Yargs**：需要复杂参数校验、嵌套命令、国际化等高级特性
- **选择 Minimist**：追求极致轻量或作为底层解析引擎

## 小结

命令行参数解析是 CLI 开发的核心环节：
- **入门首选** Commander.js，API 直观，文档完善
- **复杂场景** 选择 Yargs，提供中间件、严格校验等企业级能力
- **轻量需求** Minimist，零依赖，灵活可控
