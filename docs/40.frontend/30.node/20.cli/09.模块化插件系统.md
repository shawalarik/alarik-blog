## 概述

插件系统是 CLI 工具走向成熟的重要标志。Vite、Webpack、ESLint、Tailwind CSS 等优秀工具都拥有强大的插件生态系统。本章介绍如何设计插件的接口规范、动态加载机制、钩子系统和配置合并策略。

## 插件接口设计

### 插件契约（Contract）

首先定义插件必须遵循的结构规范：

```typescript
// types/plugin.ts

interface PluginContext {
  /** CLI 工具的版本 */
  version: string;
  /** 项目根目录 */
  root: string;
  /** 用户配置 */
  config: Record<string, unknown>;
  /** 日志工具 */
  log: Logger;
  /** 注册钩子的方法 */
  hooks: HookManager;
}

interface PluginOptions {
  /** 插件自身配置（来自用户的 plugin 配置） */
  [key: string]: unknown;
}

interface CliPlugin {
  /** 插件名称（唯一标识） */
  name: string;

  /** 插件版本 */
  version?: string;

  /** 是否启用（默认 true） */
  enabled?: boolean;

  /** 依赖的其他插件 */
  dependsOn?: string[];

  /** 应用冲突的插件（不可同时使用） */
  conflictsWith?: string[];

  /**
   * 插件入口函数。
   * 接收上下文和选项，返回可选的清理函数或 Promise
   */
  apply: (
    context: PluginContext,
    options?: PluginOptions
  ) => void | Promise<void> | (() => void | Promise<void>);
}

// 导出类型供插件作者使用
export type { CliPlugin, PluginContext, PluginOptions };
```

### 插件示例

```js
// my-plugin/index.js
/** @type {import('my-cli/types').CliPlugin} */
export default function myPlugin() {
  return {
    name: 'example-plugin',
    version: '1.0.0',

    // 声明依赖关系
    dependsOn: ['core-plugin'],

    apply(ctx, options) {
      console.log(`[plugin] ${this.name} 已激活`);

      // 注册 beforeBuild 钩子
      ctx.hooks.beforeBuild.tapPromise(
        'example-plugin',
        async (params) => {
          ctx.log.info('Example: 构建前的准备工作');
          // 修改构建参数
          params.extraFiles = [...(params.extraFiles || []), 'custom.js'];
        }
      );

      // 注册 afterBuild 钩子
      ctx.hooks.afterBuild.tap(
        'example-plugin',
        (result) => {
          ctx.log.info(`Example: 构建完成，产出 ${result.outputCount} 个文件`);
        }
      );

      // 返回清理函数
      return () => {
        console.log(`[plugin] ${this.name} 已卸载`);
      };
    },
  };
}
```

### Tapable 风格的钩子系统

```js
// core/hooks.js

class HookManager {
  #hooks = new Map();

  // 创建新的钩子点
  addHook(name, type = 'series') {
    const hook = {
      type,                    // series | parallel | waterfall | bail
      taps: [],                // 注册的回调列表
    };
    this.#hooks.set(name, hook);
    return hook;
  }

  // 获取或自动创建钩子
  getHook(name) {
    if (!this.#hooks.has(name)) {
      this.addHook(name);
    }
    return this.#hooks.get(name);
  }

  // tap — 同步回调
  tap(hookName, callback) {
    const hook = this.getHook(hookName);
    hook.taps.push({ callback, async: false });
  }

  // tapAsync — 回调风格异步
  tapAsync(hookName, callback) {
    const hook = this.getHook(hookName);
    hook.taps.push({ callback, async: true });
  }

  // tapPromise — Promise 风格异步
  tapPromise(hookName, callback) {
    const hook = this.getHook(hookName);
    hook.taps.push({ callback, async: true, isPromise: true });
  }

  // 触发钩子
  async call(hookName, ...args) {
    const hook = this.#hooks.get(hookName);
    if (!hook || hook.taps.length === 0) return undefined;

    switch (hook.type) {
      case 'parallel':  return this.#runParallel(hook, args);
      case 'waterfall': return this.#runWaterfall(hook, args);
      case 'bail':      return this.#runBail(hook, args);
      case 'series':
      default:          return this.#runSeries(hook, args);
    }
  }

  async #runSeries(hook, args) {
    for (const tap of hook.taps) {
      if (tap.isPromise) {
        await tap.callback(...args);
      } else if (tap.async) {
        await new Promise((resolve, reject) => {
          tap.callback(...args, (err) => err ? reject(err) : resolve());
        });
      } else {
        tap.callback(...args);
      }
    }
  }

  async #runParallel(hook, args) {
    await Promise.all(
      hook.taps.map(tap => {
        if (tap.isPromise || tap.async) return tap.callback(...args);
        return Promise.resolve(tap.callback(...args));
      })
    );
  }

  async #runWaterfall(hook, args) {
    let result = args[0];  // waterfall 将上一个结果传给下一个
    for (const tap of hook.taps) {
      result = await tap.callback(result);
      // 如果返回 undefined，保持原值
      if (result === undefined) result = args[0];
    }
    return result;
  }

  async #runBail(hook, args) {
    for (const tap of hook.taps) {
      const result = await tap.callback(...args);
      if (result !== undefined) return result;
    }
    return undefined;
  }
}
```

## 动态加载插件（import()）

### 插件加载器

```js
// core/loader.js
import { existsSync } from 'fs';
import { resolve, dirname } from 'path';
import { fileURLToPath } from 'url';

const __dirname = dirname(fileURLToPath(import.meta.url));

class PluginLoader {
  #loaded = new Map();  // 缓存已加载的插件

  /**
   * 支持多种插件引用方式：
   * - 'plugin-name'         → npm 包
   * - './local-plugin'      → 相对路径
   * - '/abs/path/plugin'    → 绝对路径
   * - { name, apply }       → 内联对象
   */
  async load(pluginRef) {
    // 内联插件对象
    if (typeof pluginRef === 'object' && pluginRef.apply) {
      return this.#applyPlugin(pluginRef);
    }

    // 字符串形式的插件引用
    const identifier = this.#resolveIdentifier(pluginRef);

    // 检查缓存
    if (this.#loaded.has(identifier)) {
      return this.#loaded.get(identifier);
    }

    let pluginModule;

    try {
      // 动态导入
      const modulePath = this.#resolvePath(pluginRef);
      pluginModule = await import(modulePath);
    } catch (error) {
      throw new PluginLoadError(
        `无法加载插件 "${identifier}": ${error.message}`,
        identifier
      );
    }

    // 获取导出（支持 default 和 named export）
    const pluginFactory =
      pluginModule.default ||
      Object.values(pluginModule).find(
        (exp) => typeof exp === 'function'
      );

    if (typeof pluginFactory !== 'function') {
      throw new PluginLoadError(
        `插件 "${identifier}" 没有有效的导出`,
        identifier
      );
    }

    // 执行工厂函数获取插件定义
    const pluginDef = await pluginFactory();

    if (!pluginDef.name || !pluginDef.apply) {
      throw new PluginLoadError(
        `插件 "${identifier}" 缺少 name 或 apply`,
        identifier
      );
    }

    this.#loaded.set(identifier, pluginDef);
    return pluginDef;
  }

  #resolveIdentifier(ref) {
    return ref.replace(/^[.\/]/, '').replace(/\.\w+$/, '');
  }

  #resolvePath(ref) {
    if (ref.startsWith('.') || ref.startsWith('/')) {
      return resolve(ref);
    }

    // npm 包
    try {
      return require.resolve(ref);
    } catch {
      return ref;  // 让动态 import 自己去解析
    }
  }

  async #applyPlugin(pluginDef, context, options) {
    const cleanup = await pluginDef.apply(context, options);
    return {
      name: pluginDef.name,
      cleanup: typeof cleanup === 'function' ? cleanup : null,
    };
  }
}

class PluginLoadError extends Error {
  constructor(message, pluginId) {
    super(message);
    this.name = 'PluginLoadError';
    this.pluginId = pluginId;
  }
}
```

### 批量加载与拓扑排序

```js
class PluginManager {
  #loader = new PluginLoader();
  #activePlugins = new Map();

  async loadAll(pluginConfigs) {
    // 第一轮：加载所有插件
    const loaded = [];
    for (const config of pluginConfigs) {
      const pluginDef = await this.#loadWithRetry(config);
      loaded.push({ def: pluginDef, options: config.options || {} });
    }

    // 第二轮：依赖排序（拓扑排序）
    const sorted = this.#topologicalSort(loaded);

    // 第三轮：依次激活
    for (const { def, options } of sorted) {
      await this.#activate(def, options);
    }
  }

  async #loadWithRetry(config, retries = 1) {
    const ref = typeof config === 'string' ? config : config.name;
    for (let attempt = 0; attempt <= retries; attempt++) {
      try {
        return await this.#loader.load(ref);
      } catch (error) {
        if (attempt === retries) throw error;
        await new Promise(r => setTimeout(r, 1000 * attempt));
      }
    }
  }

  #topologicalSort(plugins) {
    const visited = new Set();
    const result = [];

    const visit = (plugin) => {
      if (visited.has(plugin.def.name)) return;
      visited.add(plugin.def.name);

      // 先加载依赖
      if (plugin.def.dependsOn) {
        for (const depName of plugin.def.dependsOn) {
          const dep = plugins.find(p => p.def.name === depName);
          if (dep) visit(dep);
          else throw new Error(`插件 "${plugin.def.name}" 依赖的 "${depName}" 未找到`);
        }
      }

      // 检查冲突
      if (plugin.def.conflictsWith) {
        for (const conflictName of plugin.def.conflictsWith) {
          if (visited.has(conflictName)) {
            throw new Error(`插件 "${plugin.def.name}" 与 "${conflictName}" 冲突`);
          }
        }
      }

      result.push(plugin);
    };

    for (const plugin of plugins) {
      visit(plugin);
    }

    return result;
  }

  async #activate(def, options) {
    const context = this.#buildContext();
    const cleanup = await def.apply(context, options);
    this.#activePlugins.set(def.name, { def, cleanup });
  }
```

## 钩子机制

### 预定义钩子点

```js
// 定义 CLI 工具提供的所有钩子点
const HOOK_POINTS = {
  // 初始化阶段
  'initialize': 'series',        // 初始化配置
  'configResolved': 'waterfall', // 配置合并后

  // 构建阶段
  'beforeBuild': 'series',       // 构建前
  'buildModule': 'bail',         // 模块构建
  'afterBuild': 'series',        // 构建后

  // 服务阶段
  'beforeDevServer': 'parallel', // dev server 启动前
  'configureServer': 'waterfall', // server 配置
  'afterDevServer': 'parallel',  // dev server 启动后

  // 输出阶段
  'generateBundle': 'parallel',  // 生成产物
  'writeBundle': 'series',       // 写入磁盘
  'afterWrite': 'parallel',      // 写入完成后

  // 关闭阶段
  'closeBundle': 'series',       // 构建关闭
  'shutdown': 'parallel',        // 进程退出
};
```

### 钩子使用示例

```js
// 用户配置文件 mycli.config.js
import { defineConfig } from 'my-cli';

export default defineConfig({
  plugins: [
    // 带选项的插件
    ['my-plugin', {
      featureFlag: true,
      customHandler: (data) => data.toUpperCase(),
    }],

    // 内联插件
    {
      name: 'inline-plugin',
      apply(ctx) {
        ctx.hooks.buildModule.tap('inline-plugin', (moduleInfo) => {
          console.log('处理模块:', moduleInfo.id);
          return moduleInfo;  // 必须返回
        });
      },
    },

    // 条件加载
    process.env.NODE_ENV === 'development' && {
      name: 'dev-only-plugin',
      apply(ctx) {
        ctx.log.info('仅开发环境激活');
      },
    },
  ].filter(Boolean),  // 过滤掉 falsy 值
});
```

## 插件配置合并

### 配置层级与合并策略

```js
// core/config-merger.js

class ConfigMerger {
  /**
   * 合并多层配置：
   * 1. 插件默认配置
   * 2. 用户配置文件
   * 3. 命令行覆盖
   */
  merge(pluginDefaults, userConfig, cliOverrides) {
    const merged = this.#deepMerge({}, pluginDefaults);
    this.#deepMerge(merged, userConfig);
    this.#deepMerge(merged, cliOverrides);
    return merged;
  }

  #deepMerge(target, source) {
    for (const [key, value] of Object.entries(source)) {
      if (value === undefined || value === null) continue;

      if (
        Array.isArray(value) &&
        Array.isArray(target[key])
      ) {
        // 数组默认替换（也可根据策略 concat）
        target[key] = value;
      } else if (
        typeof value === 'object' &&
        !Array.isArray(value) &&
        typeof target[key] === 'object' &&
        target[key] !== null &&
        !Array.isArray(target[key])
      ) {
        target[key] = this.#deepMerge(target[key], value);
      } else {
        target[key] = value;
      }
    }

    return target;
  }
}
```

### 完整的插件系统整合

```js
// core/index.js — CLI 核心
import { HookManager } from './hooks.js';
import { PluginManager } from './loader.js';
import { ConfigMerger } from './config-merger.js';

class CliCore {
  #plugins;
  #hooks;
  #context;

  constructor(userConfig) {
    this.#hooks = new HookManager();
    this.#plugins = new PluginManager();
    this.#context = {
      version: '1.0.0',
      root: process.cwd(),
      config: {},
      hooks: this.#hooks,
      sharedState: {},
    };
  }

  async initialize() {
    // 注册内置钩子点
    for (const [name, type] of Object.entries(HOOK_POINTS)) {
      this.#hooks.addHook(name, type);
    }

    // 触发初始化钩子
    await this.#hooks.call('initialize', this.#context);

    // 加载用户配置的插件
    const userPlugins = this.#context.config.plugins || [];
    await this.#plugins.loadAll(userPlugins);

    // 触发配置解析完成钩子
    await this.#hooks.call('configResolved', this.#context.config);
  }

  async build() {
    const params = { files: [], extraFiles: [] };

    try {
      await this.#hooks.call('beforeBuild', params);
      await this.#hooks.call('buildModule', params);
      await this.#hooks.call('afterBuild', { outputCount: params.files.length });
    } finally {
      await this.#hooks.call('closeBundle');
    }
  }

  async shutdown() {
    await this.#hooks.call('shutdown');
    // 执行所有插件的清理函数
    for (const [, { cleanup }] of this.#plugins.active) {
      if (cleanup) await cleanup();
    }
  }
}

// 导出供 bin 入口使用
export { CliCore };
export type { CliPlugin, PluginContext, PluginOptions } from './types.js';
```

## 小结

| 设计维度 | 核心考量 | 推荐实践 |
|----------|---------|---------|
| **接口设计** | name + apply 函数 | 参考 Vite/Rollup 插件接口风格 |
| **动态加载** | `import()` 动态导入 | 支持相对路径、npm 包、内联对象 |
| **钩子系统** | Tapable 风格 | series/parallel/waterfall/bail 四种模式 |
| **依赖管理** | 拓扑排序 | dependsOn + conflictsWith 声明式约束 |
| **配置合并** | 深度合并策略 | 插件默认 → 用户配置 → 命令行覆盖 |
| **插件通信** | 共享上下文 | ctx.sharedState 跨插件数据传递 |

一个好的插件系统能让 CLI 工具的核心保持精简，同时通过社区插件无限扩展能力边界。
