# React 函数组件类型

> **一句话总结**：React 函数组件的类型体系围绕 `FC`、`Props` 接口和 `children` 三大支柱构建。从基础的 `React.FC<Props>` 到高级的泛型组件，TypeScript 让每个 prop、每次渲染返回值、每种事件处理都在编译器的严密保护之下。

## 一、从 JavaScript 到 TypeScript 的组件定义演进

```javascript
// ===== 纯 JavaScript（无类型）=====
function Welcome(props) {
  return <h1>Hello, {props.name}!</h1>
}

// 问题：
// 1. props 是什么？有哪些属性？
// 2. 返回值是什么类型？
// 3. 调用时传错参数只有运行时才发现

// ===== TypeScript 基础版 =====
interface WelcomeProps {
  name: string
  age?: number
}

function Welcome({ name, age }: WelcomeProps) {
  return <h1>Hello, {name}! {age ? ` (${age}岁)` : ''}</h1>
}

// ✅ 现在 props 有完整的类型约束了！
```

## 二、React.FC —— 函数组件的标准签名

### 2.1 FC 是什么？

`FC` 是 `FunctionComponent` 的别名，它为函数组件提供了**标准化的类型签名**：

```typescript
/**
 * React.FC 的核心定义（简化版）：
 *
 * type FC<P = (props: P & { children?: ReactNode }) => ReactElement | null
 *
 * 关键点：
 * 1. 自动包含 children 属性
 * 2. 返回值必须是 JSX 元素或 null
 * 3. displayName 和 defaultProps 可选附加
 */
```

### 2.2 基本用法

```typescript
import React, { type FC } from 'react'

// ===== 最简单的 FC 组件 =====
const Greeting: FC<{ name: string; enthusiastic?: boolean }> = ({ name, enthusiastic }) => (
  <h1>
    {enthusiastic ? '🎉 ' : ''}
    Hello, {name}!
    {enthusiastic ? ' 🎉' : ''}
  </h1>
)

// 使用
<Greeting name="Alice" />           // ✅ name 必填
<Greeting name="Bob" enthusiastic /> // ✅ 可选 prop
// <Greeting />                          // ❌ 缺少必填的 name
```

### 2.3 FC 的完整能力

```typescript
const AdvancedCard: FC<CardProps> = (props) => {
  // props 上自动有 children
  return (
    <div className="card">
      <header>{props.title}</header>
      <main>{props.children}</main>      {/* ✅ children 自动可用 */}
      {props.footer && <footer>{props.footer}</footer>}
    </div>
  )
}

// FC 还支持静态属性
AdvancedCard.displayName = 'AdvancedCard'
// AdvancedCard.defaultProps = { title: '默认标题' }
```

### 2.4 FC vs 直接标注——社区争议与最佳实践

```typescript
// 方式 A：使用 FC
const ButtonA: FC<ButtonProps> = ({ children, onClick }) => (
  <button onClick={onClick}>{children}</button>
)

// 方式 B：直接标注返回值（不使用 FC）
const ButtonB = ({ children, onClick }: ButtonProps) => (
  <button onClick={onClick}>{children}</button>
)

// 方式 C：显式声明函数类型
type ButtonFunction = (props: ButtonProps) => React.ReactElement | null
const ButtonC: ButtonFunction = ({ children, onClick }) => (
  <button onClick={onClick}>{children}</button>
)
```

**对比分析**：

| 维度 | `FC<Props>` | 直接标注 |
|------|-----------|--------|
| **children 类型** | 自动隐式包含 | 需显式声明 |
| **泛型支持** | `FC<T>` | 天然支持 |
| **displayName** | 可挂载 `.displayName` | 需额外声明 |
| **defaultProps** | 可挂载 `.defaultProps` | 需额外声明 |
| **代码量** | 稍多 | 更简洁 |
| **社区趋势** | React 官方推荐 | Vite + Vue 团队倾向 |

**当前推荐**：对于简单组件用直接标注更简洁；对于需要 `defaultProps`/`displayName` 或库导出组件时用 `FC`。

## 三、children 的类型安全

### 3.1 ReactNode 与 ReactChild

```typescript
/**
 * React.ReactNode 的组成：
 *
 * React.ReactNode =
 *   | React.ReactElement       // <Component />
 *   | string                     // "text"
 *   | number                     // {42}
 *   | boolean                    // true / false
 *   | null                       // 条件渲染
 *   | undefined                  // 不渲染
 *   | React.ReactPortal         // createPortal 结果
 *   | React.JSX.Element          // JSX 表达式
 */

// ===== 基础用法 =====
const Card: FC = ({ children }) => (
  <div className="card">{children}</div>
)

// ✅ 以下都是合法的 children
<Card>Hello</Card>                              // string
<Card><span>Nested</span></Card>                 // ReactElement
<Card>{true && <b>Visible</b>}</Card>              // 条件表达式
<Card>{[1, 2, 3].map(n => <span>{n}</span>)}</Card> // 数组
<Card>{null}</Card>                                // null（不渲染）


// ===== 限制 children 类型和数量 =====
interface SingleChildProps {
  children: React.ReactElement  // 只能是一个元素，不能是字符串/数字/多个
}

interface ExactChildrenProps {
  children: [React.ReactElement, React.ReactElement]  // 正好两个子元素
}


// ===== 函数作为 children（Render Prop 模式）=====
interface RenderPropProps<T> {
  header: (data: T) => React.ReactNode
  body: (data: T) => React.ReactNode
  footer: (data: T) => React.ReactNode
}

const Table: FC<RenderPropProps<User[]>> = ({ header, body, footer, children }) => {
  const data = children as any as User[]
  return (
    <table>
      <thead>{data.map(header)}</thead>
      <tbody>{data.map(body)}</tbody>
      <tfoot>{data.map(footer)}</tfoot>
    </table>
  )
}
```

```typescript
const ChildInspector: FC<{ children: ReactNode }> = ({ children }) => {
```

## 四、泛型组件

### 4.1 基础泛型组件

```typescript
/**
 * 泛型列表组件 —— 数据类型由调用者决定
 */
interface GenericListProps<T> {
  items: T[]
  renderItem: (item: T, index: number) => React.ReactNode
  keyFn: (item: T) => string | number
  emptyText?: string
  className?: string
}

function GenericList<T>({ items, renderItem, keyFn, emptyText = '暂无数据', className }: GenericListProps<T>) {
  if (items.length === 0) return <p className={className}>{emptyText}</p>

  return (
    <ul className={className}>
      {items.map((item, index) => (
        <li key={keyFn(item)}>{renderItem(item, index)}</li>
      ))}
    </ul>
  )
}

// ===== 使用 =====

// 用户列表
<GenericList
  items={users}
  keyFn={user => user.id}
  renderItem={(user) => <UserCard name={user.name} email={user.email} />}
/>

// 任务列表
<GenericList
  items={tasks}
  keyFn={task => task.id}
  renderItem={(task) => <TaskItem {...task} />}
/>
```

### 4.2 高阶泛型组件

```typescript
/**
 * 带排序和过滤功能的表格组件
 */
interface SmartTableProps<T extends { id: string | number }> {
  data: T[]
  columns: Array<{
    key: keyof T & string
    header: string
    render?: (value: T[keyof T & string], row: T) => React.ReactNode
    sortable?: boolean
    filterable?: boolean
  }>
  sortConfig?: { key: keyof T & string; direction: 'asc' | 'desc' } | null
  onSortChange?: (key: keyof T & string, direction: 'asc' | 'desc') => void
  onRowClick?: (row: T) => void
  emptyText?: string
}

function SmartTable<T extends { id: string | number }>({
  data,
  columns,
  sortConfig,
  onSortChange,
  onRowClick,
  emptyText,
}: SmartTableProps<T>) {
  // 内部排序逻辑...
  function getSortedData(): T[] {
    if (!sortConfig) return [...data]

    const sorted = [...data].sort((a, b) => {
      const aVal = a[sortConfig.key]
      const bVal = b[sortConfig.key]

      if (typeof aVal === 'string' && typeof bVal === 'string') {
        return sortConfig.direction === 'asc'
          ? aVal.localeCompare(bVal)
          : bVal.localeCompare(aVal)
      }

      if (typeof aVal === 'number' && typeof bVal === 'number') {
        return sortConfig.direction === 'asc' ? aVal - bVal : bVal - aVal
      }

      return 0
    })

    return sorted
  }

  const sortedData = getSortedData()

  if (sortedData.length === 0) return <div>{emptyText ?? '暂无数据'}</div>

  return (
    <table>
      <thead>
        <tr>
          {columns.map(col => (
            <th
              key={String(col.key)}
              onClick={() => col.sortable && onSortChange?.(col.key,
                sortConfig?.key === col.key && sortConfig?.direction === 'asc' ? 'desc' : 'asc'
              )}
              style={{ cursor: col.sortable ? 'pointer' : 'default' }}
            >
              {col.header}
              {col.sortable && sortConfig?.key === col.key && (
                <span>{sortConfig.direction === 'asc' ? '↑' : '↓'}</span>
              )}
            </th>
          ))}
        </tr>
      </thead>
      <tbody>
        {sortedData.map(row => (
          <tr
            key={row.id}
            onClick={() => onRowClick?.(row)}
            style={{ cursor: onRowClick ? 'pointer' : 'default' }}
          >
            {columns.map(col => (
              <td key={String(col.key)}>
                {col.render ? col.render(row[col.key], row) : String(row[col.key])}
              </td>
            ))}
          </tr>
        ))}
      </tbody>
    </table>
  )
}

// ===== 使用：完全类型安全的表格 =====
interface Product {
  id: number
  name: string
  price: number
  stock: number
  category: string
}

const productColumns = [
  { key: 'name', header: '产品名称', sortable: true },
  { key: 'price', header: '价格', sortable: true, render: (v: number) => `¥${v.toFixed(2)}` },
  { key: 'stock', header: '库存', sortable: true },
  { key: 'category', header: '分类' },
]

<SmartTable
  data={products}
  columns={productColumns}
  emptyText="还没有添加任何产品"
  onSortChange={(key, dir) => console.log(`按 ${String(key)} ${dir} 排序`)}
  onRowClick={(product) => navigate(`/products/${product.id}`}
/>
```

```typescript
  disabled?: boolean

function Select<V>({
  options,
  value,
  onChange,
  placeholder = '请选择',
  disabled = false,
  multiple = false,

  // ...

      value={multiple ? undefined : JSON.stringify(value)}
      disabled={disabled}
```

## 五、实战案例：完整类型安全的 UI 组件库

```typescript
/**
 * Modal 组件 —— 综合运用所有类型技巧
 */

// ===== 类型定义 =====
interface ModalSize {
  width: string | number
  maxWidth?: string
}

const modalSizes: Record<'sm' | 'md' | 'lg' | 'xl' | 'full', ModalSize> = {
  sm: { width: '380px' },
  md: { width: '520px' },
  lg: { width: '720px' },
  xl: { width: '960px' },
  full: { width: '100vw', height: '100vh' },
}

interface ModalProps {
  open: boolean
  onClose: () => void
  title?: React.ReactNode
  description?: React.ReactNode
  children: React.ReactNode
  footer?: React.ReactNode
  size?: keyof typeof modalSizes
  closable?: boolean
  closeOnOverlayClick?: boolean
  closeOnEsc?: boolean
  preventScroll?: boolean
  role?: 'dialog' | 'alertdialog'
  id?: string
  ariaLabel?: string
}

// ===== 组件实现 =====
const Modal: FC<ModalProps> = ({
  open,
  onClose,
  title,
  description,
  children,
  footer,
  size = 'md',
  closable = true,
  closeOnOverlayClick = true,
  closeOnEsc = true,
  preventScroll = true,
  role = 'dialog',
  id,
  ariaLabel = title ? String(title) : undefined,
}) => {
  // ESC 键监听
  useEffect(() => {
    if (!closeOnEsc || !open) return

    function handleKeyDown(e: KeyboardEvent) {
      if (e.key === 'Escape') onClose()
    }

    document.addEventListener('keydown', handleKeyDown)
    return () => document.removeEventListener('keydown', handleKeyDown)
  }, [open, onClose, closeOnEsc])

  if (!open) return null

  const sizeStyle = modalSizes[size] ?? modalSizes.md

  return createPortal(
    <div
      className="modal-overlay"
      onClick={closeOnOverlayClick ? onClose : undefined}
      style={{
        display: 'flex',
        alignItems: 'center',
        justifyContent: 'center',
      }}
      role="presentation"
    >
      <div
        className={`modal ${preventScroll ? 'modal--scroll-lock' : ''}`}
        style={sizeStyle}
        role={role}
        id={id}
        aria-modal="true"
        aria-label={ariaLabel}
      >
        {/* Header */}
        {(title || closable) && (
          <header className="modal-header">
            <div className="modal-title">
              {typeof title === 'string' ? <h2>{title}</h2> : title}
              {description && <p className="modal-description">{description}</p>}
            </div>
            {closable && (
              <button className="modal-close" onClick={onClose} aria-label="关闭">
                <CloseIcon />
              </button>
            )}
          </header>
        )}

        {/* Body */}
        <div className="modal-body">{children}</div>

        {/* Footer */}
        {footer && <footer className="modal-footer">{footer}</footer>}
      </div>
    </div>,
    document.body
  )
}
```

## 六、常见陷阱

### 陷阱一：FC 的 children 隐式问题

```typescript
// ⚠️ FC 会隐式将 children 加入 props
const MyComp: FC<{ count: number }> = ({ count }) => <span>{count}</span>

// 这意味着在 TypeScript 看来：
// MyComp 的 props = { count: number, children?: ReactNode }

// 如果你的组件不接受 children，直接标注更好：
const BetterComp = ({ count }: { count: number }) => <span>{count}</span>
```

### 陷阱二：forwardRef 的正确写法

```typescript
import { forwardRef, useRef } from 'react'

// ✅ 正确：带泛型的 ForwardRefExoticComponent
interface AutoFocusInputProps {
  defaultValue?: string
  onFocus?: () => void
  onBlur?: () => void
}

export const AutoFocusInput = forwardRef<HTMLInputElement, AutoFocusInputProps>(
  ({ defaultValue, onFocus, onBlur }, ref
) => {
  useEffect(() => {
    if (ref.current) ref.current.focus()
  }, [])

  return (
    <input
      ref={ref}
      defaultValue={defaultValue}
      onFocus={onFocus}
      onBlur={onBlur}
    />
  )
)

// 使用时能获得正确的 ref 类型
const inputRef = useRef<HTMLInputElement>(null)
<AutoFocusInput ref={inputRef} defaultValue="Auto-focused!" />
// inputRef.current.focus() → ✅ 方法可用
```

## 总结

React 函数组件的类型体系以 `FC<Props>` 为入口，通过精心设计的 `Props` 接口建立契约，利用 `children` 的 `ReactNode` 类型实现内容灵活性，再借助**泛型参数**将组件提升到可复用的工具级别。这四层结构——基础标注 → 接口设计 → 内容灵活性 → 泛型抽象——构成了从"能用"到"好用"的完整路径。
