# 样式操作 —— style 属性、getComputedStyle、classList、CSSStyleSheet

## 从"数据读写"到"视觉呈现"的能力跃迁

在[《属性与内容》](/40.frontend/50.javascript/20.browser-api/10.浏览器%20API%20与%20DOM%20操作/25.属性与内容.md)一文中，我们掌握了如何读取和修改元素的属性与内容。但这些操作主要针对的是数据的层面——属性值、文本内容、自定义数据。当我们要改变页面的外观——颜色、字体、间距、动画效果——就需要进入**样式操作**的领域。

JavaScript 操作样式的途径有多种：行内 style 属性、getComputedStyle 读取计算样式、classList 切换 CSS 类、以及通过 CSSStyleSheet 动态修改样式表。每条路径都有其适用场景和性能特征。理解它们的差异，是写出高性能动画、响应式交互的基础。

> **本文的目标**：全面讲解 JavaScript 操作 CSS 的四种主要方式——从行内样式到计算样式，从类名切换到样式表的动态修改，并结合实战案例展示最佳实践。

---

## 一、style 属性：行内样式的直接操作

### 1.1 基本语法与命名转换

每个 DOM 元素的 `style` 属性对应其 HTML 的 `style` 行内样式属性。它是一个 `CSSStyleDeclaration` 对象：

```javascript
const box = document.getElementById('box');

// 读取行内样式
box.style.color;          // 'red'（如果有 inline style 定义的话）
box.style.fontSize;       // '16px'
box.style.backgroundColor;  // '#fff'

// 设置行内样式（驼峰命名法）
box.style.color = 'blue';
box.style.fontSize = '18px';
box.style.backgroundColor = '#f0f0f0';
box.style.borderRadius = '8px';

// 注意 CSS 属性名到 JS 属性名的转换规则：
// font-size     → fontSize
// background-color → backgroundColor
// -webkit-transition → WebkitTransition（前缀首字母大写）
// float        → cssFloat（因为 float 是 JS 保留字）
```

### 1.2 cssText：批量设置行内样式

```javascript
const el = document.getElementById('card');

// 逐个设置
el.style.padding = '16px';
el.style.margin = '12px';
el.style.borderRadius = '8px';

// 或者用 cssText 一次性设置（会覆盖所有已有的行内样式！）
el.style.cssText = 'padding: 16px; margin: 12px; border-radius: 8px;';

// ⚠️ cssText 是完全替换，不是追加
el.style.cssText += '; color: red;';  // 可以用追加的方式
```

### 1.3 行内样式的局限性

```javascript
const el = document.getElementById('styled-by-css');

// 假设 CSS 中定义了：
// .highlight { color: gold; background: navy; }

el.classList.add('highlight');

// 通过 style 属性能读到这些样式吗？
el.style.color;        // '' （读不到！只有行内样式才能通过 style 读取）
el.style.background;   // ''

// style 属性只能读写内联（inline）样式，
// 无法读取来自 <style> 标签、外部 .css 文件的样式规则
```

这是一个关键的限制：`element.style` 只是**行内样式**的接口，不是元素最终渲染样式的完整视图。要想获取元素实际的渲染样式，需要用到 `getComputedStyle`。

### 1.4 生活类比：style 属性就像衣服上的别针

如果把元素的最终外观比作一个人的**整体穿搭**：

- **CSS 样式表（外部样式）就像是衣柜里搭配好的服装套装**：精心设计的配色方案、风格统一的整套搭配。
  
- **style 行内样式就像临时别在衣服上的装饰别针**：你可以在任何衣服上临时别一枚徽章、系一条丝巾。这些"额外装饰"优先级最高——别针的颜色会覆盖衣服原来的颜色。
  
- 但如果你问"这个人原本穿的衣服是什么颜色的？"（`el.style.color`），你只能得到别针的颜色，看不到被遮住的底色。

> **哲学思考**：行内样式的高优先级设计体现了**特例优于常规（Special Case over General Rule）**的原则。CSS 的层叠（Cascade）机制本质上是一套冲突解决策略：当多条规则同时作用于同一属性时，谁说了算？行内样式 > ID 选择器 > 类选择器 > 元素选择器 > 浏览器默认样式。这与社会治理中的法律层级惊人地相似：特别法优于普通法，上位法优于下位法。理解了这个层次结构，就能理解为什么有时候你的样式"明明写了却不生效"——很可能是在某个不知名的角落有一个更高优先级的规则抢先了一步。

## 二、getComputedStyle：窥探最终渲染结果

### 2.1 读取计算样式

`window.getComputedStyle()` 方法返回浏览器在渲染该元素之后应用的**所有最终样式值**：

```javascript
const el = document.querySelector('.my-element');
const styles = window.getComputedStyle(el);

// 无论样式来自哪里，都能读到最终的值
styles.width;            // '200px'
styles.height;           // 'auto'
styles.color;            // 'rgb(255, 0, 0)'（即使定义的是 color: red）
styles.fontSize;         // '16px'
styles.paddingLeft;      // '10px'
styles.display;          // 'block'
styles.position;         // 'relative'
styles.opacity;          // '0.8'（无单位数值直接返回数字字符串）
styles.zIndex;           // 'auto' 或 '100'

// 伪元素样式也可以获取
const beforeStyles = window.getComputedStyle(el, '::before');
beforeStyles.content;    // '"→ "' 或 'none'
beforeStyles.color;      // 伪元素的颜色
```

### 2.2 计算样式的特性

```javascript
const box = document.getElementById('demo-box');

const computed = window.getComputedStyle(box);

// 1. 值已经被解析为标准格式
// CSS 写: margin: 1em;
computed.marginTop;      // '16px'（em 被转换为 px）
// CSS写: color: red;
computed.color;          // 'rgb(255, 0, 0)'（颜色名转为 rgb 格式）

// 2. shorthand 属性可能为空
computed.margin;         // '' 或完整的值（取决于浏览器）
// 建议使用具体属性：marginTop, marginRight...

// 3. 只读！不能用来设置样式
computed.color = 'blue';  // 静默失败（严格模式下报错）
// 这是只读快照，不是引用

// 4. 值是实时的（live）——随布局变化而变化
console.log(computed.width);  // '200px'
box.style.width = '400px';
console.log(computed.width);  // '400px'（已更新！）
```

### 2.3 实战案例：精确测量与自适应

```javascript
/**
 * 自适应文字大小的组件
 * 根据容器宽度自动调整字体大小
 */
class AutoFittingText {
    constructor(element, options = {}) {
        this.el = element;
        this.minFontSize = options.minFontSize || 12;
        this.maxFontSize = options.maxFontSize || 48;
        this.step = options.step || 1;
        this._fit();
        
        // 监听窗口变化以重新适配
        this._resizeObserver = new ResizeObserver(() => this._fit());
        this._resizeObserver.observe(element.parentElement);
    }

    _fit() {
        const parent = this.el.parentElement;
        const parentStyle = window.getComputedStyle(parent);
        const availableWidth = parseFloat(parentStyle.width)
                             - parseFloat(parentStyle.paddingLeft)
                             - parseFloat(parentStyle.paddingRight);

        let size = this.maxFontSize;
        this.el.style.fontSize = size + 'px';

        // 逐步缩小直到文字能放下
        while (this.el.scrollWidth > availableWidth && size > this.minFontSize) {
            size -= this.step;
            this.el.style.fontSize = size + 'px';
        }
    }

    destroy() {
        this._resizeObserver.disconnect();
    }
}
```

### 2.4 生活类比：getComputedStyle 就像体检报告

- **style 属性（行内样式）就像你自己填写的健康问卷**："我每天跑步"、"我不抽烟"。这是你声称的状态。
  
- **getComputedStyle 就像医生给你做的全面体检报告**：不管你怎么说，仪器检测到的才是真实的——你的心率、血压、体脂率。体检报告显示的数据是**所有因素综合作用的结果**（遗传、饮食、运动、睡眠……），就像 computed style 是所有 CSS 规则层叠计算的最终结果。

## 三、classList + CSS 类：推荐的样式操作方式

### 3.1 为什么推荐用类名而不是直接操作 style？

```javascript
// ❌ 不推荐：直接操作 style
function showError(input) {
    input.style.borderColor = 'red';
    input.style.backgroundColor = '#fff0f0';
    input.style.boxShadow = '0 0 4px rgba(255, 0, 0, 0.3)';
}

function clearError(input) {
    input.style.borderColor = '';
    input.style.backgroundColor = '';
    input.style.boxShadow = '';
}
// 问题：样式散落在 JS 中，难以维护和主题切换

// ✅ 推荐：通过 classList 切换类名
/* CSS */
.error-state {
    border-color: red;
    background-color: #fff0f0;
    box-shadow: 0 0 4px rgba(255, 0, 0, 0.3);
}

/* JavaScript */
function showError(input) {
    input.classList.add('error-state');
}

function clearError(input) {
    input.classList.remove('error-state');
}
// 优势：样式集中在 CSS 中，JS 只负责状态管理
```

这种**关注点分离（Separation of Concerns）**的做法有几个显著好处：

1. **主题切换友好**：只需要修改 CSS 变量，不需要动 JS 代码。
2. **可维护性高**：样式变更只涉及 CSS 文件。
3. **可复用性强**：同一个类可以用在任何需要的元素上。
4. **响应式友好**：可以在不同媒体查询中定义类的表现。

### 3.2 动态生成和管理类名

```javascript
/**
 * BEM 风格的类名辅助工具
 * block__element--modifier 模式
 */
function bem(block, element, modifiers = {}) {
    let cls = element ? `${block}__${element}` : block;
    
    Object.entries(modifiers).forEach(([key, value]) => {
        if (value) {
            cls += ` ${cls}--${typeof value === 'boolean' ? key : `${key}-${value}`}`;
        }
    });
    
    return cls.trim();
}

// 使用
const btn = document.querySelector('.btn');
btn.className = bem('button', null, { size: 'large', primary: true });
// 结果：'button button--size-large button--primary'

// 结合 classList
function setBemClasses(el, block, element, modifiers) {
    el.className = bem(block, element, modifiers);
}

setBemClasses(btn, 'button', null, {
    size: 'large',
    primary: true,
    disabled: false  // falsy 值不会添加 modifier
});
```

## 四、CSSStyleSheet 与 CSSOM：动态样式表操作

### 4.1 操作样式表的基本方法

除了操作单个元素的样式，JavaScript 还可以直接增删改 **CSS 规则**：

```javascript
// 获取页面中的样式表
const sheets = document.styleSheets;
console.log(sheets.length);  // 页面中 <style> 和 <link rel="stylesheet"> 的总数

// 获取第一个样式表
const firstSheet = sheets[0];

// 获取/插入/删除规则
try {
    // 读取所有规则（跨域样式表会抛出 SecurityError）
    const rules = firstSheet.cssRules;
    
    // 插入新规则
    const index = firstSheet.insertRule(
        '.highlight { background: yellow; padding: 4px; }',
        rules.length  // 插入到末尾
    );
    
    // 删除规则
    firstSheet.deleteRule(index);
    
} catch (e) {
    console.warn('无法访问样式表规则:', e.message);
}
```

### 4.2 动态创建样式表

```javascript
/**
 * 创建动态样式表用于运行时注入样式
 */
class DynamicStyleSheet {
    constructor(name) {
        this.styleEl = document.createElement('style');
        this.styleEl.setAttribute('data-dynamic-sheet', name);
        document.head.appendChild(this.styleEl);
        this.sheet = this.styleEl.sheet;
        this.ruleIndex = 0;
        this.rules = new Map();  // 用于跟踪已插入的规则
    }

    // 添加/更新规则
    addRule(selector, styles) {
        const key = selector;
        
        if (this.rules.has(key)) {
            // 已存在则更新
            const index = this.rules.get(key);
            const declaration = Object.entries(styles)
                .map(([prop, val]) => `${kebabCase(prop)}: ${val}`)
                .join('; ');
            this.sheet.deleteRule(index);
            const newIndex = this.sheet.insertRule(
                `${selector} { ${declaration} }`,
                index
            );
            this.rules.set(key, newIndex);
        } else {
            // 新增
            const declaration = Object.entries(styles)
                .map(([prop, val]) => `${kebabCase(prop)}: ${val}`)
                .join('; ');
            const index = this.sheet.insertRule(
                `${selector} { ${declaration} }`,
                this.sheet.cssRules.length
            );
            this.rules.set(key, index);
        }
    }

    // 移除规则
    removeRule(selector) {
        const index = this.rules.get(selector);
        if (index !== undefined) {
            this.sheet.deleteRule(index);
            this.rules.delete(selector);
        }
    }

    // 清空所有规则
    clear() {
        while (this.sheet.cssRules.length > 0) {
            this.sheet.deleteRule(0);
        }
        this.rules.clear();
    }

    // 销毁整个样式表
    destroy() {
        this.styleEl.remove();
    }
}

// 辅助函数：驼峰 → 短横线
function kebabCase(str) {
    return str.replace(/[A-Z]/g, letter => '-' + letter.toLowerCase());
}

// 使用示例
const themeStyles = new DynamicStyleSheet('theme');

themeStyles.addRule(':root', {
    '--primaryColor': '#3b82f6',
    '--bgColor': '#ffffff',
    '--textColor': '#1a1a1a'
});

themeStyles.addRule('.card', {
    backgroundColor: 'var(--bgColor)',
    borderRadius: '8px',
    boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)'
});

// 切换暗色主题
themeStyles.addRule(':root', {
    '--primaryColor': '#60a5fa',
    '--bgColor': '#1a1a2e',
    '--textColor': '#e0e0e0'
});
```

### 4.3 CSS 变量（CSS Custom Properties）的操作

CSS 变量是现代样式操作的利器：

```javascript
const root = document.documentElement;

// 读取 CSS 变量
const style = window.getComputedStyle(root);
style.getPropertyValue('--primary-color').trim();  // '#3b82f6'

// 设置 CSS 变量（在任意元素上）
root.style.setProperty('--primary-color', '#ef4444');
el.style.setProperty('--item-size', '200px');

// 移除 CSS 变量
root.style.removeProperty('--primary-color');

// 在 JavaScript 中使用 CSS 变量的值
const primaryColor = getComputedStyle(root)
    .getPropertyValue('--primary-color')
    .trim();

// 实战：基于 CSS 变量的主题系统
class ThemeManager {
    constructor() {
        this.root = document.documentElement;
        this.themes = {
            light: {
                '--bg-primary': '#ffffff',
                '--bg-secondary': '#f5f5f5',
                '--text-primary': '#18181b',
                '--text-secondary': '#71717a',
                '--accent': '#3b82f6',
                '--border': '#e4e4e7',
                '--shadow': 'rgba(0, 0, 0, 0.1)'
            },
            dark: {
                '--bg-primary': '#18181b',
                '--bg-secondary': '#27272a',
                '--text-primary': '#fafafa',
                '--text-secondary': '#a1a1aa',
                '--accent': '#60a5fa',
                '--border': '#3f3f46',
                '--shadow': 'rgba(0, 0, 0, 0.4)'
            }
        };
    }

    apply(themeName) {
        const theme = this.themes[themeName];
        if (!theme) return;
        
        Object.entries(theme).forEach(([property, value]) => {
            this.root.style.setProperty(property, value);
        });
        
        // 保存偏好
        localStorage.setItem('theme', themeName);
    }

    getCurrent() {
        return localStorage.getItem('theme') || 'light';
    }

    toggle() {
        const current = this.getCurrent();
        this.apply(current === 'light' ? 'dark' : 'light');
    }
}

const themeManager = new ThemeManager();
themeManager.apply(themeManager.getCurrent());
```

### 4.4 生活类比：CSSStyleSheet 就像全局广播系统

如果说 `style` 行内样式是对一个人说的悄悄话，`classList` 是给某人穿上特定制服，那么 **CSSStyleSheet 就像公司的全员着装规范公告板**：

- 你在公告板上贴一条新规定（`insertRule`）："周五穿休闲装"——所有人立刻遵守。
- 你撤下一条规定（`deleteRule`）：不再要求戴工牌——所有人都松了一口气。
- 你更换整块公告板（修改 CSS 变量）：从"夏季规范"换成"冬季规范"——所有人的穿着风格统一改变。

这种**集中式的样式管理**让全局性的视觉调整变得异常简单——改一处，全域生效。

## 五、样式操作的性能考量

### 5.1 触发布局重算（Layout Thrashing）的风险

频繁交替读写样式会导致严重的性能问题：

```javascript
// ❌ 性能灾难：循环中反复读写导致 Layout Thrashing
const elements = document.querySelectorAll('.item');
elements.forEach(el => {
    // 读 → 强制浏览器重排（Reflow）
    console.log(el.offsetWidth);
    // 写 → 使缓存失效
    el.style.width = el.offsetWidth + 10 + 'px';
    // 下一次循环又要读 → 又触发重排...
});

// ✅ 优化方案：先收集所有读操作，再做所有写操作
const elements = document.querySelectorAll('.item');
// 第一轮：只读取
const widths = Array.from(elements).map(el => el.offsetWidth);

// 第二轮：只写入
elements.forEach((el, i) => {
    el.style.width = widths[i] + 10 + 'px';
});

// 更优：使用 requestAnimationFrame 批量处理
function batchUpdate(elements, updater) {
    const reads = [];
    const writes = [];

    elements.forEach(el => {
        reads.push({ el, width: el.offsetWidth });
    });

    requestAnimationFrame(() => {
        reads.forEach(({ el, width }) => {
            writes.push(updater(el, width));
        });
    });
}
```

### 5.2 各方法的性能排名

| 操作方式 | 性能 | 适用场景 |
|---------|------|---------|
| classList 切换 | 最快 | 绝大多数场景 |
| style 属性设置 | 快 | 少量动态样式、动画中间帧 |
| getComputedStyle 读取 | 较慢 | 需要知道实际渲染值时 |
| cssText 批量设置 | 中等 | 大量行内样式一次性设置 |
| CSSStyleSheet.insertRule | 慢 | 全局样式注入（通常初始化时做一次） |

> **最后的思考**：样式操作的核心哲学应该是 **"JavaScript 管状态，CSS 管表现"**。最好的样式代码往往是不存在的——因为你把所有的视觉逻辑都放在了 CSS 文件中，JavaScript 只是简单地切换几个类名而已。当你的 JS 代码中充斥着 `.style.xxx = ...` 时，不妨停下来问问自己：这个样式是否应该属于某个 CSS 类？这种反思不仅能提高代码质量，还能让你更深刻地理解"声明式"与"命令式"两种编程范式的本质差异。关于如何获取元素的尺寸和位置信息，推荐阅读[《尺寸与坐标》](/40.frontend/50.javascript/20.browser-api/10.浏览器%20API%20与%20DOM%20操作/35.尺寸与坐标.md)。关于 DOM 的事件系统，推荐阅读[《事件模型》](/40.frontend/50.javascript/20.browser-api/10.浏览器%20API%20与%20DOM%20操作/40.事件模型.md)。
