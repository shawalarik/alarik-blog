# 表单控件 —— value、checked、selected、reset、submit、FormData

## 从"展示内容"到"收集数据"的功能跃迁

到目前为止，我们讨论的 DOM 操作大多围绕**信息的输出**——把数据显示在页面上、改变它们的样式、响应交互事件。但 Web 的另一半核心使命是**信息的收集**——让用户通过输入框、下拉菜单、复选框等控件提供数据。这就是 **表单（Form）和表单控件（Form Controls）** 的领域。

表单是 Web 应用中用户与应用进行数据交换的主要界面。从最简单的搜索框到复杂的多步骤注册流程，表单控件覆盖了文本输入、选项选择、文件上传等多种交互形态。理解每种控件的 DOM API 特性以及 `FormData` 的序列化机制，是构建可靠的数据采集系统的前提。

> **本文的目标**：系统讲解各类表单控件的 DOM 操作方法——从 input 的 value/checked 到 select 的 selected，再到 form 的 reset/submit 以及 FormData 的完整用法。

## 一、input 元素：最复杂的表单控件

### 1.1 value 属性：读取和设置值

`input.value` 是最常用的属性，但不同类型的 input 对它的处理方式差异巨大：

```javascript
// === 文本类输入框 ===
const textInput = document.querySelector('input[type="text"]');
textInput.value;           // '当前值'
textInput.value = '新值';   // 设置值

// === 密码框 ===
const pwdInput = document.querySelector('input[type="password"]');
pwdInput.value;             // '用户输入的密码'

// === 隐藏字段 ===
const hidden = document.querySelector('input[type="hidden"]');
hidden.value;               // '隐藏值'（不可见但会随表单提交）

// === 数字/范围类型 ===
const numberInput = document.querySelector('input[type="number"]');
numberInput.value;          // '42'（注意：返回的是字符串！）
numberInput.valueAsNumber;  // 42（数值类型，方便计算）

// ⚠️ 重要：input.value 始终返回字符串！
// 即使 type="number"，value 返回的也是字符串
parseInt(numberInput.value); // 手动转换
Number(numberInput.value);   // 或者用 Number()
numberInput.valueAsNumber;   // 或者用 valueAsNumber（推荐）
```

### 1.2 checked 与 indeterminate：布尔状态

对于 checkbox 和 radio 类型的 input：

```javascript
// === Checkbox ===
const cb = document.getElementById('agree');
cb.checked;              // true/false — 是否选中
cb.checked = true;       // 选中
cb.checked = false;      // 取消选中
cb.toggleAttribute('checked');  // 切换

// 第三种状态："不确定"（半选）— 仅视觉，不影响提交值
cb.indeterminate = true;  // 显示为横线（不是勾也不是空）
// 典型用途：子项全选时打勾、全不选时空、部分选中时横线

// === Radio Button ===
const radios = document.querySelectorAll('input[name="gender"]');
radios.forEach(radio => {
    console.log(radio.checked);  // 只有被选中的那个返回 true
    
    radio.addEventListener('change', () => {
        if (radio.checked) {
            console.log(`选中了: ${radio.value}`);
        }
    });
});

// 获取当前选中的 radio 值
function getSelectedRadioValue(name) {
    const selected = document.querySelector(`input[name="${name}"]:checked`);
    return selected ? selected.value : null;
}

getSelectedRadioValue('gender');  // 'male' 或 'female'
```

### 1.3 disabled 与 readonly

```javascript
const input = document.querySelector('#username');

// disabled：完全禁用（不能编辑、不能聚焦、不会提交）
input.disabled = true;
// 视觉上变灰，Tab 键跳过，value 不包含在表单提交数据中

// readonly：只读（能看到、能聚焦、能选中文字、但不能编辑）
input.readOnly = true;
// 视觉上正常，value 会包含在表单提交数据中
// 适用场景：显示需要提交但不需要修改的预填值

// 两者的关键区别：
// ┌─────────────┬───────────┬──────────┐
// │              │ disabled  │ readonly │
// ├─────────────┼───────────┼──────────┤
// │ 可获得焦点   │    ❌     │    ✅     │
// │ 可 Tab 聚焦  │    ❌     │    ✅     │
// │ 可选中复制   │    ❌     │    ✅     │
// │ 值是否提交   │    ❌     │    ✅     │
// │ CSS 样式变化 │    ✅     │    无     │
// └─────────────┴───────────┴──────────┘
```

### 1.4 生活类比：三种输入状态的门

- **普通 input 就像一扇正常的门**：任何人都可以推开走进去（可以编辑），门上的信息会被登记在册（值会被提交）。
  
- **readonly 就像一扇有玻璃窗的门**：你可以透过玻璃看到里面的东西，甚至可以用手电筒照进去看清楚（可聚焦、可选中文本），但你推不开它（不能修改）。里面的信息仍然有效。
  
- **disabled 就像一扇被封死的门**：不仅推不开，连窗户都被木板钉上了（不能聚焦）。这扇门的信息被视为无效（值不会被提交）。

## 二、select 与 option：下拉选择

### 2.1 操作 option

```javascript
const select = document.getElementById('city');

// === 读取选中项 ===
select.value;                    // 'beijing'（option 的 value 属性）
select.selectedIndex;            // 0（第一个 option 的索引，-1 表示无选中）
select.selectedOptions;          // HTMLCollection（多选时有用）

// 获取完整的选中 option 对象
const selectedOption = select.options[select.selectedIndex];
selectedOption.text;             // 显示的文字
selectedOption.value;            // 提交的值
selectedOption.selected;         // 是否被选中

// === 设置选中项 ===
select.value = 'shanghai';      // 通过 value 设置
select.selectedIndex = 2;        // 通过索引设置
select.options[1].selected = true;  // 直接操作 option
```

### 2.2 动态填充选项

```javascript
/**
 * 级联选择器：省份 → 城市
 */
class CascadeSelect {
    constructor(provinceEl, cityEl, data) {
        this.province = provinceEl;
        this.city = cityEl;
        this.data = data;
        
        this._populateProvinces();
        this._bindEvents();
    }

    _populateProvinces() {
        this.province.innerHTML = '<option value="">请选择省份</option>';
        Object.keys(this.data).forEach(province => {
            const opt = document.createElement('option');
            opt.value = province;
            opt.textContent = province;
            this.province.appendChild(opt);
        });
    }

    _bindEvents() {
        this.province.addEventListener('change', () => {
            const province = this.province.value;
            if (!province) {
                this.city.innerHTML = '<option value="">请先选择省份</option>';
                return;
            }
            
            const cities = this.data[province];
            this.city.innerHTML = '<option value="">请选择城市</option>';
            cities.forEach(city => {
                const opt = document.createElement('option');
                opt.value = city.code;
                opt.textContent = city.name;
                this.city.appendChild(opt);
            });

            // 派发自定义事件通知外部
            this.province.dispatchEvent(new CustomEvent('province-changed', {
                detail: { province, cities },
                bubbles: true
            }));
        });
    }
}

// 使用
new CascadeSelect(
    document.getElementById('province'),
    document.getElementById('city'),
    {
        '北京': [{ code: '110100', name: '北京市' }, { code: '110200', name: '北京市辖县' }],
        '上海': [{ code: '310100', name: '上海市' }, { code: '310200', name: '上海市辖县' }],
        '浙江': [{ code: '330100', name: '杭州' }, { code: '330200', name: '宁波' }, ...]
    }
);
```

### 2.3 多选 select

```html
<select id="skills" multiple size="5">
    <option value="js">JavaScript</option>
```

```javascript
const multiSelect = document.getElementById('skills');

// 获取所有选中值
function getSelectedValues(select) {
    return Array.from(select.selectedOptions).map(opt => opt.value);
}
getSelectedValues(multiSelect);  // ['js', 'rust']

// 全选/取消全选
multiSelect.querySelectorAll('option').forEach(opt => {
    opt.selected = true;   // 全选
});
```

## 三、textarea：多行文本

```javascript
const textarea = document.querySelector('textarea');

// 读取和设置
textarea.value;             // '多行文本内容'
textarea.value = '新内容';  // 替换全部内容

// 注意：textarea 没有 innerHTML/textContent 的区别
// textarea.value 就是唯一的接口

// 实用的属性
textarea.maxLength;         // 最大长度限制
textarea.rows;              // 行数
textarea.cols;              // 列数（字符宽度）
textarea.placeholder;       // 占位提示文字
textarea.selectionStart;     // 光标起始位置
textarea.selectionEnd;       // 光标结束位置

// 在光标位置插入文本
function insertAtCursor(textarea, text) {
    const start = textarea.selectionStart;
    const end = textarea.selectionEnd;
    const before = textarea.value.substring(0, start);
    const after = textarea.value.substring(end);
    
    textarea.value = before + text + after;
    
    // 将光标移到插入内容的末尾
    const newPos = start + text.length;
    textarea.setSelectionRange(newPos, newPos);
    textarea.focus();
}

insertAtCursor(textarea, 'Hello ');  // 在光标处插入
```

## 四、form 元素的操作

### 4.1 submit 和 reset

```javascript
const form = document.getElementById('my-form');

// 编程触发表单提交
form.submit();  // 注意：这不会触发 submit 事件！直接提交
form.requestSubmit(submitButton);  // 模拟特定按钮点击提交

// 重置表单
form.reset();  // 恢复到初始 HTML 中的值（触发 reset 事件）

// 验证并提交
if (form.checkValidity()) {
    // 所有验证通过
    form.submit();
} else {
    // 显示验证错误
    form.reportValidity();
}
```

### 4.2 监听提交事件

```javascript
form.addEventListener('submit', (e) => {
    e.preventDefault();  // 阻止默认提交行为（AJAX 提交的前提）
    
    const formData = new FormData(form);
    const data = Object.fromEntries(formData.entries());
    
    // 异步提交
    fetch('/api/submit', {
        method: 'POST',
        body: formData,
        // 注意：不需要手动设置 Content-Type！
        // FormData 会自动设置正确的 multipart/form-data 边界
    })
    .then(response => response.json())
    .then(result => {
        if (result.success) {
            showSuccessMessage();
            form.reset();  // 成功后重置
        }
    })
    .catch(err => showError(err));
});
```

### 4.3 novalidate 与自定义验证

```html
<form id="my-form" novalidate>
    <!-- novalidate 禁用浏览器原生验证，使用自定义验证 -->
    <input type="email" required placeholder="邮箱">
    <input type="password" minlength="8" required placeholder="密码">
    <button type="submit">提交</button>
</form>
```

```javascript
/**
 * 自定义表单验证器
 */
class FormValidator {
    constructor(formElement) {
        this.form = formElement;
        this.rules = new Map();
        this.errors = [];
        this._setupValidation();
    }

    // 注册验证规则
    addRule(fieldName, validator, message) {
        if (!this.rules.has(fieldName)) {
            this.rules.set(fieldName, []);
        }
        this.rules.get(fieldName).push({ validator, message });
    }

    _setupValidation() {
        this.form.addEventListener('submit', (e) => {
            e.preventDefault();
            
            if (this.validate()) {
                // 自定义事件通知外部验证通过
                this.form.dispatchEvent(new CustomEvent('form-valid', { detail: this.getData() }));
            } else {
                this.form.dispatchEvent(new CustomEvent('form-invalid', { detail: this.errors }));
            }
        });

        // 实时验证
        this.form.querySelectorAll('input, select, textarea').forEach(field => {
            field.addEventListener('blur', () => this.validateField(field.name));
            field.addEventListener('input', () => this.clearFieldError(field.name));
        });
    }

    validate() {
        this.errors = [];
        let isValid = true;

        for (const [fieldName, rules] of this.rules) {
            const field = this.form.elements[fieldName];
            if (!field) continue;

            for (const rule of rules) {
                if (!rule.validator(field.value, field, this.form)) {
                    isValid = false;
                    this.errors.push({ field: fieldName, message: rule.message });
                    this._showError(field, rule.message);
                    break;  // 该字段一个错误就够了
                }
            }
        }

        this.form.classList.toggle('has-errors', !isValid);
        return isValid;
    }

    validateField(name) {
        const rules = this.rules.get(name);
        if (!rules) return true;

        const field = this.form.elements[name];
        if (!field) return true;

        for (const rule of rules) {
            if (!rule.validator(field.value, field, this.form)) {
                this._showError(field, rule.message);
                return false;
            }
        }
        return true;
    }

    getData() {
        return Object.fromEntries(new FormData(this.form).entries());
    }

    _showError(field, message) {
        field.classList.add('error');
        let errorEl = field.parentNode.querySelector('.error-message');
        if (!errorEl) {
            errorEl = document.createElement('span');
            errorEl.className = 'error-message';
            field.parentNode.appendChild(errorEl);
        }
        errorEl.textContent = message;
    }

    clearFieldError(name) {
        const field = this.form.elements[name];
        if (!field) return;
        field.classList.remove('error');
        const errorEl = field.parentNode?.querySelector('.error-message');
        if (errorEl) errorEl.remove();
    }
}

// 使用示例
const validator = new FormValidator(document.getElementById('register-form'));

validator.addRule('email', 
    val => /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(val),
    '请输入有效的邮箱地址'
);

validator.addRule('password',
    val => val.length >= 8,
    '密码至少需要 8 个字符'
);

validator.addRule('password',
    val => /[A-Z]/.test(val),
    '密码需要包含大写字母'
);

document.getElementById('register-form').addEventListener('form-valid', (e) => {
    submitToServer(e.detail);
});
```

## 五、FormData：表单数据的序列化利器

### 5.1 创建方式

```javascript
// 方式一：从 form 元素创建
const formData = new FormData(formElement);

// 方式二：创建空的 FormData 再逐个添加
const formData = new FormData();
formData.append('username', 'Alarik');
formData.append('avatar', fileInputElement.files[0]);

// 方式三：从 HTML 字符串解析（需要借助 DOMParser）
```

### 5.2 核心方法

```javascript
const fd = new FormData();

// === 添加数据 ===
fd.append('key1', 'value1');                  // 字符串
fd.append('avatar', file);                     // 文件
fd.append('tags[]', 'JavaScript');              // 同名键追加
fd.append('tags[]', '前端');                   // 变成数组

// === 读取数据 ===
fd.get('key1');           // 'value1'（只返回第一个匹配值）
fd.getAll('tags[]');      // ['JavaScript', '前端']（返回所有同名值）
fd.has('username');       // boolean
fd.entries();             // 迭代器 [['key1','value1'], ['key2','value2']]
fd.keys();                // 迭代器 ['key1', 'key2']
fd.values();             // 迭代器 ['value1', 'value2']

// === 修改和删除 ===
fd.set('key1', 'newValue');  // 替换（如果有多个同名键，只保留这一个）
fd.delete('avatar');          // 删除某个键

// === 转换为普通对象 ===
Object.fromEntries(fd.entries());

// 转换为 JSON 字符串（注意：File 类型无法 JSON 化）
JSON.stringify(Object.fromEntries(fd.entries()));

// === 转换为 URLSearchParams ===
const params = new URLSearchParams(fd);
params.toString();  // 'key1=value1&tags%5B%5D=JavaScript...'
```

### 5.3 发送 FormData

```javascript
// fetch API（推荐）
fetch('/api/upload', {
    method: 'POST',
    body: formData  // 自动设置 Content-Type: multipart/form-data; boundary=...
});

// XMLHttpRequest
const xhr = new XMLHttpRequest();
xhr.open('POST', '/api/upload');
xhr.send(formData);

// 注意：不要手动设置 Content-Type！
// 浏览器需要自动生成 boundary 参数来分隔各部分数据
```

> **哲学思考**：`FormData` 的设计体现了**封装（Encapsulation）**的力量。表单数据的格式本身非常繁琐——每个字段需要名称、内容类型、边界分隔符……这些细节如果让开发者手动处理，极易出错。`FormData` 把这一切封装成一个干净的 API，你只需要关心"添加什么键值对"，底层如何编码成 multipart 格式的细节完全透明。好的抽象就是这样——它隐藏了复杂性但不隐藏能力。

## 六、总结：表单控件的心智模型

### 6.1 控件类型与关键属性速查

| 控件 | 读写值的属性 | 布尔状态属性 | 选择状态 |
|------|------------|-------------|---------|
| text/password/hidden | `.value` | `.disabled`, `.readOnly` | - |
| checkbox | - | `.checked`, `.indeterminate` | - |
| radio | `.value` | `.checked` | - |
| select (单选) | `.value`, `.selectedIndex` | - | `.selectedOptions[0]` |
| select (多选) | - | - | `.selectedOptions` |
| textarea | `.value` | `.disabled`, `.readOnly` | - |

### 6.2 核心原则

1. **input.value 始终是字符串**：即使 `type="number"` 也一样，需要时用 `valueAsNumber` 或 `Number()` 转换。
2. **disabled vs readonly 明确区分**：前者完全禁用且不提交值，后者只读但提交值。
3. **优先使用 FormData 序列化**：比手动拼接查询字符串更安全、更完整。
4. **novalidate + 自定义验证器**：适合需要高度定制化体验的场景。
5. **级联联动用 change 事件 + CustomEvent**：保持组件间的松耦合。

> **最后的思考**：表单控件是 Web 中唯一一类专门为**数据输入**而设计的 DOM 元素。它们不同于 div 或 span（通用容器）、也不同于 img 或 video（内容展示）——表单控件的存在本身就是一种契约：**我承诺接受用户的输入，并以结构化的方式把这些输入传递出去**。这个承诺体现在 `name` 属性（标识数据字段）、`value` 属性（承载数据内容）、以及 `form` 元素的 `submit` 行为（统一的数据提交机制）之中。理解这套约定，就是在理解 Web 作为应用平台而非仅仅是文档阅读器的本质特征之一。关于焦点管理和剪贴板操作，推荐阅读[《焦点管理与剪贴板》](/40.frontend/50.javascript/20.browser-api/10.浏览器%20API%20与%20DOM%20操作/60.焦点管理与剪贴板.md)。关于浏览器历史 API 和单页路由的实现，推荐阅读[《历史 API》](/40.frontend/50.javascript/20.browser-api/10.浏览器%20API%20与%20DOM%20操作/65.历史API.md)。
