# 多媒体 —— `<audio>`/`<video>` 的 API、播放控制、时间跳转、音量

## 从"静态展示"到"动态播放"的感官跃迁

Web 从最初的纯文本页面发展到今天，早已超越了文档展示的范畴——它是一个**富媒体的交互平台**。音频和视频是其中最核心的媒介形式：音乐播放器、视频流网站、播客应用、在线会议……这些场景都依赖于浏览器对多媒体的原生支持。

HTML5 的 `<audio>` 和 `<video>` 元素不仅提供了原生的媒体播放能力，更暴露了一套完整的 JavaScript API，让开发者能精确控制播放行为、获取实时状态、处理各种媒体事件。

> **本文的目标**：系统讲解 HTMLMediaElement API 的完整体系——从加载与播放控制、时间轴操作、音量管理，到缓冲进度监控和全屏处理。

## 一、HTMLMediaElement：音视频元素的共同接口

### 1.1 基本属性

`<audio>` 和 `<video>` 元素共享同一个接口 `HTMLMediaElement`：

```html
<video id="player" src="movie.mp4" controls width="640">
    您的浏览器不支持视频播放。
</video>
```

```javascript
const player = document.getElementById('player');

// === 播放状态 ===
player.paused;       // true（是否暂停）
player.ended;        // true（是否播放完毕）
player.readyState;   // 0=无数据, 1=有元数据, 2=当前帧, 3=可播放, 4=无需缓冲即可播放

// === 时间信息 ===
player.currentTime;     // 当前播放时间（秒，可读写）
player.duration;         // 总时长（秒，加载完成后才有值，NaN 表示未知）
player.seeking;          // 是否正在 seek（跳转中）
player.playbackRate;    // 播放速率（1=正常, 0.5=半速, 2=倍速）

// === 音量控制 ===
player.volume;           // 0~1 之间的浮点数
player.muted;            // true/false

// === 尺寸信息（仅 video）===
player.videoWidth;      // 视频原始宽度（像素）
player.videoHeight;     // 视频原始高度（像素）
player.poster;          // 封面图 URL

// === 网络状态 ===
player.networkState;    // 0=空闲, 1=加载中, 2=寻找媒体, 3=找到媒体但未使用
player.currentSrc;      // 当前正在使用的资源 URL
```

### 1.2 核心方法

```javascript
const audio = document.getElementById('my-audio');

// === 播放控制 ===
audio.play();           // 返回 Promise！异步播放
audio.pause();

// ⚠️ play() 是异步的！现代浏览器要求用户手势触发
btn.addEventListener('click', async () => {
    try {
        await audio.play();
        console.log('开始播放');
    } catch (err) {
        console.warn('播放被阻止:', err);
        // 通常是因为没有用户手势或自动播放策略限制
    }
});

// === 跳转 ===
audio.currentTime = 30;         // 跳转到第 30 秒
audio.fastSeek(60);             // 精确 seek 的快速替代（不保证精确）

// === 加载 ===
audio.load();                   // 重置并重新加载
```

### 1.3 生活类比：HTMLMediaElement 就像一台多功能媒体播放器

想象你面前有一台精密的**影音播放机**：

- **play() / pause()** 就是播放键和暂停键。
  
- **currentTime** 就像显示当前时间的数字时钟——你可以看到当前位置，也可以直接拨动指针跳到任意时刻。
  
- **volume / muted** 就像音量旋钮和静音开关。
  
- **duration** 就像唱片封面上标注的总时长——但在唱片还没完全放到唱机上之前，你还不知道总时长是多少（所以初始值可能是 NaN）。
  
- **playbackRate** 就像快进/慢放功能——你可以让声音像花栗鼠一样加速，或者像深沉的旁白一样减速。

> **哲学思考**：多媒体 API 让 Web 从一个**视觉媒介**变成了一个**多感官体验平台**。文字只能传递逻辑信息，图片增加了空间感知，而音频和视频引入了**时间维度**——内容在时间上展开，观众随着时间推移经历一段旅程。这种时间性带来了全新的编程挑战：不再是"渲染什么"，而是"在什么时刻做什么"。播放器的暂停、跳转、缓冲等待——这些都是对时间的操控能力。

## 二、事件监听：完整的媒体生命周期

### 2.1 加载相关事件

```javascript
const media = document.getElementById('media');

// 加载开始
media.addEventListener('loadstart', () => {
    console.log('开始加载...');
    showLoadingSpinner();
});

// 获取到元数据（时长、尺寸等基本信息可用时触发）
media.addEventListener('loadedmetadata', () => {
    console.log(`时长: ${media.duration}秒`);
    console.log(`尺寸: ${media.videoWidth}x${media.videoHeight}`);
    
    // 初始化进度条最大值
    progressSlider.max = media.duration;
    
    // 显示时长
    formatTime(media.duration);  // "3:45"
});

// 可以开始播放了（首帧已加载）
media.addEventListener('canplay', () => {
    console.log('可以开始播放了');
    hideLoadingSpinner();
});

// 无需缓冲即可流畅播放到结束
media.addEventListener('canplaythrough', () => {
    console.log('整个文件都可以流畅播放');
});
```

### 2.2 播放相关事件

```javascript
// 开始播放
media.addEventListener('play', () => {
    updatePlayButton('pause');  // 切换按钮图标为暂停
    console.log('播放中');
});

// 暂停
media.addEventListener('pause', () => {
    updatePlayButton('play');   // 切换按钮图标为播放
    console.log('已暂停');
});

// 播放结束
media.addEventListener('ended', () => {
    updatePlayButton('replay');
    console.log('播放完成');
    
    // 自动播放下一个？
    if (autoPlayNext) playNextItem();
});

// 时间更新（高频触发，约每秒 4~66 次）
media.addEventListener('timeupdate', () => {
    const current = media.currentTime;
    const total = media.duration || 0;
    
    // 更新进度条
    progressBar.style.width = `${(current / total) * 100}%`;
    
    // 更新时间显示
    currentTimeEl.textContent = formatTime(current);
});

// 正在 seek（用户拖动进度条时持续触发）
media.addEventListener('seeking', () => {
    showBufferingIndicator();
});

// seek 完成
media.addEventListener('seeked', () => {
    hideBufferingIndicator();
});

// 音量变化
media.addEventListener('volumechange', () => {
    volumeIcon.className = media.muted ? 'icon-muted' : 
                           (media.volume < 0.5 ? 'icon-low' : 'icon-high');
});

// 播放速率变化
media.addEventListener('ratechange', () => {
    showRateIndicator(media.playbackRate);
});
```

### 2.3 缓冲相关事件

```javascript
// 缓冲进度变化（当下载的缓冲区范围改变时触发）
media.addEventListener('progress', () => {
    if (media.buffered.length > 0) {
        // buffered.length 可能 > 1（多个缓冲区段）
        // 通常取最后一个（最新的）缓冲区末端
        const bufferedEnd = media.buffered.end(media.buffered.length - 1);
        
        // 更新缓冲进度条
        const percent = (bufferedEnd / media.duration) * 100;
        bufferBar.style.width = `${percent}%`;
    }
});

// 网络状态导致播放停顿（缓冲不足）
media.addEventListener('waiting', () => {
    showBufferingSpinner();
});

// 恢复播放（缓冲足够）
media.addEventListener('playing', () => {
    hideBufferingSpinner();
});
```

## 三、实战：自定义播放器控件

### 3.1 完整的自定义播放器

```javascript
/**
 * 自定义媒体播放器
 */
class CustomPlayer {
    constructor(element) {
        this.media = element.querySelector('video, audio') || element;
        this.controls = this._buildControls(element);
        this._bindEvents();
        this.dragging = false;
    }

    _buildControls(container) {
        // 如果已有自定义控件则复用，否则生成默认的
        let toolbar = container.querySelector('.custom-controls');
        if (!toolbar) {
            toolbar = document.createElement('div');
            toolbar.className = 'custom-controls';
            toolbar.innerHTML = `
                <button class="btn-play-pause">▶</button>
                <div class="progress-wrap">
                    <div class="buffer-bar"></div>
                    <div class="progress-bar"></div>
                    <input type="range" class="progress-slider" min="0" max="100" value="0" step="0.1">
                </div>
                <span class="time-current">0:00</span>/
                <span class="time-duration">0:00</span>
                <div class="volume-wrap">
                    <button class="btn-mute">🔊</button>
                    <input type="range" class="volume-slider" min="0" max="1" value="1" step="0.05">
                </div>
                <select class="speed-select">
                    <option value="0.5">0.5x</option>
                    <option value="1" selected>1x</option>
                    <option value="1.25">1.25x</option>
                    <option value="1.5">1.5x</option>
                    <option value="2">2x</option>
                </select>
                <button class="btn-fullscreen">⛶</button>
            `;
            container.appendChild(toolbar);
        }
        
        return {
            playPause: toolbar.querySelector('.btn-play-pause'),
            progress: toolbar.querySelector('.progress-bar'),
            bufferBar: toolbar.querySelector('.buffer-bar'),
            slider: toolbar.querySelector('.progress-slider'),
            timeCurrent: toolbar.querySelector('.time-current'),
            timeDuration: toolbar.querySelector('.time-duration'),
            muteBtn: toolbar.querySelector('.btn-mute'),
            volumeSlider: toolbar.querySelector('.volume-slider'),
            speedSelect: toolbar.querySelector('.speed-select'),
            fullscreenBtn: toolbar.querySelector('.btn-fullscreen')
        };
    }

    _bindEvents() {
        const { media } = this;

        // 播放/暂停
        this.controls.playPause.addEventListener('click', () => this.togglePlay());

        // 进度条点击/拖拽
        this._setupDraggableProgress();

        // 音量
        this.controls.volumeSlider.addEventListener('input', (e) => {
            media.volume = e.target.value;
        });
        this.controls.muteBtn.addEventListener('click', () => {
            media.muted = !media.muted;
        });

        // 倍速
        this.controls.speedSelect.addEventListener('change', (e) => {
            media.playbackRate = parseFloat(e.target.value);
        });

        // 全屏
        this.controls.fullscreenBtn.addEventListener('click', () => this.toggleFullscreen());

        // 媒体事件
        media.addEventListener('loadedmetadata', () => {
            this.controls.timeDuration.textContent = this._formatTime(media.duration);
        });

        media.addEventListener('timeupdate', () => this._updateProgress());

        media.addEventListener('play', () => {
            this.controls.playPause.textContent = '⏸';
        });

        media.addEventListener('pause', () => {
            this.controls.playPause.textContent = '▶';
        });

        media.addEventListener('volumechange', () => {
            this.controls.volumeSlider.value = media.muted ? 0 : media.volume;
            this.controls.muteBtn.textContent = media.muted ? '🔇' : '🔊';
        });

        // 键盘快捷键
        document.addEventListener('keydown', (e) => {
            if (!this.isFocused()) return;
            
            switch (e.key) {
                case ' ': e.preventDefault(); this.togglePlay(); break;
                case 'ArrowLeft': media.currentTime -= 5; break;
                case 'ArrowRight': media.currentTime += 5; break;
                case 'ArrowUp': media.volume = Math.min(1, media.volume + 0.05); break;
                case 'ArrowDown': media.volume = Math.max(0, media.volume - 0.05); break;
                case 'f': this.toggleFullscreen(); break;
                case 'm': media.muted = !media.muted; break;
            }
        });
    }

    _setupDraggableProgress() {
        const { slider, media } = this.controls;

        let dragging = false;

        const seek = (e) => {
            const rect = slider.getBoundingClientRect();
            const percent = Math.max(0, Math.min(1, (e.clientX - rect.left) / rect.width));
            media.currentTime = percent * media.duration;
        };

        slider.addEventListener('mousedown', (e) => {
            dragging = true;
            seek(e);
        });

        document.addEventListener('mousemove', (e) => {
            if (dragging) seek(e);
        });

        document.addEventListener('mouseup', () => { dragging = false; });
    }

    togglePlay() {
        if (this.media.paused) {
            this.media.play();
        } else {
            this.media.pause();
        }
    }

    async toggleFullscreen() {
        try {
            if (document.fullscreenElement) {
                await document.exitFullscreen();
            } else {
                await this.media.requestFullscreen();
            }
        } catch (err) {
            console.error('全屏切换失败:', err);
        }
    }

    _updateProgress() {
        const { media, controls } = this;
        if (media.duration) {
            const percent = (media.currentTime / media.duration) * 100;
            controls.progress.style.width = `${percent}%`;
            controls.slider.value = media.currentTime;
            controls.timeCurrent.textContent = this._formatTime(media.currentTime);
        }
    }

    _formatTime(seconds) {
        if (!isFinite(seconds)) return '0:00';
        const m = Math.floor(seconds / 60);
        const s = Math.floor(seconds % 60);
        return `${m}:${s.toString().padStart(2, '0')}`;
    }

    isFocused() { return document.activeElement?.closest('.custom-player'); }
}
```

## 四、高级主题

### 4.1 MediaSource API（流式播放）

对于需要动态拼接视频片段的场景：

```javascript
if ('MediaSource' in window) {
    const mediaSource = new MediaSource();
    const video = document.getElementById('stream-video');
    video.src = URL.createObjectURL(mediaSource);

    mediaSource.addEventListener('sourceopen', async () => {
        const sourceBuffer = mediaSource.addSourceBuffer('video/mp4; codecs="avc1.42E01E, mp4a.40.2"');
        
        // 动态添加视频数据
        const response = await fetch('/api/video-chunk');
        const chunk = await response.arrayBuffer();
        
        sourceBuffer.appendBuffer(chunk);
        
        sourceBuffer.addEventListener('updateend', () => {
            if (!mediaSource.updating && !sourceBuffer.buffered.length) {
                mediaSource.endOfStream();
            }
        });
    });
}
```

### 4.2 自动播放策略

现代浏览器对自动播放有严格限制：

```javascript
// 检测自动播放能力
async function checkAutoPlay(videoEl) {
    try {
        await videoEl.play();
        console.log('允许自动播放');
        return true;
    } catch (err) {
        console.warn('自动播放被阻止:', err.name);
        // err.name 可能是：
        // 'NotAllowedError' — 用户未交互
        // 'NotSupportedError' — 不支持此格式
        return false;
    }
}

// 优雅降级：显示播放按钮
checkAutoPlay(video).then(allowed => {
    if (!allowed) {
        showPlayOverlay(video);
    }
});
```

## 五、总结

### 5.1 事件生命周期速查

```
loadstart → loadedmetadata → [canplay → playing] ↔ [waiting → playing]
                                                    ↓
                                                ended
                                                    ↓
                                              pause（随时可能发生）
```

### 5.2 核心原则

1. **play() 返回 Promise**：务必用 `await` 或 `.catch()` 处理可能的拒绝（自动播放策略等）。
2. **timeupdate 高频触发**：避免在其中做复杂 DOM 操作，考虑节流。
3. **buffered 可能有多段**：不要假设 `buffered.length === 1`。
4. **提供键盘快捷键**：空格播放/暂停、方向键快进/后退、F 全屏、M 静音。
5. **始终提供降级方案**：不支持 MediaSource 或自动播放时的备选 UI。

> **最后的思考**：HTML5 多媒体 API 的伟大之处在于它把复杂的编解码、缓冲管理、流同步等问题全部封装在了浏览器底层，开发者只需要面对一组简洁直观的属性和方法。这种**分层抽象**的思想贯穿了所有优秀的工程实践——操作系统隐藏了硬件细节，浏览器隐藏了网络细节，而多媒体 API 隐藏了解码引擎的细节。我们作为上层应用的开发者，站在这些巨人的肩膀上，只需关注"用户体验"本身：进度条的反馈是否及时？音量调节是否顺滑？错误提示是否友好？这些才是真正值得投入精力的地方。关于 Canvas 2D 绘图的详细技术，推荐阅读[《Canvas 2D 绘图》](/40.frontend/50.javascript/20.browser-api/10.浏览器%20API%20与%20DOM%20操作/85.Canvas2D绘图.md)。关于 WebGL 图形编程的基础知识，推荐阅读[《WebGL 基础》](/40.frontend/50.javascript/20.browser-api/10.浏览器%20API%20与%20DOM%20操作/90.WebGL基础.md)。
