# Canvas 2D —— 绘图上下文、路径、变换、图像处理、像素操作

## 从"使用媒体"到"创造视觉"的创作跃迁

在[《多媒体 API》](/40.frontend/50.javascript/20.browser-api/10.浏览器%20API%20与%20DOM%20操作/80.多媒体API.md)一文中，我们学习了如何播放和控制已有的音视频内容。但如果你的需求不是"展示别人的作品"，而是**从零开始绘制自己的图形**呢？——数据可视化图表、游戏画面、图像处理效果、动态粒子系统……这些场景需要的是**程序化绘图**能力，这就是 **Canvas API** 的舞台。

Canvas（画布）提供了一块由像素组成的矩形区域和一套完整的 2D 绘图命令。它不像 DOM 那样操作元素对象树，而是直接在像素层面上进行渲染——这种模式带来了极高的性能和灵活性。从简单的线条、矩形到复杂的贝塞尔曲线、渐变填充、阴影效果，再到直接的像素级操作，Canvas 的能力覆盖了绝大多数 2D 图形需求。

> **本文的目标**：系统讲解 Canvas 2D API 的核心概念——从获取绘图上下文开始，深入路径绘制、样式设置、坐标变换、文本渲染、图像处理以及像素级操作。

## 一、Canvas 基础：画布与画笔

### 1.1 获取绘图上下文

```html
<canvas id="myCanvas" width="800" height="600"></canvas>
```

```javascript
const canvas = document.getElementById('myCanvas');
const ctx = canvas.getContext('2d');  // 获取 2D 绘图上下文

// ctx 就是你所有的"画笔"——所有绘图操作都通过它完成
// 它是一个 CanvasRenderingContext2D 对象

// ⚠️ 注意：不要用 CSS 设置 width/height！那会拉伸而非改变分辨率
// canvas.width = 800;   // 属性方式 = 实际像素数（正确）
// style.width = '400px' // CSS 方式 = 显示大小（会缩放）
```

### 1.2 Canvas 的本质：一张位图

理解 Canvas 的关键在于认识到：**Canvas 本质上就是一块内存中的像素数组**。

```javascript
// 每个像素由 RGBA 四个通道组成（各 8 位）
// 800 × 600 的 Canvas = 480,000 个像素 × 4 字节 = 约 1.92 MB 显存

console.log(canvas.width);    // 800（实际像素宽度）
console.log(canvas.height);   // 600（实际像素高度）

// CSS 尺寸与 Canvas 分辨率的关系
// 如果 CSS 设置为 400×300 而 Canvas 是 800×600：
// 那么 CSS 的每个"像素"对应 Canvas 的 2×2 个物理像素
// 这就是高 DPI 屏幕下的清晰度原理
```

### 1.3 状态保存与恢复

Canvas 的状态机设计是其最重要的特性之一：

```javascript
// save() 保存当前状态到状态栈
ctx.save();

// 修改各种状态...
ctx.fillStyle = 'red';
ctx.strokeStyle = 'blue';
ctx.lineWidth = 5;
ctx.translate(100, 50);
ctx.rotate(Math.PI / 4);

// restore() 从栈中弹出上一个状态
ctx.restore();
// 现在 fillStyle 回到了 save 之前的状态
// translate 和 rotate 也被恢复了！

// 典型用法：隔离不同图形的样式影响
function drawRect(x, y, w, h, color) {
    ctx.save();
    ctx.fillStyle = color;
    ctx.fillRect(x, y, w, h);
    ctx.restore();  // 不影响外部的 fillStyle
}
```

### 1.4 生活类比：Canvas 就是画布 + 画笔套装

- **`<canvas>` 元素就是画布本身**——有固定的尺寸（宽×高），上面什么都没有或者有一些之前画的内容。
  
- **`ctx`（Context 2D）就是你的画笔套装**——包含无数支画笔（不同的颜色、粗细）、一把尺子（变换工具）、一个调色盘（渐变/图案）、还有橡皮擦（clearRect）。
  
- **`save()` / `restore()` 就像换画笔前把当前的画笔放回原处**——你换了一支红笔画画，画完后把红笔放回去拿起原来的黑笔继续画，不会搞混。
  
- **路径（Path）就像先用铅笔打草稿**——你勾勒出轮廓线（moveTo、lineTo），确认无误后决定用什么颜色填充（fill）或描边（stroke）。

> **哲学思考**：Canvas 代表了一种**命令式（Imperative）的图形编程范式**——你告诉计算机每一步该做什么："移动到这里"、"画一条线到那里"、"填充红色"。这与 SVG 的**声明式（Declarative）**风格形成鲜明对比——SVG 描述的是"这里有一个圆"，而 Canvas 描述的是"执行这些指令来画出圆"。命令式的方式更灵活但更底层；声明式的方式更直观但不那么灵活。两者各有适用场景——静态图形选 SVG，动态交互选 Canvas。

## 二、路径绘制：一切图形的基础

### 2.1 基本路径方法

```javascript
// === 开始新路径 ===
ctx.beginPath();  // 必须调用！否则可能连接到之前的路径

// === 移动画笔（不画线）===
ctx.moveTo(50, 50);     // 将画笔移到 (50, 50)

// === 画直线 ===
ctx.lineTo(200, 50);    // 从当前位置画直线到 (200, 50)
ctx.lineTo(200, 150);
ctx.lineTo(50, 150);

// === 闭合路径 ===
ctx.closePath();        // 自动从当前点连回起点（可选）

// === 渲染 ===
ctx.stroke();          // 只描边（轮廓线）
ctx.fill();            // 只填充（内部区域）
// 通常二选一，或先 fill 再 stroke
```

### 2.2 基础图形快捷方法

```javascript
// === 矩形 ===
ctx.fillRect(x, y, width, height);      // 填充矩形
ctx.strokeRect(x, y, width, height);    // 描边矩形
ctx.clearRect(x, y, width, height);     // 清除矩形区域（透明）

// === 圆弧 / 圆形 ===
ctx.arc(x, y, radius, startAngle, endAngle, counterclockwise);
// 角度为弧度制！0 在三点钟方向，Math.PI * 2 = 一整圈

// 画一个完整圆形
ctx.beginPath();
ctx.arc(100, 100, 40, 0, Math.PI * 2);
ctx.fill();

// 画一个半圆
ctx.beginPath();
ctx.arc(100, 100, 40, 0, Math.PI);  // 上半圆
ctx.stroke();

// === 椭圆 ===
ctx.ellipse(x, y, radiusX, radiusY, rotation, startAngle, endAngle);

ctx.beginPath();
ctx.ellipse(150, 100, 60, 30, Math.PI / 6, 0, Math.PI * 2);
ctx.fill();

// === 圆角矩形（自定义实现）==
function roundedRect(ctx, x, y, w, h, r) {
    ctx.beginPath();
    ctx.moveTo(x + r, y);
    ctx.arcTo(x + w, y, x + w, y + h, r);
    ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r);
    ctx.arcTo(x, y, x + w, y, r);
    ctx.closePath();
}

roundedRect(ctx, 10, 10, 200, 100, 15);
ctx.fillStyle = '#4a90d9';
ctx.fill();
```

### 2.3 贝塞尔曲线

```javascript
// 二次贝塞尔曲线（一个控制点）
ctx.beginPath();
ctx.moveTo(50, 200);
ctx.quadraticCurveTo(controlX, controlY, endX, endY);
ctx.stroke();

// 三次贝塞尔曲线（两个控制点）— 更灵活
ctx.beginPath();
ctx.moveTo(50, 200);
ctx.bezierCurveTo(cp1x, cp1y, cp2x, cp2y, endX, endY);
ctx.stroke();

// 实例：绘制平滑的心形
function drawHeart(ctx, x, y, size) {
    ctx.beginPath();
    ctx.moveTo(x, y + size / 4);
    ctx.bezierCurveTo(
        x, y - size / 2,
        x - size / 2, y - size / 2,
        x - size / 2, y - size / 4
    );
    ctx.bezierCurveTo(
        x - size / 2, y,
        x, y + size / 3,
        x, y + size / 2
    );
    ctx.bezierCurveTo(
        x, y + size / 3,
        x + size / 2, y,
        x + size / 2, y - size / 4
    );
    ctx.bezierCurveTo(
        x + size / 2, y - size / 2,
        x, y - size / 2,
        x, y + size / 4
    );
    
    ctx.fillStyle = '#e74c3c';
    ctx.fill();
}

drawHeart(ctx, 200, 200, 80);
```

```javascript
// 颜色值支持多种格式
ctx.fillStyle = '#ff5733';       // 十六进制

ctx.beginPath();

ctx.strokeStyle = '#2980b9';
ctx.stroke();
```

### 3.2 渐变填充

```javascript
// 线性渐变
const linearGrad = ctx.createLinearGradient(0, 0, 200, 0);
linearGrad.addColorStop(0, '#3498db');     // 起点
linearGrad.addColorStop(0.5, '#9b59b6');    // 中间
linearGrad.addColorStop(1, '#e74c3c');     // 终点

);
radialGrad.addColorStop(0, 'rgba(255, 255, 255, 1)');
radialGrad.addColorStop(1, 'rgba(255, 255, 255, 0)');

// 锥形渐变（较新 API）
if (typeof ctx.createConicGradient === 'function') {
```

## 四、坐标变换

### 4.1 基础变换

```javascript
// 平移 —— 移动坐标系原点
ctx.translate(dx, dy);

// 旋转 —— 围绕原点旋转（参数为弧度）
ctx.rotate(angle);  // angle = degrees * Math.PI / 180

// 缩放
ctx.scale(sx, sy);   // 可以是非均匀缩放（如 sx=2, sy=1 水平拉伸）

// 倾斜/错切
ctx.shear(sx, sy);

// 变换是累积的！顺序很重要
ctx.translate(100, 100);
ctx.rotate(Math.PI / 4);
ctx.scale(1.5, 1.5);

// 此时绘制的所有图形都受到了这三次变换的影响
ctx.fillRect(-25, -25, 50, 50);  // 以 (100,100) 为中心旋转45°后放大1.5倍的方块
```

### 4.2 变换矩阵（高级）

```javascript
// setTransform(a, b, c, d, e, f)
// [a c e]   [ scaleX skewX  translateX ]
// [b d f] = [ skewY  scaleY translateY ]
// [0 0 1]   [   0      0        1        ]

// 重置为单位矩阵
ctx.setTransform(1, 0, 0, 1, 0, 0);  // 相当于 resetTransform()

// 复杂变换示例：围绕任意点旋转
function rotateAround(ctx, x, y, angle) {
    ctx.translate(x, y);
    ctx.rotate(angle);
    ctx.translate(-x, -y);
}

rotateAround(ctx, 200, 200, Math.PI / 6);
ctx.fillRect(175, 175, 50, 50);
```

### 4.3 生活类比：变换就像是调整画架

想象你在画画：

- **translate 就像移动画布**：你把整张纸往右挪了 100px，然后你在纸上原来 (50,50) 的位置画了一个点，实际上这个点出现在了屏幕上的 (150,50)。
  
- **rotate 就像旋转画板**：你把画板顺时针转了 45 度，然后你沿着画板的"水平方向"画了一条线，这条线在观众眼里其实是倾斜的。
  
- **scale 就像拉近或拉远镜头**：你把画板上的坐标网格放大了两倍，原本 1cm 的线条现在看起来有 2cm 长。
  
- **save/restore 就像拍照记录和恢复**：每次调整画架位置之前拍张照，之后可以随时恢复到拍照时的状态。

## 五、文本渲染

### 5.1 基本文本绘制

```javascript
ctx.font = 'bold 24px "Microsoft YaHei", sans-serif';
// 语法：'font-style font-weight font-size font-family'

ctx.textAlign = 'center';    // left | center | right | start | end
ctx.textBaseline = 'middle';  // top | middle | alphabetic | bottom

// 填充文本
ctx.fillStyle = '#333';
ctx.fillText('Hello Canvas', x, y);

// 描边文本
ctx.strokeText('Outline Text', x, y);

// 文本测量
const metrics = ctx.measureText('Hello Canvas');
metrics.width;              // 文本渲染宽度（像素）
metrics.actualBoundingBoxAscent;   // 基线以上的高度
metrics.actualBoundingBoxDescent;  // 基线以下的高度
```

### 5.2 实战：文字自动换行

```javascript
/**
 * 在指定宽度内自动换行绘制文本
 */
function wrapText(ctx, text, x, y, maxWidth, lineHeight) {
    const words = text.split(' ');
    let line = '';
    let currentY = y;

    for (let i = 0; i < words.length; i++) {
        const testLine = line + words[i] + ' ';
        const metrics = ctx.measureText(testLine);
        
        if (metrics.width > maxWidth && line !== '') {
            ctx.fillText(line, x, currentY);
            line = words[i] + ' ';
            currentY += lineHeight;
        } else {
            line = testLine;
        }
    }
    ctx.fillText(line, x, currentY);
}

// 使用
ctx.font = '16px sans-serif';
wrapText(ctx, '这是一段很长的文字需要在指定的宽度内自动换行显示。',
    50, 50, 300, 24);
```

```javascript
/**
 * 图像灰度化处理
 */
function grayscaleImage(imageData) {
    const data = imageData.data;
    for (let i = 0; i < data.length; i += 4) {
        const avg = (data[i] + data[i + 1] + data[i + 2]) / 3;
        data[i] = avg;     // R
        data[i + 1] = avg; // G
        data[i + 2] = avg; // B
        // data[i + 3] 不动（A）
    }
    return imageData;
}

// 使用

ctx.putImageData(imageData, 0, 0);
```

## 七、实战：粒子动画系统

```javascript
class ParticleSystem {
    constructor(canvas) {
        this.canvas = canvas;
        this.ctx = canvas.getContext('2d');
        this.particles = [];
        this.animationId = null;
        
        this.resize();
        window.addEventListener('resize', () => this.resize());
    }

    resize() {
        this.canvas.width = this.canvas.parentElement.clientWidth;
        this.canvas.height = this.canvas.parentElement.clientHeight;
    }

    createParticle(x, y) {
        this.particles.push({
            x, y,
            vx: (Math.random() - 0.5) * 4,
            vy: (Math.random() - 0.5) * 4,
            radius: Math.random() * 3 + 1,
            life: 1,
            decay: Math.random() * 0.02 + 0.005,
            hue: Math.random() * 360
        });
    }

    update() {
        for (let i = this.particles.length - 1; i >= 0; i--) {
            const p = this.particles[i];
            p.x += p.vx;
            p.y += p.vy;
            p.vy += 0.05;  // 重力
            p.life -= p.decay;

            if (p.life <= 0) {
                this.particles.splice(i, 1);
            }
        }
    }

    draw() {
        this.ctx.fillStyle = 'rgba(0, 0, 0, 0.1)';
        this.ctx.fillRect(0, 0, this.canvas.width, this.canvas.height);

        for (const p of this.particles) {
            this.ctx.beginPath();
            this.ctx.arc(p.x, p.y, p.radius, 0, Math.PI * 2);
            this.ctx.fillStyle = `hsla(${p.hue}, 70%, 60%, ${p.life})`;
            this.ctx.fill();
        }
    }

    animate() {
        this.update();
        this.draw();
        this.animationId = requestAnimationFrame(() => this.animate());
    }

    start() { if (!this.animationId) this.animate(); }
    stop() { cancelAnimationFrame(this.animationId); this.animationId = null; }
}

// 使用
const psystem = new ParticleSystem(document.getElementById('particle-canvas'));
psystem.start();

// 鼠标点击产生粒子
document.getElementById('particle-canvas').addEventListener('click', (e) => {
    for (let i = 0; i < 20; i++) {
        psystem.createParticle(e.offsetX, e.offsetY);
    }
});
```

## 八、总结

### 8.1 核心概念速查

| 类别 | 方法/属性 | 说明 |
|------|-----------|------|
| **路径** | `beginPath/moveTo/lineTo/arc/closePath` | 构建形状 |
| **渲染** | `fill/stroke/fillRect/strokeRect/clearRect` | 输出到画布 |
| **样式** | `fillStyle/strokeStyle/lineWidth/shadow*` | 外观控制 |
| **渐变** | `createLinear/Radial/ConicGradient` | 渐变填充 |
| **变换** | `translate/rotate/scale/setTransform` | 坐标系变换 |
| **文本** | `fillText/strokeText/measureText` | 文字绘制 |
| **图像** | `drawImage/getImageData/putImageData` | 图片与像素 |
| **状态** | `save/restore` | 状态栈管理 |

### 8.2 设计原则

1. **始终 beginPath 开始新路径**：避免残留路径导致意外连线。
2. **善用 save/restore 隔离状态**：防止样式污染。
3. **注意性能**：频繁的 putImageData 很昂贵，尽量批量处理。
4. **处理高 DPI 屏幕**：Canvas 的 width/height 应为 CSS 尺寸乘以 devicePixelRatio。
5. **动画用 requestAnimationFrame**：避免 setInterval 导致的帧率不一致问题。

> **最后的思考**：Canvas 2D API 是 Web 图形编程中最具"工匠感"的接口——每一笔每一划都需要你来指挥。这种底层的精确控制既是它的优势也是它的门槛。与 WebGL 的并行计算能力相比，Canvas 2D 更适合 2D 图表、简单游戏和数据可视化；与 SVG 的声明式模型相比，Canvas 更适合高频更新的大规模图形。选择正确的工具比精通一种工具更重要——知道什么时候该用 Canvas、什么时候该用 SVG、什么时候该用 WebGL，这才是真正的智慧所在。关于 WebGL 图形编程的基础知识，推荐阅读[《WebGL 基础》](/40.frontend/50.javascript/20.browser-api/10.浏览器%20API%20与%20DOM%20操作/90.WebGL基础.md)。关于网络信息 API 的使用，推荐阅读[《网络信息 API》](/40.frontend/50.javascript/20.browser-api/10.浏览器%20API%20与%20DOM%20操作/95.网络信息API.md)。
