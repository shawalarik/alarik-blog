# 网络信息 API —— navigator.onLine、online/offline 事件、连接状态检测

## 从"假设在线"到"感知环境"的认知跃迁

在早期的 Web 开发中，我们默认用户始终处于**联网状态**。页面加载、AJAX 请求、资源获取——一切都在线发生。但随着移动设备的普及和 PWA（Progressive Web App）的兴起，这个假设不再成立：用户可能进入隧道失去信号、可能主动切换到飞行模式、可能在使用按量计费的弱网环境。应用如果能**感知网络状态的变化**并做出适配响应，用户体验将得到显著提升。

网络信息 API（Network Information API）和相关的联机/脱机事件提供了检测网络状态的标准手段——从最基本的在线/离线判断，到详细的连接类型（WiFi/4G/3G）、有效带宽估算、甚至计量连接的警告。

> **本文的目标**：全面讲解网络状态检测的各种技术方案——从 navigator.onLine 到 online/offline 事件，从 NetworkInformation API 到实际工程中的最佳实践策略。

---

## 一、在线/离线状态检测

### 1.1 navigator.onLine

这是最基础的在线状态检测属性：

```javascript
// 只读布尔值
console.log(navigator.onLine);  // true（在线）/ false（离线）

// 注意事项：
// 1. 它反映的是浏览器的网络连通性判断
// 2. 不同浏览器的判断标准不同
// 3. 不能区分 WiFi 和蜂窝网络
// 4. 可能存在误判（有网但 onLine=false，或反之）
```

### 1.2 online / offline 事件

当网络状态发生变化时，window 会触发对应事件：

```javascript
// 在线事件
window.addEventListener('online', () => {
    console.log('网络已恢复！');
    
    showNotification('🌐 网络已连接', { type: 'success' });
    retryFailedRequests();  // 重试之前失败的请求
    syncOfflineData();      // 同步离线期间保存的数据
});

// 离线事件
window.addEventListener('offline', () => {
    console.warn('网络断开了！');
    
    showNotification('⚠️ 网络已断开', { type: 'warning' });
    saveDataForLater();     // 保存未提交的数据
    enterOfflineMode();     // 切换到离线模式 UI
});
```

### 1.3 实战：智能离线处理系统

```javascript
/**
 * NetworkManager — 网络状态管理与离线队列
 */
class NetworkManager {
    constructor(options = {}) {
        this.isOnline = navigator.onLine;
        this.requestQueue = [];
        this.maxRetries = options.maxRetries || 3;
        this.retryDelay = options.retryDelay || 2000;
        this.listeners = new Set();
        
        this._bindEvents();
        this._notifyAll({ online: this.isOnline });
    }

    _bindEvents() {
        window.addEventListener('online', () => {
            this.isOnline = true;
            this._notifyAll({ online: true });
            this._processQueue();
            
            // 可选：延迟确认（有些情况下 online 事件会误触发）
            setTimeout(() => {
                if (!navigator.onLine) {
                    this.isOnline = false;
                    this._notifyAll({ online: false });
                }
            }, 3000);
        });

        window.addEventListener('offline', () => {
            this.isOnline = false;
            this._notifyAll({ online: false });
        });
    }

    // 监听状态变化
    onChange(callback) {
        callback({ online: this.isOnline });
        this.listeners.add(callback);
        return () => this.listeners.delete(callback);  // 返回取消订阅
    }

    _notifyAll(state) {
        this.listeners.forEach(fn => {
            try { fn(state); } catch (e) {}
        });
    }

    // 带重试的网络请求
    async fetchWithRetry(url, options = {}, retries = this.maxRetries) {
        if (!this.isOnline) {
            return this.enqueueRequest(url, options);
        }

        try {
            const response = await fetch(url, options);
            if (!response.ok) throw new Error(`HTTP ${response.status}`);
            return response;
        } catch (err) {
            if (retries > 0 && this.isOnline) {
                await delay(this.retryDelay);
                return this.fetchWithRetry(url, options, retries - 1);
            }
            throw err;
        }
    }

    // 入队请求（离线时）
    enqueueRequest(url, options) {
        return new Promise((resolve, reject) => {
            this.requestQueue.push({ url, options, resolve, reject, attempts: 0 });
            showOfflineIndicator(this.requestQueue.length);
        });
    }

    // 处理队列
    async _processQueue() {
        while (this.requestQueue.length > 0 && this.isOnline) {
            const req = this.requestQueue.shift();
            
            try {
                const response = await fetch(req.url, req.options);
                req.resolve(response);
            } catch (err) {
                if (req.attempts < this.maxRetries) {
                    req.attempts++;
                    this.requestQueue.unshift(req);  // 放回队首
                    await delay(1000);
                } else {
                    req.reject(err);
                }
            }
            
            updateQueueIndicator(this.requestQueue.length);
        }
    }
}

function delay(ms) { return new Promise(r => setTimeout(r, ms)); }

// 使用
const netMgr = new NetworkManager();

netMgr.onChange(({ online }) => {
    const indicator = document.getElementById('network-status');
    if (indicator) {
        indicator.className = online ? 'status-online' : 'status-offline';
        indicator.textContent = online ? '已连接' : '离线';
    }
});

// 发送请求（自动处理离线情况）
netMgr.fetchWithRetry('/api/save-data', { method: 'POST', body: JSON.stringify(data) })
    .then(response => response.json())
    .then(handleResult)
    .catch(err => showError('数据保存失败'));
```

### 1.4 生活类比：在线/离线检测就像办公室的电话线路监控

- **navigator.onLine 就像电话总机的指示灯**：亮着表示线路通畅（在线），灭了表示断线（离线）。但指示灯偶尔会出错——有时候灯亮了但电话打不通，有时候灯灭了一拨就通了。
  
- **online/offline 事件就像电话接线员的广播**："各位同事，线路恢复了！"或者"请注意，线路中断。"听到广播后你可以调整自己的工作计划——恢复打电话（发送请求）或者先把消息记下来稍后再发（入队等待）。

> **哲学思考**：网络状态的感知能力让 Web 应用从**理想化的在线世界**走向**现实的不可靠环境**。这反映了软件工程中的一个普遍真理：**任何可能出错的事情终将会出错（Murphy's Law）**。优雅地处理故障不是锦上添花，而是现代应用的基本素养。一个能在地铁隧道里正常工作的笔记应用，比在网络完美时才运行的应用更有价值——因为它尊重了用户所处的真实世界，而非开发者臆想中的理想世界。

## 二、NetworkInformation API：更细粒度的网络信息

### 2.1 连接类型检测

```javascript
// 获取网络连接信息
if ('connection' in navigator) {
    const connection = navigator.connection || 
                        navigator.mozConnection || 
                        navigator.webkitConnection;

    console.log('有效带宽:', connection.downlink);     // Mbps（估算值）
    console.log('连接类型:', connection.effectiveType);  // 'slow-2g' | '2g' | '3g' | '4g'
    console.log('RTT:', connection.rtt);                   // 往返时间（毫秒）
    console.log('节省数据模式:', connection.saveData);    // boolean
}
```

### 2.2 effectiveType 的含义与应对策略

```javascript
const strategies = {
    'slow-2g': {
        preloadImages: false,
        maxImageQuality: 0.3,
        skipFonts: true,
        lazyEverything: true,
        disableAnimations: true
    },
    '2g': {
        preloadImages: false,
        maxImageQuality: 0.5,
        skipFonts: false,
        lazyEverything: true,
        disableAnimations: true
    },
    '3g': {
        preloadImages: true,
        maxImageQuality: 0.7,
        skipFonts: false,
        lazyImages: true,
        disableAnimations: false
    },
    '4g': {
        preloadImages: true,
        maxImageQuality: 1.0,
        skipFonts: false,
        lazyImages: false,
        disableAnimations: false
    }
};

function adaptToNetwork(effectiveType) {
    const strategy = strategies[effectiveType] || strategies['4g'];
    
    // 图片质量
    if (strategy.maxImageQuality < 1) {
        setMaxImageQuality(strategy.maxImageQuality);
    }
    
    // 动画开关
    if (strategy.disableAnimations) {
        document.documentElement.classList.add('reduce-motion');
    } else {
        document.documentElement.classList.remove('reduce-motion');
    }
}
```

### 2.3 监听网络变化

```javascript
const connection = navigator.connection;

connection.addEventListener('change', (e) => {
    console.log('网络变化:', e.target);
    console.log('新类型:', e.target.effectiveType);
    console.log('带宽:', e.target.downlink, 'Mbps');
    
    adaptToNetwork(e.target.effectiveType);
    
    // 显示提示
    if (e.target.saveData) {
        showToast('您开启了省流模式，已优化加载策略');
    }
});
```

### 2.4 生活类比：effectiveType 就像道路等级

- **4G 就像高速公路**：多车道、速度快、不限流量（大多数情况下）——可以加载高清图片、播放高清视频。
  
- **3G 就像城市主干道**：速度尚可，但高峰期会堵车（延迟波动）——适合普通质量的图片和中视频。
  
- **2G 就像乡村小路**：速度慢、信号不稳定——只能传输文本和极小的图片。
  
- **slow-2g 就像泥泞土路**——勉强能用，体验很差——只应该加载纯文本。

NetworkInformation API 就是你的**导航系统**：它告诉你前方是什么等级的路，你可以据此决定开什么车（加载什么质量的资源）、以什么速度行驶（是否启用懒加载）。

## 三、综合实战：自适应加载策略

```javascript
/**
 * AdaptiveLoader — 基于网络条件的自适应资源加载器
 */
class AdaptiveLoader {
    constructor() {
        this.connection = null;
        this.cache = new Map();
        this._detectCapabilities();
    }

    _detectCapabilities() {
        // 基础能力检测
        this.supportsServiceWorker = 'serviceWorker' in navigator;
        this.supportsCacheAPI = 'caches' in window;
        this.hasNetworkInfo = 'connection' in navigator;

        if (this.hasNetworkInfo) {
            this.connection = navigator.connection;
            this._listenForChanges();
        }
    }

    _listenForChanges() {
        this.connection?.addEventListener('change', () => {
            // 网络变化时清除缓存策略缓存
            this.cache.clear();
        });
    }

    /**
     * 加载图片——根据网络条件选择合适质量
     */
    loadImage(src, qualityOptions = {}) {
        const defaultOptions = {
            high: src,                    // 原始质量 URL
            medium: src.replace(/\.(jpg|png)/, '-medium.$1'),  // 中等质量
            low: src.replace(/\.(jpg|png)/, '-low.$1')          // 低质量
        };
        const opts = { ...defaultOptions, ...qualityOptions };

        let targetUrl = opts.high;  // 默认最高质量

        if (this.hasNetworkInfo && this.connection) {
            const type = this.connection.effectiveType;
            const downlink = this.connection.downlink;

            if (type === 'slow-2g' || type === '2g' || downlink < 1.5) {
                targetUrl = opts.low || opts.medium || opts.high;
            } else if (type === '3g' || downlink < 4) {
                targetUrl = opts.medium || opts.high;
            }
        }

        return new Promise((resolve, reject) => {
            const img = new Image();
            img.onload = () => resolve(img);
            img.onerror = () => reject(new Error('图片加载失败'));
            
            // 如果支持 Cache API，优先从缓存读取
            if (this.supportsCacheAPI) {
                caches.open('adaptive-images').then(cache => {
                    cache.match(targetUrl).then(cachedResponse => {
                        if (cachedResponse) {
                            cachedResponse.blob().then(blob => {
                                img.src = URL.createObjectURL(blob);
                            });
                        } else {
                            img.src = targetUrl;
                        }
                    });
                });
            } else {
                img.src = targetUrl;
            }
        });
    }

    /**
     * 条件性预加载
     */
    conditionalPreload(urls) {
        if (!this.connection) return;  // 无法判断则不预加载

        const type = this.connection.effectiveType;
        
        if (type === '4g' && !this.connection.saveData) {
            // 高速且非省流模式：预加载下一页的资源
            urls.slice(0, 3).forEach(url => {
                const link = document.createElement('link');
                link.rel = 'prefetch';
                link.href = url;
                document.head.appendChild(link);
            });
        }
    }
}

// 使用
const loader = new AdaptiveLoader();

// 加载英雄图片（根据网络自动选质量）
loader.loadImage('/images/hero-banner.jpg')
    .then(img => document.getElementById('hero').appendChild(img))
    .catch(() => document.getElementById('hero').classList.add('no-image'));

// 导航到详情页前预加载相关资源
document.querySelectorAll('.card-link').forEach(link => {
    link.addEventListener('mouseenter', () => {
        loader.conditionalPreload([link.dataset.prefetch]);
    }, { once: true });
});
```

## 四、总结

### 4.1 API 速查表

| API | 能力 | 兼容性 | 用途 |
|-----|------|-------|------|
| `navigator.onLine` | 在线/离线布尔值 | 所有浏览器 | 快速状态判断 |
| `online/offline` 事件 | 状态变化通知 | 所有浏览器 | 响应式 UI 切换 |
| `navigator.connection` | 详细连接信息 | Chrome/Android | 精细化策略 |
| `connection.effectiveType` | 连接类型 | 同上 | 分级加载策略 |

### 4.2 设计原则

1. **永远不要假定在线**：即使 `onLine === true`，请求也可能失败。
2. **优雅降级优于报错退出**：离线时显示缓存数据或友好提示。
3. **结合 Service Worker**：offline 事件配合 SW 可以实现真正的离线可用。
4. **NetworkInformation API 作为增强**：不能作为唯一的判断依据（值是估算的）。
5. **给用户反馈**：状态变化时通知用户，让他们知道发生了什么。

> **最后的思考**：网络状态感知能力体现了**环境感知（Context-Awareness）** 编程的核心思想。一个真正智能的系统不应该只是被动地响应用户的操作，它还应该主动感知自身所处环境的变化并做出适应性调整。这种思想在移动端开发中尤为关键——设备朝向变化、电池电量下降、网络切换、内存压力增加……每一个环境变量的变化都可能影响应用的正确行为。能够感知并适应这些变化的程序，才能在各种环境下稳定可靠地运行。这也是 **PWA（渐进式 Web 应用）** 理念的基石之一：无论网络好坏，应用都应该提供可用的体验——也许不是最好的体验，但绝不是空白页或错误提示。至此，我们的浏览器 API 与 DOM 操作系列文章全部完成。感谢阅读！
