# FormData —— 构建表单、文件上传、进度追踪

> **本文的目标**：掌握 FormData 对象的完整用法——从构建表单数据到处理多部分（multipart）编码，再到结合 [Fetch](/40.frontend/50.javascript/20.browser-api/20.网络请求与实时通信/105.Fetch%20API.md) 和 [XHR](/40.frontend/50.javascript/20.browser-api/20.网络请求与实时通信/100.XMLHttpRequest.md) 实现带进度反馈的文件上传。

## 一、从 HTML 表单到程序化构建

在 Web 的早期，表单提交是用户向服务器发送数据的唯一方式。HTML `<form>` 元素配合 `action` 属性和 `method` 属性，就能把用户的输入打包发送给后端：

```html
<!-- 传统表单提交 -->
<form action="/api/register" method="POST" enctype="multipart/form-data">
    <input type="text" name="username" value="Alarik">
    <input type="email" name="email" value="a@example.com">
    <input type="file" name="avatar">
    <button type="submit">提交</button>
</form>
```

这种方式的局限在于：**提交后整个页面会刷新或跳转**。你无法在提交前对数据进行验证，无法显示上传进度，也无法在不离开当前页面的情况下处理响应结果。

`FormData` 就是解决这个问题的工具——它让你用 JavaScript **程序化地**构建表单数据，就像在代码中动态填写一张表单一样：

```javascript
// 最基本的 FormData 构建
const formData = new FormData();

// 添加文本字段
formData.append('username', 'Alarik');
formData.append('email', 'alarik@example.com');
formData.append('bio', '一个热爱前端开发的开发者');

// 添加文件字段
const fileInput = document.querySelector('#avatar');
formData.append('avatar', fileInput.files[0]);

// 通过 fetch 发送
fetch('/api/register', {
    method: 'POST',
    body: formData   // 直接传入 FormData 对象！
})
.then(res => res.json())
.then(data => console.log('注册成功:', data));
```

### 生活类比：快递打包

FormData 就像是一个**智能快递打包服务**：

- **普通表单提交**就像你手写了一张纸条（姓名、地址），然后去邮局寄出。如果还要寄照片，你得另外装信封、贴邮票、分开投递——流程繁琐且不统一。
  
- **FormData 就像专业的快递打包员**：你告诉他要寄什么（文字信息、照片、证件），他会自动选择合适的包装材料，统一打成一个包裹，贴上正确的标签（Content-Type 和 boundary 分隔符），帮你一次性搞定所有事情。你不需要知道 `multipart/form-data` 格式的具体规范——就像你不需要知道邮政编码的编码规则一样。

## 二、FormData 的核心 API

### 创建方式

```javascript
// 方式一：创建空的 FormData 实例
const fd1 = new FormData();

// 方式二：从已有的 <form> 元素创建（自动提取所有表单字段的值）
const formEl = document.querySelector('#myForm');
const fd2 = new FormData(formEl);   // 自动收集 form 内的所有字段！

// 方式三：直接传入键值对（不常用）
const fd3 = new FormData();
fd3.set('key', 'value');
```

### 操作方法

```javascript
const fd = new FormData();

// === 添加数据 ===
fd.append('name', 'Alarik');                    // 文本值
fd.append('avatar', fileObject, 'photo.jpg');   // 文件（第三个参数为可选的文件名）
fd.append('tags[]', 'frontend');                // 可以有同名字段
fd.append('tags[]', 'javascript');

// === 获取数据 ===
fd.get('name');              // 'Alarik' （返回第一个匹配值）
fd.getAll('tags[]');         // ['frontend', 'javascript'] （返回所有匹配值的数组）
fd.has('email');             // false（检查是否存在某个key）
fd.has('name');              // true

// === 修改数据 ===
fd.set('name', 'NewName');   // 如果 key 已存在则替换，不存在则新增

// === 删除数据 ===
fd.delete('avatar');         // 移除某个字段

// === 遍历所有条目 ===
for (const [key, value] of fd.entries()) {
    console.log(key, value);
}

// === 其他遍历方式 ===
fd.keys();       // 返回 key 迭代器
fd.values();     // 返回 value 迭代器
for (const key of fd.keys()) { ... }

// === 获取条目数量 ===
Array.from(fd.entries()).length;   // FormData 没有 length 属性，需要这样转换
```

### append vs set 的关键区别

```javascript
const fd = new FormData();

fd.append('hobby', 'coding');
fd.append('hobby', 'reading');
fd.get('hobby');          // 'coding' —— 只返回第一个
fd.getAll('hobby');       // ['coding', 'reading'] —— 返回全部

// set 会覆盖已有值
fd.set('hobby', 'gaming');
fd.get('hobby');          // 'gaming'
fd.getAll('hobby');       // ['gaming'] —— 只剩这一个了
```

| 方法 | 同名 key 存在时的行为 | 适用场景 |
|------|---------------------|---------|
| `append(key, val)` | **追加**，保留原有值 | 多选框、多文件上传 |
| `set(key, val)` | **替换**，覆盖原有值 | 单值字段更新 |

## 三、multipart/form-data 格式揭秘

当你在 `fetch()` 或 `XHR` 中将 `FormData` 作为 body 发送时，浏览器会自动设置 `Content-Type: multipart/form-data` 头部并生成唯一的 boundary（边界分隔符）。了解这个格式有助于调试上传问题：

```http
--WebKitFormBoundary7MA4YWxkTrZu0gW
Content-Disposition: form-data; name="username"

Alarik
--WebKitFormBoundary7MA4YWxkTrZu0gW
Content-Disposition: form-data; name="avatar"; filename="photo.jpg"
Content-Type: image/jpeg

[二进制图片数据...]
--WebKitFormBoundary7MA4YWxkTrZu0gW--
```

每一段数据由以下结构组成：
1. `--boundary` 边界标记开始
2. `Content-Disposition` 头部描述字段名和原始文件名
3. `Content-Type`（仅文件字段需要）
4. 一个空行
5. 字段内容（文本或二进制数据）

> **重要提醒**：使用 FormData 时**不要手动设置 Content-Type 头部**。浏览器会自动添加正确的 `Content-Type` 并附带生成的 boundary。如果你手动设置了，boundary 可能丢失或不匹配，导致服务端无法正确解析表单数据。

```javascript
// ✅ 正确做法
fetch('/api/upload', { method: 'POST', body: formData });

// ❌ 错误做法 —— 不要这样做！
fetch('/api/upload', {
    method: 'POST',
    headers: { 'Content-Type': 'multipart/form-data' },  // 缺少 boundary！
    body: formData
});
```

## 四、上传进度追踪

文件上传（尤其是大文件）可能需要较长时间，给用户提供进度反馈是基本体验要求。[《XMLHttpRequest》](/40.frontend/50.javascript/20.browser-api/20.网络请求与实时通信/100.XMLHttpRequest.md) 提供了原生的 `upload.onprogress` 事件来监听上传进度，这是 Fetch API 目前尚不具备的能力：

```javascript
/**
 * 带进度的文件上传函数
 * @param {File} file - 要上传的文件对象
 * @param {string} url - 上传接口地址
 * @param {Object} [extraData] - 额外的表单字段
 * @param {Function} onProgress - 进度回调 (percent: number) => void
 */
function uploadWithProgress(file, url, extraData = {}, onProgress) {
    return new Promise((resolve, reject) => {
        const xhr = new XMLHttpRequest();

        const formData = new FormData();
        formData.append('file', file);

        // 添加额外字段
        Object.entries(extraData).forEach(([key, value]) => {
            formData.append(key, value);
        });

        // 监听上传进度
        xhr.upload.onprogress = function(event) {
            if (event.lengthComputable && onProgress) {
                const percent = Math.round((event.loaded / event.total) * 100);
                onProgress({
                    percent,
                    loaded: event.loaded,
                    total: event.total,
                    formattedLoaded: formatBytes(event.loaded),
                    formattedTotal: formatBytes(event.total)
                });
            }
        };

        xhr.onload = function() {
            if (xhr.status >= 200 && xhr.status < 300) {
                try {
                    resolve(JSON.parse(xhr.responseText));
                } catch {
                    resolve(xhr.responseText);
                }
            } else {
                reject(new Error(`上传失败: HTTP ${xhr.status}`));
            }
        };

        xhr.onerror = () => reject(new Error('网络错误'));
        xhr.ontimeout = () => reject(new Error('上传超时'));
        xhr.timeout = 120000;  // 2分钟超时

        xhr.open('POST', url);
        xhr.send(formData);
    });
}

// 辅助：格式化字节大小
function formatBytes(bytes) {
    if (!bytes || bytes === 0) return '0 B';
    const k = 1024;
    const sizes = ['B', 'KB', 'MB', 'GB'];
    const i = Math.floor(Math.log(bytes) / Math.log(k));
    return parseFloat((bytes / k ** i).toFixed(2)) + sizes[i];
}

// ===== 使用示例 =====
const fileInput = document.querySelector('#file-input');
const progressBar = document.querySelector('.progress-bar');
const progressText = document.querySelector('.progress-text');

document.querySelector('#upload-btn').addEventListener('click', async () => {
    const file = fileInput.files[0];
    if (!file) return alert('请先选择文件');

    try {
        const result = await uploadWithProgress(
            file,
            '/api/files/upload',
            { description: '用户头像', category: 'image' },
            ({ percent, formattedLoaded, formattedTotal }) => {
                // 更新进度条 UI
                progressBar.style.width = `${percent}%`;
                progressText.textContent = `${formattedLoaded} / ${formattedTotal} (${percent}%)`;
            }
        );

        console.log('上传成功:', result.url);
        showSuccess(`上传完成！文件地址: ${result.url}`);
    } catch (err) {
        showError(err.message);
    });
});
```
