# 下载文件 —— blob 与 URL.createObjectURL、a 标签的 download 属性

> **本文的目标**：掌握浏览器端文件下载的完整方案——从最简单的 `<a>` 标签下载，到通过 Fetch/XHR 获取数据后使用 Blob + createObjectURL 实现动态下载，再到大文件的流式处理和下载状态管理。

## 一、浏览器下载的本质

"下载"这个动作在 Web 中有两种截然不同的实现路径：

**第一种：服务端触发下载**——用户点击链接，浏览器直接从服务器获取文件并保存到本地。这是最传统也最简单的方式：

```html
<!-- 方式一：直接链接（适用于同源静态资源） -->
<a href="/files/report.pdf" download>下载报告</a>

<!-- 方式二：download 属性指定文件名 -->
<a href="/files/generated-report-2024-Q4-final-v2.pdf" download="季度报告.pdf">
    下载报告
</a>
```

`download` 属性告诉浏览器：不要尝试导航到或显示这个链接指向的资源，而是把它当作一个文件下载下来。它还可以覆盖原始的文件名，让用户看到更友好的名称。

但这种方式有明显的局限：**无法携带自定义请求头、无法处理需要认证的接口返回、无法显示下载进度、无法处理动态生成的文件内容**。

**第二种：客户端生成下载**——先通过 JavaScript 获取文件数据（来自 API 或程序化生成），然后在浏览器内存中创建一个临时文件对象，触发浏览器的保存对话框：

```javascript
// 这就是本文要深入探讨的方式
const response = await fetch('/api/export/data');
const blob = await response.blob();
const url = URL.createObjectURL(blob);
// ... 触发下载 ...
```

### 生活类比：两种购物方式

- **直接链接下载就像去超市买成品**：商品已经包装好放在货架上，你拿起来就能走。快速方便，但你只能选择已有的商品。
  
- **JavaScript 动态下载就像去裁缝店定做**：你描述需求（发起请求），店家根据你的要求现场制作（服务器生成内容），做好后打包交给你（Blob），然后你带回家（触发下载）。过程更复杂，但你可以得到完全定制化的产品——而且可以实时跟踪制作进度。

## 二、Blob 与 Object URL：内存中的虚拟文件

### Blob 对象

**Blob (Binary Large Object)** 是浏览器中用于表示二进制大数据的对象类型。它是 `File` 的父类，所有 File 对象本质上都是带有额外元信息（文件名、修改时间）的 Blob。

```javascript
// 创建 Blob 的几种方式

// 方式一：构造函数 —— 从字符串/TypedArray 创建
const textBlob = new Blob(['Hello, World!'], { type: 'text/plain' });
console.log(textBlob.size);   // 13 （字节数）
console.log(textBlob.type);   // 'text/plain'

// 创建 JSON Blob
const jsonData = { users: [{ name: 'Alarik', age: 25 }] };
const jsonBlob = new Blob([JSON.stringify(jsonData)], {
    type: 'application/json'
});

// 方式二：从 Response 获取 —— 最常见的场景
fetch('/api/reports/monthly')
    .then(res => res.blob())
    .then(blob => {
        console.log('文件大小:', formatSize(blob.size));
        console.log('MIME类型:', blob.type);
        triggerDownload(blob, '月度报告.xlsx');
    });

// 方式三：从 Canvas 截图
canvas.toBlob((blob) => {
    triggerDownload(blob, 'screenshot.png');
}, 'image/png');

function formatSize(bytes) {
    if (!bytes) return '0 B';
    const k = 1024;
    const units = ['B', 'KB', 'MB', 'GB'];
    const i = Math.floor(Math.log(Math.max(1, bytes)) / Math.log(k));
    return (bytes / Math.pow(k, i)).toFixed(i === 0 ? 0 : 1) + units[i];
}
```

### URL.createObjectURL()：创建临时引用

Blob 存在于 JavaScript 的内存空间中——它不是一个真正的文件，没有文件系统中的路径。为了让 `<a>` 标签或其他 DOM 元素能引用它，我们需要用 `URL.createObjectURL()` 为它创建一个临时的 **Object URL**：

```javascript
const blob = new Blob(['Hello World'], { type: 'text/plain' });
const objectUrl = URL.createObjectURL(blob);

console.log(objectUrl);
// → "blob:https://example.com/a29e-4f8c-9b1d-2a3c"
//
// 这个 URL 的含义：
// blob:        ← 协议名，表示这是一个 Blob 引用
// https://example.com  ← 产生此 URL 的页面源（用于安全隔离）
// a29e-4f8c-...       ← 浏览器内部生成的唯一标识符

// 现在可以用这个 URL 了：
const link = document.createElement('a');
link.href = objectUrl;
link.download = 'hello.txt';
link.click();   // 触发下载！

// 重要：用完后释放内存！
URL.revokeObjectURL(objectUrl);
```

Object URL 的生命周期规则：

| 行为 | 效果 |
|------|------|
| 页面未关闭 | URL 持续有效 |
| 关闭标签页 | URL 自动失效 |
| 手动调用 `revokeObjectURL(url)` | 立即失效并释放内存 |
| 内存压力 | 浏览器可能自动回收 |

```javascript
// 安全的使用模式：创建 → 使用 → 释放
async function safeDownload(url, filename) {
    const response = await fetch(url);

    if (!response.ok) throw new Error(`下载失败: HTTP ${response.status}`);

    const blob = await response.blob();
    const tempUrl = URL.createObjectURL(blob);

    try {
        const a = document.createElement('a');
        a.href = tempUrl;
        a.download = filename || 'download';
        document.body.appendChild(a);   // 必须加入DOM才能在某些浏览器中工作
        a.click();

        // 给一点延迟确保下载已触发再清理
        setTimeout(() => {
            a.remove();
            URL.revokeObjectURL(tempUrl);   // 释放内存！
        }, 100);
    } catch (err) {
        URL.revokeObjectURL(tempUrl);   // 出错也要释放！
        throw err;
    }
}
```

## 三、完整的下载工具函数

下面封装一个支持多种场景的通用下载函数：

```javascript
/**
 * downloadFile —— 通用文件下载函数
 *
 * 支持特性：
 * - 自动检测 Content-Type 并推断扩展名
 * - 显示下载进度（基于 XHR）
 * - 处理中文文件名的编码问题
 * - 支持 JSON 数据导出为文件
 */
async function downloadFile(source, options = {}) {
    const {
        filename,           // 指定的文件名
        method = 'GET',
        body,
        headers,
        onProgress,
        timeout = 120000
    } = options;

    let blob;

    if (typeof source === 'string' && source.startsWith('{')) {
        // 直接传入的是字符串数据（如JSON）
        const contentType = options.contentType || 'application/json';
        blob = new Blob([source], { type: contentType });
    } else if (source instanceof Blob) {
        // 已经是 Blob 对象
        blob = source;
    } else if (onProgress) {
        // 需要进度追踪时使用 XHR
        blob = await downloadWithProgress(source, method, body, headers, onProgress, timeout);
    } else {
        // 使用 Fetch（简洁但无进度）
        const res = await fetch(source, {
            method,
            headers,
            body: body ? JSON.stringify(body) : undefined
        });

        if (!res.ok) {
            const errorText = await res.text().catch(() => '');
            throw new Error(`下载失败 (${res.status}): ${errorText}`);
        }

        blob = await res.blob();
    }

    // 推断 MIME 类型对应的扩展名（如果 filename 没有后缀）
    const finalName = inferFileName(filename, blob.type, res?.headers);

    // 触发浏览器下载
    triggerBrowserDownload(blob, finalName);
}

/**
 * 使用 XHR 实现带进度的下载
 */
function downloadWithProgress(url, method, body, headers, onProgress, timeout) {
    return new Promise((resolve, reject) => {
        const xhr = new XMLHttpRequest();
        xhr.open(method, url);

        if (headers) {
            Object.entries(headers).forEach(([k, v]) => xhr.setRequestHeader(k, v));
        }

        xhr.timeout = timeout;

        // 监听下载进度
        xhr.onprogress = (event) => {
            if (event.lengthComputable && onProgress) {
                onProgress({
                    loaded: event.loaded,
                    total: event.total,
                    percent: Math.round((event.loaded / event.total) * 100)
                });
            }
        };

        xhr.onload = () => {
            if (xhr.status >= 200 && xhr.status < 300) {
                resolve(xhr.response);   // responseType 默认为 ''，即 blob
            } else {
                reject(new Error(`HTTP ${xhr.status}`));
            }
        };

        xhr.onerror = () => reject(new Error('网络错误'));
        xhr.ontimeout = () => reject(new Error('下载超时'));

        xhr.responseType = 'blob';
        xhr.send(body ? JSON.stringify(body) : null);
    });
}

/**
 * 推断合适的文件名
 */
function inferFileName(providedName, mimeType, responseHeaders) {
    if (providedName) return providedName;

    // 尝试从 Content-Disposition 头部提取文件名
    // 服务端通常设置: Content-Disposition: attachment; filename="report.xlsx"
    const extMap = {
        'application/pdf': '.pdf',
        'application/vnd.ms-excel': '.xls',
        'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet': '.xlsx',
        'application/msword': '.doc',
        'application/vnd.openxmlformats-officedocument.wordprocessingml.document': '.docx',
        'application/zip': '.zip',
        'image/png': '.png',
        'image/jpeg': '.jpg',
        'text/csv': '.csv',
        'application/json': '.json'
    };

    const ext = extMap[mimeType] || '';
    return `download_${Date.now()}${ext}`;
}

/**
 * 触发浏览器的文件保存对话框
 */
function triggerBrowserDownload(blob, filename) {
    // 兼容性检查：IE 使用 msSaveOrOpenBlob
    if (navigator.msSaveOrOpenBlob) {
        navigator.msSaveOrOpenBlob(blob, filename);
        return;
    }

    const url = URL.createObjectURL(blob);
    const anchor = document.createElement('a');
    anchor.style.display = 'none';
    anchor.href = url;

    // 处理中文文件名编码
    anchor.download = encodeURIComponent(filename);

    document.body.appendChild(anchor);
    anchor.click();

    // 清理
    setTimeout(() => {
        document.body.removeChild(anchor);
        URL.revokeObjectURL(url);
    }, 200);
}

// ===== 使用示例 =====

// 示例1：简单的 GET 下载
downloadFile('/api/export/orders?format=csv&date=2026-04', {
    filename: '订单报表_202604.csv'
}).then(() => console.log('下载完成'))
  .catch(err => showError(err.message));

// 示例2：带进度的 POST 下载（导出大量数据）
downloadFile('/api/export/full-database', {
    method: 'POST',
    body: { tables: ['users', 'orders', 'products'] },
    headers: { 'Authorization': 'Bearer token123' },
    filename: '数据库备份.zip',
    onProgress(info) {
        updateDownloadUI(info);
        console.log(`${info.percent}% (${formatSize(info.loaded)} / ${formatSize(info.total)})`);
    }
});
```

## 四、常见问题与解决方案

### 中文文件名乱码问题

当服务端通过 `Content-Disposition` 头部传递包含中文的文件名时，容易出现乱码：

```http
# 服务端响应头（可能有编码问题）
Content-Disposition: attachment; filename="季度报告_2026Q1.xlsx"

# 正确做法：使用 RFC 5987 编码格式
Content-Disposition: attachment; filename*=UTF-8''%E5%AD%A3%E5%BA%A6%E6%8A%A5%E5%91%8A_2026Q1.xlsx
```

前端解码处理：

```javascript
// 解析 Content-Disposition 中的 filename*
function parseContentDisposition(contentDisposition) {
    if (!contentDisposition) return null;

    // 尝试匹配 filename* (RFC 5987)
    const encodedMatch = contentDisposition.match(/filename\*=(?:UTF-8''|utf-8'')(.+?)(?:;|$)/i);
    if (encodedMatch) {
        return decodeURIComponent(encodedMatch[1]);
    }

    // 回退到普通 filename
    const normalMatch = contentDisposition.match(/filename="?([^";]+)"?/i);
    return normalMatch ? normalMatch[1] : null;
}

// 在 fetch 中提取
const res = await fetch('/api/download/file');
const cd = res.headers.get('Content-Disposition');
const serverFilename = parseContentDisposition(cd);
console.log(serverFilename);   // "季度报告_2026Q1.xlsx"
```

### 大文件下载与内存限制

对于超大文件（数百 MB 到 GB 级别），将整个文件加载到 Blob 中可能会耗尽浏览器内存。此时可以考虑：

```javascript
// 方案1：使用 StreamSaver.js 库（推荐用于超大文件）
// 它利用 Service Worker 将流式数据直接写入磁盘

// 方案2：直接使用 <a> 标签 + 认证 Token
// 对于只需要简单下载的场景
function directDownloadWithAuth(url, token) {
    const link = document.createElement('a');
    link.href = `${url}?token=${token}`;
    link.download = '';   // 让服务端的 Content-Disposition 决定文件名
    link.click();
}

// 方案3：分片下载（类似上传的分片思路）
async function chunkedDownload(url, chunkSize = 10 * 1024 * 1024) {
    const headRes = await fetch(url, { method: 'HEAD' });
    const totalSize = parseInt(headRes.headers.get('Content-Length'), 10);

    const chunks = [];
    for (let start = 0; start < totalSize; start += chunkSize) {
        const end = Math.min(start + chunkSize - 1, totalSize - 1);
        const res = await fetch(url, {
            headers: { Range: `bytes=${start}-${end}` }
        });
        chunks.push(await res.arrayBuffer());
    }

    return new Blob(chunks);
}
```

> **哲学思考**：浏览器中的"文件"是一个有趣的概念——它既存在又不存在。Blob 是一段存在于内存中的二进制数据，它不是硬盘上的文件，但通过 `createObjectURL()` 这个魔法般的转换，它获得了类似文件的身份：可以被 `<a>` 标签引用、可以被下载、可以被赋予文件名。这种"虚拟实体"的设计模式在现代计算中无处不在：Docker 容器是轻量级的虚拟机、Symbol 是 JavaScript 中不可变的基本类型的包装、Promise 是尚未到达的未来值的占位符。它们都是同一个思想的不同表达——**用一个轻量级的代理来代表一个重量级的真实事物**，让你能在不承担全部成本的情况下获得大部分能力。Blob 就是文件世界里的 Symbol——它看起来像文件，行为像文件，但它比真实的文件轻盈得多。
