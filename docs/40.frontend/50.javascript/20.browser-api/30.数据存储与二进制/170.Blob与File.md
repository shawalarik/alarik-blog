# Blob 与 File —— 构造函数、slice、FileReader、转换为 DataURL/ArrayBuffer

Blob（Binary Large Object）是浏览器中表示**不可变的二进制原始数据**的对象类型。它是 [File](https://developer.mozilla.org/zh-CN/docs/Web/API/File) 的父类，几乎所有文件相关的操作最终都会追溯到这个基础类型。理解 Blob 是掌握文件上传、下载、图片处理、Canvas 截图等技术的起点。

## 一、"内存中的虚拟文件"

Blob 的本质是一段被包装起来的二进制数据。它不是磁盘上的文件（没有路径），不是字符串（不能直接当作字符内容读），但它可以代表任何类型的文件——图片、音频、PDF、压缩包……

```javascript
// 创建 Blob 的基本方式
const blob1 = new Blob(['Hello World']);          // 从字符串创建
const blob2 = new Blob(['<p>Hello</p>'], { type: 'text/html' });  // 指定 MIME 类型
const blob3 = new Blob([JSON.stringify({ a: 1 })], { type: 'application/json' });

console.log(blob1.size);     // 11 （字节数）
console.log(blob1.type);     // ''  （空字符串，默认无类型）
console.log(blob2.type);     // 'text/html'
console.log(blob3.type);     // 'application/json'
```

### 生活类比：密封的信封

Blob 就像一个**密封的信封**：
- 信封里面装着东西（二进制数据），你不需要知道具体是什么编码格式
- 信封外面贴了标签写着内容类型（MIME type），告诉你里面大概是哪类东西
- 信封上印了重量（size），告诉你里面有多少字节
- 信封一旦封口就不能修改（immutable）——想改只能拆了重做一个新的

这和 JavaScript 中的 `String` 很相似——字符串也是不可变的，任何"修改"操作实际上都是创建了新字符串。Blob 的不可变性保证了数据的安全性：你把一个 Blob 传给某个函数，不用担心它会在背地里篡改内部内容。

## 二、构造方法详解

`new Blob(parts, options)` 接受两个参数：

```javascript
// parts 参数可以是以下类型的数组元素：
const b1 = new Blob(['纯字符串']);
const b2 = new Blob([anotherBlob]);         // 另一个 Blob
const b3 = new Blob([typedArray]);          // TypedArray（如 Uint8Array）
const b4 = new Blob([arrayBuffer]);         // ArrayBuffer
const b5 = new Blob([blob1, blob2, '拼接']); // 多个部分组合在一起！

// 组合示例：构建一个多部分的复合 Blob
const header = new Blob(['--HEADER--\n']);
const body = new Blob([JSON.stringify({ name: 'test' })]);
const footer = new Blob(['\n--FOOTER--']);

const combined = new Blob([header, body, footer], { type: 'multipart/data' });
console.log(combined.size);   // 总字节数

// options 参数
const blob = new Blob(['content'], {
    type: 'application/json',   // MIME 类型（浏览器用来判断如何处理这个Blob）
    endings: 'native'            // 行尾处理：'native'(系统默认) 或 'transparent'(保持原样)
});
```

### MIME 类型一览

MIME 类型告诉浏览器这个 Blob 里装的是什么东西：

| MIME 类型 | 含义 | 常见用途 |
|-----------|------|---------|
| `text/plain` | 纯字符内容 | 日志文件、配置文件 |
| `text/html` | HTML 内容 | 动态生成网页片段 |
| `text/css` | 样式表 | 动态样式 |
| `application/json` | JSON 数据 | API 响应、配置 |
| `application/pdf` | PDF 文档 | 报告生成 |
| `image/png` | PNG 图片 | Canvas 导出 |
| `image/jpeg` | JPEG 图片 | 图片压缩处理 |
| `image/svg+xml` | SVG 矢量图 | 动态图形生成 |
| `audio/mpeg` | MP3 音频 | 音频处理 |
| `video/mp4` | MP4 视频 | 视频截取 |

```javascript
// 实际应用：动态生成文件供下载
function generateReportCSV(data) {
    const header = '姓名,年龄,城市\n';
    const rows = data.map(u => `${u.name},${u.age},${u.city}`).join('\n');
    const csvContent = header + rows;

    const blob = new Blob([csvContent], { type: 'text/csv;charset=utf-8;' });
    
    // 触发下载（配合 URL.createObjectURL 使用）
    const url = URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url;
    a.download = '用户报表.csv';
    a.click();
    URL.revokeObjectURL(url);
}

generateReportCSV([
    { name: 'Alarik', age: 25, city: 'Beijing' },
    { name: 'Bob', age: 30, city: 'Shanghai' }
]);
```

## 三、slice() 方法：切割大块数据

Blob.prototype.slice(start, end, contentType) 可以从现有 Blob 中截取出一段子 Blob——就像 Array.prototype.slice() 对数组做的那样：

```javascript
const bigBlob = new Blob(['Hello World This Is A Big Blob Content']);

// 切割出前5个字节
const part1 = bigBlob.slice(0, 5);
console.log(await part1.text());   // 'Hello'

// 切割中间一段
const part2 = bigBlob.slice(6, 11);
console.log(await part2.text());   // 'World'

// 切割时指定不同的 MIME 类型
const jsonPart = bigBlob.slice(0, bigBlob.size, 'application/json');

// slice 不会修改原始 Blob（不可变性！）
console.log(bigBlob.size);   // 不变
```

### 分片上传的核心应用

`slice()` 在[分片上传](/40.frontend/50.javascript/20.browser-api/20.网络请求与实时通信/145.文件上传进阶.md)中扮演关键角色：

```javascript
/**
 * 将大文件分割为固定大小的分片
 * @param {File} file - 原始文件
 * @param {number} chunkSize - 每片大小（字节）
 */
function* createChunks(file, chunkSize = 2 * 1024 * 1024) {
    let offset = 0;

    while (offset < file.size) {
        const chunk = file.slice(offset, offset + chunkSize);

        yield {
            index: Math.floor(offset / chunkSize),
            blob: chunk,
            start: offset,
            end: Math.min(offset + chunkSize, file.size),
            total: file.size
        };

        offset += chunkSize;
    }

    console.log(`文件 ${file.name} 共切分为 ${Math.ceil(file.size / chunkSize)} 个分片`);
}

// 使用示例：将一个 10MB 的文件切成 5 个 2MB 的分片
const file = input.files[0];
for (const chunk of createChunks(file, 2 * 1024 * 1024)) {
    console.log(`分片 #${chunk.index}: ${chunk.start}-${chunk.end} (${chunk.blob.size} bytes)`);
    await uploadChunk(chunk);   // 上传每个分片
}
```

## 四、File 对象：带身份信息的 Blob

File 继承自 Blob，并额外携带了文件的元信息属性。当用户通过 `<input type="file">` 选择文件后，得到的 `fileList` 中的每一项就是一个 File 对象：

```javascript
<input type="file" id="fileInput" multiple accept="image/*">

<script>
document.querySelector('#fileInput').addEventListener('change', (e) => {
    for (const file of e.target.files) {
        // File 继承了 Blob 的所有属性和方法
        console.log('--- File 对象 ---');
        console.log('name:', file.name);           // "photo.jpg" —— 文件名
        console.log('size:', file.size);           // 2456789       —— 字节大小
        console.log('type:', file.type);           // "image/jpeg"  —— MIME类型
        console.log('lastModified:', file.lastModified); // 1713845200000 —— 时间戳
        console.log('lastModifiedDate:', new Date(file.lastModified)); // Date对象
        console.log('webkitRelativePath:', file.webkitRelativePath); // ""或相对路径(webkitdirectory)

        // File 可以使用 Blob 的所有能力
        file.slice(0, 1024).arrayBuffer().then(buf => {
            console.log('前1024字节:', buf);
        });
        
        // 也可以直接用 FileReader 读取完整内容
        const reader = new FileReader();
        reader.onload = () => {
            console.log('DataURL长度:', reader.result.length);
            imgPreview.src = reader.result;   // 直接赋值给 <img src>
        };
        reader.readAsDataURL(file);
    }
});
</script>
```

### Blob vs File 的关系

```
                    EventTarget
                         │
                       Blob  ←  不可变的原始二进制数据
                     ╱      ╲
                (直接创建)   (File)
                            ├── name: string       ← 文件名
                            ├── lastModified: number ← 修改时间戳
                            └── type: string        ← MIME类型
```

File 就是"有身份证的 Blob"。它多出来的三个属性都是**只读的元信息**，不参与数据本身的内容。你可以把 File 当作 Blob 用在任何需要 Blob 的地方（比如 fetch body、URL.createObjectURL 等）。

## 五、FileReader：读取 Blob/File 内容的工具

Blob 和 File 本身只是数据的容器，它们并不提供直接访问内部字节的方法。要读取里面的内容，需要借助 **FileReader**：

```javascript
const reader = new FileReader();

// ===== 六种读取方法 =====

// 1. readAsArrayBuffer(blob/file) → ArrayBuffer（原始二进制）
reader.onload = (e) => {
    const buffer = e.target.result;   // ArrayBuffer
    console.log('字节数:', buffer.byteLength);
};
reader.readAsArrayBuffer(someBlob);

// 2. readAsDataURL(blob/file) → Base64 编码的 Data URL
reader.onload = (e) => {
    const dataUrl = e.target.result;
    // 格式: "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA..."
    console.log(dataUrl.substring(0, 50) + '...');
    document.querySelector('#preview').src = dataUrl;   // 可直接用于img src
};
reader.readAsDataURL(imageFile);

// 3. readAsText(blob/file, encoding?) → 字符串内容
reader.onload = (e) => {
    const content = e.target.result;   // String
    console.log(content);              // 直接可读的字符内容
};
reader.readAsText(jsonFile, 'UTF-8');

// 4. readAsBinaryString(blob/file) → 二进制字符串（每个字符代表一个字节）
// ⚠️ 已废弃！建议使用 readAsArrayBuffer 替代

// ===== 事件监听 =====
const reader2 = new FileReader();
reader2.onloadstart = () => console.log('开始读取...');
reader2.onprogress = (e) => {
    if (e.lengthComputable) {
        const pct = Math.round(e.loaded / e.total * 100);
        console.log(`读取进度: ${pct}%`);
    }
};
reader2.onload = (e) => console.log('读取完成!', e.target.result);
reader2.onerror = (e) => console.error('读取出错:', e.target.error);
reader2.onabort = () => console.warn('读取被中断');

reader2.readAsText(largeFile);
```

### FileReader vs Blob 自身方法

现代浏览器中 Blob/File 对象自身也提供了便捷的读取方法（返回 Promise，比 FileReader 更简洁）：

```javascript
const myBlob = new Blob(['{"hello":"world"}'], { type: 'application/json' });

// 方式一：Blob 自身方法（推荐，基于 Promise）
const str = await myBlob.text();           // → '{"hello":"world"}'
const buffer = await myBlob.arrayBuffer(); // → ArrayBuffer
const stream = myBlob.stream();            // → ReadableStream（流式读取）

// 方式二：FileReader（兼容旧浏览器，基于回调）
const str2 = await new Promise((resolve, reject) => {
    const fr = new FileReader();
    fr.onload = () => resolve(fr.result);
    fr.onerror = reject;
    fr.readAsText(myBlob);
});

// 推荐优先使用方式一，代码更简洁
```

### DataURL 的原理与应用

`readAsDataURL()` 生成的 Data URL 是一种将小型文件内嵌到文档中的方案：

```javascript
// Data URL 的结构分解
data:[<MIME-type>][;base64],<data>

// 示例解析：
data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJ...
│     │          │     │
│     │          │     └─ Base64 编码的实际像素数据
│     │          └─ 表示数据经过 Base64 编码
│     └─ MIME 类型：这是一张 PNG 图片
└─ Data URL 协议标识符

// 应用1：图片预览（无需上传即可本地预览）
function previewImage(file) {
    return new Promise((resolve) => {
        const reader = new FileReader();
        reader.onload = (e) => resolve(e.target.result);  // 返回 data URL
        reader.readAsDataURL(file);
    });
}
previewImage(selectedFile).then(url => img.src = url);

// 应用2：生成带嵌入图片的 HTML（单文件分享）
async function generateStandaloneHTML(imageFiles) {
    let html = '<html><body>';
    for (const file of imageFiles) {
        const dataUrl = await new Promise(r => {
            const fr = new FileReader(); fr.onload = e => r(e.target.result);
            fr.readAsDataURL(file);
        });
        html += `<img src="${dataUrl}" style="max-width:400px"><br>`;
    }
    html += '</body></html>';

    // 整个HTML包含所有图片数据，可以直接保存为一个.html文件分享
    return html;
}

// 注意：DataURL 会使数据体积增大约33%（Base64编码开销）
// 只适合小文件（几十KB以内）。大文件应使用 URL.createObjectURL()
```
