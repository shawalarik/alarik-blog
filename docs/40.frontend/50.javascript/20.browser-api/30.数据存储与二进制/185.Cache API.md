# Cache API —— Service Worker 配合使用、缓存管理

Cache API 是浏览器提供的一套**请求/响应对的存储机制**，专为 [Service Worker](https://developer.mozilla.org/zh-CN/docs/Web/API/Service_Worker_API) 而设计。它与 HTTP 缓存、[localStorage](/40.frontend/50.javascript/20.browser-api/30.数据存储与二进制/195.localStoragesessionStorage.md)、以及 [IndexedDB](/40.frontend/50.javascript/20.browser-api/30.数据存储与二进制/160.IndexedDB.md) 各有分工，共同构成了前端数据持久化的完整图景。

## 一、Cache API 的定位

在深入了解之前，先搞清楚 Cache API 在整个存储生态中的位置：

| 存储方案 | 存储内容 | 典型用途 | 生命周期 |
|---------|---------|---------|---------|
| **HTTP 缓存** | 请求响应 | 静态资源自动缓存 | 由头部控制 |
| **Cache API** | Request/Response 对 | Service Worker 离线缓存 | 手动管理 |
| **localStorage** | 字符串键值对 | 用户偏好设置 | 除非手动清除否则永久 |
| **sessionStorage** | 字符串键值对 | 临时会话数据 | 关闭标签页即清除 |
| **IndexedDB** | 结构化对象 | 大量离线数据 | 除非手动清除否则永久 |

Cache API 的独特之处在于：**它存储的是完整的 HTTP Request 和 Response 对象**。这意味着你不只是保存了数据本身，还保存了请求的所有上下文（URL、方法、头部）和响应的所有元信息（状态码、头部）。这让它在实现离线访问、资源预缓存等场景中无可替代。

### 生活类比：快递代收点

- **HTTP 缓存就像小区门卫的临时放行记录**："这个快递员昨天来过，他的东西可以直接进"。规则由物业管理处统一制定，住户不能干预。

- **localStorage 就像家里的抽屉**——你往里面放什么、什么时候取出来，完全自己决定。但抽屉容量有限，而且只能放扁平的小件物品（字符串）。

- **IndexedDB 就像自家仓库**——大得多，还能按类别分区存放结构化物品。适合长期囤货。

- **Cache API 就像小区门口的快递代收柜**——专门用来存放"从外面寄来的包裹"（HTTP 响应）。每个柜子对应一个特定的寄件人地址（Request URL），里面放着完整的包裹（Response）。你可以提前把常用包裹放进柜子（预缓存），也可以在收到新包裹时顺便存一份。下次需要时直接从柜子拿，不用再等快递员。

## 二、基础操作：打开、读写、删除

Cache API 的所有操作都是异步的，基于 Promise：

```javascript
// ===== 打开/创建缓存 =====
// caches 是全局对象（只在 HTTPS 或 localhost 下可用）
const cache = await caches.open('my-cache-v1');
// 参数是缓存名称（versioned name 是推荐实践）

// ===== 存入缓存（put）=====
// put(request, response) —— 存储一对请求/响应

// 方式1：直接传入 Response 对象
await cache.put('/api/data', new Response(JSON.stringify({ a: 1 }), {
    headers: { 'Content-Type': 'application/json' }
}));

// 方式2：先 fetch 再缓存（最常见的模式）
async function cacheAndFetch(url) {
    const cache = await caches.open('dynamic-v1');
    
    // 先尝试从缓存获取
    const cachedResponse = await cache.match(url);
    if (cachedResponse) {
        return cachedResponse;   // 命中缓存，直接返回
    }
    
    // 缓存未命中，发起网络请求
    const response = await fetch(url);
    
    // 只缓存成功的响应
    if (response.ok) {
        // 注意：response 是流式的（只能消费一次），
        // 必须克隆后才能同时使用和缓存
        const clone = response.clone();
        await cache.put(url, clone);
    }
    
    return response;
}

// ===== 读取缓存（match）=====
const response = await cache.match('/api/data');
if (response) {
    const data = await response.json();
    console.log(data);   // { a: 1 }
} else {
    console.log('缓存未命中');
}

// match 也支持 Request 对象作为参数
await cache.match(new Request('/api/data', { method: 'GET' }));

// matchOptions 可以精确控制匹配行为
const options = {
    ignoreSearch: true,    // 忽略 URL 中的查询参数
    ignoreMethod: true,    // 忽略请求方法（默认只匹配 GET）
    ignoreVary: true,      // 忽略 Vary 头部
    cacheName: 'v1',       // 指定搜索哪个命名缓存
};

await cache.match('/api/data?page=1', { ignoreSearch: true });
// 能匹配到 '/api/data' 或 '/api/data?any=thing'

// ===== 删除缓存项 =====
const deleted = await cache.delete('/api/data');
console.log(deleted ? '删除成功' : '该项不存在');

// ===== 获取所有缓存的 keys =====
const keys = await cache.keys();
for (const request of keys) {
    console.log(request.url);   // 所有已缓存请求的 URL
}
```

## 三、缓存策略模式

Cache API 最强大的地方在于它可以和 `fetch()` 组合出各种灵活的缓存策略。以下是 PWA（Progressive Web App）开发中最常用的几种模式：

### 模式1：Cache First（缓存优先）

```javascript
// 优先使用缓存，缓存不存在时才请求网络
// 适用场景：静态资源（CSS、JS、字体、图片）
async function cacheFirst(request) {
    const cache = await caches.open('static-v1');
    const cached = await cache.match(request);
    
    if (cached) return cached;   // 🎯 缓存命中
    
    // 缓存未命中，走网络
    try {
        const response = await fetch(request);
        if (response.ok) {
            await cache.put(request, response.clone());   // 存入缓存
        }
        return response;
    } catch (error) {
        // 网络也不可用 → 返回离线回退页面
        return caches.match('/offline.html');
    }
}
```

### 模式2：Network First（网络优先）

```javascript
// 优先请求网络，失败时降级到缓存
// 适用场景：API 数据、需要实时性的内容
async function networkFirst(request) {
    const cache = await caches.open('api-data-v1');
    
    try {
        const response = await fetch(request);
        if (response.ok) {
            await cache.put(request.response.clone());
        }
        return response;
        
    } catch (error) {
        // 网络失败 → 尝试缓存
        const cached = await cache.match(request);
        if (cached) return cached;   // 有旧数据就先用着
        
        // 连缓存都没有 → 返回兜底响应
        return new Response(
            JSON.stringify({ error: 'offline', message: '暂无网络连接' }),
            { status: 503, headers: { 'Content-Type': 'application/json' } }
        );
    }
}
```

### 模式3：Stale While Revalidate（后台更新）

```javascript
// 立即返回缓存（即使是旧的），同时在后台请求网络更新缓存
// 最佳的用户体验：快速响应 + 后台保持新鲜
// 适用场景：用户头像、新闻列表、社交媒体时间线
async function staleWhileRevalidate(request) {
    const cache = await caches.open('swr-v1');
    const cached = await cache.match(request);
    
    // 无论缓存是否存在，都在后台发起网络请求更新
    const fetchPromise = fetch(request).then(async (response) => {
        if (response.ok) {
            await cache.put(request, response.clone());
        }
        return response;
    }).catch(() => {});   // 网络失败不影响当前响应

    // 有缓存就直接返回（可能是旧数据）
    if (cached) return cached;
    
    // 没有缓存则等待网络响应
    return fetchPromise;
}
```

### 模式4：Cache Only / Network Only

```javascript
// 纯缓存 —— 完全不走网络（适用于预缓存资源）
async function cacheOnly(request) {
    return (await caches.open('precache-v1')).match(request)
        || new Response('', { status: 404 });
}

// 纯网络 —— 不使用任何缓存
async function networkOnly(request) {
    return fetch(request);
}
```

## 四、缓存管理与清理

随着应用版本迭代，旧的缓存如果不及时清理会占用大量存储空间并可能导致用户看到过期内容：

```javascript
class CacheManager {
    constructor(prefix = 'app') {
        this.prefix = prefix;
    }

    // 获取当前版本号对应的缓存名
    getVersionedName(version) {
        return `${this.prefix}-v${version}`;
    }

    // 版本升级时清除旧缓存
    async migrate(oldVersion, newVersion) {
        const oldName = this.getVersionedName(oldVersion);
        const newName = this.getVersionedName(newVersion);

        // 删除旧版本缓存
        const deleted = await caches.delete(oldName);
        console.log(`已清除旧版缓存: ${oldName}`, deleted ? '✅' : '❌不存在');

        // 创建新版缓存（可选：预热核心资源）
        const cache = await caches.open(newName);
        console.log(`新版缓存已创建: ${newName}`);
        
        return cache;
    }

    // 预缓存关键资源（install 阶段调用）
    async precache(urls, version = '1') {
        const cache = await caches.open(this.getVersionedName(version));
        const results = await Promise.allSettled(
            urls.map(url => cache.add(url))
        );
        
        const succeeded = results.filter(r => r.status === 'fulfilled').length;
        const failed = results.filter(r => r.status === 'rejected').length;
        console.log(`预缓存完成: ${succeeded} 成功, ${failed} 失败`);
    }

    // 清除所有该应用的缓存
    async clearAll() {
        const names = await caches.keys();
        const appCaches = names.filter(n => n.startsWith(this.prefix));
        
        for (const name of appCaches) {
            await caches.delete(name);
            console.log(`已清除: ${name}`);
        }
    }

    // 获取缓存总大小
    async getUsageStats() {
        const names = await caches.keys();
        let totalSize = 0;
        const details = [];

        for (const name of names) {
            const cache = await caches.open(name);
            const keys = await cache.keys();
            let size = 0;
            
            for (const request of keys) {
                const response = await cache.match(request);
                // 通过 Response headers 推断大小（近似值）
                const clen = parseInt(response.headers.get('content-length') || '0', 10);
                size += clen || 1024;   // 默认估计1KB
            }
            
            totalSize += size;
            details.push({ name, entries: keys.length, size: formatBytes(size) });
        }

        return { totalSize: formatBytes(totalSize), details };
    }
}

function formatBytes(bytes) {
    if (!bytes) return '0 B';
    const k = 1024;
    const units = ['B', 'KB', 'MB', 'GB'];
    const i = Math.floor(Math.log(Math.max(1, bytes)) / Math.log(k));
    return (bytes / Math.pow(k, i)).toFixed(i > 0 ? 1 : 0) + units[i];
}

// ===== 使用示例 =====
const manager = new CacheManager('my-pwa');

// 应用安装时预缓存
await manager.precache([
    '/',
    '/index.html',
    '/styles/main.css',
    '/scripts/app.js',
    '/icons/logo.png'
], '2');

// 版本升级时
await manager.migrate(1, 2);

// 查看缓存占用
const stats = await manager.getUsageStats();
console.table(stats.details);
```
