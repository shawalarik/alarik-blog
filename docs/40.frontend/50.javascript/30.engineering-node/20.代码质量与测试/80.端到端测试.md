# 端到端测试 —— Playwright/Cypress 基础

## 什么是 E2E 测试

如果说单元测试是在检查每一块砖的质量，那 E2E（End-to-End）测试就是在验证整面墙是否牢固——从用户打开浏览器到看到最终结果的完整流程。

单元测试告诉你 `add(2,3)` 返回 `5` 是对的。但 E2E 测试告诉你：用户点击"提交"按钮后，表单数据是否真的被发送到了服务器、数据库是否正确存储了记录、用户是否看到了成功提示、页面是否跳转到了正确的位置。

这就像验收一栋房子：单元测试是确认每块砖的硬度达标，E2E 测试是你拿着钥匙开门进去、打开水龙头看有没有水、开灯看亮不亮、坐在沙发上看舒不舒服——**模拟真实用户的使用场景**。

## Playwright 基础

Playwright 是目前最强大的 E2E 测试框架之一——它支持 Chromium、Firefox 和 WebKit 三大浏览器引擎：

```javascript
// e2e/login.spec.ts —— 登录流程的 E2E 测试

import { test, expect } from '@playwright/test';

test.describe('登录流程', () => {
  test.beforeEach(async ({ page }) => {
    // 每个测试前导航到登录页
    await page.goto('/login');
  });

  test('应该显示登录表单', async ({ page }) => {
    // 验证关键元素存在
    await expect(page.locator('input[name="email"]')).toBeVisible();
    await expect(page.locator('input[name="password"]')).toBeVisible();
    await expect(page.locator('button[type="submit"]')).toBeVisible();
    await expect(page).toHaveTitle(/登录/);
  });

  test('应该成功登录并跳转到首页', async ({ page }) => {
    // 填写表单
    await page.locator('input[name="email"]').fill('user@example.com');
    await page.locator('input[name="password"]').fill('correct-password');

    // 点击登录按钮
    await page.click('button[type="submit"]');

    // 验证跳转和状态
    await expect(page).toHaveURL(/\/dashboard/);
    await expect(page.locator('.user-avatar')).toBeVisible();
    
    // 验证 localStorage 中保存了 token
    const token = await page.evaluate(() => localStorage.getItem('auth_token'));
    expect(token).not.toBeNull();
  });

  test('应该在输入无效时显示错误信息', async ({ page }) => {
    await page.locator('input[name="email"]').fill('invalid-email');
    await page.locator('input[name="password"]').fill('123');

    await page.click('button[type="submit"]');

    // 错误信息应该出现
    const errorAlert = page.locator('[role="alert"]');
    await expect(errorAlert).toBeVisible();
    await expect(errorAlert).toContainText(/邮箱格式不正确|密码过短/);

    // 不应该跳转
    await expect(page).toHaveURL(/\/login/);
  });
});
```

### 核心操作 API

```javascript
/**
 * Playwright 核心操作速查
 */
test('Playwright 操作示例', async ({ page }) => {
  
  // ====== 导航 ======
  await page.goto('/dashboard');
  await page.goBack();
  await page.goForward();
  await page.reload({ waitUntil: 'networkidle' });

  // ====== 定位元素 ======

  // CSS 选择器
  page.locator('.container > .card:first-child');
  
  // 文本内容定位
  page.getByText('提交订单');
  page.getByText(/^订单 #\d+$/);     // 正则匹配

  // 角色语义化定位（推荐！）
  page.getByRole('button', { name: '删除' });
  page.getByRole('textbox', { name: '搜索' });
  page.getByRole('alert');            // role="alert"
  page.getByLabel('用户名');          // label 关联

  // 占位符 / alt text
  page.getByPlaceholder('请输入手机号');
  page.getByAltText('公司 Logo');

  // ====== 输入交互 ======
  await page.locator('#search').fill('关键词');        // 清空并填充
  await page.locator('#search').type('逐字输入');      // 模拟键盘逐字输入
  await page.locator('#search').clear();              // 清空
  await page.locator('#checkbox').check();             // 勾选
  await page.locator('#radio').click();               // 单选

  // 下拉选择
  await page.selectOption('#city', ['beijing', 'shanghai']);
  await page.selectOption('#sort', { label: '价格降序' });

  // 文件上传
  await page.setInputFiles('#avatar', './test-image.png');

  // 键盘模拟
  await page.keyboard.press('Enter');
  await page.keyboard.press('Control+A');
  await page.keyboard.type('Hello World');

  // 鼠标模拟
  await page.hover('.dropdown-trigger');   // 悬停触发下拉
  await page.dragAndDrop('.source', '.target');  // 拖拽

  // ====== 断言 ======

  // 元素状态
  await expect(page.locator('.result')).toBeVisible();
  await expect(page.locator('.modal')).toBeHidden();
  await expect(page.locator('button')).toBeEnabled();
  await expect(page.locator('input')).toBeDisabled();
  await expect(page.locator('a')).toHaveAttribute('href', '/about');
  await expect(page.locator('.count')).toContainText('42 条结果');

  // 页面级别
  await expect(page).toHaveURL(/\/dashboard/);
  await expect(page).toHaveTitle('管理后台');
});
```

### 网络拦截与 Mock

```javascript
/**
 * 在 E2E 测试中拦截和 Mock API 请求
 * 让测试不依赖真实后端服务
 */
test('使用 Mock 数据渲染列表', async ({ page }) => {
  // 拦截 GET /api/users 并返回 Mock 数据
  await page.route('**/api/users/**', (route) =>
    route.fulfill({
      status: 200,
      contentType: 'application/json',
      body: JSON.stringify([
        { id: 1, name: 'Alice', role: 'admin' },
        { id: 2, name: 'Bob', role: 'user' },
      ]),
    })
  );

  await page.goto('/users');

  // 验证 Mock 数据被正确渲染
  await expect(page.getByText('Alice')).toBeVisible();
  await expect(page.getByText('Bob')).toBeVisible();

  // 验证请求确实只发了一次
  const requests = [];
  page.on('request', req => requests.push(req.url()));
});

/**
 * 模拟网络错误场景
 */
test('网络断开时应该显示离线提示', async ({ page }) => {
  // 让所有 API 请求失败
  await page.route('**/api/**', route => route.abort('failed'));

  await page.goto('/dashboard');
  await expect(page.getByText(/无法连接服务器|网络异常/)).toBeVisible({
    timeout: 5000,
  });
});
```

## Cypress 对比

Cypress 是另一个流行的 E2E 测试框架，与 Playwright 有不同的设计哲学：

| 维度 | Playwright | Cypress |
|------|-----------|---------|
| **浏览器支持** | Chromium/Firefox/WebKit | 仅 Chromium（内核） |
| **执行方式** | 进程外独立驱动 | 注入页面内运行 |
| **多标签页** | ✅ 完整支持 | ⚠️ 受限 |
| **跨域限制** | 无 | 有（需特殊配置） |
| **并行执行** | 内置 | 需要 Dashboard 服务 |
| **录制功能** | Codegen 录制器 | Studio 可视化调试 |
| **速度** | 快 | 相对较慢 |

```javascript
// Cypress 风格的等价测试（对比参考）
describe('登录流程', () => {
  beforeEach(() => {
    cy.visit('/login');
  });

  it('应该成功登录', () => {
    cy.get('input[name="email"]').type('user@test.com');
    cy.get('input[name="password"]').type('pass123{enter}');

    cy.url().should('include', '/dashboard');
    cy.get('.user-avatar').should('be.visible');
    
    // Cypress 的自动等待机制
    cy.contains('欢迎回来').should('be.visible');
  });
});
```

## E2E 测试的最佳实践

```javascript
/**
 * 最佳实践：可维护的 E2E 测试
 */

// 1. 使用 data-testid 定位元素（避免依赖样式类名）
// <button data-testid="submit-order">提交</button>
page.getByTestId('submit-order').click();

// 2. 使用 Page Object Model 分离选择器
class LoginPage {
  constructor(private page: Page) {}

  get emailInput() { return this.page.locator('input[name="email"]'); }
  get passwordInput() { return this.page.locator('input[name="password"]'); }
  get submitButton() { return this.page.getByTestId('login-submit'); }

  async loginAs(email: string, password: string) {
    await this.emailInput.fill(email);
    await this.passwordInput.fill(password);
    await this.submitButton.click();
  }
}

// 3. 只测试关键路径（不需要覆盖所有边界情况——那是单元测试的事）
// 4. E2E 测试应该像真实用户一样操作
// 5. 使用稳定的等待策略（不要硬编码 sleep）

test('完整购买流程', async ({ page }) => {
  const loginPage = new LoginPage(page);
  
  await page.goto('/');
  await loginPage.loginAs('buyer@test.com', 'secure-pass');
  
  // 添加商品到购物车
  await page.getByTestId('product-card').first().click();
  await page.getByTestId('add-to-cart').click();
  
  // 进入结算
  await page.getByTestId('cart-badge').click();
  await page.getByTestId('checkout-btn').click();
  
  // 填写地址
  await page.getByLabel('收货地址').fill('北京市朝阳区...');
  
  // 支付（Mock）
  await page.route('**/pay/**', r => r.fulfill({
    body: JSON.stringify({ success: true, orderId: 'ORD-001' }),
  }));
  await page.getByTestId('confirm-pay').click();
  
  // 验证成功页
  await expect(page.getByText('支付成功')).toBeVisible();
  await expect(page.getByText('ORD-001')).toBeVisible();
});
```

**哲学思考**：E2E 测试是最接近真实使用场景的测试形式，但它也是最慢、最脆弱、最难维护的测试层级。一个 UI 的微调可能导致几十个 E2E 测试失败。因此 E2E 测试应该聚焦于**关键业务路径**——那些一旦出问题就会造成重大影响的流程。把边角情况的验证留给更底层的测试去做，让 E2E 测试成为"最后一道防线"而非"唯一的防线"。
