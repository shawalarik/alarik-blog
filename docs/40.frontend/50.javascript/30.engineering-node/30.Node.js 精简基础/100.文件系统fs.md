# 文件系统 —— fs 同步/异步/Promise API、流式读写

> **核心内容**：`fs` 模块的三种 API 风格（回调、同步、Promise）、文件读写操作、目录遍历与监听、Stream 流式处理大文件、文件元信息与权限控制。

## 三种 API 风格

Node.js 的 `fs` 模块提供了三套 API，满足不同场景的需求：

```
fs.readFile()        ← 回调风格（Callback API）
fs.readFileSync()    ← 同步风格（Synchronous API）— 带 Sync 后缀
fs.promises.readFile() ← Promise 风格（Promise API）
```

### 回调 API（原始风格）

```js
const fs = require('fs');

// 基本用法 — 错误优先回调（error-first callback）
fs.readFile('/path/to/file.txt', 'utf-8', (err, data) => {
  if (err) {
    console.error('读取失败:', err.message);
    return;
  }
  console.log(data);
});
```

回调 API 是 Node.js 最古老的风格。它的约定是：第一个参数是 `Error` 对象（成功时为 `null`），后续参数是结果。

### 同步 API

```js
const fs = require('fs');

try {
  const data = fs.readFileSync('/path/to/file.txt', 'utf-8');
  console.log(data);
} catch (err) {
  console.error('读取失败:', err.message);
}
```

**使用场景**：启动配置加载、命令行工具脚本、一次性数据处理。**避免在 HTTP 服务器等需要高并发的场景中使用**——同步调用会阻塞事件循环。

### Promise API（推荐）

```js
import { readFile, writeFile } from 'fs/promises';

async function processFile(filePath) {
  try {
    const data = await readFile(filePath, 'utf-8');
    const result = data.toUpperCase();
    await writeFile(`${filePath}.upper`, result);
    console.log('处理完成');
  } catch (err) {
    console.error('操作失败:', err.message);
  }
}
```

从 Node.js 14 开始，`fs/promises` 提供了原生的 Promise 支持，无需借助 `util.promisify` 手动转换。这是现代 Node.js 开发的**首选方式**。

## 文件基本操作

### 读取文件

```js
import { readFile, readFileSync } from 'fs';

// 异步读取 — 返回 Buffer 或字符串
const bufferData = await readFile('image.png');           // 默认返回 Buffer
const stringData = await readFile('data.txt', 'utf-8');   // 指定编码为字符串

// 读取部分内容（大文件的"分页"查看）
import { open } from 'fs/promises';

async function readChunk(filePath, position, length) {
  const fd = await open(filePath);
  const buffer = Buffer.alloc(length);
  const { bytesRead } = await fd.read(buffer, 0, length, position);
  await fd.close();
  return buffer.slice(0, bytesRead); // 实际读取可能少于请求量
}

// 读取前 100 字节
const header = await readChunk('large-file.bin', 0, 100);
```

### 写入文件

```js
import { writeFile, appendFile, mkdir } from 'fs/promises';
import { dirname } from 'path';

// 写入（覆盖已有内容或创建新文件）
await writeFile('output.txt', 'Hello World\n', 'utf-8');

// 追加写入（不覆盖原有内容）
await appendFile('log.txt', `[${new Date().toISOString()}] 新日志条目\n`);

// 确保目录存在后写入（原子性更强）
async function safeWrite(filePath, content) {
  const dir = dirname(filePath);
  await mkdir(dir, { recursive: true });
  await writeFile(filePath, content, 'utf-8');
}
```

### 文件复制、重命名、删除

```js
import { copyFile, rename, unlink, rm } from 'fs/promises';

// 复制文件
await copyFile('source.txt', 'destination.txt');

// 重命名/移动（可以跨目录移动）
await rename('old-name.txt', 'new-name.txt');
await rename('./file.txt', './subdir/file.txt');

// 删除单个文件
await unlink('temp-file.txt');

// 删除目录（递归）
await rm('./build', { recursive: true, force: true });

// 删除空目录
import { rmdir } from 'fs/promises';
await rmdir('./empty-dir');
```

## 目录操作

### 创建与读取目录

```js
import { mkdir, readdir, stat } from 'fs/promises';

// 创建目录（recursive 自动创建父级）
await mkdir('./data/sub/deep/nested', { recursive: true });

// 读取目录内容
const files = await readdir('./src'); // 返回文件名数组
const entries = await readdir('./src', { withFileTypes: true }); // 返回 Dirent 对象

for (const entry of entries) {
  console.log(entry.name, entry.isDirectory() ? '[DIR]' : '[FILE]');
}

// 递归列出所有文件（深度优先）
async function listAllFiles(dirPath) {
  const results = [];
  const entries = await readdir(dirPath, { withFileTypes: true });

  for (const entry of entries) {
    const fullPath = `${dirPath}/${entry.name}`;
    if (entry.isDirectory()) {
      const subFiles = await listAllFiles(fullPath);
      results.push(...subFiles);
    } else {
      results.push(fullPath);
    }
  }

  return results;
}

const allJsFiles = (await listAllFiles('./src'))
  .filter(f => f.endsWith('.js'));
console.log(allJsFiles);
```

### 文件信息查询

```js
import { stat, lstat, access, constants } from 'fs/promises';

// 获取文件状态（Stat 对象包含丰富的元信息）
const stats = await stat('./package.json');

console.log({
  isFile: stats.isFile(),
  isDirectory: stats.isDirectory(),
  isSymbolicLink: stats.isSymbolicLink(),
  size: stats.size,                    // 字节数
  createdAt: stats.birthtime,          // 创建时间
  modifiedAt: stats.mtime,             // 最后修改时间
  accessedAt: stats.atime,             // 最后访问时间
  mode: stats.mode.toString(8),        // 权限模式（八进制）
  inode: stats.ino,                    // inode 号
});

// lstat 与 stat 的区别：lstat 不跟踪符号链接
const linkStats = await lstat('./symlink');
console.log(linkStats.isSymbolicLink()); // true

// 检查文件是否存在且可访问
try {
  await access('./config.json', constants.R_OK | constants.W_OK);
  console.log('可读可写');
} catch {
  console.log('不可访问或不存在的路径');
}
```

### 文件监听（Watch）

```js
import { watch, watchFile } from 'fs';

// 方式一：基于操作系统原生通知的高效监听
watch('./src', { recursive: true }, (eventType, filename) => {
  // eventType: 'rename' 或 'change'
  console.log(`[${eventType}] ${filename}`);
}).on('error', (err) => {
  console.error('监听错误:', err);
});

// 方式二：轮询模式（跨平台兼容更好）
watchFile('./config.json', { interval: 1000 }, (current, previous) => {
  if (current.mtime !== previous.mtime) {
    console.log('配置文件已修改，需要重新加载');
  }
});
```

## Stream：流式处理大文件

当文件体积超过可用内存时（或者为了降低内存峰值），流式处理是唯一的选择。Node.js 的 Stream API 提供了四种基础流类型：

| 类型 | 用途 |
|------|------|
| `Readable` | 读取数据（如 `createReadStream`） |
| `Writable` | 写入数据（如 `createWriteStream`） |
| `Duplex` | 双向流（如 TCP socket） |
| `Transform` | 转换流（输入处理后输出，如 `zlib`） |

### 基础流式读写

```js
import { createReadStream, createWriteStream } from 'fs';

// 逐块读取大文件（默认每块 64KB）
const reader = createReadStream('./large-video.mp4', {
  highWaterMark: 1024 * 1024, // 自定义缓冲区大小为 1MB
  encoding: null,             // 二进制模式
  start: 0,                   // 从起始位置开始
  end: Infinity,              // 到结束位置
});

reader.on('data', (chunk) => {
  console.log(`收到 ${chunk.length} 字节`);
});

reader.on('end', () => {
  console.log('读取完毕');
});

reader.on('error', (err) => {
  console.error('读取错误:', err);
});
```

### 管道（Pipe）：最简洁的流连接方式

```js
import { createReadStream, createWriteStream } from 'fs';
import { createGzip } from 'zlib';

// 文件压缩的经典 pipe 链
createReadStream('large-file.log')
  .pipe(createGzip())
  .pipe(createWriteStream('large-file.log.gz'));
```

管道的优雅之处在于自动背压管理——当下游处理不过来时，上游会自动暂停发送，不会导致内存堆积。

### 使用 Transform 流做行处理

```js
import { Transform } from 'stream';
import { createReadStream, createWriteStream } from 'fs';

// 自定义 Transform 流：按行处理 CSV 数据
class LineParser extends Transform {
  #remainder = '';

  constructor(options) {
    super({ ...options, readableObjectMode: true });
  }

  _transform(chunk, encoding, callback) {
    const text = this.#remainder + chunk.toString('utf-8');
    const lines = text.split('\n');

    // 最后一行可能不完整，保留到下次处理
    this.#remainder = lines.pop();

    for (const line of lines) {
      if (line.trim()) {
        const fields = line.split(',');
        this.push({ timestamp: fields[0], value: parseFloat(fields[1]) });
      }
    }

    callback();
  }

  _flush(callback) {
    // 处理最后剩余的不完整行
    if (this.#remainder.trim()) {
      const [timestamp, value] = this.#remainder.split(',');
      this.push({ timestamp, value: parseFloat(value) });
    }
    callback();
  }
}

// 使用自定义转换流
createReadStream('sensor-data.csv')
  .pipe(new LineParser())
  .on('data', (record) => {
    console.log(`[${record.timestamp}] ${record.value}`);
  });
```

## 实战工具类

### 安全的文件读写封装

```js
import { readFile, writeFile, mkdir, stat, copyFile, unlink } from 'fs/promises';
import { dirname, join, extname, basename } from 'path';

class FileManager {
  constructor(baseDir) {
    this.baseDir = baseDir;
  }

  resolve(...segments) {
    return join(this.baseDir, ...segments);
  }

  async read(path, options = {}) {
    const filePath = this.resolve(path);
    const encoding = options.encoding ?? 'utf-8';
    return readFile(filePath, encoding);
  }

  async write(path, content, options = {}) {
    const filePath = this.resolve(path);

    // 确保父目录存在
    await mkdir(dirname(filePath), { recursive: true });

    // 原子写入：先写临时文件，再重命名
    if (options.atomic !== false) {
      const tmpPath = `${filePath}.${Date.now()}.tmp`;
      await writeFile(tmpPath, content, options.encoding || 'utf-8');
      await renameSafe(tmpPath, filePath); // 重命名是原子操作
    } else {
      await writeFile(filePath, content, options.encoding || 'utf-8');
    }
  }

  async exists(path) {
    try {
      await stat(this.resolve(path));
      return true;
    } catch (err) {
      if (err.code === 'ENOENT') return false;
      throw err;
    }
  }

  async copy(src, dest) {
    const srcPath = this.resolve(src);
    const destPath = this.resolve(dest);
    await mkdir(dirname(destPath), { recursive: true });
    await copyFile(srcPath, destPath);
  }

  async remove(path) {
    const filePath = this.resolve(path);
    await unlink(filePath);
  }

  async size(path) {
    const stats = await stat(this.resolve(path));
    return stats.size;
  }

  async readJson(path) {
    const content = await this.read(path);
    return JSON.parse(content);
  }

  async writeJson(path, data, indent = 2) {
    const content = JSON.stringify(data, null, indent);
    await this.write(path, content + '\n');
  }
}

// 辅助函数：安全的重命名（处理跨分区问题）
async function renameSafe(from, to) {
  import { rename } from 'fs/promises';
  try {
    await rename(from, to);
  } catch (err) {
    // 跨设备/分区时 rename 会失败，回退到复制+删除
    await copyFile(from, to);
    await unlink(from);
  }
}

export default FileManager;

// 使用示例
const fm = new FileManager('./data');
await fm.write('users/alice/profile.json', { name: 'Alice', age: 28 });
const profile = await fm.readJson('users/alice/profile.json');
```

### 大文件逐行读取器

```js
import { createReadStream } from 'fs';
import { once } from 'events';

class LineReader {
  constructor(filePath, options = {}) {
    this.stream = createReadStream(filePath, {
      encoding: options.encoding || 'utf-8',
      highWaterMark: options.bufferSize || 64 * 1024,
    });
    this.#remainder = '';
    this.#ended = false;
  }

  #remainder = '';
  #ended = false;
  #lineQueue = [];

  [Symbol.asyncIterator]() {
    return this;
  }

  async next() {
    while (!this.#lineQueue.length && !this.#ended) {
      const { done, value } = await this.stream[Symbol.asyncIterator]().next();
      if (done) {
        this.#ended = true;
        if (this.#remainder) {
          this.#lineQueue.push(this.#remainder);
        }
        break;
      }

      const lines = (this.#remainder + value).split('\n');
      this.#remainder = lines.pop(); // 保留最后一个可能不完整的行
      for (const line of lines) {
        this.#lineQueue.push(line);
      }
    }

    if (this.#lineQueue.length > 0) {
      return { done: false, value: this.#lineQueue.shift() };
    }
    return { done: true };
  }

  async close() {
    this.stream.destroy();
  }
}

// 使用方式 — for...of 语法
async function analyzeLog(logPath) {
  let errorCount = 0;
  const errors = [];

  for await (const line of new LineReader(logPath)) {
    if (line.includes('[ERROR]')) {
      errorCount++;
      errors.push(line.slice(0, 200)); // 只保存前200字符
    }
  }

  console.log(`共发现 ${errorCount} 条错误记录`);
  return errors;
}
```

## 性能对比：何时用哪种 API？

| 场景 | 推荐方案 | 原因 |
|------|---------|------|
| 小文件（< 10MB）读写 | `readFile/writeFile` | 简洁，内存够用 |
| 配置文件 / 启动时加载 | `readFileSync` | 同步更直观，阻塞无影响 |
| 日志追加 | `appendFile` | 原子性好 |
| 大文件（> 100MB） | `createReadStream/WriteStream` | 内存可控 |
| 文件格式转换（压缩/加密） | `pipe()` + Transform | 背压自动管理 |
| 监控文件变化 | `watch` | 操作系统原生通知 |
| 批量文件操作 | 并发 Promise.all | 充分利用 I/O 并行 |

一个常见的性能误区：对大量小文件使用同步 API：

```js
// ❌ 低效 — 顺序同步读取，完全阻塞事件循环
const files = ['a.txt', 'b.txt', 'c.txt'];
const contents = files.map(f => fs.readFileSync(f));

// ✅ 高效 — 并发异步读取
const contents = await Promise.all(
  files.map(f => readFile(f, 'utf-8'))
);
```

## 权限与安全注意事项

```js
import { chmod, constants } from 'fs/promises';

// 设置文件权限（八进制）
await chmod('script.sh', 0o755); // rwxr-xr-x（所有人可执行）

// 更安全的做法：使用常量组合
await chmod('secret.json',
  constants.S_IRUSR | constants.S_IWUSR  // 所有者：读写
  // 其他用户没有任何权限
);

// 敏感操作前的安全检查
async function secureWrite(filePath, content) {
  const stats = await stat(filePath).catch(() => null);

  // 不允许写入符号链接（防止链接攻击）
  if (stats?.isSymbolicLink()) {
    throw new Error('不允许写入符号链接');
  }

  // 检查路径是否逃逸出允许范围
  const resolved = path.resolve(filePath);
  if (!resolved.startsWith('/safe/directory/')) {
    throw new Error('路径不在允许范围内');
  }

  await writeFile(filePath, content);
}
```

## 哲学思考：文件即世界的隐喻

文件系统是人类组织信息的古老方式之一——将连续的现实切割成离散的单元，赋予名称，建立层级关系。Node.js 的 `fs` 模块本质上是在 JavaScript 这个"纯逻辑世界"和磁盘这个"物理存储层"之间架设桥梁。

同步 API 像是一次把所有书从图书馆搬回家；异步 API 是每次借一本看完还回去；Stream 则像是站在图书馆里逐页阅读，永远不需要把整本书搬走。三种方式没有绝对的优劣之分，只有是否匹配当前需求的区别。好的工程师像好的图书管理员一样，知道什么时候该批量搬运，什么时候该逐页翻阅。
